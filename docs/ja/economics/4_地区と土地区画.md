# 4. 地区と土地区画

## 4.1. 地区とは

地区は都市を分ける街のまとまりで、経済活動の集計や建築規制の単位になる。道路の集まりとして定義され、沿道の土地区画と、そこに立つ建物や入居する経済主体が同じ地区に属する。
道路の左右は別々の地区に属することがあり、そのような道路は地区の境界になる。地区は道路のつながりに沿ってまとまり、都市の成長に伴って分かれていく。プレイヤーも道路を選んで地区の範囲を編集できる。
地図上の地区の輪郭は、所属する道路や土地区画から表したものである。地区への所属はこの輪郭の内外ではなく、道路との関係で決まる。
地区には、道路の建設・修繕に必要な建設サービスを調達する代理主体と、入居先の決まっていない世帯・施設を受け入れる転居補助の主体がいる。

## 4.2. 土地区画とは

土地区画は土地の所有と利用の単位で、建物はすべていずれかの区画に建つ。区画には所有者と地価があり、市が民間の土地を公共事業に使うには、買収や補償を伴う。地価は、その土地に対する需要と周辺の家賃相場を反映する。

区画は海岸線との位置関係によって次の3種類に分かれる。建物には建てられる区画の種類があり、港湾施設は沿岸、海上構造物は水面の区画を使う。

| 種類 | 定数 | 内容 |
| --- | --- | --- |
| 陸地 | `PARCEL_LAND` | 陸上の土地 |
| 沿岸 | `PARCEL_SHORE` | 海岸線に接する土地 |
| 水面 | `PARCEL_WATER` | 海上構造物の敷地 |

船が着く港は、沿岸の区画のうち岸壁のすぐ外の水深が港の種類ごとの必要水深に届く区画にしか建たない。海底は陸の勾配を海へ延ばした形なので、急な海岸ほど深い海が近く港に向き(天然の良港)、遠浅の平らな海岸では埋め立てて深い所まで陸を延ばしてから港を建てる。

形状については[土地形状](../geometries/B_土地形状.md)、建物との関係は[建物](5_建物.md)を参照。

## 4.3. 建築規制と立地

建築規制は、建てられる建物の種類、高さ、容積率、建ぺい率の上限である。地区の規制を基本とし、区画ごとの指定もできる。規制は新しい建設に適用され、変更しても既存の建物は残る。
土地の勾配、道路への近さ、周囲の土地利用などは、その場所での活動のしやすさに影響する。斜面では工事の負担が大きく、道路から離れた土地では移動や輸送の負担が大きくなる。
立地倍率(`agent_multiplier`)は、その区画が業種や世帯にとってどれだけ有利かを表す。小売店では人通りや同業種の集積、工場では同業種と関連する業種の集積、採取施設では天然資源、世帯では住環境が重要になる。同じ土地でも、用途によって立地の良し悪しは異なる。

## 4.4. 造成

造成は、プレイヤーが指定した範囲の地形を整える公共工事である。

| 種類 | 役割 |
| --- | --- |
| 整地 | 内陸の土地を削ったり盛ったりして、目標の高さにそろえる |
| 埋立 | 海に面した範囲を埋め立て、陸地を広げる |

造成によって建設しやすい土地や新たな用地を作れるが、工事には資金と建設サービスが必要になる。

造成工事は、一時的な公共施設として表され、建物と共通の建設の仕組みを使う。工事中の範囲は造成のために確保され、別の建設や土地の編集には使えない。
地形は工事が完了した時点で変わる。工事を中止した場合は地形が変わらず、完了後は造成工事の施設や区画がなくなって、新しい土地利用に進める。
資金については[予算管理](15_予算管理.md)を参照。

整地は土地の起伏を変え、埋立は海岸線を広げる。埋立地の海に面した部分には岸壁ができ、道路や建物、港湾施設を配置する新たな場所になる。
造成は完成後の地形として残り、以後の都市開発の土台となる。形状や描画については[地形形状](../geometries/D_地形形状.md)を参照。
