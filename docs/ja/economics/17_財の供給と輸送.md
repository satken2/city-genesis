# 17. 財の供給と輸送

天然資源、インフラ財、公共交通車両などは通常の商品市場とは異なる形で供給される。
一方、商品市場で取引する物資にも、道路や構内物流、専用網による輸送が必要になる。取引や価格の考え方は[商品市場](9_商品市場.md)を参照。

## 17.1. 天然資源

天然資源は、マップ上に分布する鉱脈・油田・水源などである。資源のある土地に採取施設を置くことで、生産の原材料として利用できる。
資源の分布はシナリオが持ち、都市で成立する産業や施設の立地を左右する。

### 採取・枯渇・回復

資源には埋蔵量があり、採取すると減少する。鉱脈や油田のように回復しないものと、水源のように回復するものがある。
採取できるのは残りの埋蔵量までで、残りが少ない土地ほど立地として不利になり、枯渇すればその土地での生産を維持できなくなる。回復する資源も、採取の勢いが回復を上回れば不足する。
採取した物資は商品市場へ出たり、専用のインフラ網へ送られたりする([商品市場](9_商品市場.md))。

### 露天掘りと地形

露天掘りでは、採取に伴って土地が掘り下げられ、地形そのものが変化する。採掘による穴は施設がなくなっても残るため、資源の利用は都市の景観と将来の土地利用にも影響する。

## 17.2. インフラ網

インフラ網は、電力・水道などを専用の経路で施設間に届ける仕組みである。ここで運ぶ財をインフラ財(`GOODS_INFRASTRUCTURE`)と呼ぶ。
インフラ財は通常の商品市場で売買されず、網でつながった公共施設の間を流れる。道路が近くにあるだけでは届かず、施設と専用網の接続が必要になる。

### 生産から需要家まで

電力は、発電所から送電網で変電所へ送り、変電所から世帯や施設へサービスとして届ける。

```mermaid
graph LR
powerPlant["発電所"] -->|高圧電力| substation["変電所"]
substation -->|電力サービス| consumers["世帯・施設"]
```

水道も、取水施設などから導水管で水道ポンプへ送り、そこから需要家へ届ける構造である。生産施設、輸送する網、地域に届ける施設がそろって都市を支える。
電力サービスが需要家へ配送される方法は[商品市場](9_商品市場.md)を参照。

### パスと接続

| パス     | 定数                 | 役割      |
| ------ | ------------------ | ------- |
| 送電線    | `PATH_ELECTRICITY` | 電力を送る   |
| 水道管    | `PATH_WATER`       | 水を送る    |
| パイプライン | `PATH_PIPELINE`    | 原油などを送る |

施設には網につなぐ接続端子があり、対応するパスを接続する。パスは運べる財によって別々の網を作る。
電化線路は列車の通り道と送電網を兼ねる。鉄道の車両基地などでは、電化線路による接続が車両の供給と受電の両方を支える。

### 供給力と不足

施設の生産能力だけでなく、途中のパスの容量や網のつながりも、届けられる量を制限する。発電所に余力があっても、送電経路が細かったり途切れていたりすれば停電する。
太陽光・風力のように天気で出力が変わる施設と、需要に合わせて供給する施設では、都市を支える役割が異なる([生産活動](10_生産活動.md))。
原油や鉱石を運ぶ専用網も、この接続と容量の考え方を使う。

## 17.3. 貨物輸送

都市の原材料や製品は、道路輸送、近接する施設間の構内物流、パイプラインや貨物列車の専用網によって運ばれる。

| 運び方 | 役割 |
| --- | --- |
| トラック | 商品市場の取引に伴って道路で物資を運ぶ |
| 構内物流 | 近接した施設間で、道路を使わず原材料を受け渡す |
| 専用網 | パイプラインや貨物路線で、まとまった量を運ぶ |
| 港・国際貨物駅など | 都市外との輸出入の窓口になる |

商品の数量にはkg・バレル・台など品目ごとの単位があるが、輸送の規模は重さで扱う。道路の混雑、専用網の容量、拠点の取扱能力が物流を制約する。

### 構内物流と専用網

近接した施設同士では、配管やコンベアなどによる構内物流を行え、輸送コストはかからない。工場・採掘所・港を近くにまとめることで、道路への負荷や輸送の負担を抑えられる。
原油や鉱石の大口輸送には専用網を使う。物資は積み出す施設から網へ入り、降ろす施設から再び商品市場へ供給される。専用網の接続と容量は、インフラ網と共通の考え方である。

### 貨物路線と積み下ろし

貨物列車は旅客列車と同じく路線の設定が必要で、車両基地から車両を借りて走る。旅客路線と線路を共有するため、貨物輸送にも線路の容量が必要になる([公共交通機関](18_公共交通機関.md))。
貨物の種類に対応した専用ホームと、積み下ろしを行う施設を組み合わせる。

```mermaid
graph LR
mine["採掘所"] -->|鉱石| loadingStation["積込駅"]
loadingStation -->|貨物列車| unloadingStation["取卸駅"]
unloadingStation -->|鉱石| steelworks["製鉄所"]
```

積込駅や取卸駅は市政府の公共施設であり、都市の産業と長距離の物流をつなぐ役割を持つ。

### 国外との輸出入

海路の港、鉄道の国際貨物駅、道路の陸路輸送拠点が、都市外との取引を支える。
港(客船ターミナルを含む)は、大型船の航路で外洋につながっていないと営業できない。外洋につながる大型船航路はシナリオが用意し、港と大型船航路は接続航路で結ぶ。港を建てると、最寄りの大型船航路まで接続航路が自動で引かれる。外洋への航路は、インフラ網と同じく港の接続端子へ届く財として扱い、届いた量ではなくつながっているかだけを見る。航路は水の上にしか敷けないので、海につながらない湖や、湾の出口を埋め立てた湾には港を開けない。
国際貨物路線は、シナリオに用意された都市外の国境貨物駅と、都市内の国際貨物駅を結ぶ。輸出入できる規模は、駅の取扱能力と路線の輸送力に左右される。
取引や価格については[商品市場](9_商品市場.md)を参照。

## 17.4. 公共交通車両の調達

公共交通車両(`GOODS_TRANSIT`)は車両基地から路線へ貸し出され、路線がリース料を払う。旅客路線と貨物路線は、この車両調達の仕組みを共通で使う。車両基地には人手や原材料が必要で、基地と路線が道路・線路でつながっていることも必要になる。車両基地の供給力が、都市で運行できる車両数を支える。
路線の運行間隔や編成、運賃については[公共交通機関](18_公共交通機関.md)を参照。
