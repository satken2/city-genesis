# 20. 観光

## 20.1. 観光客とは

観光客はバリアント「観光客」(`VARIANT_TOURIST`)の経済主体であり、1つの経済主体が観光客の1組を表す。ホテルに入居し、飲食店・娯楽施設・観光地で消費を行う。
観光客は住民と共通の商品市場・不動産市場・交通網を使う。
実際の旅行者の入れ替わりは個別に追わず、継続して滞在する観光客の集団として表す。

## 20.2. 観光を支える施設

観光客の受け入れには、観光地と玄関口の両方が必要である。宿泊需要は民間のホテル建設にもつながる。

| 施設  | 役割                                                        |
| --- | --------------------------------------------------------- |
| 観光地 | 「観光体験」という商品を提供する施設。市長が建設可能な施設と、シナリオにあらかじめ置かれるランドマークなどがある。 |
| 玄関口 | 「都市外旅客輸送」という商品を提供する施設。客船ターミナルや都市外旅客輸送拠点など、都市外との往来を担う。     |
| ホテル | 観光客が宿泊可能な宿泊フロアを提供する施設。                                    |

## 20.3. 評判と都市への収入

観光地や玄関口の供給力、宿泊先の空きは、受け入れられる観光客の規模を制約する。滞在中の体験や宿泊費の負担は満足度に影響し、評判や観光客の増減につながる。
観光客が持ち込む旅費は、都市外から得る収入である。観光は都市内の需要を増やすだけでなく、外から資金を呼び込む産業でもある([金融システム](12_金融システム.md))。
