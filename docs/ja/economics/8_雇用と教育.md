# 8. 雇用と教育

## 8.1. 雇用とは

雇用は市民単位で、1人の市民は1つの勤務先で働く。給与は勤務先から市民の世帯へ支払われ、世帯の暮らしを支える。
施設は生産に必要な働き手を求め、市民は賃金や通勤の負担を考慮して仕事を選ぶ。人手の不足や求人の多さは、賃金の動きにも影響する。

## 8.2. スキルと賃金ティア

市民は6種類のスキルを持つ。施設が必要とするスキルは業種によって異なる。

| 定数 | スキル |
| --- | --- |
| `SKILL_BASE` | 基礎教養 |
| `SKILL_PHYSICAL` | 肉体労働 |
| `SKILL_OFFICE` | 事務 |
| `SKILL_RETAIL` | 販売 |
| `SKILL_TECHNOLOGY` | 科学技術 |
| `SKILL_MEDICAL` | 医療 |

働き手はスキルに応じて無教育人材・標準人材・高度人材の賃金ティアに分かれる。より上のティアに進むには教育が必要で、仕事の経験だけでは越えられない境界がある。

## 8.3. 人数と実質労働力

施設の雇用枠(`quota`)と雇用済みの労働力(`total_labor`)は、人数ではなく実質労働力を表す。スキルや労働時間によって、同じ人数でも生産を支える力は異なる。
教育による技能の向上は、都市の生産力を高める。
公共施設の雇用は市の予算にも制約される。所定労働時間を長くすると労働力は増えるが、余暇や健康への負担も大きくなる([予算管理](15_予算管理.md)・[施政スコアと達成クエスト](16_スコアと達成目標.md))。

## 8.4. 教育

教育は市民のスキルを伸ばし、都市で働ける人材の幅を広げる。

基礎教育は、幅広い仕事の土台となるスキルを育てる。高等教育は、基礎教育を受けた市民が専門分野のスキルを伸ばし、高度人材になるための教育である。
就労経験による成長にも限界があるため、学校と大学はそれぞれの段階で必要になる。

学校は教育を担う経済主体(`TYPE_EDUCATION`)である。市民が教育を受けるには、年齢に合い、通学でき、空きのある学校が必要になる。
大学では、プレイヤーが専攻ごとの受け入れ枠を配分できる。専攻の配分は、都市でどの分野の高度人材を育てるかという選択になる。

高度人材は、都市内の高等教育で育てることが基本になる。大学を建てても人材が育つまでには時間がかかるため、医療や高度な産業を支えるには先を見越した教育が必要である。
移民による人材の受け入れについては[世帯](7_世帯.md)を参照。

## 8.5. 高度人材

高度人材とは、基礎教養以外のいずれかのスキルが1.5以上に達した市民である。
基礎教育を受けた後、大学で専門分野を学ぶことで育ち、就労経験だけでは高度人材になれない。
医療施設や高度な工場など一部の施設は、必要な分野の高度人材を雇えた分しか稼働できず、一般の働き手を増やしても不足は補えない。
