# 14. 事故と災害

都市では、建物の倒壊・火災・犯罪と、道路の交通事故が起きる。被害は建物や人命、住環境に影響し、エポックの結果に現れる。

## 14.1. 倒壊と火災

老朽化や火災によって建物が倒壊すると、住民や働く人に人的被害が生じる。倒壊した建物は廃墟として残り、周囲の住環境にも悪影響を及ぼす。維持や修繕については[建物](5_建物.md)を参照。
火災の被害には、建物の耐火性や周囲との密集度が関わる。木造の密集地などでは延焼しやすく、ひとつの建物の火災が周囲へ広がる。

失火はランダムに発生し、失火のうち一部が火災に変化するが、失火の段階で「消防サービス」の調達に成功した場合は火災にはならない。
「消防サービス」は遠方まで運ぶことができず、消防署が遠い地域や渋滞の多い地域は被害が大きくなりやすい。

## 14.2. 交通事故

道路の形に対して無理のある制限速度や、交通の集中、専用駐車枠を超えた路上駐車は事故の起きやすさにつながる。交通量がない道路では交通事故は起きない。事故は人的被害を伴い、都市の評価にも影響する([パスとノード](3_パスとノード.md)・[施政スコアと達成クエスト](16_スコアと達成目標.md))。

## 14.3. 犯罪と治安

居住者・訪問者の市民の犯罪性向(`potential_criminality`)を元に「犯罪の兆候」がランダムに発生する。
火災と同様、「犯罪の兆候」はその後「犯罪」に変化するが、警察署が供給する「治安維持サービス」によって「犯罪」への変化を抑えることができる。
警察の供給力と、各地域へサービスが届くことが重要になる。
治安は住民の暮らしや住まい選びにも影響する([環境](13_環境.md))。
