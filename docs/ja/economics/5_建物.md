# 5. 建物

## 5.1. 建物とは

建物は土地区画の上に立つ経済主体である。他の世帯や施設に床を貸す共有建物と、工場・発電所など施設自身が使う専用の建物がある。床の貸し借りについては[不動産市場](6_不動産市場.md)を参照。

建物種類(`bd_type`)は、建築規制で建てられる用途を指定するための分類である。

| 建物種類 | 定数 |
| --- | --- |
| 集合住宅 | `BUILDING_APARTMENT` |
| 一戸建て住居 | `BUILDING_HOUSE` |
| 商業施設 | `BUILDING_RETAIL` |
| 工場 | `BUILDING_FACTORY` |
| オフィス | `BUILDING_OFFICE` |
| 農地 | `BUILDING_FARM` |
| 鉱山 | `BUILDING_MINE` |
| 港湾 | `BUILDING_PORT` |
| 専用建物 | `BUILDING_OTHER` |
| 公共施設 | `BUILDING_PUBLIC` |

建築規制に加え、土地の種類にも適合する必要がある。たとえば港湾施設は沿岸、洋上施設は水面の区画に立つ([地区と土地区画](4_地区と土地区画.md))。

## 5.2. 建設と都市の成長

公共施設はプレイヤーが計画し、民間の建物は床の需要と採算に応じて建つ。家賃が低い地域では簡素な低層建物が成立しやすく、地価や家賃が高まると高層化や建て替えが進む。
工事には用地の確保と建設サービスの調達が必要である。既存の建物がある土地では、入居者の移転や取り壊しを伴う。資金や都市の建設業の供給力が不足すれば、完成までに時間がかかる。
建物の規模や高さ、土地の勾配は工事の負担に影響する。公共工事の予算は[予算管理](15_予算管理.md)を参照。

## 5.3. 稼働・老朽化・更新

完成した建物では、施設が生産を始めたり、世帯やテナントが入居したりする。採算や利用率が低い民間の建物は停止し、需要が戻れば再び使われる。
建物は時間とともに老朽化し、修繕によって維持される。使われなくなった建物や維持できない建物は、取り壊しや建て替えへ向かう。老朽化や火災で倒壊すると廃墟になり、人命や周辺環境にも被害をもたらす([事故と災害](14_事故と災害.md))。

状態の一覧と遷移は[経済主体](2_経済主体.md)を参照。

## 5.4. 都市を特徴づける施設

市庁舎は、市政府をマップ上に表す施設である。プレイヤーが市庁舎を置くことで都市の開発が始まる。
観光名所は、都市を特徴づける象徴的な施設で、観光客を呼び込む役割を持つ。国境検問所は、都市外との旅客・物流の窓口になる。これらはシナリオに用意される施設である([観光](20_観光.md)・[財の供給と輸送](17_財の供給と輸送.md))。

## 5.5. 駐車

建物には駐車容量(`parking_capacity`)がある。車は昼には勤務先や買い物先、夜には住まいへ集まるため、駐車需要は時間帯と土地利用によって異なる。
建物内に収まらない車は、周囲の駐車施設や路上へあふれる。駐車施設は、この駐車需要を受け入れる土地利用である。
