# 16. スコアと達成目標

## 16.1. 世帯満足度

世帯満足度(`qol_score`)は、住民の暮らしを次の4つの軸で表す。

| 軸      | 内容                              |
| ------ | ------------------------------- |
| 経済的豊かさ | 衣料・家電・嗜好品など、暮らしを豊かにする商品を得られているか |
| 娯楽と余暇  | 外食や娯楽を楽しみ、余暇を持てているか             |
| 健康     | 栄養・衛生・医療などに支えられ、健康に暮らせているか      |
| 生活の快適さ | 住まいの広さや質、静けさ、日当たり、治安が良いか        |

所得だけでなく、都市に商品やサービスが届くこと、住環境が整っていることも満足度につながる([消費活動](11_消費活動.md)・[環境](13_環境.md))。
労働時間を長くすれば生産を支える労働力は増えるが、余暇が減り、健康への負担も大きくなる。経済と暮らしの両方を考える必要がある。

## 16.2. 施政スコア

施政スコア(`city_score`)は、住民の暮らしを都市全体で評価する指標である。世帯の満足度と都市の規模を反映し、事故による人的被害は評価を下げる。
都市全体のスコアは規模の影響も受けるため、暮らしの水準を比べるときは1世帯あたりの評価も見る。
観光客の旅の満足度は、住民の暮らしとは別に扱う([観光](20_観光.md))。

## 16.3. 達成クエスト

達成クエストは、シナリオやチュートリアルがプレイヤーに示す目標である。人口や財政などの到達目標に加え、一定の状態を維持する目標、期限のある目標、別の目標の達成後に解放される目標を表せる。
目標の内容はシナリオ制作者が設定し、達成の判定はコアが行う。フロントはその状態と進捗をプレイヤーへ伝える。

| 状態 | 意味 |
| --- | --- |
| `locked` | 先行する目標の達成を待っている |
| `active` | 取り組める目標 |
| `completed` | 達成した目標 |
| `failed` | 期限内に達成できなかった目標 |

目標には達成時の交付金を設けられる。交付金は都市外から市政府へ入り、開発の資金になる([金融システム](12_金融システム.md))。

シナリオやチュートリアルでは、用意されたクエストをすべて達成するとクリアになる。クリアした記録はプレイヤーの実績として残る。
シナリオとの関係は[セッションと保存](../programs/セーブデータ仕様.md)、統計と文言の表示は[UI共通基盤](../programs/UI共通基盤.md)を参照。
