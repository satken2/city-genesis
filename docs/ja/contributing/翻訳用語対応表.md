# 翻訳用語対応表

UIとドキュメントを翻訳するとき、ゲーム固有の用語の訳語をそろえるための対応表。ここに載っている用語は、この表の訳語を正とする。原文は日本語(`ja`)。

- 載せるのは、ゲーム固有で訳が揺れやすい用語だけ。一般的な語は載せない。
- 列はUIの言語コードと同じ。`en` 英語、`es-419` ラテンアメリカのスペイン語、`zh-Hans` 簡体字中国語、`zh-Hant` 繁体字中国語(台湾の表記)、`fr` フランス語、`ko` 韓国語。 追加の言語コードは `de` ドイツ語、`pl` ポーランド語、`ru` ロシア語、`pt-BR` ブラジルのポルトガル語、`es-ES` スペインのスペイン語、`tr` トルコ語、`it` イタリア語、`id` インドネシア語、`ar` アラビア語、`pt-PT` ポルトガルのポルトガル語、`uk` ウクライナ語、`th` タイ語、`vi` ベトナム語、`ms` マレー語、`nl` オランダ語、`sv` スウェーデン語、`nb` ノルウェー語(ブークモール)、`da` デンマーク語、`fi` フィンランド語、`cs` チェコ語、`hu` ハンガリー語、`ro` ルーマニア語、`bg` ブルガリア語、`el` ギリシャ語。
- 訳語は文頭形で示す。大文字・小文字や活用は文脈に合わせる。
- `ja` 列のかっこは、似た用語と区別するための意味の補足。
