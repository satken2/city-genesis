# 素材とクレジット

Unity と Tauri で使う外部素材の出所は、ゲーム全体で一つの一覧にまとめる。画像・音声・フォント・3Dモデル・テクスチャを取り込むときは、出所と利用条件を確かめ、同じ変更でクレジットを記録する。後から出所を辿れなくなるため、素材の取り込みと記録を分けない。

## 記録する場所

掲載データの正は `tauri/src/data/credits.ts` の `CREDIT_ENTRIES` で、項目の意味は同ファイルのコメントにある。確認の手順は公開リポジトリの `.claude/skills/asset-credits/SKILL.md` にまとめる。

作者名や利用条件は推測で書かない。指定された表記の文面は翻訳・要約せず、必要な著作権表示やライセンス文書も配布物に含める。

編集ソフトの署名やファイル名だけでは配布元を判定しない。取得元URLは画像本体との対応を確かめ、差し替え前の画像に付いた記録と現在使っている画像の出所を区別する。

## 対象の区別

自作の素材は外部素材の一覧に載せない。外部の地形・地理データは、それを含むシナリオ(チュートリアルの都市を含む)のクレジットに出所と利用条件を書き、ゲーム全体の一覧には載せない。地図はゲームと別に増減・配布され、シナリオから作った派生のシナリオにもクレジットが引き継がれるためである。

エンジンや OSS ライブラリの表示義務は素材のクレジット画面と分け、各ライセンスが求める著作権表示と条文を配布物で管理する。
