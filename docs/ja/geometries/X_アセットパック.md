# アセットパック

アセットパックは、建物・パス・プロップ・乗り物の見た目と、名前で引くマテリアルを入れ替える DLC である。都市は使うパックのIDを `asset_pack`（`GET /api/v1/city`）に持ち、標準の見た目は共有定数 `ASSET_PACK_STANDARD` で表す。シミュレーションはパックを参照しない。

## パックの中身

DLC 1本はフォルダ1つで、アセットパックは表示名の `pack.json`（多言語テキスト）と、`assets/windows/` の AssetBundle（ファイル名はパックID）・論理名の一覧 `index.txt`・建物と乗り物のモデルの表 `model_weights.json` を持つ。論理名は標準と同じで、モデルは `Models/…`（`Resources` からの相対パス）、名前で引くマテリアルは `Materials/{名前}` である。バンドルはエディタの `Tools/Asset Packs` で `Assets/Packs/{パックID}/` から作り、本体と同じ Unity の版でビルドする。パックの原本は公開リポジトリに置かない。

使えるのは、所有していてインストールされているパックだけで、一覧は `GET /api/v1/system/asset_packs` が返す。都市の `asset_pack` がこの一覧に無ければ、標準で描く。

## 探す規則

モデル本体は標準と同じく、描くときに読む。パックが持っている単位はパックの中だけを探し、持っていない単位は標準を探す。単位は `Models/{分類}/{フォルダ}`（建物の接頭辞・パスのバリアントと種別・車種・駅舎）、`Models/{分類}/{名前}`（プロップなど。`_close`・`_far`・`_right`・`_left` を除いた名前）、マテリアルの名前で、1つの単位の中でパックと標準を混ぜない。

- 建物の接頭辞（名所 → バリアント → 建物種別）はパックの中から先に探し、パックに1つも無ければ標準で探す。
- パスのバリアントは、パックがそのバリアントか種別のフォルダを持っていればパックで描く。
- 乗り物は、車種と外観 → 車種 → 乗用車の探索順をパックの中で先に行う。
- パックで見つかった単位は標準へ戻らないので、その時代に無いもの（旅客機など）はパックに空のモデルを入れれば描かれない。

## 外観のモデルと重み

建物と乗り物は、単位（建物の接頭辞のフォルダ、車種）ごとに番号の付いたモデルを複数持てる（建物は `{接頭辞}/{番号}/` のフォルダ、乗り物は `{車種}/{番号}` のモデル）。単位のモデルの番号と標準の重みは、その単位を持つ側（パックか標準）の表 `model_weights.json`（`{単位: {番号: 重み}}`。標準は `Resources/Config/`）にあり、表に無い番号は使わない。表はエディタの `Tools/Asset Packs` で実在のモデルから作り直す（既存の重みは残り、新しいモデルの重みは100）。

プレイヤーがアセットマネージャーで変えた重みは、ユーザーフォルダ（コアのセーブと同じ場所）の `asset_weights.json`（`{出どころ: {単位: {番号: 重み}}}`。出どころは `standard` かパックID）にあり、あれば標準の重みより優先する。Unity は都市を開くたびに読み直す。

モデルは、番号順に重みを積み上げた区間のうち、引いた値を含むものを選ぶ。値は建物では `visual_variant`、乗り物では描画の種から作るので、同じ値からは同じモデルになり、セーブの値は変わらない。重みの合計が0なら番号が最も小さいモデルを使う。

## 都市の切り替え

都市を切り替えたら、マスターとアセットパックを取り直し、モデル・マテリアルを解決した結果を捨ててから描き直す（[バックエンドデータロード](H_バックエンドデータロード.md)）。
