# 道路メッシュの生成

道路・線路・送電線・索道などのパスは、API のパスデータとマスターの寸法をもとに、Unity がパーツのモデルを組み立てて描く。本ページは全パスに共通する仕組みを道路を例に説明する。線路固有のパーツは[線路メッシュの生成](N_線路メッシュの生成.md)、駅舎は[駅舎パスのメッシュ生成](Q_駅舎パスのメッシュ生成.md)、形状データの意味は[パス形状](A_パス形状.md)に定義する。

生成・更新・キャッシュ・LOD は `PathManager` が受け持ち、形状は `PathMeshFactory` が選んだ生成器(道路は `RoadPath`)が作る。

## 生成の流れ

1. **生成器の選択** — マスターの `model_type` で選ぶ。`default` は道路、`track` は線路、`station_house` は駅舎、`pier` はフェリー桟橋、`outline` は航路のように実体の無いパスを幅の両縁の点線で描く生成器、`power_line` は送電線の鉄塔と架線を描く生成器で、`none` は何も描かない(未設定は `default`)。
2. **点列** — 保存された三次ベジエを共通の形状計算でサンプリングして中心線を作る。制御点の補完、地形追従、設計縦断は[パス形状](A_パス形状.md)の約束に従う。地形は取得した造成後の標高を使い、道路の描画は断面を水平に保つ。
3. **接続と切断** — 同じ断面の道路が直進するだけのノードは、各パスをノードまで描いて直接つなぐ。それ以外のノードは点列を切断断面で切り、その外周を交差点の路面で埋め、歩道・壁などは同じモデルでつなぐ([パスの交差処理](J_パスの交差処理.md))。公共交通の論理パスは交差点の生成対象に含めず、下地の道路・線路だけが接合形状を決める。路面を持たない索道・送電線・パイプラインは交差点を作らず、アンカーまで描く。
4. **スプライン** — 切断後の点列からスプラインを作る。経由点で折れる直線のパスは、交差点の内側に入る経由点を除き、残る区間ごとにスプラインを分ける。外側に残る角と各区間の高さの指定を保ち、角を交差点と同じ方法で埋める。
5. **パーツの配置** — 各パーツのモデルを、Dreamteck Splines の SplineMesh でスプラインに沿って曲げながら長さ方向に繰り返し並べる。
6. **クリック判定** — 描画とは別に、スプラインに沿った道路幅の帯をコライダーにする。

描画は保存データを変えない。交差点での切断、高速道路のランプを本線へ寄せる高さの補正、橋脚の省略などは描画上の補正で、保存形状・接続・交通に影響しない。台数や位置が変わる路上駐車の車両や索道の搬器は道路メッシュに含めず、[車両の走行描画](O_車両の走行描画.md)が別に描く。敷設中のプレビューも同じ生成器で描く。

## 断面と高さ

パスの `width`(コアがパスを作るときにバリアントの幅を写したもの)は道路の全幅で、歩道は全幅の内側の両端に、防音壁・ガードレールは外側に、中央分離帯は中心に置く。各パーツの幅はマスターの幅の項目(`sidewalk_width`・`wall_width`・`center_width` など)で決まる。高さは、スプラインを地形から少し浮かせ、各パーツをスプラインから決まった高さに置く2段で決める。この値は `RoadPartHeights` に集め、交差点・車両・歩行者の描画も同じ値を使う。モデルはこの配置位置を原点にして著作し、描画時は頂点の相対高さをそのまま使う。路面・道床は上面を原点に揃え、導水管のように地面から立ち上がる構造は原点より上に形状を持たせる。

区画線のある街路と高速道路(`PATH_STREET`・`PATH_MOTORWAY`)は、区画線や停止線をパーツの板にせず、路面のシェーダーで描く。車線の位置は一つの定義から求め、区画線と車両の走行位置が共有する。

## パーツの命名

パーツのモデルは `Models/Paths/p{path_variant}/{パーツ名}` に置き、無ければタイプの `Models/Paths/p{path_type}/{パーツ名}` を使う。プレイヤーがパスの外観(`appearance`)を選んでいれば、外観のフォルダ `Models/Paths/p{path_variant}/{外観の番号}/` を先に探す。外観のフォルダには標準と違うパーツだけを置き、無いパーツはバリアントのフォルダのものを使う。接写用の `_close` は、そのパーツと同じフォルダから探す。

| パーツ名 | 役割 |
| --- | --- |
| `body` | 路面 |
| `line` | 区画線(路面のシェーダーで標示を描かないパス) |
| `sidewalk` | 歩道 |
| `wall` | 防音壁・ガードレール・高欄 |
| `center`・`center_start`・`center_end` | 中央分離帯と、その丸めた端 |
| `wall_underground`・`ceiling_underground` | トンネル内の側壁と天井 |
| `pillar`・`pillar_cap` | 高架の柱と、その上に載るキャップ |
| `pillar_leg`・`pillar_crossbeam` | 門型橋脚の柱と横梁 |
| `span` | 橋脚と橋脚の間に1体ずつ伸ばして置く橋の構造(トラス・アーチなど) |
| `tree`・`center_tree`・`streetlight`・`utility_pole`・`utility_box`・`fence`・`bench`・`bin`・`planter`・`advert` | 沿道設備 |
| `far` | 遠景モデル |
| `{パーツ名}_close` | 接写用のモデル |

専用の構造を持つパス(吊り橋、道路上の LRT、索道の駅など)は、その生成器が読むパーツを同じフォルダに置く。吊り橋の主塔のように、パーツがあるときだけ描く構造は、外観のフォルダに置けば外観ごとに変えられる。材質は名前で共有する([マテリアルの解決](R_マテリアルの解決.md))。マスターの `body_material` は、交差点の路面や遠景の板のようにモデルを持たない路面に使う材質の名前である。

## フォールバックと LOD

パーツは外観 → バリアント → タイプの順に探し、無ければ省く。`body` が無いときだけは `width` の白い板で代替し、プレイを続けられるようにする。

描画 LOD はパスごと(長い道路は区間ごと)にカメラとの距離で選ぶ([LOD処理](E_LOD処理.md))。Close はスプラインに沿って敷くパーツに `_close` があればそれを使い、Far は `far` を(パーツと同じ順に探して)点列に沿って並べる(無ければ `width` の板)。板は実体の代わりなので、実体の無い `outline` のパスは Far と超遠景では描かない。

## 高架と地下

`height_editable` で `pillar_spacing` を持つバリアントは、アンカーと一定の間隔ごとに、路面の下へキャップと地面まで伸ばした柱を立てる。柱は他のパスの車道・線路と、足元より高い路面(高架の床版)を避け、道路の歩道と中央分離帯(マスターの `sidewalk_width`・`center_width`)には立てる。避けられない柱は門型橋脚に替えるか省く。キャップと門型の横梁は、下の通行空間の上へ張り出してよい。`single_span` のバリアントは、アンカーの間ごとに路面を1枚で架ける。`base_height` は描画だけの高さのずらしで、パスは相対高さから `base_height` を引いた高さに描く。送電線のように、モデル自体が地上からの高さを持つバリアントで使う。

地下を通るパスの開削区間とトンネルは、取得した地形と路面の形状をもとに、同じ生成器で描き分ける。トンネルは地形の下に隠れ、外からは坑口を通してだけ見える。坑口の切土面を覆う坑門(面壁・アーチの縁・笠石)はパーツではなく地形から生成し、坑門の厚みの範囲で内空に入る地形は地形シェーダーが描かない。坑内をクリックで選べるのは、地形を透かす地下表示([Unity表示モード](../programs/Unity表示モード.md))のときだけである。

## 沿道設備

沿道設備はパスごとの保存値(項目の一覧は共有定数 `PATH_EQUIPMENT_FIELDS`)で選ぶ。値は `PATH_EQUIPMENT_NONE`(なし)か `PATH_EQUIPMENT_STANDARD`(標準)で、配線の `utility_mode` だけは `PATH_UTILITY_NONE`・`PATH_UTILITY_OVERHEAD`(架空)・`PATH_UTILITY_UNDERGROUND`(地中)をとる。マスターの `*_allowed` はそのバリアントに置けるか、`default_*` は新設時の値である。設備は描画専用で、経済に影響しない。

## 工事中の表示

建設中(`STATUS_CONSTRUCTING`)のパスは、始点から終点へ施工が進む様子で描き(高架は橋脚、桁の順)、稼働状態になると通常のメッシュに替わる。進捗は `construction_progress`(建設に必要な体積のうち調達済みの割合。百分率)で、パスの一覧の各項目に、生成スキーマに無い描画用の項目として付く。
