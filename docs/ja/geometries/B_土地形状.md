# B. 土地形状

土地区画の形状データと、Unity・Tauri が描画や操作に使う値の意味をまとめる。区画の経済的な意味は[地区と土地区画](../economics/4_地区と土地区画.md)、パスの形状は[A_パス形状](A_パス形状.md)、建物の底面は[C_建物形状](C_建物形状.md)を参照する。

## 区画の形状と座標

土地区画は建物が立地する地面の範囲で、ポリゴンで表す。フロントはプレビューも確定後の区画も API から受け取り、その形を使う。道路・線路などのパスは区画を持たない。

外周の `polygon` はワールド座標の水平面 `[x, z]` の頂点列で、上から見て反時計回りに並び、末尾に始点を繰り返した閉じた輪である。高さは持たず、ほぼ一直線上に並ぶ頂点を含むことがある。座標の基準は[D_地形形状](D_地形形状.md)による。

基準標高の `altitude` は絶対標高である。陸の建物の接地には使わず、建物と地面の関係は[F_建物メッシュの生成](F_建物メッシュの生成.md)に従う。

## 区画の種別と水際

区画には陸地・沿岸・海上の種別がある。フロントは API が返す種別を使い、現在の海岸線から独自に分類し直さない。区画のポリゴンは海岸線で切り取られているとは限らない。

沿岸区画の `water_depth` は港の建設候補を示すための水深で、岸壁の線は建物の `berth_line` として返る。Unity の建設可能な区画の強調とクリック判定では、区画種別が `agent_master.parcel_type` に対応することと、水深が `agent_master.berth_depth` の必要水深を満たすことを確認する。建設の最終的な可否はコアの応答に従う。

海上区画は水上の設備の敷地で、接道を持たない。Unity は海上区画の建物と区画の上面を基準標高である海面の 0 に置く。その地点の地形は海底なので、地形に合わせると沈む。

## 路面辺と接道

路面辺の `facade_edge_index` は、区画のどの辺が道路側かを示す。番号 i は頂点 i から次の頂点への辺を指し、末尾に繰り返した始点は数えない。路面辺は複数あることも空であることもある。

接道の `front_path_id` は区画が接続する街路を示し、未設定は `VALUE_NONE` である。路面辺と接道は用途の違う値なので、描画や操作にはそれぞれの取得値を使い、フロントで周辺道路から選び直さない。

## 天然資源との対応

`resource_id` は区画に対応する天然資源を `{資源種別: 資源ID}` で表す。資源との関係は取得した値を使い、意味は[財の供給と輸送](../economics/17_財の供給と輸送.md)を参照する。
