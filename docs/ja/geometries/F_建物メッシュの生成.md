# 建物メッシュの生成

建物の3Dモデルは、コアから受け取る底面・階数・外観の値をもとに、Unity が FBX のパーツを組み立てて作る。組み立て方はマスター `agent_master` の `model_type` で決まり、底面の形（[C_建物形状](C_建物形状.md)）とは別の軸である。このページには全方式に共通する約束を書き、方式ごとの違いと工事中・倒壊時の描画は [建物メッシュの生成方式](F1_建物メッシュの生成方式.md) にまとめる。

## 入力

底面の頂点の並びと正面の約束は [C_建物形状](C_建物形状.md) による。建物は底面の原点（`center_point`）の地形標高に置き（海上区画の建物だけは海面）、各階の高さはマスターの `height_per_floor` の格子で決まる。フェンスや地面パネルなどの敷地装飾は、底面ではなく土地区画の形に沿って置く。`visual_variant` は外観バリアントの選択に、`visual_variant2` は塔屋や散布パーツの位置などのゆらぎの種に使い、同じ値からは同じ見た目になる。

モジュラー建物の本体は水平なので、傾斜地では谷側の隙間をコンクリートの基盤で埋める。敷地装飾は地形に沿わせる。玄関や外階段の張り出しは底面の中に収め、そのぶん本体を後退させて描くので、底面は部材を含めて建物が占める範囲を表す。

## パーツの置き場と名前

FBX は `Assets/Models/Buildings/{prefix}/{番号}/{パーツ名}.fbx` に置き、同じ相対パスのラッパープレハブを `Assets/Resources/Models/Buildings/` に置く（[P_マテリアル共有とエクスポート](P_マテリアル共有とエクスポート.md)）。`{prefix}` は建物ごとに、観光名所の `landmark-{model_prefix}`、バリアント専用の `a{variant}`、建物種別で共有する `b{bd_type}` の順に、あるものを1つ使う。名所とバリアントのフォルダの有無は `Resources/Config/agent_model_config.yaml` の一覧で判定する。アセットパックを使う都市では、この順をパックの中で先に探す（[アセットパック](X_アセットパック.md)）。全建物で共通に使うパーツは `Buildings/common/` に置く。

| パーツ名 | 役割 |
| --- | --- |
| `{level}-{type}{n}` | モジュラー建物の外壁。level は `base`・`mid`・`top`（1階・中層・最上階）と `fence`（敷地のフェンス）、type は `w`（壁）・`c`（角）・`stair`（外階段）。n は位置番号で、壁・外階段は底面の頂点 n−1 から始まる辺、角は頂点 n−1 を指す（位置1が正面） |
| `roofprop` / `entrance` / `interior-floor` | 塔屋・玄関・各階の床 |
| `ceil` / `floor` / `generic-wall` | 形は使わず、屋根面・地面パネル・妻壁にマテリアルだけを渡す（[R_マテリアルの解決](R_マテリアルの解決.md)） |
| `tile` / `scatter{n}` | 地面に敷き詰めるタイル、建物の外の空き地に散らす車両や資材 |
| `base-prebuilt` / `mid-prebuilt` / `top-prebuilt` | 既成建物の段。マッシュアップの棟は `mashup-{model_prefix}-base-prebuilt` などの名前にする |
| `port_*` / `yard_*` / `site_*` | 港・車両基地・オープンスペースの部品 |
| `scaffold-*` / `crane-*` / `demo-*` / `excavator` / `collapse` | 工事中・解体中・倒壊の現場 |
| `far` / `mashup-{model_prefix}-far` | 遠景モデル（建物全体・棟ごと） |
| `{パーツ名}_close` | 接写用のモデル |
| `road_access_{種類}_{識別子}` | モデルの中に置く、道路への間口の目印（空のオブジェクト） |

## 外観バリアントとフォールバック

`{番号}` は外観のモデルのフォルダで、建物は接頭辞のフォルダのモデルの表と `visual_variant` で番号を1つ選ぶ（[アセットパック](X_アセットパック.md)）。パーツは選んだ番号以下でパーツのある最も大きいフォルダから探し、建物種別で共有するフォルダ（`b{bd_type}`）も同じ番号で探す。モジュラー建物は `mid-w1` のある番号で建物全体のフォルダを1つに決め、ほかの方式はパーツごとに決める（既成建物と車両基地は常に `0`）。

パーツが無いときは、同じフォルダの中で代わりを探す。壁と角は、同じレベルの位置1、中層（`mid`）の同じ位置、中層の位置1の順に探し、角は見つからなければ置かない。`floor` と工事系のパーツは `common` まで探す。描けるものが何も無い建物は、底面を押し出した白い箱で位置だけを示す。

## 描画LOD

接写（Close）では、同じフォルダの `{パーツ名}_close` を先に探し、無ければ無印を使う。番号のフォルダの選択は、描画LODによらず無印のパーツの有無で決まる。遠景（Far）は方式によらずパーツを組み立てず、遠景モデル1つを建物（マッシュアップ・露天掘りは棟）の外形の箱へ引き伸ばして置き、遠景モデルが無ければ箱にする。工事中・解体中・倒壊の遠景は低い箱である。生成した建物の保持・再利用と、地形が届くまで詳細を待つ規則は [LOD処理](E_LOD処理.md)・[バックエンドデータロード](H_バックエンドデータロード.md) に書く。

散布パーツ（`scatter{n}`）は建物のメッシュに組み込まず、[地形プロップ](M_地形プロップ.md)と同じく共有モデルのGPUインスタンシングで建物をまたいで描く。描画LODも建物によらず地形プロップと同じ規則で1個ずつ選び、`_close`・`_far` の扱いも地形プロップに従う。建設計画のプレビューなど、街に建つ建物の描画物を作らない生成では、散布パーツも1つのメッシュに含める。

## 道路への間口

施設は道路への出入口（間口）を持て、道路の描画がそこへ舗装をすり付ける（[G_道路メッシュの生成](G_道路メッシュの生成.md)）。間口は既成建物と港の施設のモデルの中の目印、または駅前ロータリーの配置計画から得る。間口を持つのは稼働中・停止中・解体予定の建物だけで、建物の描画LODでは変わらない。
