# バックエンドデータロード

Unity は、コアの HTTP API から取得した都市データを常駐範囲の中に描く。`CellDataLoader` がロードの起点と順序を受け持ち、`TerrainManager` が地形タイルの公開を、各 `*Manager` が対象のデータと描画物の寿命を管理する。常駐範囲と描画品質の決め方は [LOD処理](E_LOD処理.md)、地形データの形式は [地形形状](D_地形形状.md) に定める。

## 更新の起点

| 起点 | 更新 |
| --- | --- |
| カメラの移動・投影条件の変化 | 常駐セルの集合の差分を取得し、外れたセルを退避する |
| エポック完了・編集の確定・`session:reload` | 取得済みのデータを要再取得にして、常駐範囲を差分で取り直す |
| 地区詳細の保存（`zone:updated`） | その地区だけを取り直す |
| 強制リロード | 描画物をすべて消してから取り直す |
| セッションの切り替え・ゲーム終了 | 進行中の処理と全データを消す |

更新の要求はロードバッチにまとめ、新しいバッチは進行中の古いバッチを取り消す。要再取得の印は要求した時点で付け、取得と適用が成功してから消すので、途中で取り消されても次のバッチが引き継ぐ。海岸線・湖・川・埋立地は、セッションの開始と `session:reload` のたびに、区画・建物より先に取り直す（港の岸壁や埋立地の帯の接地がこれを参照するため）。

## 取得と差分の基準

| データ | 取得の単位 | 描き直しの基準 |
| --- | --- | --- |
| 地形 | 常駐セルごとの現在標高、全域の現在標高、背景 | セルの版と全域の版 |
| 建物・道路・ノード・区画・プロップ | 常駐範囲の一覧 | 各データの `version`（プロップは配置と障害物の署名）と、描画に効く形状・敷地・地形 |
| 地区・IC/JCT・道路名・資源 | 都市全体の一覧 | `version` と内容 |
| 都市全域の建物・道路（超遠景） | 都市全体の概観一覧 | 地形セルごとの内容 |

建物・道路の一覧はページ分割で返るので、次のカーソルが無くなるまで取得し、全ページが成功してから、一覧から消えた ID の描画物を消す。データの受信と描画の完成は別の状態として扱い、生成が中断された同じ版のデータも描き終えていなければ処理し直す。アラートの変化は描画物の版に表れないので、専用の API で取る（[通知とアラート](../programs/通知レベル管理.md)）。アラート由来の3D演出も同じ取得結果を使い、応答のエポック番号で結果の世代を区別する。Unity内で抽選した外観や配置は同じ世代の再表示で保持し、次の世代や都市には引き継がない。

## 地形の取得と公開

地形タイルは表示から切り離して組み立て、完成してから差し替える。表示・コライダー・接地の参照先と版は同じ時点で切り替え、その後に `OnTerrainTileReady` を通知する。タイルの取得の寿命はセルが常駐している間で、バッチの取り消しでは止めない。常駐から外れたタイルは非表示で保持し、戻ったときに版が同じなら取り直さずに使う。常駐に入らなかった近くのセルは、手が空いているときに先読みしておく。

物体の側は、通知の有無ではなく地形の版（`TerrainManager.GetTerrainSignature`）を生成時の値と比べて、作り直すかどうかを決める。

## 依存する描画の更新順序

1. 地形の版の一覧・全域の現在標高・背景を揃え、常駐セルを確定する。タイルの取得と公開はここから並行して進む。
2. カメラが止まったら、道路・地区・資源・プロップの取得を始める。区画も取得し、その適用後に建物を取得する（海上区画の建物は区画の基準標高に置くため）。動いている間は物体の取得を始めず、都市全域の超遠景が埋める。
3. 建物・道路は全域の現在標高で遠景から出し、接地・通過する常駐セルのタイルが公開されてから詳細を作る。
4. タイルが公開されるたびに、各マネージャーがそのセルと周辺の物体を新しい地形に合わせる。

## 描画の寿命と時間予算

生成と退避は、共通のフレーム予算（[LOD処理](E_LOD処理.md)）の中で少しずつ進める。セルを離れた道路などは非表示にして退避し、同じ描画キーなら戻ったときに復元する。建物は詳細を退避しても、周辺の範囲では輪郭を残す。道路を作り直すときは、新しいパーツがすべて揃うまで古い道路を表示し続け、揃った時点で一度に差し替える。

## セッション切り替え

`session:reset` から `session:reload` まではカメラ由来の取得を止める（その間のコアは新しい都市を準備中のため）。地形・描画キャッシュ・空間索引・進行中のロードはセッション単位で捨て、別の都市で同じ版番号を使っていても再利用しない。マスターとアセットパックも都市ごとに違いうるので、都市が替わったら取り直してから描き直す（[アセットパック](X_アセットパック.md)）。

## 初期ロードの完了

Unity は、初期の視点の常駐範囲の地形・区画・建物・道路・地区・資源・プロップと、全域の地形・都市全域の超遠景の準備が整い、保存されたカメラの視点を戻し終えたら、`game:loaded` を UI へ送る。都市全域の詳細なモデルまでは待たない。準備中も LOD の判定に使うカメラは動かし、入力だけを止める。
