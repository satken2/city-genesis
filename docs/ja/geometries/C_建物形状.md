# C. 建物形状

建物の底面（水平に投影した輪郭。フットプリント）は、コアが返す `polygon` を描画に使う。区画に建てるときのプレビューの底面も API で受け取る。フロントは底面を作り直さず、階数や階高などの描画に必要な値と組み合わせて建物を描く。建物の経済的な意味は[経済主体](../economics/2_経済主体.md)を参照する。

## フロントが受け取る底面

`polygon` は `center_point` を原点とする XZ 座標の頂点列で、反時計回りに並び、原則として区画の中に収まる。頂点0→1の辺が建物の正面で、玄関や既成パーツの向きを決める（[F_建物メッシュの生成](F_建物メッシュの生成.md)）。角が直角とも、頂点が4つとも限らない（L字・台形・区画そのままの多角形など）。区画の形状データは[B_土地形状](B_土地形状.md)を参照する。

## 形状カテゴリ（`building_shape`）

マスターの `building_shape` は底面の形状カテゴリであり、メッシュの組み立て方を表す `model_type` とは別である。`SHAPE_FULL` は区画全体を底面に使うカテゴリで、Unity の描き分けにも関わる（[建物メッシュの生成方式](F1_建物メッシュの生成方式.md)）。カテゴリから具体的な底面を推測せず、どのカテゴリも返された `polygon` を使う。
