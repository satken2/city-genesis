# Unity表示モード

表示モードは、都市の描画をレイヤーごとに切り替える仕組みである。[入力モード](Unity入力制御.md)とは独立して持ち、編集ステートに入るときは両方をまとめて適用する。

## 表示を決める軸

| 軸 | 役割 |
| --- | --- |
| 色モード | レイヤーごとに通常表示・非表示・データの色分けなどを選ぶ |
| 表示フラグ | 色モードとは独立に、計画中の対象や付加情報を表示する |
| 個体のフィルタ | 特定の建物・道路を ID で隠す |

状態の正は Unity の共通管理に置き、UI は切り替えを指示して結果を表示する。各描画物が状態を独自に決めず、後から生成・復元された対象にも現在の表示を適用する。非表示の物体はクリック対象からも外す。

個体の表示フィルタはセッション内だけの状態で、セーブには残らない。建設プロジェクトのタグはコアが保存する都市データであり、表示フィルタとは別である。UI がタグから対象の ID を解決し、Unity は描画対象として扱う。

## 通常表示と一時表示

利用者が選んだ通常の表示と、編集や詳細確認のための一時的な表示を区別する。編集を終えると通常の表示へ戻り、一時的な変更で利用者の選択を上書きしない。

通常の変更は `view:change_view`、編集ステートを持たない画面の一時表示はプリセットを使う。共通管理を通さずに描画を直接切り替えると、UI が示す状態と実際の表示が食い違う。同期の仕組みは[IPC連携](IPC連携の整理.md)に定める。

## 表示と都市データ

地下表示は、地形や地上物を透かして地下の構造を見せる描画上の変更である。地形の高さやコライダーは変えず、カメラ・配置・編集の基準を保つ。

ヒートマップ、ハイライト、[アラート](通知レベル管理.md)も、コアから得た状態を見せるための層である。表示の切り替えが都市の状態やシミュレーションの結果を変えることはない。
