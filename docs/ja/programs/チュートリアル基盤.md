# チュートリアル基盤

チュートリアルは、教材の都市の上で案内と操作の制限を進める共通基盤である。個別画面は教材を知らず、基盤が観測と案内に使う接点を提供する。

## モジュールの役割

| モジュール | 役割 |
| --- | --- |
| Tauri | 教材定義、進行、達成の判定、案内、UI の操作制限 |
| Unity | 指示されたマーカー・カメラ案内・3D操作の制限 |
| コア | 教材の都市、都市に関する判定結果、明示的に要求された代行操作 |

進行の正は Tauri に置く。Unity は進行や合否を独自に判断せず、現在の指示を適用する。教材を終えた都市は通常プレイとして続けられる([セッションと保存](セーブデータ仕様.md))。

## 定義と判定

教材は、決められた条件と操作を組み合わせた宣言的な定義で表す。任意のコードや URL を実行する仕組みにせず、定義の構造と意味を検証してから使う。

案内する段階は画面と都市の現在の状態から求める。パネルを閉じたり操作を取り消したりしたときも、案内が実際の操作状態から取り残されないようにする。

条件の判定は読み取りに限り、都市を変更するアクションと分ける。アクションは実行する時点を定義で明示し、同じ作成操作が繰り返されないよう進行側で管理する。

## 操作の制限と案内

各 UI 部品は安定した操作名を提供し、共通の案内層が許可と強調を適用する。部品ごとに教材固有の条件や別の強調表示を持たない。制限中も、終了や復旧のための操作経路を確保する。

Unity へは現在の指示の全体を同期し、再接続でも復元できるようにする。案内のマーカーは描画物であり、都市データへ登録しない。同期の原則は[IPC連携](IPC連携の整理.md)、個別の定義形式は `tauri/src/tutorial/` のスキーマとソースを参照する。
