# サウンドシステム

音は都市と操作の状態を伝える演出で、再生がシミュレーションやセーブを変えることはない。都市空間に結び付いた音は Unity、BGM と UI の音は Tauri が担う。

## 再生の分担

Unity はカメラ周辺の環境音、天気、工事や車両などの音を扱う。都市の全対象に音源を持たせず、描画する範囲と共通の音源管理により、都市規模に比例して再生負荷が増えないようにする。

Tauri の BGM は共通の管理に集約する。各画面や演出は優先度付きの要求を出し、終了時に解除する。ウィンドウごとに独立した BGM を再生しない。UI の単発音も共通の再生処理を使う。

## 設定の同期

音量設定は Tauri が管理し、Unity が使う効果音系統の音量を設定変更時と再接続時に同期する。Unity は設定を受け取るまで無音とし、後から生成された音響部品にも同じ設定を適用する。

音量はそれぞれの再生系統で扱い、Unity のリスナー全体を別の音量制御として重ねない。設定の同期方法は[IPC連携](IPC連携の整理.md)に従う。

## 素材と配布

Unity の音声素材は `Assets/Resources/Audio/`、Tauri は `src/assets/sounds/` に置く。Tauri は import を通して配布物に含め、開発環境のソースパスに依存しない。

形式・取り込み・加工の指定は各素材フォルダと処理スクリプトで管理する。素材を取り込むときは[素材クレジットの原則](../contributing/素材クレジット管理.md)に従う。
