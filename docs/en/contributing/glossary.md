# Translation glossary

This glossary keeps game-specific terminology consistent across the UI and documentation. Its translations are authoritative for listed terms. Japanese (`ja`) is the source language.

- Include only game-specific terms whose translations could vary, rather than ordinary vocabulary.
- Columns use UI language codes: `en` for English, `es-419` for Latin American Spanish, `zh-Hans` for Simplified Chinese, `zh-Hant` for Traditional Chinese using Taiwanese terminology, `fr` for French, and `ko` for Korean.
- Terms use sentence-initial forms. Adjust capitalization and inflection to context.
- Parentheses in the `ja` column clarify distinctions between similar terms.
