システム構成と実行のヒント

  • 本シミュレータは、バックエンドエンジン（Python）とフロントエンドUI（Tauri/Unity）のハイブリッド構成となっています。
  • ビルド済みバイナリには、Python実行環境およびバックエンドの動作に必要なライブラリがすべて内包されています。
  • お使いのOSによっては、初回起動時に開発元未確認の警告（Windows SmartScreen または macOS Gatekeeper）が表示される場合があります。セキュリティ設定で「実行」を許可してください。
