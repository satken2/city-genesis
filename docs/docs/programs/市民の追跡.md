# 市民の追跡

3Dビューを走る車と歩行者から市民を選び、その市民の訪問先と経路を市民パネルで見たり、カメラで追いかけたりする機能。選んだ市民は追跡リストに残せる。

車と歩行者はパスの交通量から再現した描画専用の個体で([車両の走行描画](../geometries/O_車両の走行描画.md)・[歩行者の描画](../geometries/W_歩行者の描画.md))、市民の身元を持たない。身元はクリックしたときに初めてコアが推定する。推定も行程も、コアが直近のエポックで計算した結果を読むだけで、都市の状態は変えない。

## 一時停止

画面右上のカメラモードのボタン(見下ろし・フライ・撮影)の並びに、交通演出の一時停止ボタンがある。ボタンはシーンに置かれ、`CameraController` の `trafficPauseButton` に割り当てる。動いているときと止まっているときのアイコン(`trafficPauseIcon` / `trafficResumeIcon`)は、両方とも割り当てたときだけ切り替わる。

止まるのは一般車・歩行者・公共交通の編成・索道の搬器・航空機と船で、天気・時刻・水面・火災・建設クレーンは止めない。止め方は `Time.timeScale` ではなく、交通演出の時計 `TrafficClock` で行う。`Time.timeScale` はカメラの慣性やドラッグ速度の計算(経過時間での除算)、通信の再試行の待ち時間まで止めてしまうためである。各 Manager は経過時間に `TrafficClock.Scale` を掛け、飛行機雲・航跡の寿命と入港船の停泊・船の寿命は止めている間は進まない `TrafficClock.Time` で数える。一時停止はセーブしない。都市を切り替えると解除する。

## クリックした車・歩行者の市民

一時停止中は、自家用車(`VEHICLE_STANDARD`)と歩行者をクリックで選べる(入力モードが通常のときだけ)。トラック・商用車は市民ではないので反応せず、バス・電車は従来どおり路線詳細を開く。

常時コライダーを持たせると重いので、押下した瞬間に画面内の個体だけを集め、向き付きの箱にレイを当てる(`CitizenPickSelection`)。車は車体の Renderer の局所境界、歩行者は実寸より少し大きい箱を使う。最も近い個体を選び、手前を建物などのコライダーが遮っていれば選ばない(`TransitVehicleManager.TryPick` と同じ判定)。5px 以上動いたらカメラ操作として扱い、物理レイキャストより先に判定する。

離したら、Unity は個体の手段(自動車か徒歩)・今いるパス・進行方向・直前に通ってきた2本のパスをコアへ送り、市民を抽選させる(`POST /api/v1/citizens/pick`)。抽選は次の考え方で行う。

- パスの交通量は、通勤・通学と買い物の移動1件ごとの量を足したものである。Unity はパスごとの交通量に比例して個体を出しているので、そのパスへの寄与に比例して移動を1件選べば、交通モデルと同じ確率で「いまここにいる人」が決まる。
- 選んだ市民の通常の経路がそのパスをその向きに通るなら、その経路の途中から追う。直前に通ってきたパスの並びが合う移動を優先するので、眺めていた個体の動きと行き先が食い違いにくい。
- 通常の経路が通らなければ、「いまこのパスにいて行き先へ向かう」移動を、クリックした地点の先から作る。カメラが別の場所へ飛ぶことはない。

抽選できたら Unity は `world:select_object`(`citizen_detail`)で市民パネルを開き、選んだ個体と抽選結果を覚える。同じ個体をもう一度押しても抽選し直さない。エポックが進むと経路が変わるので、覚えた結果は捨てる。推定できなかったときは `citizen:pick_failed` で理由を送り、コックピットが通知で案内する(エポックの経路計算の前、シミュレーション中など)。

## 市民パネル

市民パネル(`citizen_detail`)は見出しの下にカメラと追跡のボタンを持ち、「基本」と「行動」のタブで構成する。

- カメラ: Unity でその市民を追いかける(`citizen:follow`)。追いかけている間は強調表示になり、もう一度押すとやめる(`citizen:unfollow`)。表示は Unity からの `citizen:follow_state` に従う。後から開いたウィンドウも今の状態を知れるよう、通知を受けたウィンドウが追従中の市民IDを `localStorage` に書く。市民パネルも追跡リストも閉じている間の通知を取りこぼさないよう、常駐するコックピットも書き、アプリの起動時には消す。Unity は追従していないときに解除を受けても、その市民の終了を通知し直す(ボタンが「追従中」のまま固まらないように)。
- 追跡: 追跡リストに加える・外す。変更は `tracking:changed` で他のウィンドウへ知らせる。
- 「基本」タブ: 年齢・性別・配偶関係・所属世帯、勤務先・通学先、スキル、犯罪性向。
- 「行動」タブ: 住まいと移動手段、訪問先の一覧。訪問先は勤務先・学校と、世帯が前エポックに買い物をした店(病院の医療サービスなども小売の買い物)で、どれも自宅との往復である。店には買っている品目を、各行には自宅からの片道の所要時間と乗り継ぎ(徒歩・車・路線名)を添える。

市民パネルは自分自身と排他で、別の市民を選ぶと入れ替わる。エポックが終わると行程を取り直す。

## 追従

追従は `CitizenFollow` が行う。開始すると撮影・フライ・見下ろし・ドライブを終え、行程が届いたら一時停止を解除する(先に動かすと、クリックした個体が抽選したパスから進んでしまうため)。

- 行程は自宅との往復の集まりで、Unity はコアの行程(`GET /api/v1/citizens/{id}/itinerary`)を自分で取る。自宅に戻ると、次の訪問先を1日あたりの回数(通勤・通学は毎日、買い物は品目ごとにエポックに1回)に比例して選んで出かける。訪問先では交通の時計で数秒滞在する。
- 移動は、続けて描けるパス(自動車は街路・高速道路、歩行者は街路・歩行者専用道路)の区間を指名した1台・1人に走らせる。指名した個体は他の個体と同じ車線・速度・前車追従で動き、分岐だけをパスの列に従わせる。経路から外れないよう、路面標示の進行方向の制約・到着予約・管理範囲外の削除からは外す。同じパスで向きを変える経路は、パスの端で折り返す。
- 出発では建物の位置に最も近い接道パスの地点から出て、到着では行き先の建物の最寄りの地点で建物へ入って消える(建物が最後のパスから60mより遠ければ入らず、パスの端で消える)。クリックで選んだ個体は、まだ走っていて、今いるパスと向きが抽選した移動の経路(抽選した位置から先)にあれば、そのまま引き継ぐ。経路から外れていれば引き継がず、自宅から追う。
- 公共交通の乗車・人員搬送設備・停留所への接続・駅の通路のように車や歩行者として描けない区間は、個体を消し、経路の形に沿ってカメラだけが区間の所要時間に合った速さで進む。
- 管理中心(`VehicleManager.ResolveTrafficCenter`)を追従対象に置くので、周辺の道路の走査と交通は対象の周りで行われる。道路の走査が区間の出発点に届くまで待ち、届かなければその区間はカメラだけで進む。個体が長く進めなくなったら区間を打ち切る。
- カメラは対象の後方上空から追い、向きの変化には遅れて追従する。ホイールで距離、右ドラッグで向きと俯角を変え、地表から一定の高さより下へは下げない。この追従カメラ(`ChaseCamera`)はドライブの三人称と共通。追従中は `CameraController` の操作を止める(ドライブと同じ `BlocksCamera`)。
- Esc・WASD・撮影・フライ・見下ろし・ドライブの開始・編集モードへの移行・都市の切り替えで終わり、`citizen:follow_state` を送る。終えるとカメラはその場から通常操作に戻る。
- エポックが終わると行程を取り直し、今の移動はそのまま続ける。

## 追跡リスト

コックピットの常用ツールは2行2列で、上段に表示切替・都市マップ、下段に追跡リスト・ブルドーザを並べる。追跡リストは都市マップの下にある監視カメラのアイコンで開く(`citizen_tracking`)。

追跡中の市民を追加した順に並べ、名前(市民パネルを開く)・年齢と地区・勤務先か学校を表示し、行ごとにカメラ(追従)と解除のボタンを持つ。亡くなった市民などはコアが一覧に出さず、次に一覧を書き換えるときに外す。

右上の「ランダムに1人追跡」は、一覧が空でも表示する。都市全体の未追跡の市民から等確率で1人を選び、リストへ追加する。候補がいないときや追加に失敗したときはメッセージを表示し、追加成功時は `tracking:changed` で他のウィンドウへ知らせる。

追跡中の市民IDの並びは都市の `tracked_citizen_ids` で、セーブに残る([セーブデータ仕様](セーブデータ仕様.md))。シナリオとして保存するときは空にする。

## HTTP契約

手書きのJSONで応答する。市民の抽選(`/pick`)と行程(`/itinerary`)は保存されない推定値で、エポックの経路計算の結果を使う。エポック実行中は `status: "busy"`、都市をロードした直後など経路の計算前は `status: "not_ready"` を返す(都市マップの経路案内と同じ)。追跡リストの操作は経路計算を必要としない。

| API | 内容 |
|---|---|
| `POST /api/v1/citizens/pick` | 本文 `{mode: "automobile" \| "pedestrian", path_id, forward, previous_path_ids}`(`forward` はパスを始点→終点の向きに進むか、`previous_path_ids` は直前に通ってきたパスを古い順に最大8件)。応答は `{status, citizen_id, snapshot, from_agent_id, to_agent_id, step_index, trip}`。`trip` は市民がいま行っている移動で、`step_index` はその `steps` の中でクリックしたパスの位置(経路を作れなかったときは null)。手段の合う住民がいなければ `status: "none"` |
| `GET /api/v1/citizens/{id}/itinerary` | `{status, citizen_id, household_agent_id, snapshot, epoch, mode, visits, trips}`。`visits` は先頭が自宅(建物)で、続いて勤務先・学校・店。各要素は `kind`(home / work / school / shop)・`agent_id`・`name`・`parcel_id`・`per_day`(自宅との往復の1日あたりの回数)・`product_ids`(店で買う品目)・`x`・`z`。`trips` は自宅と各訪問先の往路と復路で、`from_visit`・`to_visit`(`visits` の添字)・`status`・`minutes`・`distance_m`・`fare`・`legs`・`steps` を持つ。住宅待ちで建物の無い市民は `status: "no_home"`、いない市民は `"missing"` |
| `GET /api/v1/citizens/tracked` | 追跡中の市民 `{citizens: [{id, name, age, gender, household_agent_id, zone_name, employer_agent_id, employer_agent_name, school_agent_id, school_agent_name}]}`(追加した順) |
| `POST /api/v1/citizens/tracked/random` | 未追跡の市民をランダムに1人追加する。応答は `{citizen_id, citizens}`。`citizens` は追跡中の一覧と同じ。候補がいなければ `citizen_id: null` で一覧を変更しない |
| `PUT /api/v1/citizens/tracked/{id}` | 追跡中に加える(重複しない)。応答は一覧と同じ |
| `DELETE /api/v1/citizens/tracked/{id}` | 追跡中から外す。応答は一覧と同じ |

移動の `legs` は[都市マップの経路案内](都市マップの検索と経路案内.md#http契約)の区間と同じ形である。`steps` は Unity が辿るパスの列で、徒歩・自動車の区間のパスを順に並べ、両端に建物の接道パスを足したもの。各要素は `path_id`・`forward`・`leg`(`legs` の添字。接道パスとして足した要素は -1)・`type`(`path_type`)を持つ。公共交通・人員搬送設備の区間は `steps` に入らず、前後の要素の `leg` の間の `legs` として残る。

## IPC

| イベント | 方向 | 内容 |
|---|---|---|
| `world:select_object` | `graphic -> ui` | `window_type: "citizen_detail"`、`entity: {type: "citizen", id}` |
| `citizen:follow` | `ui -> graphic` | `{citizen_id}` |
| `citizen:unfollow` | `ui -> graphic` | `{citizen_id}`。追従していなければ `citizen:follow_state`(`following: false`)を返し直す |
| `citizen:follow_state` | `graphic -> ui` | `{citizen_id, following}`。全ウィンドウへ中継する |
| `citizen:pick_failed` | `graphic -> ui` | `{status}`。コックピットだけへ中継する |

一時停止は Unity の中で完結し、IPC を持たない。
