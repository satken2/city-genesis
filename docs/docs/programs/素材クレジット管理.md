# 素材クレジットの管理

クレジットウィンドウは、ゲームで使う外部素材の出所と、利用条件が求める表記を載せる画面である。画像・音声・フォント・3Dモデル・テクスチャ・地理データを対象に、Unity と Tauri で使う素材をゲーム全体で1つの一覧にまとめる。掲載内容はコアに依存せず、都市やセッションの状態によらない。

掲載データの唯一の正は `tauri/src/data/credits.ts` の `CREDIT_ENTRIES` で、項目の意味と記載の原則(表記の文面を翻訳しないことなど)は同ファイルのコメントにある。素材を取り込む・差し替えるときは、Skill `asset-credits` の手順で出所と利用条件を確かめ、同じコミットで `CREDIT_ENTRIES` に追記する。出所は後から辿れなくなるので、取り込みと追記を分けない。作者名やライセンス名は推測で書かず、出所を確かめられない素材は使わない。

自作の素材は載せない。地形・地理データは外部素材として扱い、加工してチュートリアルやシナリオの都市データに含めて配布するものの出所と利用条件を記録する。ゲームエンジンや OSS ライブラリはクレジットウィンドウに載せず、各ライセンスが求める著作権表示と条文を配布物に別途同梱する。
