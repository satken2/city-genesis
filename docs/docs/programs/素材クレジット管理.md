# 素材クレジットの管理

## 目的と対象

クレジットウィンドウは、ゲームで使用する外部素材の出所と、利用条件が要求する表記を掲載する画面である。画像・音声・フォント・3Dモデル・テクスチャ・地理データを対象とし、UnityとTauriの両方で使う素材をゲーム全体の一覧として管理する。

自作素材は外部素材の一覧へ含めない。制作記録やAI生成物の開示に関する記録は、クレジットとは別に扱う。ゲームエンジンやOSSライブラリのライセンス管理も、素材クレジットとは分ける。

## 掲載データと表示

掲載データの唯一の正は `tauri/src/data/credits.ts` の `CREDIT_ENTRIES` である。個別素材の作者、取得元、利用条件、加工内容はこのデータで管理する。

| 情報 | 役割 |
| --- | --- |
| `title`・`category` | 素材または素材セットの名前と分類 |
| `author`・`source`・`url` | 作者・権利者、配布元、配布ページへの参照 |
| `license`・`requiredText` | ライセンス名と、利用条件が指定する表記文面 |
| `note` | 使用箇所や加工内容などの補足 |

カテゴリと表示順は同ファイルの型定義と `CREDIT_CATEGORY_ORDER` で管理し、`tauri/src/components/taskbar/CreditsWindow.tsx` が描画する。バックエンドは関与せず、掲載内容は都市やセッションの状態に依存しない。

カテゴリ見出しと項目ラベルは多言語化する。作者名・配布元名・ライセンス名・指定文面は原文のまま表示し、`requiredText` を翻訳・要約・改変しない。配布元へのリンクは既定ブラウザで開く。

クレジットは設定ウィンドウの「情報」グループから開ける。設定ウィンドウはトップメニューとゲーム中の双方から開けるため、ゲーム開始前でもプレイ中でも参照できる。

## 素材登録の原則

- 外部素材は取得時に配布元と利用条件を確認し、商用利用・再配布が許可されたものを採用する。同じ配布サイトでも素材ごとに条件を確認する。
- 素材の追加・差し替えと同じコミットで `CREDIT_ENTRIES` を更新する。表記義務の有無によらず、採用する外部素材の出所を記録する。
- 作者名やライセンス名を推測で埋めない。出所や利用条件を確認できない素材は採用せず、原本や埋め込みメタデータなどから出所を確認する。確認できなければ差し替える。
- 加工や変換を行った場合は、その内容と必要な表記を個別素材の記録に残す。

素材フォルダのREADMEには、原本と出力ファイルの対応や変換条件などを記録できる。これはファイル管理のための情報であり、ゲーム画面への掲載データは `CREDIT_ENTRIES` に集約する。

## 地形・地理データ

地形・地理データも外部素材として扱う。元データを直接同梱せず、加工した地形をチュートリアルやシナリオの都市データへ含める場合も、配布するデータの出所と利用条件を確認する。利用者が自分で取り込むだけのデータは、ゲームの配布物のクレジットへ含めない。

出典表示だけでなく、加工した旨や指定文面なども提供元の条件に合わせて記録する。一つのデータセットに第三者のデータが含まれることもあるため、実際に利用する範囲と付属情報を確認し、必要な出典を記録する。

## ゲームエンジン・OSSライブラリ

ゲームエンジンやOSSライブラリは素材クレジットウィンドウへ載せず、各ライセンスで必要な著作権表示・ライセンス条文を配布物へ別途同梱する。素材の作者名を画面に表示する仕組みと、依存ソフトウェアのライセンス表示は別の責務である。
