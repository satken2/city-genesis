# アラートフラグ管理

建物・道路の `alert` は、直近のエポックで観測された問題を表す整数のビットフィールドである。建設・解体などのライフサイクルは `status`、調達不足・事故・接続不良などの問題は `alert` で表す。アラートはエポックごとに更新され、続く状態の問題は解消するまで、出来事は起きたエポックだけ立つ。セーブされるので、ロードの直後にも表示できる。

`alert` だけの変化はオブジェクトの `version` を上げないので、メッシュの差分取得では観測できない。Unity は `GET /api/v1/alerts` から別に取得し、オーバーレイだけを更新する。

## ビットの意味

建物と道路のビットは別の名前空間で、値は同期される共有定数にある。

| 対象 | 定数 | 意味 |
| --- | --- | --- |
| 建物・道路 | `ALERT_*_CONSTRUCTION_SHORTAGE` | 建設・解体のサービスの調達不足 |
| 建物 | `ALERT_AGENT_ON_FIRE` / `ALERT_AGENT_ACCIDENTAL_FIRE` | 火災 / 失火 |
| 建物 | `ALERT_AGENT_CRIME` / `ALERT_AGENT_CRIME_SIGN` | 犯罪 / 犯罪の兆候 |
| 建物 | `ALERT_AGENT_INFRA_DISCONNECTED` | 稼働中の施設が必要なインフラ網へ未接続 |
| 建物 | `ALERT_AGENT_LABOR_SHORTAGE` / `ALERT_AGENT_MATERIAL_SHORTAGE` | 労働力 / 原材料の不足が生産を制約 |
| 建物 | `ALERT_AGENT_HIGH_SKILL_SHORTAGE` | 必要な高スキル人材が不足 |
| 建物 | `ALERT_AGENT_BUDGET_CAPPED` | 公共予算の不足が稼働計画を制約 |
| 道路 | `ALERT_PATH_ACCIDENT` | 交通事故 |
| 道路 | `ALERT_PATH_NO_STATION_HOUSE` | ホームが駅舎に所属していない |

3Dに表示するビットは `ALERT_AGENT_ICON_BITS`・`ALERT_AGENT_VFX_BITS`・`ALERT_PATH_ICON_BITS` が定める。API はこれらのビットだけを残して返し(倒壊した対象は表示するビットが無くても返す)、生産の不足などの詳細用のビットは各エンティティの `alert` と[通知](通知レベル管理.md)で見る。火災・失火はアイコンではなく[炎と煙](../geometries/S_火災エフェクトの描画.md)で表す。

## L1警告の位置表示

[通知トレイ](通知レベル管理.md)の warning のうち、資源の枯渇予測・公共施設の運営不能・深刻な衛生悪化・インフラ施設の停止と倒壊は、同じ API の `warnings` が位置付きで返し、Unity がアラートと同じ層に表示する(caution は対象外)。警告かどうかはコアが決め、UI と Unity は閾値や重要度を判定し直さない。`entity_type` は `agent`(建物)・`resource`・`parcel` で、`warning` は表示専用のビット `ALERT_DISPLAY_*_WARNING` の和であり、エンティティの `alert` には入らない。衛生の警告は、原因の処理施設ではなく、被害を受けている世帯が住む土地区画の位置に出す。Tauri の建物詳細も同じ `warnings` から、建物自身と所属区画の警告を出す。

## 表示フィルター

UI は `view:change_view` の `layer=alert` で、表示するビットの和を `sub_mode` に10進の文字列で送る。建物のビットはそのまま、道路のビットは `ALERT_PATH_MASK_SHIFT` だけ左へずらして1つのマスクに合わせ、廃墟は `ALERT_DISPLAY_RUIN`、L1 の警告は `ALERT_DISPLAY_*_WARNING` で指定する。マスク0はすべてを隠す。

Unity では `AlertManager` が一覧の取得とアイコンの表示を担い、火災のエフェクトも同じ応答とフィルターを使う。アイコンは建物・道路の子にしないので、LOD の切り替えに巻き込まれない。
