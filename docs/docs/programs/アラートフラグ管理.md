# アラートフラグ管理

建物・道路のアラートは、直近のエポックで観測された問題を表すビットフラグ(`alert`)である。建設・解体などのライフサイクルは `status`、調達不足・事故・接続不良などの問題は `alert` で表す。アラートはエポックごとに更新され、続く状態の問題は解消するまで、出来事は起きたエポックだけ立つ。セーブされるので、ロードの直後にも表示できる。

`alert` だけの変化はオブジェクトの `version` を上げないので、メッシュの差分取得では観測できない。Unity は `GET /api/v1/alerts` から別に取得し、オーバーレイだけを更新する。

## ビットの意味

建物と道路のビットは別の名前空間で、値は同期される共有定数(`ALERT_*`)にある。

| 対象 | アラートの種類 |
| --- | --- |
| 建物・道路 | 建設・解体のサービスの調達不足 |
| 建物 | 火災・失火、犯罪・犯罪の兆候、インフラ網への未接続、労働力・原材料・高スキル人材・公共予算の不足 |
| 道路 | 交通事故、駅舎に所属していないホーム |

3Dに表示するビットは共有定数の `ALERT_AGENT_ICON_BITS`・`ALERT_AGENT_VFX_BITS`・`ALERT_PATH_ICON_BITS` が定め、API はこれらのビットだけを残して返す(倒壊した対象は表示するビットが無くても返す)。生産の不足などの詳細用のビットと、プレイヤーが直接手を打てない小さな出来事(失火・犯罪の兆候)は3Dに出さず、各エンティティの `alert` と[通知](通知レベル管理.md)で見る。火災はアイコンではなく[炎と煙](../geometries/S_火災エフェクトの描画.md)で表す。

## L1警告の位置表示

[通知](通知レベル管理.md)の L1 の warning のうち場所を持つものは、同じ API が位置付きの警告(`warnings`)として返し、Unity がアラートと同じ層に表示する。警告かどうかはコアが決め、UI と Unity は判定し直さない。警告は表示専用のビット `ALERT_DISPLAY_*_WARNING` で表し、エンティティの `alert` には入らない。

## 表示フィルター

UI は `view:change_view` の `layer=alert` で、表示するビットの和を `sub_mode` に10進の文字列で送る。建物のビットはそのまま、道路のビットは `ALERT_PATH_MASK_SHIFT` だけ左へずらして1つのマスクに合わせ、廃墟と L1 の警告は表示用のビット(`ALERT_DISPLAY_*`)で指定する。マスク0はすべてを隠す。

Unity では `AlertManager` が一覧の取得とアイコンの表示を担い、火災のエフェクトも同じ応答とフィルターを使う。アイコンは建物・道路の子にしないので、LOD の切り替えに巻き込まれない。
