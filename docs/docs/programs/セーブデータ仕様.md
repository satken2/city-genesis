# セーブデータ仕様

都市の保存単位と、フロントが一覧・保存・読み込みで扱う項目の意味を説明する。版情報と読み込めるかの判定は[バージョニングと互換性](バージョニングと互換性.md)、シナリオの保存元と制作の流れは[シナリオ制作と配布](シナリオ制作と配布.md)、保存先のフォルダは[ファイル配置](ファイル配置.md)を参照する。

## 保存ファイル

都市は丸ごと1つの `.cg` ファイルに保存し、通常セーブもシナリオも同じ形式である。ファイルを読み書きするのはコアだけで、UIとグラフィックはコアに都市を読み込ませてからAPIで取得する。地形も都市の一部としてすべてファイルに入り(初期地形・都市外の背景地形・書き換えた標高・海岸線・水面・川・埋立地)、ロードではファイルの中身だけから戻す([地形形状](../geometries/D_地形形状.md))。経路探索の結果やヒートマップのように再計算できる値は保存せず、コアが計算し直す(ヒートマップはロードの後、エポックを実行するまで空である)。

## 通常セーブとシナリオ

通常セーブはプレイ中の都市の続きを、シナリオは新しいゲームの開始点を保存したものである。シナリオのIDは保存元つきである([シナリオ制作と配布](シナリオ制作と配布.md#保存元と置き場))。

上書き保存の先は `GET /api/v1/sessions` の `current_save_id` で表す。通常セーブをロードするとそのセーブになり、シナリオから始めるとまだ保存していない新しいIDになる(元のシナリオを上書きしない)。シナリオ管理の「都市を編集」で開いたときだけシナリオのIDになり、`current_save_is_scenario` が真になる。シナリオは保存した状態のまま始まるので、市庁舎の無いシナリオは未創設で始まる。

## 一覧の項目

`GET /api/v1/saves`・`GET /api/v1/scenarios` の一覧は、ファイルに入っている一覧用の情報に、コアがその場で判定した読み込み可否と所有状況を加えたものである。読み込めないファイルも理由付きで残る。項目は通常セーブ(都市名・人口・ゲーム内日付など)とシナリオ(紹介文・開始設定・マップの大きさなど)で異なる。解釈を誤りやすい項目は次のとおり。

| 項目 | 意味 |
| --- | --- |
| `language` | 都市内の固有名詞が付いている言語。UIの表示言語とは独立している |
| `saved_at` | 最後に保存した実時間(`YYYYMMDD_HHMMSS`)。ゲーム内の日付は `current_date`(基準日からの経過日数) |
| `simulation_days` | 通常セーブでは確定したエポック日数、シナリオでは開始時の初期値 |
| `scenario_title` などの紹介文 | 作者が書く多言語テキスト `{言語コード: 文}`。表示言語の文が無ければ英語を使うので、タイトルと、書いた項目には英語の文がある |
| `scenario_city_name` | 開始時の都市名入力欄の初期値(多言語)。確定した都市名は通常セーブの `city_name`(1つの文字列) |
| `content_revision` | シナリオの内容の改訂番号。コアがシナリオを書き換えるたびに上げる |
| `pack_status` | 必要パックごとの所有状況。`unverified` は、製品版で Steam 認証の結果がまだ無く所有を確かめられない状態 |
| `compatibility` | 読み込めるか(`loadable`)と、読み込めない理由(`code`) |

`compatibility.code` には、ファイルと版の検査、必要パックの所有、DLCの置き場のシナリオだけ公式署名の順に判定して、最初に当たった理由を1つだけ入れる。ロードも同じ判定を都市の初期化より前に行うので、読み込めないファイルを開こうとしても現在の都市は変わらない。

## 保存に入る画像

保存の直前に、UIがグラフィックへ3Dビューの撮影を頼み(IPCの `camera:capture_thumbnail`)、グラフィックが撮った画像をコアへ預ける(`PUT /api/v1/sessions/thumbnail`)。預けた画像は次の1回の保存に入り、撮れなかった保存には前の画像が引き継がれる。作者がシナリオの画像を選んだときは、撮影の代わりにその画像を預ける。

## 暗号化と出自

DLCのシナリオから始めた都市は、必要パック(`required_packs`)を出自として記録し、以後のすべての保存へ引き継ぐ。ユーザーの操作で消す経路は無い。必要パックのある都市は、どの保存の経路でも暗号化して保存される(一覧の `encrypted`)。一覧用の情報と画像は鍵なしで読めるので一覧には出るが、都市を開けるのは必要パックをすべて所有しているときだけである。パックの鍵は Steam 認証で所有者にだけ届く([コンポーネント連携](コンポーネント連携.md))。必要パックや一覧用の情報を書き換えたファイルと、暗号化を外して必要パックを名乗るファイルは開けない(`SCENARIO_ENCRYPTION_INVALID`)。
