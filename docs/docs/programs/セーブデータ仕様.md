# セーブデータ仕様

本ページは現行の保存形式を説明する。コアの版番号、互換性の保証、更新前バックアップと画面表示の設計方針は[バージョニングと互換性](バージョニングと互換性.md)を参照する。アーカイブのメタデータが版情報の正であり、ロード前に本体を検査する。

## セーブファイルの形式

セーブデータは拡張子 `.cg` の ZIP ファイルとして保存される。ZIPの圧縮レベルは6（deflate）。

## ZIP 内部構造

| ファイル名 | 内容 |
|---|---|
| `soa.npz` | 全テーブルのSoA配列（numpy savez_compressed） |
| `scalars.npz` | SoAではない通常スカラー値を列指向numpy配列として格納 |
| `variable/{table}.msgpack.gz` | 可変長プロパティ（polygon, list, dict等）をmsgpack+gzipで圧縮 |
| `city.json` | Cityシングルトン（都市名、税率、人口統計、海岸線・湖・川、埋立地等） |
| `params.json` | Parametersシングルトン（`GENERAL_PARAMS`, `RATIO_PARAMS`, `TIME_VARYING_CONSTANTS`） |
| `metadata.json` | 都市情報、コア版、シナリオの紹介情報・作品リビジョン |
| `thumbnail.png` | 任意のシナリオ画像。外部ファイルなしで持ち運べる |
| `terrain/settings.json` | Terrainシングルトンの設定値（マップサイズ、グリッド間隔等） |
| `terrain/far_map.npy` | 遠景用標高マップ（numpy float16） |
| `terrain/near_map.npy` | 近景用標高マップ（numpy float16） |
| `terrain/dynamic/cell_{id}.npz` | 各セルの超近景標高マップ（numpy float32、圧縮） |

## セーブデータ一覧メタデータ（saves_metadata.json）

セーブデータ一覧画面を素早く表示するため、セーブファイルとは別に `saves_metadata.json` を保存ディレクトリに配置する。このファイルには全セーブのサマリーが記録されるが、失われても各 `.cg` の `metadata.json` から一覧を復元できる。

```json
{
  "{save_id}": {
    "id": "...",
    "city_name": "...",
    "population": 12345,
    "current_date": 20250601,
    "epoch": 5,
    "simulation_days": 90,
    "saved_at": "20260927_120000",
    "created_core_version": "1.0.0",
    "saved_core_version": "1.0.0",
    "last_simulated_core_version": "1.0.0",
    "language": "ja",
    "scenario_title": "自給自足社会を作ろう",
    "scenario_description": "この島は一切の輸出入を拒み、自らの力で都市を築く。",
    "scenario_objective": "輸出額が0、輸入額が0、人口1万人以上。",
    "terrain_map_id": "yoron",
    "terrain_map_name": "yoron"
  }
}
```

`scenario_*` はシナリオ（テンプレート）の紹介文で、テンプレート作成者が任意に記入するフリーテキスト。達成条件（`scenario_objective`）は文章として提示するだけで、判定には一切使われない（判定を伴う目標は達成クエストが担う）。`terrain_map_id` は舞台となった地形マップの識別子で、ニューゲーム画面がサムネイル（`GET /api/v1/terrain/maps/{id}/thumbnail`）とマップ名の解決に使う。

### サムネイル画像

セーブデータおよびシナリオ（テンプレート）にはサムネイル画像（PNG）を関連付けることができる。画像は `.cg`（ZIP）のルートに `thumbnail.png` として格納し、本体内の画像を優先する。既存の外部 `{save_id}.png` は本体画像がない場合に読める。画像更新時は本体も更新する。

- `GET /api/v1/saves/{save_id}/thumbnail`（シナリオは `?template=true`）で画像を取得する。
- `POST /api/v1/saves/{save_id}/thumbnail`（シナリオは `?template=true`）で画像を保存する。
- テンプレート作成モード中は `GET /api/v1/templates/thumbnail` および `POST /api/v1/templates/thumbnail` で現在のテンプレートに対する画像の確認と設定が行える。
- ニューゲーム画面では、シナリオ固有のサムネイル画像が存在すれば最優先で表示し、未設定の場合は舞台となる地形マップのサムネイルにフォールバックする。

紹介文の実体は `City` のプロパティ（`city.json` に保存される）で、メタデータへは一覧表示のために複製される。ニューゲーム画面のシナリオ詳細パネルはセーブ本体（`.cg`）を開かずに描画するため、この複製が必要となる。紹介文は任意なのでUIでは欠落を空欄として扱う。コア版の欠落は別に検査し、読み込みを拒否する。

## 通常セーブとシナリオテンプレートの違い

通常セーブとシナリオテンプレートは同一のファイルフォーマットを使用する。主な違いは以下のとおり。

| 項目                          | 通常セーブ            | シナリオテンプレート                                                       |
| --------------------------- | ---------------- | ---------------------------------------------------------------- |
| 保存先                         | `AppData/saves/` | `AppData/templates/`（ユーザー作成）、`AppData/downloaded_scenarios/`（取り込み）、または `<インストール先>/city/template/`（組み込み） |
| ロード後の `gd3.current_save_id` | セーブIDをそのまま設定     | `init_game()` で採番したUUIDを維持（元テンプレートを上書きしない新規セーブ扱い）                |

進行状態を表すフラグ `city.city_hall_placed`（市庁舎配置＝都市創設済みかどうか。保存対象）は、通常セーブ・シナリオテンプレートともに保存時の値をそのまま復元する。ロード側は進行フラグに一切手を触れない。シナリオを「プレイ」として開始する場合の創設状態の上書きは、`sessions` コントローラがロード後に別途 `city_hall_placed=True` を強制することで行う。

なおゲームバランスパラメータ（シミュレーション日数など）は都市創設（市庁舎配置）の前まで変更でき、創設後はロックされる（テンプレート作成モードは常に変更可能）。

## 海岸線と埋立地

海岸線・湖・川（`City.terrains` の `coastline`・`water_surfaces`・`rivers`）と、埋立地（`City.reclaimed_lands` と次に採番するID `City.reclaimed_land_next_id`）は `city.json` に保存される。

- **海岸線はロードで作り直さない。** 海岸線を地形から抽出するのは新規都市の作成時だけで、以後は埋立の完了で埋立地の範囲が足されて広がる。広がった海岸線は初期地形（`terrain/near_map.npy`）からは再現できないため、セーブに入っている値が正で、ロードではそのまま戻す。
- **埋立地は範囲・ID・版だけを保存する**（`{reclaimed_land_id, polygon, version}` の列。[地形形状](../geometries/D_地形形状.md) §D.17.1）。岸壁区間・帯・壁・天端の高さは保存せず、ロード後も現在の海岸線と地形から求める。
- 造成（整地・埋立）で書き換えた地形は、ほかの地形の編集と同じく編集セルの標高（`terrain/dynamic/cell_{id}.npz`）として保存される。工事中の造成は通常の建物と同じく経済主体と区画として保存され、ロード後も工事を続ける。

## 保存対象外のプロパティ

再計算可能なキャッシュデータは保存対象外とし、ロード後のシミュレーションフェーズで自動的に再計算される。除外定義は `assets/save_exclusions.yaml` に記載されており、主に以下が対象。

- 経路探索キャッシュ（`global_route`, `automobile_local_route`, `pedestrian_local_route` 等）
- ヒートマップ（`noise_heatmap`, `air_pollution_heatmap`, `crime_heatmap`）

## 互換性とシナリオの配布

APIの一覧には `compatibility` を付ける。本体の版が不明・不正、実行コアより新しい、MAJORが異なる場合は読み込まない。バランス変更の確認は最終実行版を基準とする。保存先と原本保護、テンプレートのメタデータ入力・取り込み・書き出しは[シナリオ制作と配布](シナリオ制作と配布.md)を参照する。
