# 地区編集パネル

地区編集パネル(`zone_edit`)は、都市マップの上でブラシを使って道路の面を塗り、新しい地区を作ったり既存の地区へ取り込んだりする画面である。地区と道路の面・土地区画の関係は[地区と土地区画](../economics/4_地区と土地区画.md)を参照する。地図は都市マップと同じ `CityMapCanvas` で描き、ブラシが拾う対象(生活道路に囲まれたブロックと、道路の片側の面)は地図が取得したベクターから組み立てる。

## コアとの連携

塗った面は、道路IDの列 `path_ids` と、同じ並びの面の指定 `sides`(`PATH_SIDE_*`。道路の始点→終点の向きに対する左右)で送る。新しい地区は `POST /api/v1/zones/`、既存の地区への取り込みは `POST /api/v1/paths/batch-zone` で行う。

割り当て後の地区の連結性と大きさはコアが検証し、満たさなければその操作の割り当てを一切変えない。パネルは結果の文言を出すだけで、同じ判定を持たない。成功したら地図のベクターを取り直し、Unity へ `session:reload` を送って3Dに反映する。

地区の名前・識別色・建築規制を地区詳細(`zone_detail`)で保存したら、IPC の `zone:updated` で地区IDを知らせ、Unity はその地区だけを取り直す。

地区の `auto_managed` は地区の状態を表さないので、フロントの判定に使わない。
