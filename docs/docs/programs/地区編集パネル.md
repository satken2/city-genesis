# 地区編集パネル

地区の作成と拡張は、都市マップの上でブラシを使って道路の面を塗る専用ウィンドウ（`zone_edit`）で行う。アイコンパネルの地区ボタンで開く。地区と道路の面・土地区画の関係は [地区と土地区画](../economics/4_地区と土地区画.md) を参照する。

実装は `tauri/src/components/zone/ZoneEditWindow.tsx`（ブラシが拾う対象は同じフォルダの `zoneBrushTargets.ts` が組み立てる）。地図の描画は都市マップと同じ `CityMapCanvas` を使う。

## ツールと塗り方

ツールバーで、塗った面の行き先（ツール）と、ブラシが拾う面（塗り方）を別々に選ぶ。

| ツール | 塗った面の行き先 | 送信先 |
| --- | --- | --- |
| 新規地区 | 新しい地区になる | `POST /api/v1/zones/`（`path_ids`・`sides`・`color`） |
| 既存地区の拡張 | マウスを重ねた地区に取り込まれる | `POST /api/v1/paths/batch-zone`（`path_ids`・`sides`・`zone_id`） |

| 塗り方 | ブラシが触れたもの | 拾う面 |
| --- | --- | --- |
| ブロック一括 | 生活道路に囲まれたブロック | ブロックを囲む道路の、ブロック側の面すべて（ブロックの中で行き止まる道路は両面） |
| 道路単位 | 道路の片側の半分の帯（中心線からその側の端まで）か、その面に接道する土地区画の集まり | その道路のその面 |

`sides` は `path_ids` と同じ並びの面の指定（`PATH_SIDE_LEFT` / `PATH_SIDE_RIGHT`）で、同じ道路を左右の面で2回送ることもある。

| 操作 | 内容 |
| --- | --- |
| Ctrl+左ドラッグ | 塗る。マウスを離した時点で送信する |
| 左ドラッグ | 地図の移動 |
| ホイール | 拡大・縮小 |

- 拡張ツールでは、カーソルの下の地区を強調し、ツールバーにその地区の色と名前を出す。塗り始めた地点の地区が取り込み先になり、塗り終えるまで変わらない。道路の帯や沿道区画の上ではその面の所属を優先し、それ以外では地区の輪郭で選ぶ。区画がなく輪郭を持たない地区にも道路の面から塗り足せる。地区も道路の面もない地点からのドラッグは地図の移動になる。地区のポリゴンは外周だけで飛び地を覆うため、カーソルの下で地区が重なるときは小さい（内側の）地区を指す。
- 新規地区で作った地区は続けて塗り足せるよう、作成後は拡張ツールに切り替わる。
- 新規地区の識別色はツールを選ぶたびに決め直し、ツールバーに示した色を `color` として送る。配色は彩度0.65・明度0.90で色相だけを振る（コアが色を決める場合と同じ規則）。名前は送らず、コアの既定名になる。

## ブロックと道路の片側

どちらも `CityMapCanvas` が取得した表示範囲のベクター（`onVectorsLoaded` の道路・土地区画）から組み立てる。取得範囲の外にはみ出すブロックは閉じないのでブロック一括では塗れないが、その面も道路単位なら塗れる。

- ブロックは、ノードでつながる生活道路（`PATH_STREET`）の中心線で囲まれた領域である。道路の網を、領域を左に見て一周する向きでたどり、反時計回りに一周したものをブロックとする。たどった向きが道路の始点→終点なら左の面、逆なら右の面がブロック側になる。外側に開いた領域と、端点がノードにつながっていない計画中の道路はブロックにならない。ノードを共有しない立体交差は領域を区切らない。
- 道路単位の対象は面ごとに、道路の片側の半分の帯（幅は道路の `width`）と、`front_path_id` と `front_path_side` がその面の土地区画をまとめたものである。接道か面が決まっていない区画は含めない。区画の無い面も帯で塗れるので、どの面もどちらかの塗り方で塗れる。

## ブラシ

- 半径は画面上で一定（20px）。拡大すれば細かく、縮小すれば広く塗れるので、大きさの設定は持たない。
- 円がブロックや区画の集まりに触れたら、その面を拾う。速くドラッグしても途中を取りこぼさないよう、前の位置から半径の半分の間隔で判定する。
- 都市の範囲（詳細地形の矩形）の外の道路の面は所属を変えられないので拾わない。道路が範囲の内か外かは、中心線の中点（道のりの半分の位置）で決める。
- 拡張では、すでに取り込み先に属している面は送らない。送る面が無ければ何も送らない。

## 検証と反映

割り当て後の地区全体について、道路網の連結性と市街地の最大距離・接道区間総延長の上限をコアが検証する。繋がらない場合は `ZONE_CONTIGUITY_ERROR`、サイズ上限を超える場合は `ZONE_SIZE_ERROR` を返し、その操作の割り当ては一切変更しない。パネルはエラーコードに対応する翻訳文を地図の下端に出すだけで、同じ判定を持たない。別の地区から面を奪った結果その地区が分かれることは妨げられず、次のエポックで分離される。

送信に成功したら、`CityMapCanvas` のベクター（道路・土地区画・地区など）だけを取り直し（`reloadVectors`。地形は取り直さない）、Unityへ `session:reload` を送って3Dに反映する。取り直しが届くまでは、塗った軌跡と拾ったブロック・区画を描いたまま残す。

## 描画

- 地区は識別色の半透明で塗る。データが変わったときだけ描けばよいので `overlayDraw` に描く。地区のポリゴンは外周だけなので、作業用のキャンバスに大きい地区から不透明で塗り重ねてから半透明で写し、飛び地の色が囲む地区の色と混ざらないようにする。拡張先の強調も同じ方法で、外周の内側にある飛び地を除いて塗る。
- カーソルに追従するブラシの円・拡張先の強調・塗った軌跡と拾ったブロック・区画は、地図全体を描き直さずに済む `animatedOverlayDraw` に描く。
- 地区の枠線（実線）と土地区画の枠線は `CityMapCanvas` のレイヤーで表示する。地区の一覧は `zoneBorders` レイヤー、土地区画は `parcels` レイヤーがONのときだけ取得されるため、このパネルでは常にONにする。

## 地区詳細の設定

地区詳細パネル（`zone_detail`）では、名前・識別色・建築規制を `PATCH /api/v1/zones/{id}` で保存する。識別色は通り・路線と共通の `ColorSwatchPicker` で選び、色見本の選択またはカラーコードの確定時に保存する。色見本は通りと共通のパレットを使う。

保存成功後は [`zone:updated`](IPC連携の整理.md) に地区IDを渡す。Unityはその地区だけを再取得し、地区名・建設可能建物のアイコン・枠線を更新する。非表示中もキャッシュを更新するため、次に表示した際に保存済みの内容を使う。

APIの `auto_managed` は生成済みの応答型と保存データの互換用の欄であり、地区の管理状態を表さない。クライアントは地区の成長可否や枠線の描き方の判定に使わない。
