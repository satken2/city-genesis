# 地区編集パネル

地区の作成と拡張は、都市マップの上でブラシを使って道路を塗る専用ウィンドウ（`zone_edit`）で行う。アイコンパネルの地区ボタンで開く。地区と道路・土地区画の関係は [地区と土地区画](../economics/4_地区と土地区画.md) を参照する。

実装は `tauri/src/components/zone/ZoneEditWindow.tsx`。地図の描画は都市マップと同じ `CityMapCanvas` を使う。

## ツールと操作

| ツール | 塗った道路の行き先 | 送信先 |
| --- | --- | --- |
| 新規地区 | 新しい地区になる | `POST /api/v1/zones/`（`path_ids`・`color`） |
| 既存地区の拡張 | マウスを重ねた地区に取り込まれる | `POST /api/v1/paths/batch-zone`（`path_ids`・`zone_id`） |

| 操作 | 内容 |
| --- | --- |
| Ctrl+左ドラッグ | 道路を塗る。マウスを離した時点で送信する |
| 左ドラッグ | 地図の移動 |
| ホイール | 拡大・縮小 |

- 拡張ツールでは、カーソルの下の地区を強調し、ツールバーにその地区の色と名前を出す。塗り始めた地点の地区が取り込み先になり、塗り終えるまで変わらない。地区の外から塗り始めたドラッグは地図の移動になる。
- 新規地区で作った地区は続けて塗り足せるよう、作成後は拡張ツールに切り替わる。
- 新規地区の識別色はツールを選ぶたびに決め直し、ツールバーに示した色を `color` として送る。配色は彩度0.65・明度0.90で色相だけを振る（コアが色を決める場合と同じ規則）。名前は送らず、コアの既定名になる。

## ブラシ

- 半径は画面上で一定（20px）。拡大すれば細かく、縮小すれば広く塗れるので、大きさの設定は持たない。
- 道路の中心線の中点（道のりの半分の位置）を円が覆ったら、その道路を拾う。円が道路に触れただけで拾うと、交差点を通るたびにそこから伸びる横道まで拾い、塗った範囲の縁から1本ずつはみ出すため。中心線は地図に描くのと同じ曲線（`pathCenterline`）から求める。
- 拾うのは生活道路（`PATH_STREET`）だけ。都市の範囲（詳細地形の矩形）の外の道路は所属を変えられないので拾わない。
- 速くドラッグしても途中の道路を取りこぼさないよう、前の位置から半径の半分の間隔で判定する。
- 拡張では、すでに取り込み先に属している道路は送らない。送る道路が無ければ何も送らない。

## 検証と反映

割り当て後の地区の道路が1つに繋がっているかはコアが検証し、繋がらない場合は `ZONE_CONTIGUITY_ERROR` を返す。パネルはエラーコードに対応する翻訳文を地図の下端に出すだけで、同じ判定を持たない。別の地区から道路を奪った結果その地区が分かれることは妨げられず、次のエポックで分離される。

送信に成功したら、`CityMapCanvas` のベクター（パス・地区など）だけを取り直し（`reloadVectors`。地形は取り直さない）、Unityへ `session:reload` を送って3Dに反映する。取り直しが届くまでは、塗った軌跡と拾った道路を描いたまま残す。

## 描画

- 地区は識別色の半透明で塗る。データが変わったときだけ描けばよいので `overlayDraw` に描く。
- カーソルに追従するブラシの円・拡張先の強調・塗った軌跡と拾った道路は、地図全体を描き直さずに済む `animatedOverlayDraw` に描く。
- 地区の枠線（確定=実線・自動管理=破線）と土地区画の枠線は `CityMapCanvas` のレイヤーで表示する。地区の一覧は `zoneBorders` レイヤーがONのときだけ取得されるため、このパネルでは常にONにする。
