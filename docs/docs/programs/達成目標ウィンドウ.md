# 達成目標と住民満足度スコア

`AchievementsWindow`は、都市づくりの方向性を示す目標と、住民の暮らしの評価を左右に配置する。スコアの概念は[施政スコア](../economics/23_施政スコア.md)、目標の状態は[達成クエスト](../economics/24_達成クエスト.md)を参照する。UIの表示名は「住民満足度スコア」で、APIのcity_score系の名称は変えない。

## 左ペイン：達成目標

シナリオ紹介と目標カードを表示し、進行中・未解放・達成済み・期限切れの順に並べる。同じ状態のカードはAPIの順序を保つ。名称と説明は折り返して全文表示し、状態を文字でも示す。進捗はサーバのprogressを参照する。未達成の隠し目標は通常プレイでは名前・説明・条件・進捗を伏せる。テンプレート作成時は紹介の編集、目標の追加・編集・削除が可能。

## 右ペイン：住民満足度スコア

減点後の1世帯あたりスコアを最大2点の主指標として表示する。横に当期の都市合計と生活水準・住環境・倒壊減点の数値内訳、集計世帯数を示す。エポック未実行なら評価前の案内を出し、実行済みでも世帯数が0なら主指標はダッシュ表示とする。

推移は単一軸のグラフで、生活水準と住環境を正方向に積み上げ、倒壊減点を負方向に描く。白い線が減点後の確定スコアを示す。1世帯あたり表示では正方向の軸上限を2点に固定し、各エポックの世帯数で内訳を割る。都市合計への切替時は絶対量を表示する。線はどちらの表示でもAPIの確定値を使う。

世帯満足度の内訳は栄養・医療・娯楽・住環境の平均値を百分率とメーターで示す。住環境は正規化後の値で、各項目には評価対象を説明する短文を添える。これらの平均値には倒壊減点を適用しない。当期の焼失・倒壊一覧は詳細開閉内に表示する。

左右ペインは独立してスクロールする。極端に狭い表示（540px以下）は縦配置へ切り替える。配色は共通のflatトークン、文言は全7言語のachievements.jsonを用いる。

## 履歴API

`GET /api/v1/score`のhistoryは各エポックのcity_score・city_score_per_household・city_score_qol・city_score_env・city_score_collapse_penalty・city_score_household_countを含む。最新の内訳を過去へ流用しない。historyが空なら未実行として扱う。
