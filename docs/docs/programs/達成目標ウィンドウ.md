# 達成目標と住民満足度スコア

達成目標ウィンドウ(`AchievementsWindow`)は、都市づくりの方向性を示す達成目標と、住民の暮らしの評価(住民満足度スコア)を並べて見せる画面である。スコアの概念は[施政スコア](../economics/23_施政スコア.md)、目標の状態と条件は[達成クエスト](../economics/24_達成クエスト.md)を参照する。UI の表示名は「住民満足度スコア」だが、API の名前は `city_score` 系のままである。

## コアとの連携

目標は `GET /api/v1/quests` から取得する。進捗(`progress`)と条件節ごとの状態(`clause_states`)は、コアが取得の時点で達成を判定して付けた値で、UI では計算し直さない。API は隠しクエストの内容も返すので、未達成の隠しクエストは通常プレイでは UI が伏せる。名前・説明は作者が書く多言語テキストである([UI共通基盤](UI共通基盤.md#言語と作者のテキスト))。

スコアは `GET /api/v1/score` の最新値と、各エポックの確定値を持つ履歴(`history`)を使い、履歴が空ならエポック未実行として扱う。推移の描き方は[UI共通基盤](UI共通基盤.md)の統計の扱いに従う。

## 達成と失敗の通知

`POST /api/v1/epochs` の応答には、そのエポックで新たに達成した目標(`completed_quests`)と失敗した目標(`failed_quests`)が通知用のデータとして入り、達成の演出は実測値と報酬をここから使う。実測値(`achieved_values`)のキーは条件木の中の節の位置である。目標の `notify` が知らせ方を決め、`toast` の達成と全ての失敗は共通の通知ポップアップで、`modal` の達成は結果ウィンドウを閉じた後のお祝いウィンドウで知らせる。
