# 通知レベル管理

プレイヤー(市長)に知らせる事象は、緊急度で3つのレベルに分け、レベルごとに別の UI で表す。

| レベル | 定義 | 表現 |
| --- | --- | --- |
| L1 | 知っておくべき継続中の問題や重大な出来事で、常に見えているべきもの | コックピットのアラートアイコンと件数、通知一覧ウィンドウ |
| L2 | 放置すると悪化する傾向 | エポック結果ウィンドウの統計 |
| L3 | どこで起きているかが主な情報の事象 | 3D空間のアラートフラグ([アラートフラグ管理](アラートフラグ管理.md)) |

L3 はその場所をカメラで見ているときにしか気づけないので、都市全体に関わる危機は L1 で、カメラの向きによらず伝える。同じ事象でも深刻さでレベルが変わり、例えば交通事故の発生は L3 だが、死者が出たら L1 になる。

## L1 の重要度

L1 の通知は `severity` で2段階に分かれる。`warning` は、築いた都市の機能が損なわれつつあり、かつプレイヤーが数エポックのうちに打てる手がある事象で、コックピットのアイコンを点滅させ、赤い件数で示す。`caution` はそのどちらかを欠く事象(打てる手が無い・効くまで年単位かかる、または損なわれるのが成長や余力に留まる)で、点滅させずに黄色の件数だけで示す。急ぎでない問題で点滅が常態化すると、本当の危機の合図が薄まるためである。未知の `severity` は、安全側の `warning` として扱う。

## L1 通知の受け渡し

コアはエポックの最後に通知の一覧を作り直し、Tauri は `GET /api/v1/notifications` から取得する。一覧は保存されるので、ロードの直後にも復元できる。コックピットは定期的に取得し、エポックの完了でも取り直し、セッションが切れたら消す。L1 は通知ポップアップを出さず、アイコンと件数で続いている状態を知らせる。操作の結果やクエストの達成などの一時的な知らせは、共通の通知ポップアップ(`utils/notification.ts`)で出す。

- `id` は通知を見分ける安定したキーである。状態が続く通知は続く間ずっと同じ `id` で作り直され、解消すると消える。発生したエポックだけの通知は日付を含む `id` を持ち、次の作り直しで消える。
- `created_date` は発生した時点のゲーム内の日付(1800年1月1日からの経過日数)である。
- `entity` は通知の対象(`agent`・`resource`・`zone`)で、通知一覧から対応する詳細ウィンドウを開くのに使う。件数をまとめた通知では `null` である。

コアは文言を組み立てず、`type` と `params` だけを返す。Tauri が i18n キー `notifications.types.<type>` に `params` を差し込んで文言にする(表示言語の知識をコアに持たせないため)。未知の `type` は汎用の文言に落とすので、コアが先に新しい種類を返しても UI は壊れない。対象の名前(資源名・施設名)は表示用のデータとして `params` に入る。取得・文言化・詳細ウィンドウとの対応は `utils/cityNotifications.ts` にまとめる。

## 通知の種類

| `type` | `severity` | 内容 |
| --- | --- | --- |
| `resource_runway` | warning | 天然資源が、今の減り方が続くと近く枯渇する見込み |
| `resource_depleted` | caution | 資源が枯渇した(そのエポックだけ) |
| `facility_inoperative` | warning(原因が予算・高スキル人材なら caution) | 稼働中の公共施設が実質的に運営できていない。原因は `params.reason` |
| `education_low_enrollment` | caution | 教育機関の在籍者が定員を大きく下回る |
| `infra_facility_down` | warning | インフラ財を授受する施設(発電所・変電所など)が停止・倒壊している |
| `infra_disconnected` | warning | インフラ網に未接続の施設の件数(位置は L3 のアラートフラグが示す) |
| `rail_capacity_exceeded` | caution | 列車の便数が線路の容量を超えた線路の本数 |
| `tenant_blocked_by_parcel_size` | caution | 建てたい業種があるのに、地区のどの土地区画でも必要な床面積を確保できない |
| `sanitation` | 深刻なら warning、その前段階は caution | 下水・ごみの処理不足で衛生が悪化した世帯の数 |
| `collapse` | warning | そのエポックの建物・道路の倒壊(死者の数を含む) |
| `deaths_traffic` | warning | そのエポックの交通事故による死者 |

warning のうち資源の枯渇予測・公共施設の運営不能・深刻な衛生悪化・インフラ施設の停止と倒壊は、Unity でも対象の位置に示す([アラートフラグ管理](アラートフラグ管理.md#l1警告の位置表示))。コックピットの件数は通知の単位で数える。
