# プレイモード

セッションには次のプレイモード(`play_mode`。値は共有定数の `PLAY_MODE_*`)がある。

| モード | 用途 |
| --- | --- |
| 通常 | 通常のプレイ。配布済みのシナリオを遊ぶときもこのモードを使う |
| シナリオ | シナリオの制作・編集(神モード) |
| チュートリアル | 同梱の教材 |
| 読み取り専用 | 公開サーバーで不特定多数に都市を見せる。ゲームのルールは通常モードと同じ |

モードはセーブに保存しない。通常のセーブのロードとセッションの終了で通常モードへ戻り、チュートリアルを完了すると都市を保ったまま通常モードへ移る。UI はモードを共有のセッション状態から `usePlayMode` で読み、画面ごとに別のフラグを持たない([UI共通基盤](UI共通基盤.md))。

## シナリオモードとチュートリアル

シナリオモードは、建設資金の審査と、市庁舎を置く前の HUD のロック・エポック実行の禁止を外し、制作用の操作を許す。制作用の操作は、創設後のパラメータや任意のプロパティの編集、天然資源・入居する経済主体・`template_only` の施設・クエストの編集、都市の一括の編集(一括完成・街路の自動生成・民間施設への一括変更・市民のスキル構成の編集)、プロップの範囲散布、天候の手動の切り替え、ブルドーザでの即時削除である。他のモードでは UI が入口を出さず、制作用の API(`/api/v1/templates/` など)はコアが 403 で断る。チュートリアルは、資金の審査と市庁舎を置く前の制限だけを外し、それ以外は通常モードと同じ判定と UI を使う。

都市の一括の編集はシステムトレイの「シナリオ編集」ウィンドウにまとめ、`/api/v1/templates/` の API を呼ぶ。操作の間は `epoch:executing` で HUD をロックし、終わったら Unity へセッションの再読み込みを送る。街路の自動生成は計画中の街路を作るだけなので、作者は要らない街路を消してから一括完成で竣工させる。市民のスキル構成の編集は、適用した時点の住民を一度だけ変え、比率を保つ設定は残さない。

## 読み取り専用モード

1つのコアを大勢で見るときに都市を書き換えられないよう、読み取り専用モードではコアが書き込みを断る。管理者だけが、コアの起動時に設定した秘密をヘッダー `X-Admin-Secret` で示して操作できる。

- 秘密の無い書き込みは 403 `READ_ONLY` になる。書き込みとみなすのは GET・HEAD・OPTIONS 以外の要求と、デバッグ API のすべてである。都市を書き換えない見学用の問い合わせ(車の動き・車と歩行者の市民の抽選・経路案内)は、POST でも秘密なしで使える。
- 読み取り専用モードへは、秘密を示した `PATCH /api/v1/sessions` でだけ入れる。秘密を設定していないコアでは入れない。抜けるのも書き込みなので秘密が要る。
- `POST /api/v1/sessions` で都市を開くと、モードはその要求で決まり、読み取り専用は外れる。

UI は、都市に物を作る操作(造成・パスの建設・土地区画・地区の編集・建物の建設・プロップの配置)と、システムトレイのシステム統計・設定・セーブとロードを出さない。それ以外の操作は UI に残り、実行するとコアが 403 で断る。
