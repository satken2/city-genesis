# 公共交通ハイライト

表示オプションの公共交通タブで「公共交通ハイライト」をONにすると、路線カラーの帯、停留所の丸印、駅名・バス停名の吹き出しを表示する。初期状態はOFF。全体のON/OFFと種別フィルターを別々に保持する。

帯は画面上8px、暗い輪郭を含め12pxの平面メッシュで、建物や地形より手前に描く。地下の路線も透けて見える。路線・停留所・名前をクリックすると路線詳細を開き、複数路線が重なる場合は路線名の候補を表示する。マウスを5px以上動かした操作はカメラドラッグとして扱う。

走行中の公共交通車両はハイライトOFFでもクリックできる。車体の描画範囲とレイで判定し、建物・地形に隠れた車両とプール内の非表示車両は対象外。詳細パネルの表示・保存・削除でハイライトを強制ONにしない。

## 経路と描画

`TransitRouteGeometry` は車両とハイライトの共通の経路補間を担う。`TransitDataStore` が取得する `journeys.steps` のパスID・方向・開始/終了割合を使い、下地パスの曲線と高さ、車線位置、実際に生成されたレール接続に沿って描画する。停留所間の直線や、未取得のパスを飛ばした連結は使わない。描画範囲外の未ロード区間や未生成のレール接続は表示を切る。実経路が成立しない路線を仮の直線で表示することもない。

`TransitOverlayManager` は0.5秒周期でロード済みの経路形状を更新する。カメラ移動・回転・画角・解像度の変化では帯の幅を再計算する。`OverlayMeshRenderer` の2枚のメッシュを `Custom/OverlayLine` の `ZTest Always`、描画順3200/3201で重ねる。

名前は路線詳細APIの `stops` を10秒間隔で逐次取得する。停留所のXZを下地パスへ射影して描画上の高さを求め、同じ駅舎に属する停留所の名前を集約する。名前がない場合はノードIDを表示する。吹き出しは `WorldCallout` で配置し、近い地点を優先して最大80件、重ならない範囲で表示する。画面外・カメラ背後の名前は描かない。道路建設の勾配ラベルも引出線の描画関数を共有する。

## 入力・通信・寿命

`InputHandler` は通常のPATH/TERRAIN入力時に `TransitSelection` を先に呼ぶ。前面の帯はスクリーン座標で選択し、建物の物理コライダーに遮らせない。押下時の路線IDをリリースまで保持する。編集操作、UnityのUI、カメラドラッグ、フライモード、ラジアルメニューでは選択候補を破棄する。

既存の `view:change_view` の `layer=transit` で、`mode=default/hidden` が全体ON/OFF、`sub_mode` が種別IDのCSVとなる。OFF中もCSVは保持し、帯・ラベル・クリック候補だけを消す。車両描画と共有路線データの5秒ポーリングは継続する。

詳細の表示は既存の `world:select_object`（`window_type=transit_detail`、対象は路線エージェントID）を使う。セッション切替では名前キャッシュ・取得コルーチン・選択候補を破棄し、別の都市へ古い表示を持ち込まない。

## 検証

`unity/Tests/Vehicles/run.ps1 -TransitOnly` で実アセンブリを独立Unityから検証する。走行時計・車両モデル・折り返し・曲線と高さの追従・未ロード区間の非補完・車両クリックと遮蔽・プール車両の除外・重なる路線の候補・カメラ背後の非選択を対象にする。

実際の都市では、地下・高架・分岐・同一軌道の複数路線・駅が密集する場所での見え方と、Tauriの路線詳細への遷移を確認する。
