# 公共交通ハイライト

表示パネルの公共交通レイヤーを ON にすると、路線の色の帯、停留所の印、駅名・バス停名を3Dビューに重ねる。帯は建物や地形より手前に描くので、地下の路線も見える。帯・停留所・名前をクリックすると、その路線の詳細を開く(重なった路線は名前の候補から選ぶ)。走行中の公共交通の車両は、ハイライトが OFF でもクリックで同じように選べる。

表示の切り替えは `view:change_view` の `layer=transit` で行い、表示する路線種別を `sub_mode` に公共交通マスターの `transit_path_id` の CSV で指定する。路線の詳細(`transit_detail`)は、路線の経済主体を対象に開く。

帯は車両の描画と共通の経路(`TransitRouteGeometry`)に沿って描く。経路は路線データの `journeys` の走行区間を、下地のパスの曲線・高さ・車線や軌道の位置に当てはめて作り、停留所の間を直線で補わない。下地のパスが読み込まれていない区間では帯を切る。帯は建物の手前に描かれるので、選択は物理のレイキャストより先に画面座標で判定する([Unity入力制御](Unity入力制御.md))。
