# Unity表示モード

3Dビューの建物・道路・土地区画・地区・地形の見せ方(表示・非表示、ハイライト、データの色分け)を、レイヤーごとにまとめて切り替える仕組み。実装は `unity/Assets/Scripts/VisualHandlers/` にある。クリックしたときに何が起きるかを決める入力モード([Unity入力制御](Unity入力制御.md))とは別系統で、編集ステートに入るときは両方を組で切り替える。

## レイヤー・色モード・表示フラグ

表示の状態は、表示パネルのレイヤー(地形・道路・建物・土地区画・地区など)ごとに持つ。UI は `view:change_view` で切り替えを指示し、Unity は現在の状態を `view:current_state` で返す。1つのレイヤーの見え方は、互いに独立した次の3つで決まる。

| 系統 | 性質 |
| --- | --- |
| 色モード(`mode`・`sub_mode`) | レイヤーごとに1つを選ぶ。通常・非表示・境界線や、交通量・地価・人口などのデータの色分け |
| 表示フラグ(`flags`) | 色モードと独立に ON/OFF する。計画中の表示・公共施設のハイライト・制限速度標識など |
| オブジェクト単位の非表示 | 建物・道路を ID で隠す([建設プロジェクト管理](建設プロジェクト管理.md)) |

`flags` は有効なフラグの CSV で、`null` は現在の値の維持、空文字はすべて OFF を表す。

建物・道路・区画・地区・地形のレイヤーは `VisualModeHandler` がオブジェクトタイプごとに持ち、登録された描画物へ数フレームに分けて知らせるので、一度に全オブジェクトが切り替わるわけではない。描画物は、建物・道路などの個体ごとに付くコンポーネント(`VisualModeObject`)か、区画・地区のように全体を1つのオーバーレイで描くマネージャ自身で、後から生成された描画物も登録した時点の表示を受け取る。公共交通の帯・効果範囲・プロップなど、それ以外のレイヤーと常駐のオーバーレイは、この通知を通さずにそれぞれの描画担当が切り替える。

## 個体の見え方

個体の見え方は、オブジェクト単位の非表示、建設のプレビューや干渉の警告色、ステータス、色モードの順に決まる。建設中・解体中・倒壊(`STATUS_CONSTRUCTING`・`STATUS_DEMOLISHING`・`STATUS_COLLAPSED`)は専用の形をそのまま見せて色モードで塗らず、計画中(`STATUS_TEMPORARY`・`STATUS_PENDING`・`STATUS_SCHEDULED_CONSTRUCTION`)は計画中の表示フラグが ON で、色モードが非表示でないときだけ見せる。非表示にした描画物はクリックの対象からも外す。

## 地下表示

地形レイヤーの透過(`transparent`)は地下表示を兼ねる。地形を薄い膜に、地上のモデルを半透明にして、通常は描かない地中の道路・線路の区間を見せる。地形のコライダーと高さは元のまま使うので、カメラ・配置・地形の編集の基準は変わらない。

## 編集ステートの表示

編集ステートに入ると、その作業に必要なもの(計画中の道路・建物、区画、地区など)が見える表示へ切り替わり、通常モードへ戻ると元の表示に戻る。表示の状態の正は Unity の `IpcViewCoordinator` が持つレイヤーごとの記憶で、ステートやプリセットが表示を強制するときもこの記憶を通す(描画を直接切り替えると、UI へ通知する状態と実際の見え方がずれる)。

- 記憶するのは、通常モード(`STATE_NORMAL`)の間に `view:change_view` でユーザーが選んだ表示だけで、編集ステート中やプリセットによる変更は記憶しない。
- `STATE_NORMAL` に戻るかプリセットを解除すると、記憶した表示へ戻す。記憶の無いレイヤーは既定値に戻し、既定値は UI の `DISPLAY_LAYERS` の初期値と一致させる。新しい都市の読み込み(`game:loading`)では記憶ごと既定値に戻す。

専用の編集ステートを持たないウィンドウは `view:apply_preset` で同じ仕組みに乗り、閉じたときに Rust 側が送る `STATE_NORMAL` か `view:restore_preset` で元に戻す。UI のパネルは一時的な表示の変更を `view:change_view` で送ってはいけない。通常モードで送ると「ユーザーが選んだ表示」として記憶され、元に戻せなくなる。
