# モックバックエンド

コアシミュレーター(バックエンド)はクローズドソースで、このリポジトリには含まれない。UI(Tauri)・グラフィック(Unity)の開発者が製品版のコアなしで開発・テストできるよう、**モックバックエンド**を実行ファイルとして配布する。

## モックでできること

モックは製品版と同じ REST インターフェースを持ち、エポックの実行だけができない。データの取得と編集、新しいゲームの作成、セーブ・ロード、シナリオの読み込みと管理、マスターデータ・地形・統計の取得は製品版と同じに動く。エポックの実行(`POST /api/v1/epochs`)は 501 `SIMULATION_DISABLED` を返し、エポックを実行できるかは `GET /api/v1/sessions` の `simulation_available`(モックでは常に false)で分かる。シミュレーション本体はモックに含まれていないので、設定を変えても有効にはできない。

都市の状態はエポックの実行でしか変わらないので、建設・編集の操作とその描画、各ウィンドウの表示など、フロントの開発の大部分はモックでできる。経済が動いている状態のデータが要るときは、配布するサンプルのセーブデータを読み込む。

## 起動

モックの配布物は製品版のコア(インストール先の `Core/`)と同じ構成で、`genesis.exe` を含む。

- 単独で起動すると、`127.0.0.1` のポート 5000(使用中なら次の番号を順に探す)で待ち受け、実際のポートを起動時のコンソールに出す。開発中の Tauri はコアを起動しないとき `http://127.0.0.1:5000` に、Unity は `--api-base-url` が無ければ同じ接続先につなぐ。
- Tauri の実行ファイルの隣の `Core/` に置くと、製品版と同じく Tauri がコアを子として起動・終了する([コンポーネント連携](コンポーネント連携.md#起動順序))。

接続の窓口と API の資料(Swagger・OpenAPI)の扱いは製品版と同じである([コンポーネント連携](コンポーネント連携.md#ローカルapiへの接続))。

## 製品版と同じ制限

モックはデバッグ用のエンドポイントを持たず(デバッグ統計は空を返す)、そのほかの制限は製品版と同じである。神モードへは都市を開くとき(`POST /api/v1/sessions` の `play_mode`)にしか入れず、Steam での認証が無い環境では暗号化された DLC のシナリオを開けない。都市のデータを返す API は、新しいゲームを作るかロードするまで 503 `NO_SAVE_LOADED` を返す。
