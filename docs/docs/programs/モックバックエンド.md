# モックバックエンド

City Genesis のコアシミュレーター(バックエンド)はクローズドソースであり、このリポジトリには含まれない。UI(Tauri)・グラフィック(Unity)の開発者が製品版のバックエンドなしで開発・テストできるよう、**モックバックエンド**が実行ファイルとして配布される。

## モックでできること・できないこと

モックは製品版と同じ REST インターフェースを持つ。エポック実行だけができない。

| 機能 | モックでの挙動 |
| --- | --- |
| データの取得・CRUD(建物・道路・土地区画・地区・プロップなど) | 製品版と同一 |
| 新規ゲーム作成・セーブ/ロード・シナリオのロード・シナリオ管理 | 製品版と同一 |
| マスターデータ・地形・統計の取得 | 製品版と同一 |
| エポック実行(`POST /api/v1/epochs`) | `501 Not Implemented` (`{"code": "SIMULATION_DISABLED"}`) |

エポック実行(シミュレーション本体)のプログラムはモックのバイナリに含まれていないため、設定変更などで有効化することはできない。

都市の状態はエポック実行でしか変化しないゲームデザインのため、モックでも「建設・編集操作とその描画」「各種ウィンドウの表示」といったフロントエンドの大部分の開発が可能である。経済が動いている状態のデータが必要な場合は、配布されるサンプルセーブデータをロードして使う。

## エポック実行可否の判別

`GET /api/v1/sessions` のレスポンスに `simulation_available`(bool)が含まれる。モックでは常に `false` になるため、フロントエンドはこのフラグでエポック実行 UI の表示可否やモック環境向けの案内を出し分けられる。エポック実行を試みた場合のエラーレスポンスは以下。

```json
HTTP 501
{
  "code": "SIMULATION_DISABLED",
  "message": "このビルドではシミュレーション(エポック実行)は利用できません。"
}
```

## 起動方法

モックの `genesis.exe` を起動すると、バックエンドが `127.0.0.1` のポート 5000(使用中なら 5001, 5002, … と順に探索)で待ち受ける。実際のポートは起動時のコンソール出力に表示される。

製品版と異なり、モックの `config.toml` には `[ui]` / `[graphic]` セクションがないため、Unity や Tauri の子プロセスは自動起動されない。開発者は自分でビルドしたフロントエンドを起動し、`http://127.0.0.1:<port>/api/v1` に接続する(開発中のフロントエンドは通常ポート 5000 決め打ちの接続で問題ない)。

すべての要求にローカルAPIの認証トークンが要る。モックは起動のたびにトークンを作り、ユーザーフォルダの `api_token`(Windows なら `%LOCALAPPDATA%\UrbanGenesis\api_token`)に書く。手動で起動した Tauri・Unity は環境変数 `GENESIS_API_TOKEN` が無いのでこのファイルを読み、モックを再起動したときは401を受けて読み直す。curl などで直接叩くときは `X-City-Genesis-Token` ヘッダーにこの値を付ける。ホスト名は `127.0.0.1` / `localhost` を使う(ほかのホスト名は421で拒否される)。仕様は[コンポーネント連携](コンポーネント連携.md#ローカルapiの認証)を参照する。

API の一覧とスキーマは本ドキュメントの API Reference にある。モックは製品版と同じくAPI仕様のページ(`/docs`・`/redoc`・`/openapi.json`)を提供しない。

## 注意点

- モックはデバッグ機能(デバッグ用エンドポイント・デバッグ統計)も無効化されたビルドである。`GET /api/v1/stats/spawn_debug` は常に空を返し、`/api/v1/debug/*` と `/data/*` は存在しない
- 製品版と同じく、`PATCH /api/v1/sessions` で神モード(`template_mode`)を有効にすることはできない(403 `TEMPLATE_MODE_FORBIDDEN`)。神モードの都市は、シナリオ管理の「都市を編集」など `POST /api/v1/sessions` の `template_mode` で開く
- Steam認証は製品版と同じ扱いで、Steamでの検証が済んでおらず有効な認証結果も残っていない環境では、暗号化されたDLCのシナリオを開けない(`SCENARIO_PACK_UNVERIFIED`)
- セーブデータがロードされるまで、ゲームデータ系のエンドポイントは `503 NO_SAVE_LOADED` を返す。先に `POST /api/v1/sessions` で新規ゲーム作成またはロードを行うこと
