# ファイル配置とデータ管理責任

ゲームで扱うデータは、コア・Tauri・Unity・Steam がそれぞれ受け持って保存する。どのプログラムが何を記録するかをここで定める。

## データ管理責任の分担

| データ | 管理するもの | 置き場所 |
| --- | --- | --- |
| 都市の状態(セーブデータ)・自作シナリオ・プレイヤーのプロフィール | コア | ユーザーフォルダ |
| コミュニティのシナリオ(Steam Workshop) | Steam(ゲームは読むだけ) | Workshop の購読フォルダ |
| DLC のシナリオ | Steam(ゲームは読むだけ) | インストール先の `dlc/` |
| チュートリアルの都市 | コア(読むだけ) | コアに同梱 |
| 地形エディタの作業コピー | Tauri | ユーザーフォルダ |
| 音量・ディスプレイ番号・言語・チュートリアル完了など | Tauri | Tauri の設定 |
| 3D 画面の表示ディスプレイ・解像度 | Unity | Unity プレイヤーが終了時に記録する |

コアはシミュレーションに関わるデータだけを管理し、UI・操作系の設定は Tauri が持つ。コアが管理するファイルは、UI もコアの API を通して扱う。

## ユーザーフォルダ

ユーザーごとのデータは、OS のアプリデータ領域の `UrbanGenesis/` に置く。コアと Tauri は同じ規則でこの場所を決める(Windows は OS の既知フォルダより環境変数を優先する)。規則がずれると、UI が開くセーブフォルダとコアの保存先が食い違う。開発版と製品版で保存先は変わらない。

| OS | 場所 |
| --- | --- |
| Windows | `%LOCALAPPDATA%\UrbanGenesis\`(`LOCALAPPDATA` が無ければ `%APPDATA%\UrbanGenesis\`) |
| macOS | `~/Library/Application Support/UrbanGenesis/` |
| Linux / Steam Deck | `$XDG_DATA_HOME/UrbanGenesis/`(未設定なら `~/.local/share/UrbanGenesis/`) |

```
UrbanGenesis/
├── saves/            セーブデータ … コア
├── scenarios/        自作シナリオ … コア
├── profile.bin       プレイヤーのプロフィール … コア
└── terrain_editor/   地形エディタの作業コピー … Tauri
```

プロフィールは都市とは独立で、どのセーブを開いていても共有する([達成クエスト](../economics/24_達成クエスト.md))。暗号化されており、平文の JSON を置いても読み込まれない。地形エディタの作業コピーはウィンドウ間で初期データを渡すためだけのもので、シナリオへの反映はコアの API を通す([地形形状](../geometries/D_地形形状.md))。

## Steam が管理するシナリオ

コミュニティと DLC のシナリオは Steam が置き・更新するフォルダにあり、ゲームは読むだけで書き込まない。一覧では自作シナリオと合わせて表示する([シナリオ制作と配布](シナリオ制作と配布.md))。

```
<インストール先>/dlc/{pack_id}/{stem}.cg                    DLC のシナリオ(公式署名つき。多くは暗号化されている)
steamapps/workshop/content/<AppID>/{item_id}/{stem}.cg     コミュニティのシナリオ
```

DLC と Workshop のフォルダは Tauri のストア連携がストアから得てコアへ渡し、コアは自分の位置から推測しない。Steam の外から起動したときは渡されず、コミュニティと DLC のシナリオは一覧に出ない。

## 同梱するデータ

ゲームは標高マップを同梱しない。地形はシナリオ・セーブ(`.cg`)が自分で持ち、新しい地形は利用者が任意の場所に置いた標高ファイルをシナリオ管理で取り込んでシナリオにする(取り込んだファイルはゲームが保管しない)。同梱するのはチュートリアルの都市だけで、シナリオと同じ形式で開くが、シナリオの一覧には出さない([チュートリアル基盤](チュートリアル基盤.md))。

公開リポジトリ直下の `version.json` が、Tauri・Unity 共通のフロントの版と IPC の契約番号を定め、`tauri/tools/sync-version.mjs` が配布設定と Unity の定数へ写す([バージョニングと互換性](バージョニングと互換性.md))。
