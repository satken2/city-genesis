# サウンドシステム

都市空間に連動する音は Unity、BGM と UI の音は Tauri が鳴らす。音は都市の状態を表す演出で、再生処理がシミュレーションやセーブデータを変えることはない。

| 系統 | 担当 | 掛かる音量設定 |
| --- | --- | --- |
| 都市の環境音・雨音 | Unity `CameraAmbience` | master × sfx |
| 工事音・車両の走行音・完成や解体などの単発音 | Unity の各音響コンポーネント | master × sfx |
| BGM | Tauri のコックピットが持つ `BgmManager` | master × bgm |
| UI の単発音・クエスト達成のファンファーレ | Tauri の共通の再生処理(`utils/playSound.ts`)・対象のウィンドウ | 再生処理では設定音量を掛けない |

## Unity の音

Unity の音響コンポーネントは `AppRoot` が生成し、音量は各コンポーネントが持つ AudioSource に掛ける(AudioListener 全体の音量は変えない)。環境音は発音位置を持たないループを重ね、カメラの地表からの高さと天気に応じて層ごとの音量を変える。工事音と走行音は発音体の位置から鳴る3Dのループで、全ての現場・車両に音源を持たせず、数に上限のある音源をカメラに近い発音体へ割り当てる。車両の位置と速度は[走行描画](../geometries/O_車両の走行描画.md)が知らせる。

## BGM

BGM はコックピットの `BgmManager` が一元管理し、ゲーム内の月に対応する曲を鳴らす(対応表は `utils/bgm.ts`)。ロード中・セッション外・エポック実行の演出中は止める。演出中も止めるのは、実行中にコアの日付が進み、月の曲が演出の途中で切り替わらないようにするためである。

画面や演出は、Tauri のグローバルイベントで通常の選曲を上書きできる。

| イベント | データ | 意味 |
| --- | --- | --- |
| `bgm:request` | `{id, track, priority}` | ID ごとに要求を持ち、優先度の最も高い曲を鳴らす。同じ ID の要求は置き換える。`track` が `none` なら止める |
| `bgm:release` | `{id}` | その ID の要求を取り下げ、残りの要求か通常の選曲へ戻る |

## 音量設定の同期

コックピットが、設定の音量を IPC の `ambience:volume`(`{volume}`。master/100 × sfx/100 を0〜1で表す)で Unity へ送る。BGM の音量は Tauri の中で掛け、Unity へは効果音系統の音量だけを送る。送るのは設定の読み込み・変更時と、Unity の起動・再接続を知らせる `graphic-reconnected` の受信時で、周期的には送らない。Unity は音量を受け取るまで無音とし、受け取った値を後から購読する音響コンポーネントにも渡す。

## 音声素材の配置

| 担当 | 配置 | 形式と読み込み |
| --- | --- | --- |
| Unity | `unity/Assets/Resources/Audio/` | Ogg Vorbis。長い環境音はストリーミング、複数の位置で鳴らす工事音・走行音はメモリ上に圧縮して持つモノラルで取り込む |
| Tauri | `tauri/src/assets/sounds/` | Ogg Opus を基本とし、音声ファイルを import して得た URL で鳴らす |

Tauri でソースのパス文字列を直接再生に渡すと、バンドルの対象から外れて配布ビルドで鳴らなくなるので、import を通す。Unity 用のループ加工・音量調整・圧縮の条件は `tauri/tools/prepare_unity_audio.py` と各素材フォルダの README で管理する。素材の出所の記録は[素材クレジット管理](素材クレジット管理.md)に従う。
