# サウンドシステム

## 責務と構成

音声はTauriのWebView2で再生する。Unityは天候とカメラの地表相対高度を通知し、Tauriが環境音を混ぜる。経済シミュレーション・都市のセーブデータ・共有マスターには音響状態を追加しない。

| 系統 | 所有・実装 | 再生条件 | 音量 |
| --- | --- | --- | --- |
| BGM | Cockpitの`BgmManager`（`src/utils/bgm.ts`） | セッションが存在し、ロード中ではないとき | master × bgm |
| 環境音・雨音 | Cockpitの`useWeather`が所有する`WeatherAudio`（`src/utils/weatherAudio.ts`） | HUDセッションが有効なとき | master × sfx × 各レイヤーのゲイン |
| 単発効果音 | 各呼び出し元の`playSound`（`src/utils/playSound.ts`） | ボタン操作・通知など | 現状は共通ヘルパで設定音量を適用しない |

BGMと環境音はCockpitだけで生成する。他のHUDやポップアップに同じ管理クラスを置くと多重再生になる。環境音はエポックの実行待ちやカメラ静止中にも流れ続け、天候通知や高度通知で音源の再生位置を先頭に戻さない。

## 環境音のレイヤー

| レイヤー | ファイル（`src/assets/sounds/weather/`） | 動作 |
| --- | --- | --- |
| ベース | `city-base.opus`（Freesound 808956） | プレイ中は常時ループ。高所ではこの環境音だけ、低所でも小さく残す |
| 地表近景 | `city-ambience.opus`（242539） | 地表に近づくほど増え、地表付近ではベースより強くなる |
| 霧雨 | `drizzle.opus`（442296） | 天候のrain=1で追加 |
| 雨 | `rain.opus`（515839） | 天候のrain=2で追加 |
| 大雨 | `heavy-rain.opus`（346562） | 天候のrain=3で追加 |

「高所ではベースだけ」は環境音2層の関係を表す。雨天の雨音とBGMは独立して重なる。雨量の正はUnityの`WeatherPreset.Rain`で、天候を手動選択した場合も同じ経路を通る。

## 地表への接近とミックス

Unityの`CameraAmbience`は`AppRoot`で生成し、メインカメラ直下の地形標高を既存の`Utils.GetGroundHeight(position)`から取得する。カメラのYから地形標高を引いた相対高度を使うので、高い山の上でも地表に近ければ近景音が聞こえる。建物の屋根や視線先までの距離は使わない。

高度の調整箇所はTauriの`weatherAudio.ts`の`NEAR_HEIGHT_METERS`と`FAR_HEIGHT_METERS`。現行値は25mと250mである。

`t = clamp((250 - 高度) / (250 - 25), 0, 1)`、接近度`p = t² × (3 - 2t)`で滑らかに補間する。時間方向にも50msごとにゲインを最大1/30ずつ変え、急なカメラ移動でも音量が跳ねないようにする。

| 相対高度 | 接近度p | ベースゲイン | 近景ゲイン |
| --- | --- | --- | --- |
| 250m以上 | 0 | 0.50 | 0 |
| 137.5m | 0.5 | 0.35 | 0.35 |
| 25m以下 | 1 | 0.20 | 0.70 |

ベースは`0.5 - 0.3p`、近景は`0.7p`。雨音のゲインは霧雨0.4・雨0.6・大雨0.8。これらは音量設定を掛ける前の値で、音源は共通の目標ラウドネスへ正規化している。近景音量が0の間はその音源を一時停止し、再び近づくと停止位置から再開する。

## IPCと復帰

| イベント | 方向 | データ |
| --- | --- | --- |
| `weather:state` | Unity → Cockpit | `rain`を含む現在の天候。天候名・候補の契約は[天気と環境光](../geometries/U_天気と環境光.md)を参照 |
| `ambience:camera` | Unity → Cockpit | `{height_above_ground: number または null}`。単位m、0以上。カメラ不在・ゲーム外・無効な計測値ではnull |

`CameraAmbience`は描画用の時間で0.2秒ごとに高度を送る。最大5回/秒で、都市オブジェクトの全走査はしない。Rustの`ipc.rs`がCockpitだけへ中継し、`WeatherAudio`が直接受ける。Reactの天候表示を高度通知のたびに再描画しない。

定期通知なのでTauriが後から起動しても復帰する。2秒以上届かなければ近景音をフェードアウトし、ベースへ戻す。高度未取得時も同様。無効化時はUnityがnullを通知し、ゲーム終了時はTauri側の全環境音を停止する。天候シェーダーが無効でもカメラ高度の送信は動く。

## 音量・ループ・終了処理

設定は`loadAppSettings`で読み、`settings-updated`を購読する。環境音の音量は0〜100を0〜1に変換したmasterとsfxの積で、ミュートはフェードを待たず即時反映する。初回設定の取得が遅れた場合、先に受け取った新しい設定を上書きしない。

音源は`import`で得たURLを`HTMLAudioElement`に渡し、ループ再生する。長い録音全体をWeb AudioのPCMバッファへ展開しない。未再生の音源は`preload=none`。自動再生が拒否された場合は2秒間隔で再試行し、同一音源の再生開始Promiseを重複させない。破棄時はタイマー・購読・音源を解放し、遅れて再生が完了しても停止する。

## BGMと単発効果音

`BgmManager`は通常曲`default`を使い、月に対応する曲があれば切り替える（現行は4月の`04`）。`bgm:request {id, track, priority}`で優先曲を登録し、`bgm:release {id}`で解除する。優先度が高い要求を採用し、track=`none`は停止。結果画面向けの`result`も曲テーブルにある。

単発用の`playSound(src)`はURLごとに音源をキャッシュし、呼び出しで再生位置を0へ戻す。同一音の重複再生には使わず、長時間ループは`WeatherAudio`で管理する。

## 素材と圧縮

既定形式はOgg Opus。環境音は64kbps、モノラルの大雨は40kbps。`tauri/tools/prepare_weather_audio.py`はWAV原本から先頭・末尾2秒の等電力クロスフェード、-24 LUFS・最大-3dBTPの音量調整、Opus圧縮を行う。原本をリポジトリへコピーしない。

新しいベースの原本は16.108604秒・4,639,906 bytes。加工後は約14.11秒・100,583 bytes（約98%削減）。5音源の合計は4,983,929 bytes。音源の出所・作者・加工内容は`credits.ts`と音源フォルダのREADMEに記録する。

```powershell
# tauriディレクトリで実行。--trackを省略すると全環境音を再生成する。
python tools/prepare_weather_audio.py --source C:/Users/User/Downloads --ffmpeg <ffmpeg.exeの絶対パス> --track city-base
```

[新しいベース音の配布元](https://freesound.org/people/klankbeeld/sounds/808956/)はklankbeeld作、[CC BY 4.0](https://creativecommons.org/licenses/by/4.0/)（2026-09-13確認）。従来の近景音と大雨もCC BY 4.0、霧雨と雨はCC0。詳細は[素材クレジット管理](素材クレジット管理.md)を参照。

## 検証

- `node tools/check_weather_audio.mjs`: 高所・中間・低所ミックス、通知途絶、無効高度、音量・雨音切替、非同期競合と終了処理。
- `unity/Tests/Weather/run-unity.ps1`: 本編C#のビルドと、地形標高との差・無効値・送信停止のUnity検証。
- `npx tsc --noEmit -p tsconfig.json`と`npx vite build`: 型と音源のバンドルを検証。
- 本編で平地・高地の両方を上下移動し、地表付近で近景音が優勢になること、雨音とのバランス、ミュート、終了・再開を試聴する。
