# 気候設定

都市の気候は、名称と12か月分の天気の出現割合・平均気温・降水量・日照で構成される。Coreが天気の種類と気候プリセットを管理し(プリセットはケッペンの気候区分ごとに1つで、表示名の末尾に区分記号を付ける)、都市とシナリオはコピーした実データを保存する。プリセットのIDや参照は保存しない。名称もコピーした通常のテキストであり、編集した数値から気候名を自動判定しない。風速は気候に含めず、気候によらずエポックごとに決まる（[生産活動](../economics/9_生産活動.md#気候による生産変動)）。

## パネル

Cockpitの確定気候（気温・降水量・日照・風速）の表示全体が一つのボタンになり、シナリオ作成モードでは `climate_settings` ウィンドウ、それ以外のモードでは `climate_effects` ウィンドウを開く。

### 気候設定ウィンドウ

左側には気候名の入力欄と12か月の割合メーターを置く。各色は一種類の天気を表し、境界のドラッグは両隣の割合を交換する。選んだ月の数値欄では0%の天気も編集でき、残りの天気への比例配分で合計100%を保つ。

右側のプリセット選択は、名称と左右すべての月別値を編集の初期値としてコピーする。雨温図は気温を折れ線、降水量を棒、日照を棒に重ねた縦線で描き、それぞれ独立した単位の軸を持つ。凡例で編集する項目を選び、月ごとの点を上下にドラッグする。選んだ月の数値入力でも調整できる。

編集はウィンドウ内の下書きに保持し、「適用」でまとめてCoreへ送る。キャンセルや閉じる操作では都市を変更しない。適用後は既存の `session:reload` 通知でUnityに再取得させる。

### 気候ウィンドウ

上の「今月の平均気候」カードに、確定気候の気温・降水量・日照強度・風速をCockpitと同じアイコンと表記で横に並べる。

その下の「気候による施設の生産効率」の表は、気候の条件を持つ施設ごとに確定気候での生産倍率を並べる。対象は、マスターで最大出力に必要な日照・降水・風速か適温範囲を1つ以上設定したバリアントで、バリアントID順に並ぶ。施設名の右の生産効率は、[生産活動](../economics/9_生産活動.md#気候による生産変動)の気候倍率そのものを共通のメーターと割合で示す。続く気温・降水量・日照強度・風速の列はその要素による倍率で、生産効率はそれらの積である。その施設の生産を左右しない要素のセルは「-」、気候が未確定の間は値を「—」で表示する。

気候の値と倍率は1回の取得でCoreから受け取り、倍率はCoreが生産と同じ計算で返す。UIでは計算しない。ウィンドウを開いたときに取得する。

## データ契約

| API・フィールド | 内容 |
| --- | --- |
| `GET /api/v1/master/weather` | 天気IDをキーとしたマスター。`display_name` は既存のマスター翻訳処理で選んだ表示名 |
| `GET /api/v1/master/climates` | プリセットIDをキーとしたマスター。`display_name` は翻訳済みの表示名、`months` は12か月の初期値 |
| `GET /api/v1/city/` の `city.climate` | `name: string` と `months` を持つ都市の実データ |
| `PUT /api/v1/city/climate` | シナリオ作成モードで都市の気候を全置換する。本文は `city.climate` と同じ構造 |
| `GET /api/v1/city/climate-effects` | `climate` に確定気候の `temperature`(°C)・`precipitation`(月相当のmm)・`sunlight`(%)・`wind_speed`(m/s)、`variants` に気候の条件を持つバリアントごとの `variant`・`factors`・`factor` を返す。`factors` はその施設を制限しうる要素だけを `climate` と同じキーで持ち、値は要素ごとの倍率(0〜1)。`factor` はその積。気候が未確定なら気候の値と倍率はすべて `null` |
| シナリオの地形・紹介情報APIの `climate` | 都市と同じ実データ。地形だけを編集するときもカスタム気候を保持する |
| ゲーム開始時の `climate` 選択 | プリセットIDを送った場合はコピーして置換する。省略・`null` はシナリオの実データを保持する |

`months` は1月から12月の順で、各月は次の値を持つ。

| フィールド | 単位・制約 |
| --- | --- |
| `temperature` | 平均気温、°C。有限の数値 |
| `precipitation` | 月間降水量、mm。0以上の有限の数値 |
| `sunlight` | 日照強度、%。0〜100の有限の数値 |
| `weather` | 全天気IDの出現時間の割合。各値は0〜100の整数、合計100 |

Coreが月別平均値を[生産用のエポック気候](../economics/9_生産活動.md#気候による生産変動)の基準に使い、Unityが同じ月の出現割合を[描画中の天気](../geometries/U_天気と環境光.md)に使う。設定を適用しても確定済みの `epoch_temperature`・`epoch_precipitation`・`epoch_sunlight` は変更しない。Unityの現在の天気と時刻も再抽選せず、更新した割合は次の自然な遷移から使う。
