# 建物メッシュの生成

## 概要

バックエンドの Agent データから、建物の外装メッシュを組み立てて配置する仕様。

建物の3Dモデル生成方法は、`agent_master` に定義された **`model_type`** によって分かれる。`model_type` は3Dモデルの組み立て方式を表すものであり、建物の底面ポリゴンの形状（[[C_建物形状]]）とは全く別軸の話である。

本ドキュメントには**すべての生成方式に共通する仕様**（データフロー、底面形状、パーツの命名規則とフォールバック、壁・角の配置、地面パネル・基盤・フェンス、塔屋・エントランス、結合とコライダー）を記述する。方式ごとの固有ロジックは別ドキュメントに分ける。

| model_type               | 生成方式                   | 詳細                                                                                                                      |
| ------------------------ | ---------------------- | ----------------------------------------------------------------------------------------------------------------------- |
| **MODEL_MODULAR_FLAT**   | モジュラーパーツ組み立て + 平屋根     | [[F1_モジュラー建物のメッシュ生成]] §1                                                                                                |
| **MODEL_MODULAR_HOUSE**  | モジュラーパーツ組み立て + 住宅風三角屋根 | [[F1_モジュラー建物のメッシュ生成]] §2                                                                                                |
| **MODEL_MODULAR_GABLE**  | モジュラーパーツ組み立て + 切妻屋根    | [[F1_モジュラー建物のメッシュ生成]] §3                                                                                                |
| **MODEL_MODULAR_GROUND** | モジュラーパーツ組み立て（地面用途）     | [[F2_地面アセットのメッシュ生成]]。建物本体は描画せず、フェンス・地面パネル・タイルオブジェクトを土地区画の形状に沿って配置する                                                     |
| **MODEL_PREBUILT**       | 既成パーツ組み立て              | [[F3_既成建物のメッシュ生成]]。電波塔やオブジェ、銅像、観覧車など、通常の建物とは全く異なる形状の建物に適用する                                                             |
| **MODEL_PORT**           | 厚みのある板（岸壁）をプロシージャル生成   | [[F4_港湾岸壁のメッシュ生成]]。海岸土地区画（PARCEL_SHORE）の港湾（BUILDING_PORT）用。モジュラーの壁・角パーツは使わない                                            |
| **MODEL_MASHUP**         | 複数のサブ建物を既成パーツで配置       | [[F6_マッシュアップ建物のメッシュ生成]]。学校（校舎＋体育館）のような複数棟の複合施設用。バックエンドが土地区画を8m×8mセルに分割して決めた配置計画（`sub_buildings`）に従い、各棟を既成パーツと同じ規則で積み上げる |

model_type とは別軸で、status が `STATUS_CONSTRUCTING` の建物はすべて「工事現場」メッシュに差し替わる（[[F5_工事中建物のメッシュ生成]]）。分岐は model_type 分岐より先にある。

## 1. データフロー

```
バックエンド API  ──→  BuildingSummary
                          ├─ polygon         底面の頂点列（center_point 基準の相対座標）
                          ├─ center_point    ワールド座標
                          ├─ floors          階数
                          ├─ variant         建物バリアント
                          ├─ visual_variant  外観バリアント1（0.0-1.0）
                          ├─ visual_variant2 外観バリアント2（0.0-1.0）
                                │
                                ▼
                     BuildingMeshBuilder.Generate()
                          │
                          ├─ status が STATUS_CONSTRUCTING → ConstructingBuildingMeshBuilder（F5）
                          │
                          ├─ model_type で分岐
                          │    ├─ MODEL_MODULAR_* → ModularBuildingMeshBuilder（F1 / F2）
                          │    │                      ├─ 1. ModularBodyBuilder で壁・地面を生成
                          │    │                      ├─ 2. FlatRoofBuilder / HouseRoofBuilder / GableRoofBuilder で屋根を生成
                          │    │                      ├─ 3. 塔屋を配置
                          │    │                      └─ 4. 結合・ベイク
                          │    ├─ MODEL_PREBUILT    → PreBuiltBuildingMeshBuilder（F3）
                          │    ├─ MODEL_PORT        → PortBuildingMeshBuilder（F4）
                          │    ├─ MODEL_MASHUP      → MashupBuildingMeshBuilder（F6）
                          │    └─ その他             → BuildingMeshBuilder.GenerateSimpleBuilding（白い箱）
                          │
                                ▼
                     BuildingMeshResult (Mesh + Material[] + ColliderMesh)
```

## 2. 底面形状

### 2.1 polygon データ

バックエンドの Agent データに含まれる `polygon` を使用する。
これは `float[][]`（頂点の配列）で、各頂点は Agent の `center_point` からの相対座標 `[x, y]` である。

### 2.2 頂点の並び順

polygon の頂点は **反時計回り（CCW）** に正規化する。
符号付き面積が負の場合は配列を反転させる。

### 2.3 壁・角の番号付け

底面ポリゴンの頂点インデックスをそのまま壁・角の位置番号に対応させる。
頂点 0 = 位置 1、頂点 1 = 位置 2、… とする。

N辺ポリゴンのとき：

| 位置番号 | 壁（辺） | 角（頂点） |
|---|---|---|
| 1 | 辺 0（頂点0 → 頂点1） | 頂点 0 |
| 2 | 辺 1（頂点1 → 頂点2） | 頂点 1 |
| 3 | 辺 2（頂点2 → 頂点3） | 頂点 2 |
| … | … | … |

壁の位置 n に対応する辺は `edge_index = n − 1`。
角の位置 n に対応する頂点は `vertex_index = n − 1`。

### 2.4 ワールド配置

生成されたメッシュの頂点座標はすべて `center_point` 基準の相対座標とする。
配置時に `center_point` のワールド座標と接地高を足して最終位置とする。

接地高（建物の接地面の標高）は model_type によって異なる。

- **MODEL_MODULAR_FLAT / HOUSE / GABLE** — 所属する土地区画の基準標高（`parcel.altitude`）。
  傾斜地でも建物は水平面に接地し、谷側にできる地形との隙間は基盤（§8.2）が埋める。
  区画が取得できない場合は `center_point` 位置の地形標高にフォールバックする。
- **それ以外（MODEL_MODULAR_GROUND / MODEL_PREBUILT / MODEL_PORT / MODEL_MASHUP）** — `center_point` 位置の地形標高。
  MODEL_MASHUP では、さらに各サブ建物が自分の配置座標の地形標高へ個別に接地する（[[F6_マッシュアップ建物のメッシュ生成]] §4）。

## 3. パーツの配置と命名規則

### 3.1 フォルダ構成

パーツは FBX モデルを Unity プレハブ化したものを `Assets/Resources/Models/` に配置する。
元の FBX ファイルは `Assets/Models/` に同じ構成で置く。

`ModelManager` がリソースパスをキーとしてキャッシュする。

```
Assets/Resources/Models/
├── Buildings/
│   ├── b{bd_type}/
│   │   └── {threshold}/             # 閾値フォルダ（0, 250, 500, 750 等）
│   │       ├── base-w1.prefab       # 1階壁 位置1
│   │       ├── base-w2.prefab       # 1階壁 位置2
│   │       ├── base-c1.prefab       # 1階角 位置1
│   │       ├── base-c2.prefab       # 1階角 位置2
│   │       ├── mid-w1.prefab        # 中層壁 位置1
│   │       ├── mid-c1.prefab        # 中層角 位置1
│   │       ├── top-w1.prefab        # 屋上壁 位置1
│   │       ├── top-c1.prefab        # 屋上角 位置1
│   │       ├── fence-w1.prefab      # フェンス壁 位置1（土地区画ポリゴンに沿って配置）
│   │       ├── fence-c1.prefab      # フェンス角 位置1（ボーンで角度変形／Y方向スケールなし）
│   │       ├── ceil.prefab          # 屋上マテリアル用
│   │       ├── floor.prefab         # 地面マテリアル用
│   │       ├── generic-wall.prefab  # 無地の壁マテリアル用（切妻屋根の妻壁など）
│   │       ├── tile.prefab          # タイルオブジェクト（MODEL_MODULAR_GROUND 専用）
│   │       ├── roofprop.prefab      # 塔屋
│   │       ├── entrance.prefab      # エントランス（前面の辺の中央・地面レベル）
│   │       └── port_crane.prefab    # 荷役クレーン（MODEL_PORT 専用。水際に実寸配置）
│   ├── a{agent_variant}/
│   │   └── {threshold}/
│   │       ├── base-prebuilt.prefab
│   │       ├── mid-prebuilt.prefab
│   │       ├── top-prebuilt.prefab
│   │       ├── mashup-{model_prefix}-base-prebuilt.prefab   # マッシュアップのサブ建物（MODEL_MASHUP 専用）
│   │       ├── mashup-{model_prefix}-mid-prebuilt.prefab
│   │       └── mashup-{model_prefix}-top-prebuilt.prefab
│   └── common/                      # 全建物共通の標準パーツ（工事中表示用）。suffix フォルダなし
│       ├── scaffold-wall.prefab       # 足場の辺パーツ
│       ├── scaffold-corner.prefab     # 足場の角パーツ（ボーンで角度変形）
│       ├── crane-base.prefab          # クレーン最下段
│       ├── crane-mid.prefab           # クレーン繰り返しセグメント
│       ├── crane-top.prefab           # クレーン頂部（実寸・スケールなし）
│       └── ceil.prefab                # 施工済み階の天面パネル用マテリアル
└── Paths/
    └── p{path_variant}/
        ├── body.prefab
        ├── line.prefab
        ├── sidewalk.prefab
        └── tree.prefab
```

### 3.2 パスの構成要素

建物パーツのリソースパス：

```
Models/Buildings/{prefix}/{threshold}/{partName}
```

| 構成要素          | 値                             | 説明                                                        |
| ------------- | ----------------------------- | --------------------------------------------------------- |
| **prefix**    | `b{bd_type}` または `a{variant}` | `AgentModelConfig` に定義があれば `a{variant}`、なければ `b{bd_type}` |
| **threshold** | `0`, `250`, `500`, `750` …    | 外観バリアントの閾値フォルダ                                            |
| **partName**  | `base-w1`, `mid-c2` 等         | レベル・種類・位置番号をハイフン結合                                        |

partName の構成：

| 構成要素         | 値                              | 説明                  |
| ------------ | ------------------------------ | ------------------- |
| **level**    | `base` / `mid` / `top` / `fence` | 1階・中層・屋上・フェンス       |
| **type**     | `w` / `c`                      | 壁（wall）または角（corner） |
| **position** | `1`, `2`, `3`, `4` …            | ポリゴン頂点インデックス + 1    |

位置番号を持たないパーツ：

```
roofprop         塔屋（§10）
entrance         エントランス（前面の辺の中央・地面レベル。§11）
ceil             屋上マテリアル用
floor            地面マテリアル用
generic-wall     無地の壁マテリアル用（切妻屋根の妻壁。[[F1_モジュラー建物のメッシュ生成]] §3）
tile             タイルオブジェクト（[[F2_地面アセットのメッシュ生成]] 専用）
port_crane       荷役クレーン（[[F4_港湾岸壁のメッシュ生成]] §6 専用。水際に実寸スケールなしで並べる）
scaffold-wall    足場の辺パーツ（工事中表示専用。[[F5_工事中建物のメッシュ生成]] §4）
scaffold-corner  足場の角パーツ（工事中表示専用。[[F5_工事中建物のメッシュ生成]] §4）
crane-base       クレーン最下段（工事中表示専用。[[F5_工事中建物のメッシュ生成]] §5）
crane-mid        クレーンの繰り返しセグメント（工事中表示専用）
crane-top        クレーン頂部（工事中表示専用・実寸スケールなし）
```

工事中表示専用パーツ（scaffold-\* / crane-\*）は、通常の prefix（`a{variant}` / `b{bd_type}`）に加えて、
全建物共通の**標準パーツ置き場 `Models/Buildings/common/`** へのフォールバックを持つ（[[F5_工事中建物のメッシュ生成]] §2）。

マッシュアップ建物（MODEL_MASHUP）のサブ建物パーツは、`subbuilding_master` の `model_prefix` を
名前に埋め込んだ `mashup-{model_prefix}-{base|mid|top}-prebuilt` という動的な命名を用いる
（[[F6_マッシュアップ建物のメッシュ生成]] §2）。

道路パーツのリソースパス：

```
Models/Paths/p{path_variant}/{partName}
```

partName: `body`, `line`, `sidewalk`, `tree`

### 3.3 命名例

```
Models/Buildings/b16/500/base-w1       1階壁1、閾値 500
Models/Buildings/b16/500/base-c1       1階角1
Models/Buildings/b16/0/mid-w1          中層壁1、閾値 0
Models/Buildings/b16/0/mid-c1          中層角1
Models/Buildings/b16/0/top-w1          屋上壁1
Models/Buildings/b16/0/top-c1          屋上角1
Models/Buildings/b16/500/roofprop      塔屋
Models/Buildings/b16/500/ceil          屋上マテリアル用
Models/Buildings/a2101/0/base-prebuilt  既成建物ベース
Models/Buildings/b16/0/tile             タイルオブジェクト（MODEL_MODULAR_GROUND 専用）
Models/Paths/p1/body                   道路ボディ
```

### 3.4 パーツの総数

建物本体（地上）のパーツは、位置番号が 1〜4 の場合、1つの閾値フォルダにつき最大 28 種類：

| 種類 | 数 | 説明 |
|---|---|---|
| 1階壁 (base-w1〜4) | 4 | 1階の各辺 |
| 1階角 (base-c1〜4) | 4 | 1階の各頂点 |
| 中層壁 (mid-w1〜4) | 4 | 中層の各辺 |
| 中層角 (mid-c1〜4) | 4 | 中層の各頂点 |
| 屋上壁 (top-w1〜4) | 4 | 屋上の各辺 |
| 屋上角 (top-c1〜4) | 4 | 屋上の各頂点 |
| 屋上面マテリアル (ceil) | 1 | ポリゴン塗りつぶし用 |
| 塔屋 (roofprop) | 1 | 屋上装飾 |
| エントランス (entrance) | 1 | 前面の辺の中央・地面レベルの装飾 |
| 無地の壁材 (generic-wall) | 1 | プロシージャルな壁面（妻壁）のマテリアル用 |
| **合計** | **28** | |

地面アセット（`MODEL_MODULAR_GROUND`）や地面パネルまわりのパーツは上記とは別枠で、以下が加わる：

| 種類 | 数 | 説明 |
|---|---|---|
| フェンス壁 (fence-w1〜4) | 4 | 土地区画の各辺 |
| フェンス角 (fence-c1〜4) | 4 | 土地区画の各頂点 |
| 地面パネル材 (floor) | 1 | 地面塗りつぶし用 |
| タイルオブジェクト (tile) | 1 | 畑・庭など（`MODEL_MODULAR_GROUND` 専用） |

## 4. 外観バリアントの選択

### 4.1 バリアント番号の計算

`visual_variant`（0.0〜1.0）を 1000 倍して整数化する。

```
variant_number = floor(visual_variant × 1000)     → 0 〜 1000
```

### 4.2 閾値フォルダの選択ルール

閾値フォルダ名（`0`, `250`, `500`, `750` 等）は閾値を表す。
自身の `variant_number` 以下で最も大きい閾値フォルダを選ぶ。
閾値 `0` のフォルダは必ず用意する。

選択方法：標準閾値候補（0, 100, 200, ..., 1000）の中から `mid-w1` パーツが存在するものを探し、`variant_number` 以下で最大のものを選ぶ。

**例：** `variant_number = 600`、フォルダ `0`, `250`, `500`, `750` が存在 → **500** を選択。

`MODEL_PORT` は `visual_variant` を岸壁の幾何パラメータとして消費するため、この選択を行わず閾値 `0` のフォルダを使う（[[F4_港湾岸壁のメッシュ生成]] §5）。

`MODEL_MASHUP` は建物本体の壁パーツ（mid-w1）を持たないため、この共通ルールではなく
**サブ建物パーツごとに独立して**同じ閾値走査（variant_number 以下で存在する最大閾値）を行う
（[[F6_マッシュアップ建物のメッシュ生成]] §2）。

### 4.3 レベル間のバリアント整合性

閾値フォルダが決まると、建物全体（1階・中層・屋上）で同じフォルダからパーツを取得するため、レベル間の閾値は自動的に一致する。

1. 中層壁1（`mid-w1`）が存在する閾値フォルダを確定 → これが建物全体の閾値になる
2. 該当フォルダに `mid-w1` が存在しない場合：
   - `MODEL_MODULAR_GROUND` 以外 → **白い箱フォールバック**
   - `MODEL_MODULAR_GROUND` → suffix を `0` とし、敷地装飾の描画を継続する（[[F2_地面アセットのメッシュ生成]] §1）

### 4.4 位置番号のフォールバック

指定位置のパーツがない場合は **位置1** にフォールバック。
壁3（`w3`）がない → 壁1（`w1`）を使う。

## 5. フォールバック階層

すべて同一の閾値フォルダ内でフォールバックする。

**壁パーツ（w）** はレベルをまたいでフォールバックする。

```
指定レベル・指定位置のパーツ（例: top-w3）
    ↓ ない場合
位置1のパーツ（同じレベル）: top-w1
    ↓ ない場合
中層レベルの同じ位置のパーツ: mid-w3
    ↓ ない場合
中層レベルの位置1のパーツ: mid-w1
    ↓ ない場合
白い箱（底面ポリゴンを高さまで押し出した直方体）
```

**角パーツ（c）** はレベルをまたぐフォールバックを行わない。角はレベル単位のオプトインであり、
用意されていないレベルでは角を描画せず、壁パーツを辺の端まで敷き詰める
（角の張り出し量が 0 になる。§6.3・§7.6）。

```
指定レベル・指定位置のパーツ（例: top-c3）
    ↓ ない場合
位置1のパーツ（同じレベル）: top-c1
    ↓ ない場合
角を描画しない（壁パーツが辺いっぱいに敷かれる）
```

## 6. 壁パーツの配置

### 6.1 基本考え方

壁パーツは辺に沿って並べる。1つの辺に複数パーツが並ぶとき、隙間ができないように X 方向（辺の長さ方向）に引き伸ばして埋める。

### 6.2 パーツの座標系と寸法

壁パーツは以下を仮定する：

- ローカル X 軸 = 辺の長さ方向、Y 軸 = 高さ方向、Z 軸 = 外壁の奥行き
- 原点 = 片端の下端角

パーツのメッシュバウンディングボックスから元の寸法を取得する。

### 6.3 スケールと配置の方針

壁パーツの奥行き（Z）はスケールせず、モデリング時の実寸（メートル単位）のまま使用する。幅（X）は下記の敷き詰め調整のぶんだけ伸縮する。

高さ（Y）は**階のレベルによって扱いが分かれる**。

| 階のレベル | Yスケール |
| --- | --- |
| 1階（base） | **なし（著作高さのまま）** |
| 中層（mid） | 階高（`height_per_floor`）に合わせて**Y方向のみ**スケール |
| 最上階（top） | **なし（著作高さのまま）** |

1階と最上階はパーツの著作高さがそのまま描画高さになる。階高が 4m でもパーツが 15m で著作されていれば **15m の高さで描画される**。中層だけは、積む枚数で建物の高さを調整する「詰めもの」の役割を持つため階高にそろえる。

**この判定は「階のレベル」で行う。** 1階に `base-w1` が無く `mid-w1` へフォールバックした場合（§5）でも、その階は1階なのでスケールされない。最上階も同様である。

**スケールしないのはパーツの形状だけで、配置位置は変わらない**（§6.4）。1階のパーツが 1m しかなければ2階との間に 3m の隙間が空き、逆に 10m あれば2階のパーツに埋もれる。これは仕様であり、プログラムは補正しない。

敷き詰めの手順は次のとおり。

1. **有効長を求める** — 辺の全長から、両端の角パーツがその辺へ実際に張り出す長さ（§7.6）を差し引く。壁は**手前の角パーツが終わったところから始まり、次の角パーツが始まるところで終わる**。
2. **枚数を決める** — 有効長をパーツの著作幅で割り、**四捨五入**して敷き詰め枚数とする（最低1枚）。切り捨てにすると端数を必ず引き伸ばす方向にしか吸収できず、最大で 2 倍近くまで間延びしてしまうため、縮小側も使って歪みを抑える。
3. **スロットへ合わせ込む** — 有効長を枚数でちょうど割った幅を1スロットとし、X 方向スケールでパーツをスロット幅に合わせる。合計は常に有効長と厳密に一致するため、**はみ出しも隙間も生じない**。
4. **原点のずれを補正する** — 各ユニットは「メッシュの X 範囲がスロットに一致する」ように置く。幅の中央に原点があるパーツ（規格どおりのパーツ）ではスロットの中央に原点が来る。

ただし、辺の長さが両端の角パーツの張り出し合計以下の場合は、有効長が存在しないため壁パーツは配置しない。この場合、両端の角パーツのみを配置して隙間を埋める。

**寸法の警告**: XZ実寸が 0.3m 未満の壁・角パーツは、cm単位や 1×1 の単位スケールでエクスポートされた疑いが強いため警告ログを出す。パーツはスケールされないので、この場合そのまま極小サイズで描画される。実寸（1 Blenderユニット = 1m）で再エクスポートすること（[[I_建物パーツ作成マニュアル]]）。

各壁ユニットは、変換行列（位置・回転・スケール）をメッシュの全頂点に適用して配置する。
回転はモデルの X 軸を辺の方向に向ける。

### 6.4 階の配置位置と躯体の高さ

**パーツの配置位置は常に階高グリッドに乗る。** パーツの著作高さは配置に影響しない。

```
床面Y(n階) = n × height_per_floor
躯体の高さ  = floors × height_per_floor
```

屋根・塔屋の配置Yとコライダーの高さは、この躯体の高さを使う。

したがって、スケールしない1階・最上階（§6.3）では、パーツの著作高さと階高のズレがそのまま見た目に出る。

- **パーツが階高より低い** — 上の階との間に隙間が空く（階高 4m・`base-w1` が 1m なら 3m の隙間）
- **パーツが階高より高い** — 上の階のパーツに埋もれる（階高 4m・`base-w1` が 10m なら、2階のパーツは 4m の位置から始まるので1階のパーツと重なる）

いずれもプログラムは補正しない。パーツを階高に合わせるか、意図した見た目になるよう著作側で調整する。

1階・最上階で位置ごとに違う高さのパーツを置いた場合（`base-w1` が 4m、`base-w3` が 6m 等）も同様に、パーツはスケールされないため壁面の高さが揃わない。

## 7. 角パーツの配置と変形

### 7.1 基本考え方

角パーツは各頂点に1つ配置する。2つの辺ベクトルから内角を計算し、その角度に合わせてパーツを向ける。

角パーツはレベル単位のオプションである（§5）。そのレベルに角パーツが用意されていない場合は
角を描画せず、壁パーツが辺の端まで敷き詰められる（§7.6）。

### 7.2 内角の計算

角の頂点とその前後の頂点から2つの辺ベクトルを作り、符号付き角度から内角を求める。
CCW ポリゴンでは凸頂点の内角は 0°〜180°。
凹頂点（180°超）は警告しつつ処理を続行する。

### 7.3 向きの決定

2つの辺ベクトルの二等分線（bisector）方向に角パーツの正面を向ける。

### 7.4 ボーン変形（SkinnedMeshRenderer がある場合）

角パーツがボーンを2本持つ場合、90° を基準に作成されたモデルを任意の角度に変形できる。

ボーン構造：
- `Bone`（bones[0]）：左側の壁方向
- `Bone.001`（bones[1]）：右側の壁方向

変形の考え方：
- 90° からのズレ（angleDiff = 内角 − 90°）を求める
- 各ボーンを angleDiff の半分ずつ Y 軸周りに回転させる
- 左ボーンは +halfDiff、右ボーンは −halfDiff
- ボーンの開き角が内角と一致するように調整される

ボーン変形後のメッシュは `SkinnedMeshRenderer.BakeMesh()` でジオメトリを確定させる。
これは最終的なメッシュ結合（ベイク）とは別の、ジオメトリ準備の段階である。

### 7.5 静的メッシュ（ボーンなし）の場合

ボーンがない角パーツは 90° 専用。内角が 90° から離れていても変形せず、そのまま配置する。

### 7.6 スケールと、辺への張り出し量

角パーツは壁パーツと同じ規則でスケールする。アーム長（XZ）は常にモデリング時の実寸のまま使用し、高さ（Y）は中層（mid）の階だけ階高に合わせてY方向スケールする。1階・最上階の角パーツは著作高さのまま描画される（§6.3）。

壁パーツの配置開始・終了オフセット（§6.3 の「有効長」）は、**角パーツを実際に配置したときに、その辺の方向へどれだけ張り出すか**を測って決める。ローカル X/Z 軸のバウンディングボックスを見るのではなく、実配置と同じ回転・スケールを掛けた角パーツの全頂点を辺方向へ射影し、その最大値を採る。これにより

- アームがどちらのローカル軸向きで著作されていても正しい値になる
- 庇や胴差しのような、辺方向へ伸びる造作も張り出しに含まれる
- 角パーツが存在しない建物では張り出しが 0 になり、壁が辺いっぱいに敷かれる

ため、壁が角パーツにめり込んだり、角パーツから離れて隙間ができたりしない。

ボーン変形（§7.4）で角を開閉する場合も、アームは辺と一緒に回転するため張り出し量は変わらない。射影先には**バインドポーズ（内角90°）での辺の向き**（二等分線から ±45°）を使うことで、変形後の実際の張り出し量と一致する。

## 8. 地面パネルと基盤

### 8.1 地面パネル

底面形状のポリゴンを高さほぼ 0 の位置に配置する（Zファイティング回避で微小量だけ浮かせる）。

**地面パネルはマスターデータの `draw_floor=yes` の建物でのみ描画する（オプトイン。未設定は描画しない）。**
描画時のマテリアルは `floor` パーツから取得し、解決順は **`a{variant}` → `b{bd_type}` → `common`** の
フォールバックチェーン（工事系パーツと同じ規約。`common` は suffix フォルダを挟まず
`Models/Buildings/common/floor`）。**どこにも `floor` パーツが無ければ地面パネルは描画しない**
（既定建物マテリアルにはフォールバックしない）。これにより、地面パネルが不要な地面アセット
（例: `tile` パーツのみのソーラー発電所）に意図しないスラブが敷かれることを防ぐ。
この仕様はモジュラー建物・既成建物（プレビルド）で共通。

通常の建物では建物の底面ポリゴン（`footprint`）に対して水平な地面パネルを生成する。
ただし超近景（Dynamic）LODセルでは、水平ではなく地形の傾斜に沿った面として生成する（§9.4 参照）。
このとき、外周の頂点だけで面を張ると区画内部の起伏を拾えず地形を突き抜けるため、ポリゴンを
三角形分割したうえで一定長（既定6m）を超える辺を中点分割して内部頂点を作り、外周・内部を
問わず全頂点を地形標高に合わせる（中点は辺単位で溶接され、隣り合う三角形の間に隙間はできない）。

`MODEL_MODULAR_GROUND`・`MODEL_PREBUILT`・`MODEL_MASHUP` では、地面パネルは建物底面ではなく
土地区画のポリゴンに基づいて生成する（[[F2_地面アセットのメッシュ生成]] §2・
[[F3_既成建物のメッシュ生成]] §3・[[F6_マッシュアップ建物のメッシュ生成]] §5）。

### 8.2 基盤（コンクリート基盤）

傾斜地では建物が土地区画の基準標高（§2.4）の水平面に接地するため、谷側では底面と地形の間に
隙間ができて建物が浮いて見える。この隙間を埋めるため、建物の底面ポリゴン（`footprint`）を
Y方向に押し出した柱状のコンクリート基盤を生成する。

- **対象** — MODEL_MODULAR_FLAT / HOUSE / GABLE のみ。
  MODEL_MODULAR_GROUND・MODEL_PREBUILT・MODEL_PORT・MODEL_MASHUP は基盤を生成しない
  （§2.4 の接地規則で地形標高に直接接地する。土地区画の形状を押し出すこともしない）。
- **形状** — 上面 = 建物の接地面（ローカルY=0。地面パネルのわずかに下）、
  下面 = 底面頂点でサンプリングした最低地形標高の5m下（最低でも接地面の10m下）。
  頂点間で地形が局所的に落ち込んでも突き抜けないよう、下面には余裕を持たせている。
- **UV** — 上面・側面ともワールドスケール（10mで1タイル）。側面のUは外周に沿った累積距離で、
  辺をまたいでもタイリングが連続する。
- **マテリアル** — 全建物共通のコンクリートマテリアル `Resources/COMMON_CONCRETE`
  （未配置時は警告を出してデフォルト建物マテリアルにフォールバック）。
- 工事中（[[F5_工事中建物のメッシュ生成]] §3）は同じ形状を土マテリアルで生成する。

## 9. フェンス（fence）の配置

### 9.1 配置対象ポリゴン

フェンスは建物の底面ポリゴンではなく、**土地区画（parcel）のポリゴン**の形状に沿って配置する。
土地区画の頂点列を `fenceFootprint` とする。

### 9.2 レベル

フェンスは `fence-w*`（壁）と `fence-c*`（角）のパーツを使用する。
配置ロジック・角の変形・フォールバック階層は `base` / `mid` / `top` と同じである。

### 9.3 スケール

フェンスは**Y方向にはスケールしない**（建物の1階・最上階の壁・角と同じ扱い）。元のメッシュサイズのまま配置する。
X方向（辺の長さ方向）については、建物の壁と同じ敷き詰めロジック（§6.3）を使う。すなわち、両端のフェンス角パーツが辺へ張り出す長さ（§7.6 と同じ射影による計測。フェンス角は無スケールなので実寸がそのまま張り出し量になる）を差し引いた有効長に、四捨五入で決めた枚数を隙間なく敷き詰める。

### 9.4 地形追従

フェンスと地面パネルとタイルオブジェクトは、**超近景（Dynamic）LODセルの場合のみ**、配置場所の地形に沿って曲げる。それ以外のセル（NearやFarセルなど）に属する場合は、変形は行わず、水平な状態で配置される。この地形追従は**すべての model_type の敷地装飾**が対象である。傾斜地対応の建物（MODEL_MODULAR_FLAT / HOUSE / GABLE）は建物本体こそ基準標高（§2.4）の水平面に接地しコンクリート基盤（§8.2）で谷側を埋めるが、その敷地装飾（フェンス・タイル・地面パネル）は地形に追従させる。追従の基準高さは建物 `center_point` の配置高さ（傾斜地対応の建物では §2.4 の基準標高、それ以外では地形標高）で、建物GameObjectの配置高さと一致する。

Dynamicセルかどうかの判定はメッシュ生成器側では行わない。ロード処理（`BuildingManager`）が確定済みのティアを `isDynamic` 引数としてメッシュ生成器に渡す。LODロード中はティア表の更新がロード完了後になるため、生成器側からティア表を参照すると古い値を読んでしまうからである。

各メッシュの頂点に対し、その頂点の水平位置（XZ座標）での地形標高を `HeightmapTextureManager.GetTerrainHeight`（建物GameObjectの配置高さと同じ取得経路）で取得し、頂点のY座標をその標高に合わせる。基準高さは建物の `center_point` 位置の地形標高であり、建物GameObjectがこの高さに配置されることを前提として、各頂点のローカルY座標を「頂点位置の地形標高 − center_point位置の地形標高」を基準にローカル座標化する。

フェンスの場合、元のメッシュ頂点の相対的な高さ関係（上端が下端より高い状態）は維持する。つまり、頂点位置の地形高さに元のローカルY（スケール適用後）を加算した値を新しいY座標とする。

地面パネルの場合、ポリゴンを三角形分割したうえで長辺（既定6m超）を中点分割して内部頂点を作り、外周・内部を問わず各頂点でその位置の地形高さを取得し、center_point位置の地形高さを基準としてローカル座標化する。これにより地面パネルは水平ではなく地形の傾斜に沿った面になり、区画が大きくても内部の起伏に追従して地形を突き抜けない。

タイルオブジェクトの場合、まずすべてのタイルを平面上に配置してから、各タイルメッシュの頂点をフェンスと同様に地形に合わせて変形する（元のメッシュ頂点の相対的な高さ関係を維持したまま、頂点位置の地形高さを加算する）。

建物はDynamic地形のロード完了より先に生成されることがあるため、地形ロード完了後（およびDynamic地形タイルの更新時）に、Dynamicセル内の建物はメッシュごと再生成され、最新の地形に追従し直す（[[E_LOD処理]]参照）。

## 10. 塔屋（roofprop）の配置

### 10.1 配置条件

パーツ `roofprop` が存在する場合のみ配置。なければ配置しない。

### 10.2 位置

`visual_variant2` をシード値として、屋上面上の位置を決定する。
屋上面の重心を中心に、シードから角度と距離を計算してオフセットした位置に置く。

### 10.3 角度

塔屋の向きは底面ポリゴンの最初の辺（頂点0 → 頂点1）の方向に合わせる。

### 10.4 高さ

屋上パネルと同じ高さ（躯体の高さ `floors × height_per_floor`。§6.4）に配置する。最上階のパーツが背高で塔屋を突き抜けても補正はしない。

`MODEL_PORT` は位置・角度・高さを岸壁の幾何から決めるため、この規則ではなく専用ルールで配置する（[[F4_港湾岸壁のメッシュ生成]] §5）。

`MODEL_MASHUP` は塔屋を配置しない（各サブ建物が完成モデルとして頂部まで含む前提のため）。

## 11. エントランス（entrance）の配置

### 11.1 配置条件

パーツ `entrance` が存在する場合のみ、建物1棟につき1つ配置する。なければ配置しない。
対象は MODEL_MODULAR_FLAT / HOUSE / GABLE（MODEL_MODULAR_GROUND は建物本体を持たないため対象外）。
`building_shape = SHAPE_FULL` の建物は最上階のみを描画する（[[F1_モジュラー建物のメッシュ生成]] §4）ため、地上に壁が存在する1階建ての場合に限って配置する。

### 11.2 位置と向き

前面の辺は、底面ポリゴンの**最初の辺（頂点0 → 頂点1、位置1の壁の辺）**とする（塔屋の向き決定 §10.3 と同じ規約）。

その辺の中央、**地面レベル（ローカルY=0）**に配置する。原点は壁のアライメントライン（前面の辺の直線上）に一致し、回転は壁パーツと同じ規約（辺方向へ向けてY軸まわりに180°反転。§6）を用いる。すなわち、壁パーツと同じ座標系で著作したモデルがそのまま前面の壁面に重なる。

### 11.3 スケール

一切スケールしない（実寸）。庇や階段などの造作が階高・辺長に引き伸ばされるのを防ぐため。

## 12. メッシュの結合とベイク

壁・角・屋上・地面・塔屋のすべてのパーツの配置が完了した後、**一括で**メッシュを結合する。

1. 各パーツを `CombineInstance` に変換（サブメッシュごとに個別のインスタンス）
2. `Mesh.CombineMeshes()` でサブメッシュ構造を維持したまま結合
3. 法線とバウンディングボックスを再計算
4. 結合後、同じマテリアルのサブメッシュを統合してドローコールを最小化
5. 一時メッシュを解放

角パーツのボーン変形（BakeMesh）はあくまで個別パーツのジオメトリ準備であり、この最終的な結合ベイクとは別物である。

## 13. コライダー

クリック判定のため、底面ポリゴンを建物高さまで押し出した形状の `MeshCollider` を生成する。

- **下面**：CCW の三角形ファン（法線下向き）
- **上面**：CW の三角形ファン（法線上向き）
- **側面**：各辺について、上下の頂点4点で構成する四角形を2つの三角形に分割

高さは躯体の高さ `floors × height_per_floor`（§6.4）である。1階・最上階のパーツがこれをはみ出して著作されていても、コライダーは伸ばさない。

押し出すポリゴンと高さは model_type によって異なる。

| model_type | ポリゴン | 高さ |
| --- | --- | --- |
| MODEL_MODULAR_FLAT / HOUSE / GABLE | 建物底面 | 躯体の高さ（`floors × height_per_floor`） |
| MODEL_MODULAR_GROUND | 土地区画 | `floorHeight`（[[F2_地面アセットのメッシュ生成]] §4） |
| MODEL_PREBUILT | 建物底面 | 描画された実高さ（[[F3_既成建物のメッシュ生成]] §4） |
| MODEL_PORT | 岸壁フットプリント | 岸壁上面の高さ（[[F4_港湾岸壁のメッシュ生成]] §7） |
| MODEL_MASHUP | 土地区画 | 描画された最も高いサブ建物の天端（[[F6_マッシュアップ建物のメッシュ生成]] §6） |
| 工事中（STATUS_CONSTRUCTING） | 建物底面 | 施工済み階の高さ（[[F5_工事中建物のメッシュ生成]] §7） |

## 14. 1階あたりの高さ

マスターデータの `height_per_floor` を使用する。
設定されていなければ `LocalConstants.FLOOR_HEIGHT`（デフォルト: 4.0）を使う。

**すべてのパーツの配置位置（各階の床面Y）と躯体の高さはこの値で決まる**（§6.4）。一方、この値でパーツが**スケール**されるのは中層（mid）だけで、1階（base）・最上階（top）の壁・角と prebuilt の base / top は著作実寸で描画される（§6.3・§7.6・[[F3_既成建物のメッシュ生成]]）。用途は次のとおり。

- 各階の床面Y（`階 × height_per_floor`）と躯体の高さ（`floors × height_per_floor`）（§6.4）
- 中層の壁・角・`mid-prebuilt` のYスケール目標高さ（§6.3・[[F3_既成建物のメッシュ生成]] §1）
- 切妻屋根の棟の高さ（その半分。[[F1_モジュラー建物のメッシュ生成]] §3）
- 白い箱フォールバックの高さ（`floors × height_per_floor`）
- `MODEL_MODULAR_GROUND` のコライダー高さ（[[F2_地面アセットのメッシュ生成]] §4）
- 工事中の足場・クレーンの1段の高さ（[[F5_工事中建物のメッシュ生成]]）

| **`BuildingMeshBuilder.cs`**                | **エントリポイント兼 static ユーティリティ**。`Generate` が status → `model_type` の順に分岐して各ビルダーへ振り分ける。`MergeSubMeshes`、`GenerateSimpleBuilding`、`GenerateColliderMesh`、`GenerateFoundationMesh`、塔屋・エントランス配置ロジック、`AddSegmentToCombineList` などの汎用メソッドを保持。 |
| **`ModularBuildingMeshBuilder.cs`**         | `IBuildingMeshGenerator`。`ModularBodyBuilder` で壁・地面を生成 → `***RoofBuilder` で屋根を生成 → 塔屋を配置 → 結合・ベイク（[[F1_モジュラー建物のメッシュ生成]] / [[F2_地面アセットのメッシュ生成]]）。 |
| **`ModularBodyBuilder.cs`**                 | **static クラス**。モジュラーパーツの壁・角・地面パネルを配置し、CombineInstance / Material / tempMesh リストを返す。敷地装飾（フェンス・タイル・地面パネル）の生成は既成建物・工事中とも共通。 |
| **`FlatRoofBuilder.cs`**                    | **static クラス**。平らな屋上パネルを生成して返す。                                                                                                          |
| **`HouseRoofBuilder.cs`**                   | **static クラス**。住宅風三角屋根メッシュを生成して返す。                                                         |
| **`GableRoofBuilder.cs`**                   | **static クラス**。切妻屋根メッシュ（厚みのある勾配面2枚＋妻壁）を生成して返す。屋根面と妻壁でサブメッシュ・マテリアルを分ける（[[F1_モジュラー建物のメッシュ生成]] §3）。 |
| **`PreBuiltBuildingMeshBuilder.cs`**        | `IBuildingMeshGenerator`。既成パーツ組み立て（[[F3_既成建物のメッシュ生成]]）。                                                                         |
| **`PortBuildingMeshBuilder.cs`**            | `IBuildingMeshGenerator`。海岸線で底面ポリゴンをカットし、厚みのある岸壁スラブを押し出して塔屋・荷役クレーンを配置する（[[F4_港湾岸壁のメッシュ生成]]）。                                                  |
| **`MashupBuildingMeshBuilder.cs`**          | `IBuildingMeshGenerator`。`sub_buildings` の配置計画に従い、複数のサブ建物を既成パーツと同じ積み上げ規則で配置する（[[F6_マッシュアップ建物のメッシュ生成]]）。                                        |
| **`ConstructingBuildingMeshBuilder.cs`**    | `IBuildingMeshGenerator`。工事中専用の「工事現場」メッシュ（土マウンド + 足場リング + クレーン）を生成する（[[F5_工事中建物のメッシュ生成]]）。model_type 分岐より先に status で分岐する。 |
| **`DefaultBodyBuilder.cs`**                 | **static クラス**。モジュラーパーツが一切存在しない場合のフォールバック躯体。底面ポリゴンを高さまで押し出した壁面と地面パネルを生成する（屋根は屋根ビルダーが担当）。 |
| **`BuildingMeshUtils.cs`**                  | **static クラス**。パーツの存在確認・パス解決（`common` フォールバック含む）、プレハブ配下の全メッシュ結合、閾値 suffix の解決、積み上げモジュール配置などの共通処理。 |
