# T. 交通シミュレーションと走行描画の整合

## 責任の分離

コアは交通量・走行時間・停車時間・運行間隔を確定し、Unity はその結果を道路・線路上の動きとして再現する。描画の時計は経済の時計から独立しており、計画中も車両は動くが都市の状態は変わらない。カメラ位置・描画上限・フレームレートで都市の経済結果が変わってはならず、描画上の渋滞や車両の位置をコアへ書き戻さない。

整合の基準は瞬間の速度ではなく、同じ区間・同じ時間単位で数えた通過数と平均所要時間である。コアの所要時間は加速・カーブでの減速・前車への追従・停止を含んだ平均なので、平均速度で走らせたうえに停止を足すと、同じ遅れを二重に数える。

## 時間と位置の契約

時間は秒、距離はメートルで受け渡す。所要時間は、自由走行の時間・混雑で増えた時間・停留所での停車時間を分けて持つ。乗客の乗車待ちや運賃の時間換算は経路選択のコストで、車両の動きには加えない。

公共交通の停留所間の走行は、路線の `journeys` が区間ごとの向き・始終の速度・所要時間・停車時間として持つ。カーブや坂での減速はこの所要時間に含まれている。コアの乗車時間・必要車両数・便数と Unity の走行は同じ値を使う。編成は目標運行間隔より短い間隔では発車せず、1周の時間が余れば次の発車まで先頭の停留所で待つ。この待ちも、コアの便数・線路の負荷と Unity の走行で共通である。

位置はパスID・進行方向・中心線に沿った水平距離の割合で表す。停留所は最寄りの端点へ寄せず、パスの途中の位置のまま扱う。一方通行・途中の転回の制約・往路と復路を区別する。表示上の高さは Unity のパス形状を正とし、下地の経路の決定はコアを正とする。

## 流量と台数

定常状態では、区間内の平均台数は毎秒の流入台数と平均滞在時間の積になる。流量・速度・表示台数を独立した演出値にしない。日次の交通量は、コアが返す1日の活動時間(`active_hours`)で毎秒の流量へ換算する。

描画上限による間引きは表示の標本化であり、経済上の交通量を変えない。時間を倍速にするときは、走行・停車・発車間隔を同じ倍率で変える。台数だけを増やして前車への追従を強めると、コアに無い渋滞を作るので避ける。

## 描画上の近似

一般車は同じ道路・方向・車線の中で前車に追従し、自由走行の平均速度を上限にする。描画範囲の端での発生・到着や追従の遅れがあるので、通過数と平均所要時間の厳密な一致は保証しない。交差点での競合、列車の閉塞・単線での行き違い、バスと一般車の相互の追従は描画しない。

描画の経路・編成・時計は[車両の走行描画](O_車両の走行描画.md)、経済上の運行条件は[公共交通機関](../economics/6_公共交通機関.md)に定義する。
