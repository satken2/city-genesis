# 既成建物のメッシュ生成（MODEL_PREBUILT）

## 概要

洋上風力1071と洋上石油プラットフォーム1072は、完成形を `a1071/0` / `a1072/0` の
`top-prebuilt`・`top-prebuilt_close`・`top-prebuilt_far` として持つ。
1071は1055の塔・ナセル・羽根を再利用し、黄色の洋上基礎と保守デッキを付ける。
1072は46×38mの主デッキと下層機械デッキ、直径約4.1mのジャケット脚、屋上ヘリポート付き居住棟、2本の掘削塔、2基のクレーンを持つ。
設備を密集させ、クレーンの四面トラス、デッキ上下の機械室・圧力容器・配管ラックを表現する。
脚は海面基準から約80m下へ延ばし、多段の水平梁・交差筋交いで連結する。
接写では手すり・梯子・細い配管を追加し、3距離の原点と外寸を共通にする。
海上区画のモデル原点は区画標高に配置され、水中脚は固定長の造形で海底へ追従しない。
原本は `blender/buildings.blend`。再生成と実FBX検証は非公開制作ツールの
`build_offshore.py`（1072の形状は`offshore_platform.py`） / `import_offshore.ps1`、制作記録は同ツールの `offshore.md` にある。

通常の建物とは全く異なる形状（電波塔、オブジェ、銅像、観覧車など）や、モジュラー組み立てに向かない完成済みモデルの建物に適用する。
`base-prebuilt` / `mid-prebuilt` / `top-prebuilt` の3種類のパーツを下から積み上げて組み立てる。

共通仕様（パーツの命名規則・外観バリアントの選択・地面パネル・フェンス）は
[[F_建物メッシュの生成]] に記述する。本ドキュメントはその差分を記述する。
パーツの制作規格は [[I_建物パーツ作成マニュアル]] を参照。

接地高は建物中心位置の地形標高であり、コンクリート基盤（[[F_建物メッシュの生成]] §8.2）は生成しない。

観光名所（`landmark` > 0）もこの方式で描画する。名所は一点物なのでパーツフォルダだけが名所ごとに分かれ
（`landmark-{model_prefix}`。[[F_建物メッシュの生成]] §3.2）、積み上げ規則は通常の既成建物と変わらない。

実装は `PreBuiltBuildingMeshBuilder`。

### 観光名所の3段階モデル

`landmark-{model_prefix}/0/` に通常（無印）・接写（`_close`）・遠景（`_far`）を置く。
遠景用prebuiltの選択と組み立ては全建物共通で、名所専用の分岐は持たない。同じ階高・同じ原点で組み立て、敷地装飾は省略する。
`base/mid/top-prebuilt_far` が1つも無ければ既存の簡易形状へ戻る。通常の生成方式がモジュラーでも、遠景はこの形式の完成モデルで提供できる。baseのみ・midのみ・topのみも有効。工事中・解体中・倒壊中は状態に応じた簡易生成を使う。

| model_prefix | 構成・外観 |
| --- | --- |
| great_tower | Nソウルタワー風の白い円柱塔。75mのテラス付き基部、75mの反復円柱、75mの段状展望室・赤白アンテナ頂部。標準4階で300m、2階で150m、8階で600m |
| colossal_statue | 緑青の衣像・松明・石造台座を高さ90mの `top-prebuilt` にまとめる |
| old_castle | 石垣・四隅の櫓・重層天守を `top-prebuilt` にまとめる |
| grand_cathedral | 身廊・双鐘塔・バラ窓・控壁を `top-prebuilt` にまとめ、配置回転込みで80m×50mの敷地に収める |
| ancient_ruins | 部分的に残る列柱・環状遺構・壁・倒れた柱を `top-prebuilt` にまとめる |

接写は瓦筋・建具・顔・柱溝などを追加する。遠景は主要な輪郭と材質を残し、外寸と接続点を維持する。
原本は `blender/buildings.blend`、FBXは `unity/Assets/Models/Buildings/landmark-*/0/`。
制作・比較・実Unity検証は非公開の制作ツール `genesis-gallery` の `build_landmarks.py`、`render_landmarks.py`、`import_landmarks.ps1` が担当する。

### 貨物駅（404・1077〜1081）

貨物PFの隣に建てる積み下ろしの施設（[貨物輸送](../economics/33_貨物輸送.md) 33.6・33.7）は、敷地全体を1つの `top-prebuilt` で持つ。

### 国境検問所（4）

都市境界のすぐ外で、都市から延びる道路の突き当たりに置く建物（[建物](../economics/12_建物.md) 12.13）は、敷地全体を `a4/0` の1つの `top-prebuilt` で持つ。
底面は固定（`resizable=no`）の間口110m×奥行き70mで、マスターの `default_width`×`default_height` と一致させる。
道路は前面の辺（道路側。Blender -X）の中点に突き当たる。4車線（各3.5m）を3つのブース島で分けた幅18.5mの車路が4車線道路の車道をそのまま受け、中央棟の門をくぐって背面の辺（国外側。Blender +X）へ抜ける。
配置は自由配置で前面の辺を道路の端へ向けるか、道路の端に接する区画を作って建てる。

- **中央棟**: 車路をまたぐ幅20m・高さ9.5mの門（石の額縁）、赤地に金の縁と文字板の国名板、金と赤の国章、二段の大庇、屋上の国旗。国名板の文字は形状で再現せず、金の板で示す。
- **翼棟と低層棟**: 中央棟の左右に石張りの1階と3層の窓を持つ翼棟（玄関と庇・屋上設備）、両端に低層棟。
- **都市側の前庭**: 門の手前の審査ブースと閉じた遮断機、車路沿いの石の欄干と3灯の街灯、植え込み。
- **国外側**: 車路をまたぐ審査上屋とブース・遮断機、トラックの駐車場、芝生、車路だけを開けた国境の柵、車路を横切る黄色の国境線。
- 舗装は底面全体を覆い、下端を-1.5mまで延ばす。`draw_floor` の地面パネルは `floor` パーツの材質（舗装と同じコンクリート）で描く。
- 遠景は `top-prebuilt_far`。水平範囲と天端（国旗の竿の頂部）を通常と揃え、舗装と車路の板、棟と大庇の箱、審査上屋の屋根、国名板だけにする。接写専用のモデルは持たず、Closeは通常を使う。
- 原本は `blender/buildings.blend`。制作元は非公開制作ツールの `build_a4.py`、実FBX・正規プレハブ・向き・遠景の検証は `import_border_checkpoint.ps1`。

## 1. パーツの意味とスケール規則

| パーツ | 個数 | Yスケール | XZスケール | 用途 |
| --- | --- | --- | --- | --- |
| base-prebuilt | 0〜1 | **なし（実寸）** | なし（実寸） | 1階部分（エントランス等） |
| mid-prebuilt | 0〜N回繰り返し | 階高に合わせる | なし（実寸） | 繰り返しフロア1階分 |
| top-prebuilt | 0〜1 | **なし（実寸）** | なし（実寸） | 頂部。尖塔や、完成済みモデル丸ごと |

base / top は一切スケールされず、モデリング時の実寸のまま配置される。階高（`height_per_floor`）に合わせて縮めたり伸ばしたりはしないため、階高が 4m でもパーツが 15m で著作されていれば 15m の高さで描画される。

mid だけは、積む枚数で建物の高さを調整する「詰めもの」の役割を持つため、高さが階高になるよう**Y方向のみ**スケールされる（幅・奥行きは実寸のまま）。モジュラー建物の mid レベル（[[F_建物メッシュの生成]] §6.3）と同じ規約である。

**スケールされないのはパーツの形状だけで、段の位置は階高グリッドのまま**である（§2）。base の実寸が階高より低ければ mid との間に隙間が空き、高ければ mid のパーツに埋もれる。これは仕様であり、プログラムは補正しない。

## 2. 積み上げ規則

- base と top はそれぞれ論理階数（floors）のうち **1階分を消費**する。mid は残りの階数分繰り返される: `midCount = max(0, floors − (baseあり?1) − (topあり?1))`
- 各パーツのY位置は **階高グリッド**（`消費した段数 × 階高`）で決まる。パーツの著作高さは配置位置に影響しない。段を進めるのは**ファイルが存在するパーツ**だけなので、base / mid のファイルが無い建物では top が地面（y=0）に接地する。**完成済みの建物モデルを top-prebuilt 1つだけで表現できる**（例: 完成済み4階建て庁舎モデル、風力発電所）。
- base / top が階高へ縮められないため、描画上の建物はシミュレーション上の高さ（`floors × 階高`）と一致しないことがあるが、これは仕様として許容する。コライダーは描画された実高さに合わせる（§4）。
- 積み上げの天面を塞ぐパネルは生成しない。prebuilt パーツはモジュラーの壁パーツと違い完成された3Dモデルなので、上から見える面はモデル側で閉じておくこと。
- 各パーツはモデルの原点（y=0）を各段の接続点（下端）に合わせて積まれる。XZはモデルの原点を建物原点（center_point）に重ねる。
- **向き**は底面ポリゴンの前面の辺（頂点0→頂点1。接道辺の規約）の角度から決まり、Unityメッシュのローカル +Z が前面の辺の方向（頂点0→1）、ローカル +X が辺の外側（道路側）を向くよう全パーツがY軸回転される（`PreBuiltBuildingMeshBuilder.Generate` の `rotation`。塔屋と同じ回転）。標準FBX（[[I_建物パーツ作成マニュアル]] §5.1設定A）で著作する場合、**Blenderの −Y が前面の辺の方向、−X が道路側**になる。壁・エントランスの「−Yが屋外」とは90°異なる。フットプリントの形状そのものはコライダーと敷地装飾のフォールバックにしか使われない＝**パーツは区画に合わせて伸縮せず、向きだけ合わせて実寸で置かれる**。
- FBXが複数オブジェクトで構成されていても、全メッシュがノードのTransform込みで結合されて描画される。

## 3. 敷地装飾（フェンス・タイル・地面パネル）

土地区画の外周フェンス（`fence-w` / `fence-c`）・敷地内のタイル（`tile`）・地面パネル（`floor`）は、モジュラー建物と共通のロジックで配置される（[[F_建物メッシュの生成]] §8.1・§9）。

- フェンス・タイルは該当パーツを置いた場合のみ描画されるオプション要素
- 地面パネルはモジュラーと同じく**マスターの `draw_floor=yes` の建物だけ描画**し、マテリアルは `floor` パーツを `a{variant}` → `b{bd_type}` → `common` の順で解決する（無ければ描画しない）
- 既成建物は建物中心位置の地形標高に接地するため、超近景セルではフェンス・タイル・地面パネルが地形に追従する（`MODEL_MODULAR_GROUND` と同じ扱い。[[F_建物メッシュの生成]] §9.4）

## 4. コライダー

**描画された実高さ**（実際に描画されたメッシュの天端のうち最も高いもの。最低でも1階分）を使用する。
base / top の実寸が論理高さ（`floors × floorHeight`）をはみ出す建物でも全体をクリックできるようにするためである。
構成は [[F_建物メッシュの生成]] §13 に準じる。

---

## 5. フォールバック

3種類のパーツがいずれも存在しない場合は白い箱（`BuildingMeshBuilder.GenerateSimpleBuilding`）にフォールバックする。

## 6. モデルに記録する道路間口

道路への出入口は、FBX内に `road_access_{entry|exit|both}_{識別子}` というEmptyと、その直下の3つのEmpty `a`・`b`・`inside` を持たせて表す。`a` と `b` が舗装端の両端で、距離が間口幅、中点が接続点になる。`inside` は中点から敷地内側へ置き、中点との差が道路へ向かう向きになる。著作規約は [[I_建物パーツ作成マニュアル]] §11。

`BuildingRoadAccess` は無印モデルを読み、建物本体と共通の `PrebuiltRotation` で回す。地上に実際に配置する最初の段だけを採用し、baseが無くmidを配置しない建物ではtopが対象になる。地上段がmidの場合は、本体と同じ原点基準のYスケールをマーカーにも適用する。舗装高は建物中心の地形標高に相対で、モデルの描画LODを切り替えても間口は変えない。

国境貨物駅1081は `top-prebuilt` に検査場の入口45mと出口10mを持つ。通常・接写・遠景の原本とFBXに同じマーカーを記録する。別の既成建物もこの規約でモデルを著作すれば、Unityにバリアント別の固定座標を追加せず接続できる。マーカーは描画・メッシュ結合・コライダーの対象にならない。
