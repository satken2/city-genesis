# 既成建物のメッシュ生成（MODEL_PREBUILT）

電波塔・像・観覧車や、形の特殊な施設のように、壁の組み立てに向かない建物の方式である。完成形に近いパーツ `base-prebuilt`・`mid-prebuilt`・`top-prebuilt` を建物の中心に下から積み、区画に合わせて伸縮させずに向きだけを正面の辺に合わせる。`base` と `top` が1階分ずつ、`mid` が残りの階数ぶんを受け持ち、ファイルのある段だけを積むので、完成した建物を `top-prebuilt` 1つで表せる。共通の約束は [F_建物メッシュの生成](F_建物メッシュの生成.md) による。

外観バリアントは持たず、`0` フォルダのパーツを使う。観光名所は名所ごとのフォルダ `landmark-{model_prefix}` を使い、積み方は同じである。敷地装飾はモジュラー建物と同じで、基盤は作らない。クリック判定は描いた段の天端まで底面を押し出した形にし、実寸の段が階数×階高をはみ出しても全体を選べるようにする。

道路への間口は、地上に置く段のモデルの中の目印 `road_access_{種類}_{識別子}`（[F_建物メッシュの生成](F_建物メッシュの生成.md#道路への間口)）から読む。
