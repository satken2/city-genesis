# C. 建物形状

建物の底面（水平に投影した輪郭。フットプリント）は、土地区画の形・建蔽率・マスターの形状カテゴリからコアが決める。フロントはこの決め方を持たず、コアが返す `polygon` を描画に使う。区画に建てるときのプレビューの底面も API で受け取る。階数や階ごとの用途は底面とは別の値で、底面の面積と階数・階高から延床面積や建物の高さが決まる。どの区画にどのバリアントを建てるかは経済の側の話である（[経済主体](../economics/2_経済主体.md)）。

## フロントが受け取る底面

`polygon` は `center_point` を原点とする XZ 座標の頂点列で、反時計回りに並び、原則として区画の中に収まる。頂点0→1の辺は、区画の接道辺（`facade_edge_index`。[B_土地形状](B_土地形状.md)）に最も近い辺になるよう並べてあり、建物の正面として玄関や既成パーツの向きを決める（[F_建物メッシュの生成](F_建物メッシュの生成.md)）。角が直角とも、頂点が4つとも限らない（L字・台形・区画そのままの多角形など）。

## 形状カテゴリ（`building_shape`）

マスターの `building_shape` は、バリアントごとの底面の作り方を表す。いずれも、建蔽率で決まる面積の上限に近づけて作る。

| 値 | 底面 |
| --- | --- |
| `SHAPE_FULL` | 区画そのもの |
| `SHAPE_OFFICE` | 区画の向きに合わせた矩形 |
| `SHAPE_HOUSE` | 接道辺から下がって建つ、正方形に近い矩形 |
| `SHAPE_COMMERCIAL` | 接道辺に沿った帯状の矩形 |
| `SHAPE_SETBACK` | 区画の奥に寄せ、接道側に空き地を残す |
