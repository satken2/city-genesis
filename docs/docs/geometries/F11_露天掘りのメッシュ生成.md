# 露天掘りのメッシュ生成（MODEL_OPEN_PIT）

鉱山のように、区画を掘り下げて資源を採る施設の方式である。掘った穴は地形そのもので、建物としては描かない。コアが採掘に応じて区画の地形を書き換え、Unity は版が変わった地形セルを取り直して穴を描く（[LOD処理](E_LOD処理.md)・[天然資源](../economics/21_天然資源.md)）。建物として描くのは、掘らずに残す接道側の前庭に並ぶ設備だけで、設備はマッシュアップ建物（[F6_マッシュアップ建物のメッシュ生成](F6_マッシュアップ建物のメッシュ生成.md)）と同じ `sub_buildings` として届き、同じ規則で組み立てる。

建物の原点（中心位置の地形標高）は穴の中にあるので、中心の高さに置いた形は穴に蓋をし、そこから押し出した形は前庭に届かない。このため、区画を押し出したクリック判定や白い箱を作らず、地形に沿う区画の面と設備ごとの外接箱でクリック判定を作る。地面パネルは前庭と穴を含む区画の全体を地形に沿って覆う。工事中・解体中は土の盛り上がりだけ、倒壊は瓦礫だけで表す。
