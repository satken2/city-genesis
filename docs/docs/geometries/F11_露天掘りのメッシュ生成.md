# 露天掘りのメッシュ生成（MODEL_OPEN_PIT）

## 概要

鉱山のように区画を掘り下げて鉱石を採る施設に適用する生成方式。

掘った穴は地形そのもので、建物としては描かない。コアシミュレータが採掘量に応じて区画の地形を書き換え、Unityは版が変わった地形セルを取り直して描く（[E_LOD処理](E_LOD処理.md)「地形の取得と確定」）。建物として描くのは、接道側の前庭に並ぶ設備だけである。設備はマッシュアップ建物（[F6_マッシュアップ建物のメッシュ生成](F6_マッシュアップ建物のメッシュ生成.md)）と同じ `sub_buildings` として届き、同じ規則で組み立てる。

実装は `MashupBuildingMeshBuilder` を露天掘りとして生成したもの（コンストラクタ引数 `openPit`）。共通仕様は [F_建物メッシュの生成](F_建物メッシュの生成.md)、穴の形のルールは [21. 天然資源](../economics/21_天然資源.md) §21.10 を参照。

---

## 1. 前庭と掘削範囲

- 前面辺（接道辺）から `OPEN_PIT_YARD_DEPTH`（40m）までの帯が前庭で、ここは掘らない。バックエンドの配置計画は、全体が前庭に収まるセルにだけ設備を置く（F6 §1 の配置と同じ規則で、使うセルだけが前庭に限られる）。
- 前庭の奥が掘削範囲で、区画の境界・前庭・設備・区画にかかるパスから一定の余白を残して掘る。隣の区画や道路、トンネル・送電鉄塔の足元の地形は変わらない。
- Unityは掘削範囲の形を受け取らない。穴は地形なので、描画に必要な情報は地形タイルだけで足りる。

## 2. 地面パネル

`draw_floor=yes` の露天掘りでは、地面パネル（[F_建物メッシュの生成](F_建物メッシュの生成.md) §8.1）が前庭と穴を含む土地区画の全体を覆う。パネルは実際の地形格子で切り抜いて張るので、穴の段と法面に沿う。

鉱山（1022）の `floor` は `BD_IRON_DUST`（鉄分で赤茶けた土）を参照する。テクスチャを持たない単色の材質なので、パネルのUV（局所XZ）が急な法面で縦に伸びても見た目には出ない。テクスチャを貼った材質を使うと、法面で縦に伸びて見える。

## 3. 設備

設備のパーツは `Models/Buildings/{prefix}/{threshold}/mashup-{model_prefix}-{base|mid|top}-prebuilt` で、解決・積み上げ・回転・接地は F6 §2〜§4 と同じである。各棟は自分の位置の地形標高に接地し、前庭は掘られないので元の地面に立つ。

鉱山（1022）の設備はすべて1階建てで、`mid-prebuilt` 1枚で完結する。

| model_prefix | 棟 | セル | 内容 |
| --- | --- | --- | --- |
| `crusher` | 破砕プラント | 3×2 | 受入ホッパ・破砕棟・覆い付きのコンベヤ・ふるい塔・製品の山。施設の顔として前面に置かれる。受入ホッパは掘削範囲の側（Blender +Y）を向く |
| `office` | 事務所・計量所 | 2×1 | 現場事務所とトラックスケール |
| `stockpile` | 製品ストックパイル | 2×2 | 破砕した鉱石の山と、山を積む旋回式スタッカ |
| `rom` | 原石置き場 | 2×2 | 発破で崩した原石の山と岩塊 |
| `machinery` | 重機置き場 | 2×1 | ダンプとホイールローダ |
| `workshop` | 整備工場 | 3×2 | 重機の整備棟、軽油タンクと給油場、予備のタイヤ |

建屋は明るい外装に淡青の腰壁、鉄骨は橙、手すりと重機は黄色で、赤茶けた地面パネルと穴の手前で設備が沈まないようにしている。

## 4. マッシュアップ建物との違い

建物のGameObjectは中心位置（`center_point`）の地形標高に置かれる（F §2.4）。露天掘りでは中心が穴の中にあるので、中心の高さに置いた箱や板は穴に蓋をし、中心の高さから押し出した形は前庭に届かない。このため次の点がマッシュアップ建物と異なる。

| 項目 | マッシュアップ建物 | 露天掘り |
| --- | --- | --- |
| コライダー | 土地区画を最も高い棟の天端まで押し出す | 地形に沿う土地区画の面と、設備ごとの外接箱を結合する。穴の底・段・前庭・設備のどこでもクリックできる |
| 何も描けないとき | 建物底面の白い箱 | 何も描かない（コライダーだけを持つ） |
| 遠景（Far） | 遠景用モデル、無ければ棟ごとの遠景パーツ（[F6_マッシュアップ建物のメッシュ生成](F6_マッシュアップ建物のメッシュ生成.md) §8）、それも無ければ押し出した箱 | 何も描かない。穴は地形として遠景でも見える |
| 工事中・解体中 | 足場・建機を立てる | 土マウンドのみ（[F5_工事中建物のメッシュ生成](F5_工事中建物のメッシュ生成.md) §7） |
| 倒壊 | 瓦礫マウンドと躯体片 | 瓦礫マウンドのみ（[F8_倒壊建物のメッシュ生成](F8_倒壊建物のメッシュ生成.md)） |

## 5. メッシュテストシーン

メッシュテストシーン（`MeshTestController`）は、露天掘りのバリアントでもマッシュアップと同じく `TestSubBuildingLayout` で配置計画を自前で作る。前庭のセルだけを使う規則もバックエンドから移植してある。テストシーンの地形は掘られないので、前庭の設備と地面パネルだけが表示される。
