# 港湾岸壁のメッシュ生成（MODEL_PORT）

## 概要

`MODEL_PORT` は、海岸土地区画（`PARCEL_SHORE`）に立地する港湾（`BUILDING_PORT`）の建物に適用するモデルタイプである。港の岸壁（コンクリートで固められた水際の壁）をイメージした、厚みのある板状のスラブを生成する。

底面形状としては `SHAPE_FULL`（[[C_建物形状]]）、すなわち土地区画ポリゴンそのものを底面とする方針を前提とするが、メッシュの組み立て方は `MODEL_MODULAR_*`（[[F1_モジュラー建物のメッシュ生成]]）とは大きく異なる。モジュラーパーツ（壁・角）は一切使わず、底面ポリゴンを海岸線との交点に基づく**直線**でカットした形状を上下に押し出して、厚みのあるスラブをプロシージャルに生成する。さらに、`visual_variant`（1）・`visual_variant2` を外観バリアント閾値（[[F_建物メッシュの生成]] §4）の選択ではなく、岸壁の形状を決める**幾何パラメータ**として消費するのが最大の特徴である。

接地高は建物中心位置の地形標高であり、コンクリート基盤（[[F_建物メッシュの生成]] §8.2）は生成しない。

実装は `PortBuildingMeshBuilder`。

---

## 1. 入力データ

岸壁の生成には次の3種類の情報を用いる。

- **底面ポリゴン** — 建物 Agent の `polygon`。`SHAPE_FULL` なので土地区画のポリゴンと一致する。海岸土地区画のポリゴンは海岸線でクリップされず元の形状のまま保持される（[[B_土地形状]] B.5）ため、海岸線を跨いで海側にはみ出した形状（矩形など）である。海岸線との交点の特定と直線カットはフロントエンドが行う（§2〜§3）。
- **海岸線ポリゴン** — `GET /api/v1/terrain/coastline` で取得する、陸地の境界を表す GeoJSON ライクなポリゴン（ワールド座標、マップ中心が原点。詳細は[[D_地形形状]]）。底面外周との交点の特定と、弦に対する海側方向の判定に用いる。海岸線は `init_game` 時に確定して以降不変なので、フロントエンドは初回に一度取得してキャッシュしておけばよい。
- **visual_variant1 / visual_variant2** — それぞれ岸壁の左端・右端の突き出し量を表す（0.0〜1.0）。他のモデルタイプのように閾値フォルダの選択には使わない。`visual_variant3` は使用せず、上面の高さは海面から 2m 固定である。

---

## 2. 海岸線との交点と海側方向の特定

底面ポリゴンの外周と海岸線（陸地領域の境界）との交点を求め、そのうち最も離れた2点を岸壁の**左端 A**・**右端 B** とする。陸地領域は、海岸線のリング集合（外周と穴を区別しない）を偶奇合成（XOR）したものとする。A・B を結んだ線分を「**弦**」と呼び、陸地に含まれない底面頂点が弦に対して平均的に存在する側を「**海側**」とする。左右の対応は、A→B が海を左手に見る向きになるよう正規化して決める（同じ建物では常に同じ対応になる）。

交点が2点未満（底面が全域陸または全域海）の場合・海側の底面頂点が無い場合・幾何演算に失敗した場合は、カットせず底面ポリゴンをそのまま岸壁フットプリントとして使う。

---

## 3. 突き出しと直線カット（visual_variant1 / visual_variant2）

A・B をそれぞれ海側方向（弦の法線）へ突き出した2点 A'・B' を結ぶ**直線**で底面ポリゴンをカットし、陸側を残した形状が岸壁フットプリントとなる。**岸壁の海側境界は海岸線の曲線をなぞらず、常に1本の直線になる**。

突き出し距離は左右独立で、次の式で決まる。

```
突き出し距離 = lerp(最小突き出し比率, 1.0, visual_variant) × 奥行き上限
```

- **奥行き上限** — 弦から、底面の海側最遠頂点までの距離。土地区画が海側に持っている「余白」の深さに相当する
- **最小突き出し比率** — 0.2。`visual_variant = 0.0` でも岸壁は必ず一定程度海へ張り出す
- 左端 A' には `visual_variant1`、右端 B' には `visual_variant2` を用いる

これにより、

- 両方 0.0 → 海岸線の近くに控えた、張り出しの浅い岸壁
- 両方 1.0 → 土地区画の海側いっぱいまで張り出した岸壁
- 片側のみ大きい → 一方の端だけが海側へ張り出した、海側エッジが斜めの岸壁

といった形状を表現できる。カットは底面ポリゴンとの交差なので、岸壁は常に土地区画の範囲内に収まる。

カット後の「陸側境界 + 直線の海側境界」で構成される閉じたポリゴンが、岸壁スラブの新しい底面（以下、岸壁フットプリント）となる。

---

## 4. 岸壁スラブ（厚みのある板）の生成

岸壁フットプリントを上下に押し出して、厚みのあるスラブを作る。

- **上面** — 岸壁フットプリントを高さ `H = 2m`（海面基準の固定値。visual_variant によらない）の水平ポリゴンとして配置する。三角形分割は耳切り法（ear clipping）を用い、失敗時はファン型にフォールバックする（[[F1_モジュラー建物のメッシュ生成]] §1 と同じ）。
- **側面** — 岸壁フットプリントの各辺について、上面（高さ `H`）から下面まで垂直な四角形を張る。
- **下面** — 各頂点の水平位置（XZ座標）での地形標高（＝海底の高さ）を `Utils.GetGroundHeight` で取得し（[[F_建物メッシュの生成]] §9.4 と同じ取得経路）、その高さまでスラブを下げる。上面と海底の差分が厚みになり、岸壁が「厚みのある壁」として見える。

生成する全頂点は `center_point` 基準の相対座標とし、配置時に `center_point` のワールド座標を足して最終位置を決める（[[F_建物メッシュの生成]] §2.4 と同じ）。

---

## 5. 塔屋（roofprop）の配置

石油パイプライン受入基地1073は、この配置を使って2基のタンク・ポンプ棟・受入配管を
岸壁重心へ1組置く。設備は22×18m、高さ7.9m、接写版は梯子・タンクの手すり・弁を持つ。
`floor` / `ceil` は共有コンクリート材を参照する。専用Farは同じ設備と高さ2mの簡易基壇を
`top-prebuilt_far` で表し、動的な岸壁全体は省く。岸壁の形状・重心は区画と海岸線で変わるため、
Farで任意の岸壁形状まで再現するものではない。原本は `blender/buildings.blend`。

パーツ `roofprop` が存在する場合のみ、岸壁の上に塔屋を1つ配置する。`visual_variant` をシードに位置を散らす通常の塔屋（[[F_建物メッシュの生成]] §10）とは異なり、次の固定ルールで配置する。

- **位置** — 岸壁フットプリントの重心。
- **角度** — 海側境界（A'・B' を結ぶ直線エッジ）の方向に合わせる。岸壁の向きに沿わせることで、岸壁の中央に水際と平行に置かれる。
- **高さ** — 上面と同じ高さ `H`。

`visual_variant` は岸壁の幾何（突き出し）に消費されるため、閾値フォルダ `suffix` の選択には使えない。塔屋を含むパーツは閾値 `0` のフォルダから取得する。

---

## 6. 荷役クレーン（port_crane）

パーツ `{prefix}/0/port_crane` が存在する場合、岸壁の**水際＝海側の直線エッジ（§3 の A'-B' カットで生じた辺）** に沿ってガントリークレーン等の荷役機械を並べる。パーツが無ければ配置しない。

- **配置場所** — 岸壁フットプリントのうち、カット直線上に乗っている辺。海岸線が取得できずカットできなかった建物（§2 のフォールバック）では水際が定まらないため配置しない。
- **原点** — **モデル原点が水際の境界線上**に一致する。高さは岸壁上面と同じ `H`。ブームを海側へ張り出させるか、脚を陸側に置くかはモデル側の造形で決める。
- **向き** — **ローカル +Z が海側**（＝ローカル X が水際に沿う）。
- **スケール** — **一切しない（実寸）**。パーツの実寸幅（X）がそのまま設置間隔の基準になる。
- **基数と間隔** — 設置間隔 = パーツ実寸幅 × 4.5（`CRANE_SPACING_RATIO`）。1つの辺に置く基数 = floor(辺長 ÷ 設置間隔)（最低1基、岸壁あたり最大8基）。辺全体に等間隔で、両端の余白が等しくなるよう配置する。**辺長がパーツ1基の幅に満たない水際には置かない**ため、小さな港では0基になる。

クレーンのブームが海側へ張り出しても、コライダー（§7）には含めない。

---

## 7. マテリアル・敷地の地面パネル・コライダー

- **マテリアル** — 上面は `floor`、側面・下面は `ceil` のマテリアルを流用する。上面に floor を使うのは、後述の敷地全体の地面パネルと同一マテリアルにして、陸側の敷地と岸壁を一続きの床に見せるためである。該当パーツがなければ建物全体のデフォルトマテリアルを使う（[[F1_モジュラー建物のメッシュ生成]] §1・[[F_建物メッシュの生成]] §8 と同方針）。
- **敷地の地面パネル** — 他のモデルタイプと同様に、マスターの `draw_floor` が有効な建物では土地区画全体に地形追従の地面パネルを描画する（floor パーツを `a{variant}` → `b{bd_type}` → `common` で解決。モジュラー・既成建物と共通の敷地装飾処理）。フェンス・タイルパーツが存在する場合も同様に描画される。
- **コライダー** — クリック判定のため、岸壁フットプリントを高さ `H` まで押し出した形状の `MeshCollider` を生成する（構成は [[F_建物メッシュの生成]] §13 に準じる）。
