# 港湾岸壁のメッシュ生成（MODEL_PORT）

海岸の区画（`PARCEL_SHORE`）に建つ港の方式である。港は、船が着く水際と、その陸側で荷を扱うヤードからなる。水際に荷役設備 `port_crane` を並べ、区画の辺0（道路側）に施設 `port_building`（ゲートと建屋）を置き、その間の空きにその港が扱う荷（段積みするコンテナ `port_container{n}`、または地面に並べる荷 `port_cargo{n}`）を置く。モジュラーの壁・角パーツは使わない。共通の約束は [F_建物メッシュの生成](F_建物メッシュの生成.md) による。

水際とヤードの決め方は2通りある。天然の海岸では、コアが海岸線で切らずに渡す区画（[B_土地形状](B_土地形状.md)）を、区画の中の水際の両端を結ぶ弦に平行な直線で海側で切り、厚みのある岸壁の板を海底まで押し出す。埋立地の上に引いた港は、埋立地が描く岸壁（[D_地形形状](D_地形形状.md)）を水際にして、板を作らない。埋め立てでは港の version が変わらないので、埋立地の中身が変わったら表示中の港を作り直す。水際は入港する船の接岸位置にも使う（[V_環境演出の乗り物](V_環境演出の乗り物.md)）。

荷は港の種類ごとに違うので、各港の `a{variant}` に置く。配置は区画・水際の形と通常モデル（無印）の寸法だけで決まり、`visual_variant2` を荷の配置の乱数の種に使う。岸壁の板の上面には地面パネルと同じ `floor` のマテリアルを使い、陸側の敷地と岸壁を一続きの床に見せる。道路への間口は `port_building` の中の目印から得る。
