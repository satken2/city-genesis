# 車両基地のメッシュ生成（MODEL_RAIL_YARD）

鉄道の車両基地・モノレールの車庫・LRT の車両基地のように、敷地の中の線路を施設の接続端子ノードへ収束させて描く方式である。並行する留置線、端子へ集まる集約線と分岐の曲線、架線と架線柱、車止め、検修庫を `yard_*` パーツで敷地に並べ、引き込み線は端子へつながる線路の軌道数に合わせて単線か複線で描く。モジュラーの壁・角パーツは使わない。共通の約束は [F_建物メッシュの生成](F_建物メッシュの生成.md) による。

端子ノードは `depot_node_id`（無ければ `infra_node_id`）で、電化した基地では走行網と送電網に共通の接続ノードになる（[インフラ網](../economics/26_インフラ網.md)）。端子の位置と端子へつながる線路は建物の version を変えずに変わるので、端子の移動や線路の変化を建物の側へ知らせて描き直す。

構内の設備は地形に沿わせる。地面パネルは `a{variant}` 自身の `floor` だけで張り、共通の舗装を線路の下に敷かない。クリック判定は架線柱の高さまで底面を押し出した形にし、架線や検修庫も選べるようにする。工事中・解体中は土の盛り上がりだけ、倒壊は瓦礫だけで表す。
