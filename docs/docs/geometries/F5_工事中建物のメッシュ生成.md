# 工事中建物のメッシュ生成（STATUS_CONSTRUCTING）

建設中（`STATUS_CONSTRUCTING`）の建物は、`model_type` に関わらず完成品を描かず、工事現場として描く。工事現場は、敷地を覆う土の盛り上がり、進捗に応じた高さまで組んだ足場、一定以上の階数の建物に立つタワークレーンで構成する。遠景ではクレーンを省いた簡易な形にする。

共通の仕組み（パーツの命名・外観バリアントの選択・壁と角の並べ方）は [F_建物メッシュの生成](F_建物メッシュの生成.md) による。

## 進捗の表し方

足場とクレーンの高さは、API の `construction_progress`（建設に必要な体積のうち調達済みの割合。百分率）から決める積み上げ済みの階数で表す。着工直後でも1階分は描き、着工した現場が見えるようにする。進捗が進んだエポックや竣工したエポックには建物の version が上がるので、差分ロードで描き直され、竣工すると通常の建物に切り替わる。

## パーツ

工事現場のパーツは `scaffold-wall`・`scaffold-corner`（足場）と `crane-base`・`crane-mid`・`crane-top`（クレーン）である。建物ごとのフォルダ（`a{variant}` → `b{bd_type}`）に無ければ、全建物共通の `Models/Buildings/common/` を使う。足場は通常の建物の壁・角と同じ規則で建物の外周に並べ、1段を階高に合わせる。クレーンは原点を下の段との接続点に置いて積み上げ、頂部だけを実寸で載せる。パーツが無いものは描かない。

畑・庭などの地面型、港湾の岸壁、露天掘りの建物は、土の盛り上がりだけで工事中を表す。
