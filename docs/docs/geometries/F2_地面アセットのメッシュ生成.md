# 地面アセットのメッシュ生成（MODEL_MODULAR_GROUND）

畑・庭・舗装広場のように、建物本体を持たない施設の方式である。壁・角・屋根・塔屋・玄関は描かず、建物の底面ではなく土地区画の全体に、フェンス・地面パネル・タイル（`tile` を実寸で敷き詰める）を置く。区画を引けないときは底面を使う。クリック判定も区画の形を押し出した形にする。パーツの命名・閾値フォルダ・地形への追従は [F_建物メッシュの生成](F_建物メッシュの生成.md) による。

工事中・解体中は土の盛り上がりだけ、倒壊は瓦礫だけで表す（[F5](F5_工事中建物のメッシュ生成.md)・[F8](F8_倒壊建物のメッシュ生成.md)）。
