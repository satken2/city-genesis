# B. 土地形状

土地区画の形状データの表し方と、区画の種別・路面辺・接道の決まり方について。区画の経済的な意味と作り方の種類は [4_地区と土地区画](../economics/4_地区と土地区画.md)、パスの形状は [A_パス形状](A_パス形状.md)、建物の底面の形は [C_建物形状](C_建物形状.md) を参照する。

## B.1. 何のための形状か

土地区画は、建物が立地する地面の区画であり、任意のポリゴンで表す。ポリゴンは建物の底面の上限（建蔽率の分母）であり、どの辺が道路に面するか、天然資源と重なるかといった判定にも使う。道路・線路などのパスは区画を持たず、区画の無い場所に敷く。

## B.2. 土地区画が持つ幾何プロパティ

区画の外周（`polygon`）は `[[x, z], ...]` の頂点列で、上から見て反時計回りに並び、末尾に始点を繰り返した閉じた輪である。ほぼ一直線上に並ぶ頂点を含むことがある。基準標高（`altitude`）は絶対標高で、接道があれば接道の路面の高さ、無ければ区画中心の地形の高さである（海上区画は B.5）。陸の建物の接地には使わない（[F_建物メッシュの生成](F_建物メッシュの生成.md)）。

## B.3. 座標系の取り扱い

土地区画の座標はワールド座標の水平面 `[x, z]` で（[D_地形形状](D_地形形状.md)）、高さを持たない。区画どうし・区画とパス・区画と海岸線の重なりや接道の判定は、すべてこの水平面で行う。

## B.4. 区画の作成

区画の形はコアが作る。作り方の種類は [4_地区と土地区画](../economics/4_地区と土地区画.md) を参照する。どの作り方も、都市の状態と入力が同じなら同じ形を作る（ゆらぎのある分割も乱数を入力から決める）ので、プレビューで返した形と確定で作られる区画の形は一致する。

## B.5. 海岸線と区画種別

区画の種別は、区画を作るときに、ポリゴンの位置とその時点の海岸線（[D_地形形状](D_地形形状.md)）から自動で決まる。外周が海岸線に接する区画（海・湖・川の岸）は沿岸、陸地とほとんど重ならない区画（海・湖・川の上）は海上、どちらでもなければ陸地になる。海岸線を持たないマップと都市の範囲の外は、すべて陸地とする。ポリゴンは海岸線で切らず、作成済みの区画の種別は埋立で海岸線が広がっても変わらない。どの種別の区画に建てられるかは、建物のバリアントごとにマスターの `agent_master` の `parcel_type` で決まる（指定が無ければ陸地）。

海上区画は、海上に建つ設備の敷地である。人や物が陸路で出入りしないので接道を持たず、基準標高は海面の 0 で、Unity は海上区画の建物と区画の上面をこの高さに置く（その地点の地形は海底なので、地形に合わせると沈む）。地区には属するが、地区のポリゴンの形には寄与しない。

## B.6. 既存区画との重なり

区画は互いに重ならない。新しい区画は既存の区画と重なる部分を除いて作り、除いた結果がいくつかに分かれれば、それぞれを別の区画にする。パスの建設と用地の確保については[パスとノード](../economics/3_パスとノード.md)を参照。

## B.7. 路面辺と接道の判定

路面辺（`facade_edge_index`）は、道路に物理的に接している辺である。番号 i は頂点 i から次の頂点への辺を指し、末尾に繰り返した始点は数えない。辺の中点から道路の中心線までの距離で判定するので、道路と直交する側面の辺は路面辺にならず、角地では複数の辺が路面辺になる。接道（`front_path_id`）は区画の辺に向かい合う街路を優先し、そうした街路が無い区画では、路面辺より緩い距離の範囲で近傍の街路を選ぶ。接道があるのに路面辺が無いときは、接道に最も近い辺を路面辺とするので、接道を持つ区画は必ず1つ以上の路面辺を持つ。近くに街路が無い区画は、路面辺が空で接道は未設定（`VALUE_NONE`）になる。

路面辺・接道・基準標高は、区画の作成・変形や周辺の道路の変化のたびにコアが決め直す。対象は沿道に区画を持てる街路だけである（橋などは除く）。区画の所属地区は、接道のうち区画がある側の面の地区になる（[4_地区と土地区画](../economics/4_地区と土地区画.md)）。

## B.8. 天然資源との重なり

区画は重なる天然資源を `resource_id` に `{資源種別: 資源ID}` の形で持ち、区画の形が変わると付け直す（[21_天然資源](../economics/21_天然資源.md)）。

## B.9. 土地区画の削除

建物が建っている区画は削除できない（解体が済んだ `STATUS_EMPTY` の建物の区画は、その建物とともに削除できる）。削除は市政府による収用で、所有者が市政府以外なら土地の価格を補償として支払う（[22_予算管理](../economics/22_予算管理.md)）。
