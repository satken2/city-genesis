# V. 環境演出の乗り物(高高度の航空機と沖合の船舶)

## V.1. 概要

空を横切る航空機と、海をゆっくり進む船舶をUnity側だけで描く。経済シミュレーションへは何も書き戻さず、保存もされない純粋な飾りである。空港が近くになくても高い空を旅客機が横切って見えるように、航空機と沖合の船は都市の状態に関わらず一定の頻度で現れる。例外は入港船(§V.5)で、稼働中の港があるときだけ、その港へ向かう船を描く。

| 種類 | モデル | 高度 / 速度 | 発生 |
|---|---|---|---|
| 旅客機 | `ambient_airliner` | 1,500〜2,300m / 170〜230m/s | 45〜110秒ごと、同時2機まで。飛行機雲を引く |
| プロペラ機 | `ambient_propeller` | 350〜650m / 45〜60m/s | 70〜200秒ごと、同時1機 |
| ヘリコプター | `ambient_helicopter` | 150〜300m / 35〜55m/s | 70〜200秒ごと、同時1機 |
| コンテナ船 | `ambient_container_ship` | 海面 / 4.5〜6m/s | 沖合の船は外洋40km²あたり1隻の期待値(上限6隻)。種類は重み(3 : 2 : 1.5 : 3.5)で抽選。コンテナ埠頭の入港船にも使う |
| 石油タンカー | `ambient_tanker` | 海面 / 3.5〜5m/s | 同上。タンカー埠頭の入港船にも使う |
| クルーズ客船 | `ambient_cruise_ship` | 海面 / 4.5〜6m/s | 同上。客船ターミナルの入港船にも使う |
| 漁船 | `ambient_fishing_boat` | 海面 / 3〜5m/s | 同上 |
| ばら積み船 | `ambient_bulk_carrier` | 海面 / §V.5 | バルク港の入港船だけ。沖合の船の抽選には入らない |

沖合の船の速度は実物より遅い。画面上でゆっくり動いて見えることを優先し、実速度(コンテナ船で約12m/s)に合わせない。入港船は港外の実際の航行速度から実船並みの減速度で止まる(§V.5)。航空機はほぼ実速度だが、遠くを飛ぶので画面上では緩やかに見える。

乗り物は GameObject を持たない。状態は保存座標(FloatingOrigin のずれを含まない座標)で持ち、毎フレーム `Graphics.RenderMesh` で描く。`AmbientVehicleManager` 自身の GameObject は動かさないので、FloatingOrigin がシーン全体をずらしたときはその位置が累積オフセットになり、描画時に足す。カメラ位置は `CameraCellChecker.CurrentWorldPosition` からオフセットを引いて保存座標へ戻す。

描画LODは、専用の接写・遠景モデルを持つ船だけを建物と同じ投影比の判定(`DrawLodEvaluator.EvaluateBySize`。接近と離脱でしきい値を分け、接写は建物と同じ距離上限の内側だけ)で切り替え、前のフレームのLODを乗り物ごとに持つ。縦画角60°では、全長160〜172mの船は約3.2〜3.4kmまで近づくと通常になり、4.8〜5.2kmより離れると遠景へ戻る。全長22mの漁船は約510mで通常になる。どちらも接写へ切り替わるのは距離上限に入ってからである。遠景は影を落とさない。専用モデルの無い航空機は常に無印で描く(`PropRenderModel` の自動の頂点集約は、数十m以上ある機体の輪郭を崩すため使わない)。

表示条件は `GameStateManager.IsGameStarted()` かつ海岸線ロード済み。航空機と沖合の船は海岸線の世代(`CoastlineStore.Version`)が変わるたびに消して配り直す。入港船は海岸線の取り直しでは消さず、エポックが進んだとき(§V.5)に入れ替える。`session:reset` とゲーム終了では入港船も含めて全消去し、前の都市の船や飛行機を残さない。ゲーム速度や一時停止の概念はUnity側に無いので、既存の車両と同じく `Time.deltaTime` だけで進む。表示トグルは `SetVisible` を用意しているが、表示パネルのレイヤーには接続していない。

## V.3. 航空機の航路

航路は直線で、カメラ注視点から半径1,200m以内の焦点を通る。焦点の前後7,000mを始点・終点とし、カメラの遠景クリップ(4,500m)の外で現れて消える。方位・高度・速度は種類ごとの範囲から乱数で決め、途中で変えない。カメラが移動しても航路は追従せず、そのまま飛び去る。地形や建物とは干渉しない(最低高度150mは都市内の建物より十分高い)。

旅客機だけが飛行機雲を引く。60mごとに通過点を記録し、45秒で消える。幅は機体直後14mから消える直前70mへ広がり、不透明度は先端で立ち上がり寿命の終わりで0になる。帯は水平な四角形の連なりで、地上から見上げる前提の形状である。

## V.4. 沖合の船の航行と陸地回避

海岸線 `CoastlineStore` を陸地の正として使い、船の判断はこれだけに依存する。海岸線は新規都市の作成時に `near_map` から抽出され、以後は埋立の完了で広がる（[D_地形形状](D_地形形状.md) §D.17.4）。Unity は `session:reload` のたびに海岸線を取り直し、そのたびに `CoastlineStore.Version` が進む。版が変わったら沖合の船をすべて消し、下記の外洋の面積の見積もりからやり直すので、埋め立てた範囲に船が残ったり、そこを航路が通ったりしない。

**数**: 常に一定数を保つのではなく、たまに見かける程度の希少さにする。海岸線のロード時にマップ矩形を40×40の格子でサンプリングして外洋の面積を見積もり、期待値 = 面積 × (1隻/40km²) とする(上限6隻)。10km四方の半分が海なら約1.25隻。各船は7〜13分の寿命を持ち、発生率 = 期待値 ÷ 平均寿命 の定常過程で出入りする。寿命が尽きた船は描画範囲(6km)の外に出た時点で消し、目の前では消さない。都市の読み込み直後は期待値のポアソン分布で数を決め、残り寿命を一様にばらして最初から定常状態に近づける。

**発生**: マップ矩形(+500m)内の乱数点から、次を満たす点を最大30回試す。

- 外洋であること。どの海岸線リングにも含まれない点だけを海とする(陸地リングの内側の穴は湖なので、偶奇判定ではなく包含数0で判定する)。
- マップ内なら標高が海面より2m以上低いこと(海岸線の粗さで岸に乗るのを防ぐ)。
- 海岸線までの距離が「全長×0.6+150m」以上あること。
- カメラ注視点から600m以上離れていること(目の前に突然現れない)。

**操舵**: 2.5秒ごとに18方位(現在の方位±0〜180°)を採点し、最も広い水面へ向かう。各方位で先読み距離を4分割した点の「海岸線までの距離−必要余裕(全長×0.6+30m)」の最小値を採点値とし、300mで頭打ちにする。マップ外1,500mより先へ出る点は−400m、方位変更は1°あたり−0.6m、加えて0〜12mの乱数で減点する。直進が十分安全なら直進し、行き止まりでは反転する。先読み距離は 300m・全長×3・旋回半径×2 の最大値で、大型船ほど遠くを見る。方位は種類ごとの旋回速度(大型船0.8〜1.0°/s、漁船5°/s)で目標へ寄せる。

海岸線までの距離は全辺走査なので毎フレームは計算せず、操舵の周期でだけ評価する。それでも岸へ乗り上げた(海岸線までの距離が全長×0.3未満)船は消して別の場所に発生させる。船同士の衝突回避は行わない。海岸線が無い(陸地の無い)マップでは船を出さない。

**航跡**: 船ごとに1枚の水平な帯メッシュ(海面から0.1m上)を毎フレーム組み直し、`Custom/ShipWake` で泡を描く。成分は次の4つで、濃さはどれも船の前進の速さで決まる。前進の速さは船尾の移動を船首の向きへ射影して求めるので、入港船の横寄せや接岸中は航跡が出ない。

| 成分 | 位置と形 | 濃さ |
|---|---|---|
| 船首波・船体沿いの泡 | 船体に固定。喫水線の外側に、船首で喫水線長×0.06(2〜9m)、船体中央でその3割、船尾の手前で6割5分の幅(船首波が淡いほど狭く、最小4割) | フルード数(速さ÷√(9.81×喫水線長))0.04〜0.2で立ち上がる |
| ケルビン波の腕 | 船首から両側へ19.47°(正接0.354)で開く線。船尾より後ろは、通過点を記録したときの速さ×経過時間だけさらに開く | フルード数0.07〜0.3で立ち上がる。泡は 0.5×喫水線長÷速さ+3秒 の時定数で減り、波頭の明るさは寿命の4割で消える |
| 船尾の乱流 | 半幅は船尾で船の半幅の0.3倍。喫水線長の4割ほど進む間に、白濁の濃さに応じて最大0.8倍まで開き、その後は経過時間の平方根で広がる | 前進0.4m/sで出始め、5m/sで最も濃い。泡は 喫水線長÷速さ+4秒 の時定数で減り、寿命の7割を過ぎてから寿命までに消える |
| 白濁(泡を含んで白く濁った水) | 乱流の帯 | 2.5m/sで最も濃い。寿命まで薄れながら残る |

寿命は大型船150秒・漁船60秒。通過点は前進の速さ×1.2(1〜10m)ごとに記録し、旋回の曲がりを同じ細かさで追う。巡航中の大型船ではケルビン波の腕は淡く、漁船ではくっきり出る。港内の微速では船尾の薄い白濁の筋だけになる。

泡は、ノイズの値が濃さで決まる閾値を超えた所に描く。ノイズの座標は航跡に沿った横位置と船尾が前進した累積距離で、泡は水面に固定され、船が進んでもその場に残る。乱流の泡は、船尾の直後がプロペラのかき回す丸い渦の塊、古くなるほど前後に長い筋と網目になり、濃さが下がるにつれて途切れて消える。帯の縁はノイズで揺らがせる。小さな船ほどノイズの粒を細かくする(半幅÷13.8、0.25〜1倍)。遠景では画素がノイズの粒より粗くなるので、ノイズを平均の濃さに置き換えてちらつきを防ぐ。泡は太陽光と環境光の拡散だけで照らし、船の影とフォグを受ける。船体・岸と交わる線は深度差0.2mでなじませる。海面(`Transparent`)の上に重ねるため、描画キューは `Transparent+1`。

喫水線の平面形は、モデル(無印)のメッシュの喫水線(原点の高さ)を横切る辺から、モデルごとに一度だけ測る。船首波の内縁は喫水線より0.3m内側に置き、船体の内側に回り込んだ泡は船体に隠れる。

## V.5. 入港船

稼働中(`status` が `STATUS_ACTIVE`)の港に、外洋から入ってくる船を描く。港の種類と船は次のとおりで、漁港(1001)と石油パイプライン受入基地(1073)は対象外である。

| 港(バリアント) | 船 | 港外の速さ | 接岸している時間 |
|---|---|---|---|
| バルク港(401) | ばら積み船 | 4.6〜5.4m/s(9〜10.5ノット) | 36〜84時間 |
| タンカー埠頭(402) | 石油タンカー | 4.6〜5.4m/s | 18〜36時間 |
| コンテナ埠頭(403) | コンテナ船 | 5.6〜6.4m/s(11〜12.5ノット) | 12〜24時間 |
| 客船ターミナル(1068) | クルーズ客船 | 5.6〜6.4m/s | 8〜11時間 |

港外の速さは港へ近づく航路で出す速さ、接岸している時間は実際の港での荷役・寄港に掛かる時間で、どちらも船ごとに範囲から乱数で決める。時間は実時間なので、接岸した船はエポックを進めない限り実質的に動かない。

**取得と抽選**: 港は `GET /api/v1/buildings/?filter=[variant][eq]{バリアント}` を上の4種について読み、`GET /api/v1/city/` のエポックと一緒に扱う。読み直すのは `TerrainManager.FetchCoastline` が海岸線・湖・川・埋立地を取り終えるたび(`TerrainManager.ShoreDataVersion`。都市の読み込み・エポック後と編集後の `session:reload`)で、埋立地の岸壁まで揃ってから水際を求める。

- 港ごと・エポックごとに1回抽選し、確率0.6で船が向かっている。
- エポックが進んでいたら入港船をすべて消して抽選し直す。
- 同じエポックの読み直し(建物の編集など)では、稼働中でなくなった港の船だけを消し、まだ抽選していない港だけを抽選する。編集のたびに船が入れ替わらない。

**接岸位置**: 港の水際([港湾岸壁](F4_港湾岸壁のメッシュ生成.md))のうち最も長い1本に、船首尾を水際と平行にして横付けする。船体はモデルの外接箱の長さ×幅の長方形として扱い、船側と岸壁の隙間(防舷材)は1.5mとする。船体は水際の中点に置き、次のどちらかに当たるときは岸壁に沿って全長の±0.25倍、±0.5倍ずらして試す。どこにも置けなければ、その港には船を出さない。

- 船体の外周が陸地(海岸線の内側)に掛かる。
- 先に決めた入港船の船体と15m未満に近づく。
- 平行に進む区間(下記)が、どちら向きにも岸から「半幅+10m」を空けられないか、他の入港船の船体(同じ幅だけ広げる)に掛かる。

船は岸壁より長くてよい(桟橋や短い岸壁でも実際に船首尾がはみ出す)。

**航路**: 接岸位置から沖へ「船幅+10m」の点を停止点とする。停止点の手前には全長ぶん岸壁と平行に進む区間を置き、岸壁の両向きのうち岸と他の入港船から遠い向きを選ぶ。実船は岸壁に沿って行き足を落としてから止まり、正面から岸壁へ向かうと船首が岸に掛かるので、この区間が取れない位置には船を置かない。停止点までの航路は `SeaRoute` が次の手順で求める。

1. マップの矩形を間隔 max(40m, マップの長辺÷400) の格子で覆い、格子点ごとに海岸線までの距離を求める(400mで頭打ち)。海岸線はマップの矩形で切られていてマップの外の陸地を知らないので、航路はマップの外へ出さない。
2. 岸から「半幅+10m」未満の点と、他の入港船の接岸位置(同じ幅だけ広げる)の中の点は通れない。
3. 平行区間の始点に最も近い通れる格子点を根に、8近傍のダイクストラで最短経路木を張る。岸から「半幅+80m」に足りない水域は、不足の割合×4だけ距離を割増す(水路の中央を好む)。斜めの辺は両脇の格子点も通れるときだけ使う。
4. 出発点は、木に含まれる格子点のうち岸から「全長×0.6+150m」以上離れ(沖合の船の発生条件と同じ)、どの海岸線リングにも含まれない外洋の点から無作為に選ぶ。湖の港や外洋へつながらない水域の港には船を出さない。
5. 出発点から根までの格子の経路を、見通せる点まで一直線にまとめる。まとめた線分は、置き換えた区間の点の岸までの距離の最小値(ただし「半幅+80m」が上限)より岸へ寄らないものだけ採る。狭い水路では格子の経路がそのまま残る。
6. 曲がり角を、全長×2までの距離から二次ベジエで丸める。丸めた曲線が両隣の線分より岸へ寄るなら距離を半分ずつ縮めて試し、だめなら角のまま残す。

距離の格子と最短経路木は格子の点数に比例して重いので、バックグラウンドスレッドで求める。

**置き方と動き**: 船は航路と横寄せを通した道のりの一様乱数の位置に置く。

- 航路の上では、停止点までの残り d に対して 速さ = min(港外の速さ, √(0.25² + 2×0.005×d)) [m/s] とする。一定の減速度 0.005m/s² で行き足を落とす規則で、12ノットの船は停止点の約3.6km手前から減速し、停止点で0.25m/s になる。向きは航路の頂点ごとの進行方向を補間する。
- 停止点から接岸位置へはタグボートで押し付けるように真横へ寄せる。速さは残り d に対して √(2×0.0005×d) を 0.05〜0.2m/s に収め、船首は平行に進んできた向きのまま保つ。
- 接岸したら接岸している時間だけ留まる。時間を過ぎた船は描画範囲(6km)の外にある時点で消し、同じエポックの間はその港に次の船を出さない。
- 航跡は沖合の船と同じ規則(§V.4)で、減速に合わせて薄くなり、横寄せと接岸中は出ない。航路の途中に置いた船は、航跡の寿命ぶん遡った道のりから今の位置まで進め直して航跡の履歴を作ってから描く(後ろに航跡の無い船が目の前に現れない)。沖合の船はカメラから600m以上離れて発生するので履歴を作らない。

## V.6. モデル制作規約

| 項目 | 規約 |
|---|---|
| 置き場 | `Assets/Models/Props/ambient_{名前}.fbx`。環境演出は固定名で読む。手動配置用に数値ID 301〜307 の別名FBX(メッシュ共有。船は `_close` / `_far` も)も書き出し、`prop_master` に登録している([地形プロップ](M_地形プロップ.md) §M.7.2)。ばら積み船は入港船専用で別名を持たない |
| 原点 | 航空機は接地面(車輪・スキッド・ナセルの最下点)、船舶は喫水線(船体は原点より下へ沈む)。水平はbbox中心 |
| 向き | Blender -Y が前方(機首・船首)。標準書き出しで Unity +Z になり、進行方向へ `LookRotation` で向ける |
| 寸法 | 実寸。旅客機は全長37.5m・翼幅36m。船は都市の規模に合わせた中型船。入港船は外接箱の長さ×幅を船体として接岸位置と航路の余裕を決めるので、船体より大きく張り出す部品を付けない |
| 構成 | 1モデル1メッシュの固定形状。ローターやプロペラも本体に含め、回転させない |
| 材質 | 既存の `PROP_*` と、建物の `BD_*`(`BD_NAVY`・`BD_GREY`・`BD_YELLOW` など)を名前で共有する。新規材質は作らない |
| LOD | 船は接写 `_close`(無印と同じ外接箱。許容0.05m)と遠景 `_far`(無印と同じ水平範囲と天端。許容0.3m)を持つ。航空機は無印だけ |

船舶の実寸は各モデルのbboxを使う。接岸計算でその外接箱を船体として扱うため、船体より大きく張り出す部品を付けない。原本は `blender/props.blend`。

## V.7. 描画の範囲

航跡は海面に重ねる半透明の帯で、海面の波の法線を変えない。船どうしの航跡も干渉しない。船は互いに避け合わず、入港船の経路は他の船の接岸位置だけを避ける。航行中の船や港の荷役設備との干渉は判定しない。

天候による視程は共通フォグに従う。航空機は夜間灯火を持たない。表示と発生は `AmbientVehicleManager` が管理する。
