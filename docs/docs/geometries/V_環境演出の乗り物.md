# V. 環境演出の乗り物(高高度の航空機と沖合の船舶)

## V.1. 概要

空を横切る航空機と、海をゆっくり進む船舶をUnity側だけで描く。空港や港湾施設、交通量、貿易といった経済シミュレーションの状態には一切連動せず、保存もされない純粋な飾りである。空港が近くになくても高い空を旅客機が横切って見えるように、都市の状態に関わらず一定の頻度で現れる。

| 種類 | モデル | 高度 / 速度 | 発生 |
|---|---|---|---|
| 旅客機 | `ambient_airliner` | 1,500〜2,300m / 170〜230m/s | 45〜110秒ごと、同時2機まで。飛行機雲を引く |
| プロペラ機 | `ambient_propeller` | 350〜650m / 45〜60m/s | 70〜200秒ごと、同時1機 |
| ヘリコプター | `ambient_helicopter` | 150〜300m / 35〜55m/s | 70〜200秒ごと、同時1機 |
| コンテナ船 | `ambient_container_ship` | 海面 / 4.5〜6m/s | 船舶は合計6隻を維持。種類は重み(3 : 2 : 1.5 : 3.5)で抽選 |
| 石油タンカー | `ambient_tanker` | 海面 / 3.5〜5m/s | 同上 |
| クルーズ客船 | `ambient_cruise_ship` | 海面 / 4.5〜6m/s | 同上 |
| 漁船 | `ambient_fishing_boat` | 海面 / 3〜5m/s | 同上 |

船の速度は実物より遅い。画面上でゆっくり動いて見えることを優先し、実速度(コンテナ船で約12m/s)に合わせない。航空機はほぼ実速度だが、遠くを飛ぶので画面上では緩やかに見える。

## V.2. 実装ファイル

| ファイル | 役割 |
|---|---|
| `Vehicles/AmbientVehicleManager.cs` | 発生・移動・陸地回避・描画。`AfterSceneLoad` で自己生成する |
| `Vehicles/AmbientTrail.cs` | 飛行機雲・航跡の帯メッシュ |
| `Resources/Shaders/AmbientTrail.shader` | 帯用の頂点色アルファの半透明シェーダー |
| `DataLoaders/PropRenderModel.cs` | 固定名(文字列)でも共有FBXから描画部品を取り出せる |
| `Assets/Models/Props/ambient_*.fbx` | 7種のモデル。ミラープレハブは `ModelPrefabGenerator` が生成する |

乗り物は GameObject を持たない。状態は保存座標(FloatingOrigin のずれを含まない座標)で持ち、毎フレーム `Graphics.RenderMesh` で描く。`AmbientVehicleManager` 自身の GameObject は動かさないので、FloatingOrigin がシーン全体をずらしたときはその位置が累積オフセットになり、描画時に足す。カメラ位置は `CameraCellChecker.CurrentWorldPosition` からオフセットを引いて保存座標へ戻す。

表示条件は `GameStateManager.IsGameStarted()` かつ海岸線ロード済み。`session:reset`、海岸線の世代(`CoastlineStore.Version`)の変化、ゲーム終了で全消去し、前の都市の船や飛行機を残さない。ゲーム速度や一時停止の概念はUnity側に無いので、既存の車両と同じく `Time.deltaTime` だけで進む。表示トグルは `SetVisible` を用意しているが、表示パネルのレイヤーには接続していない。

## V.3. 航空機の航路

航路は直線で、カメラ注視点から半径1,200m以内の焦点を通る。焦点の前後7,000mを始点・終点とし、カメラの遠景クリップ(4,500m)の外で現れて消える。方位・高度・速度は種類ごとの範囲から乱数で決め、途中で変えない。カメラが移動しても航路は追従せず、そのまま飛び去る。地形や建物とは干渉しない(最低高度150mは都市内の建物より十分高い)。

旅客機だけが飛行機雲を引く。60mごとに通過点を記録し、45秒で消える。幅は機体直後14mから消える直前70mへ広がり、不透明度は先端で立ち上がり寿命の終わりで0になる。帯は水平な四角形の連なりで、地上から見上げる前提の形状である。

## V.4. 船舶の航行と陸地回避

海岸線 `CoastlineStore` を陸地の正として使う。マップの海岸線は `near_map` 由来で `init_game` 後は不変なので、船の判断もこれだけに依存する。

**発生**: マップ矩形(+500m)内の乱数点から、次を満たす点を最大30回試す。

- 外洋であること。どの海岸線リングにも含まれない点だけを海とする(陸地リングの内側の穴は湖なので、偶奇判定ではなく包含数0で判定する)。
- マップ内なら標高が海面より2m以上低いこと(海岸線の粗さで岸に乗るのを防ぐ)。
- 海岸線までの距離が「全長×0.6+150m」以上あること。
- カメラ注視点から600m以上離れていること(目の前に突然現れない)。

**操舵**: 2.5秒ごとに18方位(現在の方位±0〜180°)を採点し、最も広い水面へ向かう。各方位で先読み距離を4分割した点の「海岸線までの距離−必要余裕(全長×0.6+30m)」の最小値を採点値とし、300mで頭打ちにする。マップ外1,500mより先へ出る点は−400m、方位変更は1°あたり−0.6m、加えて0〜12mの乱数で減点する。直進が十分安全なら直進し、行き止まりでは反転する。先読み距離は 300m・全長×3・旋回半径×2 の最大値で、大型船ほど遠くを見る。方位は種類ごとの旋回速度(大型船0.8〜1.0°/s、漁船5°/s)で目標へ寄せる。

海岸線までの距離は全辺走査なので毎フレームは計算せず、操舵の周期でだけ評価する。それでも岸へ乗り上げた(海岸線までの距離が全長×0.3未満)船は消して別の場所に発生させる。船同士の衝突回避は行わない。海岸線が無い(陸地の無い)マップでは船を出さない。

**航跡**: 海面から0.3m浮かせた白い帯。大型船は40mごとの通過点を80〜90秒、漁船は5mごとを30秒保持し、船幅程度から数倍へ広がって消える。

## V.5. モデル制作規約

| 項目 | 規約 |
|---|---|
| 置き場 | `Assets/Models/Props/ambient_{名前}.fbx`。環境演出は固定名で読む。手動配置用に数値ID 301〜307 の別名FBX(メッシュ共有)も書き出し、`prop_master` に登録している([地形プロップ](M_地形プロップ.md) §M.7.2) |
| 原点 | 航空機は接地面(車輪・スキッド・ナセルの最下点)、船舶は喫水線(船体は原点より下へ沈む)。水平はbbox中心 |
| 向き | Blender -Y が前方(機首・船首)。標準書き出しで Unity +Z になり、進行方向へ `LookRotation` で向ける |
| 寸法 | 実寸。旅客機は全長37.5m・翼幅36m、コンテナ船200m、タンカー240m、クルーズ客船250m、漁船18m |
| 構成 | 1モデル1メッシュの固定形状。ローターやプロペラも本体に含め、回転させない |
| 材質 | 既存の `PROP_*` と `BD_YELLOW` を名前で共有する。新規材質は作らない |
| LOD | `_close` / `_far` は使わない(常に無印を描く) |

正本は `genesis-gallery/library/props.blend`、生成ジョブは `pipeline/jobs/build_ambient_vehicles.py`(寸法・面数・再生成手順は `pipeline/jobs/ambient_vehicles.md`)。バリデータは `ambient_` 接頭辞のファイルを環境演出として扱い、水平中心と専用の頂点予算(Normal 3,500)だけを検査する。船は喫水線原点なので地形プロップの接地検査は適用しない。

## V.6. 検証と制限

- モデルは `validator/validate.py Assets/Models/Props` と `build_gallery.py --only ambient_` のサムネイルで確認する。
- Unity側の独立検証は無い。実機で、船が陸地や湖に現れない・岸へ乗り上げない・セッション切り替えで消えることを目視する。
- 天候による視程は既存のフォグに従う。飛行機の灯火や夜間表現は無い(昼夜サイクルが存在しない)。
- 表示パネルからのON/OFF、発生頻度の設定、港や空港との連動は未実装。
