# モジュラー建物のメッシュ生成（MODEL_MODULAR_FLAT / HOUSE / GABLE / SHED）

底面の外周に壁・角のパーツを階ごとに並べる、通常の建物の方式である。壁・角・敷地装飾・塔屋・玄関・外階段・基盤の扱いは4方式で共通で（[F_建物メッシュの生成](F_建物メッシュの生成.md)）、違いは屋根だけである。

| model_type | 屋根 |
| --- | --- |
| `MODEL_MODULAR_FLAT` | 平屋根 |
| `MODEL_MODULAR_HOUSE` | 寄棟状の三角屋根 |
| `MODEL_MODULAR_GABLE` | 切妻屋根（勾配面2枚と妻壁） |
| `MODEL_MODULAR_SHED` | 片流れ屋根（薄い1枚と妻壁。粗末な小屋のトタン屋根） |

屋根は形のパーツを持たずに生成し、屋根面のマテリアルを `ceil`、妻壁のマテリアルを窓の無い `generic-wall` から取る。勾配屋根の立ち上がりは建物の高さではなく階高に比例させ、階数の多い建物だけ屋根が巨大にならないようにする。`interior-floor` があれば各階に床を張り、平屋根ではその床が屋上を兼ねる。

`building_shape` が `SHAPE_FULL`（区画いっぱいの底面。[C_建物形状](C_建物形状.md)）の建物は、最上階1階分の壁・角に屋根と塔屋を載せた形で描く。
