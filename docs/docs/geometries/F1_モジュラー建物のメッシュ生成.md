# モジュラー建物のメッシュ生成（MODEL_MODULAR_FLAT / HOUSE / GABLE / SHED）

## 概要

モジュラーパーツ（壁・角）を底面ポリゴンに沿って組み立てる、通常の建物のモデルタイプ。
壁・角・地面パネル・基盤・フェンス・塔屋・エントランス・コライダーの生成規則は4者で完全に共通で、
[[F_建物メッシュの生成]] に記述する。本ドキュメントはその差分、すなわち**屋根の作り方**を記述する。

| model_type | 屋根 |
| --- | --- |
| **MODEL_MODULAR_FLAT** | 平屋根（底面形状と同じ水平ポリゴン） |
| **MODEL_MODULAR_HOUSE** | 住宅風三角屋根（寄棟状。妻側も傾斜する） |
| **MODEL_MODULAR_GABLE** | 切妻屋根（厚みのある勾配面2枚 + 妻壁） |
| **MODEL_MODULAR_SHED** | 片流れ屋根（薄い勾配面1枚 + 妻壁。粗末な小屋のトタン屋根） |

いずれも塔屋（[[F_建物メッシュの生成]] §10）を配置する。

**躯体（壁・角）の作り方は4者で同一で、model_type による分岐は無い。** 壁パーツ（`mid-w1` など）
があればそれを辺に敷き詰め、閾値フォルダのどこにも `mid-w1` が無ければ底面ポリゴンを躯体の
高さまで押し出した**白い箱**（`DefaultBodyBuilder`）になる（[[F_建物メッシュの生成]] §4.3・§5）。
角パーツも同様にオプトインで、無ければ角を描かず壁を辺の端まで敷き詰める
（[[F_建物メッシュの生成]] §5・§7.6）。

**屋根の立ち上がりはいずれも階高（`height_per_floor`）基準で決め、建物高さには比例させない。**
比例させると階数の多い建物だけ屋根が巨大になり、街並みの中で屋根の高さが揃わなくなるため。
**屋根面のマテリアルもいずれも `ceil` パーツから解決する**（[[R_マテリアルの解決]] §3）。

実装は `ModularBuildingMeshBuilder`（躯体 = `ModularBodyBuilder`、屋根 = `FlatRoofBuilder` /
`HouseRoofBuilder` / `GableRoofBuilder` / `ShedRoofBuilder`）。屋根ビルダーが共有する
ポリゴン幾何（軒の出の輪郭を作る `OffsetPolygonOutward`、棟線・傾斜方向を決める
`TryResolveMinAreaRect`）は `BuildingMeshUtils` に置く。

## 1. 平屋根（MODEL_MODULAR_FLAT）

`interior-floor` があれば、各階と屋上に厚み付きの床を生成し、別の平屋根パネルは重ねない。
`mid-stair` がある場合はF文書§11.4の描画用セットバック輪郭を壁・各階床・屋根で共有する。
元の占有範囲は維持し、外階段の帯を床や屋根で塞がない。立体駐車場3005はこの仕組みで
頂点3側の折り返しスロープと、各階・屋上の踊り場を接続する。

### 各階の床（任意）

選択されたprefix・閾値フォルダに`interior-floor`がある場合、`InteriorFloorBuilder`が
建物の各階に厚みのある水平床を生成する。通常・接写の共通パーツ解決を通し、建物IDで分岐しない。
GROUNDとSHAPE_FULLは対象外。パーツが無い既存建物には床を追加しない。
HOUSE/GABLE/SHEDにも適用できるが、これらの勾配屋根は従来の屋根ビルダーが作る。

参照モデルの高さを厚み、材質スロット0を上面、1を下面と小口（無ければ0を共有）として読む。
形状自体を並べず、底面の耳切り三角形分割から上面・下面・外周を作るため、凹多角形にも追従する。
各階の上面は階番号×階高。地上階だけは敷地面・基盤との重なりを避けて0.02mとする。
下面はその位置から床厚ぶん下げる。地形へは変形させない。

FLATでは階数×階高の屋上にも同じ床を置き、FlatRoofBuilderの平面を重ねない。
この場合、屋上の材質もinterior-floorのスロット0が正となり、ceilは使用しない。
top-wパーツにパラペットや照明を付けても、屋上面の高さは変わらない。
床メッシュは1棟内で共有して階ごとの変換を加え、最終結合後に破棄する。

### 各階床を持たない平屋根

底面ポリゴンと同じ形状の水平ポリゴンを建物最上部に配置する。
マテリアルは `ceil` パーツから取得する。該当パーツが存在しない場合は、壁面マテリアル等の他の配置済みパーツの有効なマテリアル、または建物全体のデフォルトマテリアルを使用する。
ポリゴンの三角形分割は耳切り法（ear clipping）を用い、失敗時はファン型にフォールバックする。

## 2. 住宅風三角屋根（MODEL_MODULAR_HOUSE）

建物底面を**軒の出（0.4m）だけ外側に広げた**ポリゴンから棟線を求め、底面の各頂点を棟線へ
射影することで屋根の傾斜面を生成する。棟線の両端は内側にセットバックする（引き込み量は
棟の立ち上がりの2倍）。L字建物にも対応する。

棟の立ち上がり（壁の天端から棟まで）は切妻屋根（§3）と同じく**1階あたりの高さ
（[[F_建物メッシュの生成]] §14）の半分に固定**する。

妻側も傾斜させて隙間を作らない（寄棟状の）形状であり、妻壁を必要としない点が切妻屋根（§3）と根本的に異なる。

マテリアルは平屋根・切妻屋根と同じく `ceil` パーツから取得し、無ければ他の配置済みパーツの
有効なマテリアル、さらに無ければ建物全体のデフォルトマテリアルにフォールバックする。

---

## 3. 切妻屋根（MODEL_MODULAR_GABLE）

屋根は**厚みのある2枚の板**として作り、板が塞がない妻側の三角形の隙間は**妻壁**の板で塞ぐ。

1. 建物底面の**最小面積外接矩形**を求め、その長辺方向を棟線方向、短辺の半分を半幅とする。
   棟の高さ（壁の天端からの立ち上がり）は建物の大きさによらず **1階あたりの高さ（[[F_建物メッシュの生成]] §14）の半分に固定**する。
   間口の広さに比例させると大きな建物の屋根だけが巨大になるため、街並みの中で屋根の高さを揃える。
2. 屋根面（板の裏面）の高さは棟線からの水平距離だけで決まる（`棟の高さ − 距離 × 勾配`）。
   勾配は棟の高さと半幅から逆算する（＝間口が広い建物ほど緩勾配になる）ため、
   **屋根面は建物外周＝壁の位置でちょうど躯体の天端を通る**。
3. 建物底面を軒の出（0.4m）だけ外側にオフセットしたポリゴンが屋根板の輪郭になる。屋根板は
   壁面より外側かつ下側へ張り出し、その下が**軒下**になる。妻側では、けらばが同じだけ張り出す。
4. 輪郭を棟線で左右に切り分け、それぞれを1枚の板として張る。板は裏面・**厚み 0.25m（垂直方向）**の
   表面・外周の小口（軒先の鼻隠し、けらばの破風）で構成される。棟線上の辺は反対側の板と接するため
   小口を張らない。板は棟をまたがないので、**妻側は開いたまま**になる。
5. 建物底面の各辺について、壁の天端から屋根面までの隙間を垂直な板（**妻壁**）で塞ぐ。平側では
   屋根面が壁の位置で天端を通るため高さ 0 に潰れ、妻側では棟までの三角形になる。棟線をまたぐ辺は
   屋根面が折れる位置で2本に分割するため、棟の頂点がそのまま妻壁の頂点になる。

マテリアルはサブメッシュを分けて2種類を使う。

- **屋根面** — 平屋根と同じく `ceil` パーツから取得する。
- **妻壁** — `generic-wall` パーツ（無地の壁。マテリアル参照専用で形状は使わない）
  から取得する。窓の意匠が入る通常の壁パーツを流用すると妻壁に窓が並んでしまうため、専用の
  パーツを設ける。

どちらも該当パーツが無ければ他の配置済みパーツの有効なマテリアル、さらに無ければ建物全体の
デフォルトマテリアルにフォールバックする。棟線方向を決定できない退化ポリゴンでは平屋根に
フォールバックする。

## 4. 片流れ屋根（MODEL_MODULAR_SHED）

粗末な小屋・仮設物置向けの、トタン板1枚を一方向に傾けただけの屋根。棟を持たず、屋根面全体が
**1枚の平面**になる点が切妻屋根（§3）と異なる。

1. 建物底面の**最小面積外接矩形**を求め、その**短辺方向**を傾斜方向、長辺方向を軒先・けらばの
   方向とする。
2. 傾斜の向きは、**前面の辺（頂点0 → 頂点1。塔屋 §10.3・エントランス §11.2 と同じ規約）の側が
   低くなる**ように決める。軒先が接道側を向き、街路からは低い側の軒を見上げる形になる。
   前面の辺が傾斜方向とほぼ直交していて向きを決められない場合は短辺方向をそのまま使う。
3. 高い側の立ち上がり（低い側の壁の天端から高い側の壁の天端までの高さ）は建物の大きさによらず
   **1階あたりの高さ（[[F_建物メッシュの生成]] §14）の 0.35 倍に固定**する。勾配は立ち上がりと
   建物の全幅から逆算するため、**屋根面は低い側の壁の位置でちょうど躯体の天端を通る**
   （＝間口が広い建物ほど緩勾配になる）。
4. 建物底面を軒の出（0.3m）だけ外側にオフセットしたポリゴンが屋根板の輪郭になる。屋根板は
   壁面より外側へ張り出し、低い側では壁の天端より下、高い側では上へ抜ける。張り出した下が軒下。
5. 屋根板は**厚み 0.08m（垂直方向）**の薄板として作る（波トタンを想定し、切妻屋根の板より薄い）。
   裏面・表面・外周全周の小口で構成する。棟が無いので、切妻屋根と違って小口を省く辺は無い。
6. 建物底面の各辺について、壁の天端から屋根面までの隙間を垂直な板（**妻壁**）で塞ぐ。低い側では
   高さ 0 に潰れ、高い側では立ち上がりぶんの矩形、側面では三角形になる。屋根面は1枚の平面で
   折れないため、切妻屋根と違って辺を分割する必要は無い。

マテリアルの割り当ては切妻屋根（§3）と同じで、**屋根面 = `ceil` パーツ**、**妻壁 = `generic-wall`
パーツ**の2サブメッシュに分ける。トタンらしい見た目は `ceil` パーツのマテリアルで表現する。
傾斜方向を決定できない退化ポリゴンでは平屋根にフォールバックする。

## 5. 最上階のみの処理（building_shape = SHAPE_FULL）

`building_shape = SHAPE_FULL`（[[C_建物形状]]）の建物は、モジュラーパーツ組み立て方式を使うが、階の範囲が異なる：

- **最上階のみ**を処理する（1階・中層階はスキップ）
- 最上階では **屋上レベルの壁・角パーツ（top-w*, top-c*）** を使用する
- 屋上面マテリアル・塔屋も通常の MODEL_MODULAR_FLAT と同様に配置する

すなわち、SHAPE_FULL は「1階分の屋上レベル壁・角パーツ + 屋上面 + 塔屋」という構成になる。

地上に壁が存在しないため、エントランス（[[F_建物メッシュの生成]] §11）は1階建ての場合に限って配置される。
