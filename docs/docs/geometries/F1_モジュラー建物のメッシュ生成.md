# モジュラー建物のメッシュ生成（MODEL_MODULAR_FLAT / HOUSE / GABLE）

## 概要

モジュラーパーツ（壁・角）を底面ポリゴンに沿って組み立てる、通常の建物のモデルタイプ。
壁・角・地面パネル・基盤・フェンス・塔屋・エントランス・コライダーの生成規則は3者で完全に共通で、
[[F_建物メッシュの生成]] に記述する。本ドキュメントはその差分、すなわち**屋根の作り方**を記述する。

| model_type | 屋根 |
| --- | --- |
| **MODEL_MODULAR_FLAT** | 平屋根（底面形状と同じ水平ポリゴン） |
| **MODEL_MODULAR_HOUSE** | 住宅風三角屋根（寄棟状。妻側も傾斜する） |
| **MODEL_MODULAR_GABLE** | 切妻屋根（厚みのある勾配面2枚 + 妻壁） |

いずれも塔屋（[[F_建物メッシュの生成]] §10）を配置する。

実装は `ModularBuildingMeshBuilder`（躯体 = `ModularBodyBuilder`、屋根 = `FlatRoofBuilder` /
`HouseRoofBuilder` / `GableRoofBuilder`）。

---

## 1. 平屋根（MODEL_MODULAR_FLAT）

底面ポリゴンと同じ形状の水平ポリゴンを建物最上部に配置する。
マテリアルは `ceil` パーツから取得する。該当パーツが存在しない場合は、壁面マテリアル等の他の配置済みパーツの有効なマテリアル、または建物全体のデフォルトマテリアルを使用する。
ポリゴンの三角形分割は耳切り法（ear clipping）を用い、失敗時はファン型にフォールバックする。

---

## 2. 住宅風三角屋根（MODEL_MODULAR_HOUSE）

建物底面を少し拡張したポリゴンから棟線を求め、二段構成で屋根を押し出してメッシュ化する。
棟線の両端を内側にセットバックし、底面の各頂点を棟線へ射影することで屋根の傾斜面を生成する。
L字建物にも対応する。

妻側も傾斜させて隙間を作らない（寄棟状の）形状であり、妻壁を必要としない点が切妻屋根（§3）と根本的に異なる。

---

## 3. 切妻屋根（MODEL_MODULAR_GABLE）

屋根は**厚みのある2枚の板**として作り、板が塞がない妻側の三角形の隙間は**妻壁**の板で塞ぐ。

1. 建物底面の**最小面積外接矩形**を求め、その長辺方向を棟線方向、短辺の半分を半幅とする。
   棟の高さ（壁の天端からの立ち上がり）は建物の大きさによらず **1階あたりの高さ（[[F_建物メッシュの生成]] §14）の半分に固定**する。
   間口の広さに比例させると大きな建物の屋根だけが巨大になるため、街並みの中で屋根の高さを揃える。
2. 屋根面（板の裏面）の高さは棟線からの水平距離だけで決まる（`棟の高さ − 距離 × 勾配`）。
   勾配は棟の高さと半幅から逆算する（＝間口が広い建物ほど緩勾配になる）ため、
   **屋根面は建物外周＝壁の位置でちょうど躯体の天端を通る**。
3. 建物底面を軒の出（0.4m）だけ外側にオフセットしたポリゴンが屋根板の輪郭になる。屋根板は
   壁面より外側かつ下側へ張り出し、その下が**軒下**になる。妻側では、けらばが同じだけ張り出す。
4. 輪郭を棟線で左右に切り分け、それぞれを1枚の板として張る。板は裏面・**厚み 0.25m（垂直方向）**の
   表面・外周の小口（軒先の鼻隠し、けらばの破風）で構成される。棟線上の辺は反対側の板と接するため
   小口を張らない。板は棟をまたがないので、**妻側は開いたまま**になる。
5. 建物底面の各辺について、壁の天端から屋根面までの隙間を垂直な板（**妻壁**）で塞ぐ。平側では
   屋根面が壁の位置で天端を通るため高さ 0 に潰れ、妻側では棟までの三角形になる。棟線をまたぐ辺は
   屋根面が折れる位置で2本に分割するため、棟の頂点がそのまま妻壁の頂点になる。

マテリアルはサブメッシュを分けて2種類を使う。

- **屋根面** — 平屋根と同じく `ceil` パーツから取得する。
- **妻壁** — `generic-wall` パーツ（無地の壁。マテリアル参照専用で形状は使わない）
  から取得する。窓の意匠が入る通常の壁パーツを流用すると妻壁に窓が並んでしまうため、専用の
  パーツを設ける。

どちらも該当パーツが無ければ他の配置済みパーツの有効なマテリアル、さらに無ければ建物全体の
デフォルトマテリアルにフォールバックする。棟線方向を決定できない退化ポリゴンでは平屋根に
フォールバックする。

---

## 4. 最上階のみの処理（building_shape = SHAPE_FULL）

`building_shape = SHAPE_FULL`（[[C_建物形状]]）の建物は、モジュラーパーツ組み立て方式を使うが、階の範囲が異なる：

- **最上階のみ**を処理する（1階・中層階はスキップ）
- 最上階では **屋上レベルの壁・角パーツ（top-w*, top-c*）** を使用する
- 屋上面マテリアル・塔屋も通常の MODEL_MODULAR_FLAT と同様に配置する

すなわち、SHAPE_FULL は「1階分の屋上レベル壁・角パーツ + 屋上面 + 塔屋」という構成になる。

地上に壁が存在しないため、エントランス（[[F_建物メッシュの生成]] §11）は1階建ての場合に限って配置される。
