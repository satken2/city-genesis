# 倒壊建物のメッシュ生成（STATUS_COLLAPSED）

## 概要

status が `STATUS_COLLAPSED`（倒壊）の建物は、`model_type` に関わらず完成品のメッシュを生成せず、専用の「瓦礫」メッシュ（瓦礫マウンド + 任意の倒壊片）で描画される。

分岐は `BuildingMeshBuilder.Generate` の冒頭（model_type 分岐より先）にあり、工事中・解体中と同様に Near/Far・詳細生成ワーカー・直接呼び出しのすべての生成経路をカバーする。実装は `CollapsedBuildingMeshBuilder`。

詳細パネルの爆破操作では、HTTP成功後の `building:exploded` 通知で対象建物だけを再取得し、この瓦礫メッシュへ即座に切り替える。炎・煙と音は同時に開始し、建物とは独立して短時間で消える（[火災エフェクトの描画](S_火災エフェクトの描画.md#爆破操作の単発エフェクト)）。

共通仕様（パーツの命名規則・外観バリアントの選択）は [[F_建物メッシュの生成]]、敷地ポリゴンの解決や土マウンド生成の詳細は [[F5_工事中建物のメッシュ生成]] に記述する。

---

## 1. 瓦礫マウンド

敷地（土地区画のポリゴン。区画が取得できない場合は建物底面）全体を、厚みとランダムな凹凸を持つ瓦礫で覆う。

- **工事中の土マウンド生成をそのまま流用する**（[[F5_工事中建物のメッシュ生成]] §3）。耳切り三角形分割 → 長辺の中点分割 → Perlinノイズ（fbm）＋境界フェード → 外周スカート、および超近景（Dynamic）セルでの地形追従まで同一。外周頂点では凹凸0になるため隣接区画との隙間や Z-fighting は起きない
- **瓦礫は土より厚く荒くする**。基本厚みとノイズ振幅を工事中より大きい値（`CONSTRUCTION_RUBBLE_THICKNESS` / `CONSTRUCTION_RUBBLE_BUMP_AMPLITUDE`）に差し替えて生成する
- **任意ポリゴンに完全追従する**ため、矩形でない区画でもはみ出さない
- マテリアルは `Resources/CollapsedRubble`（未配置時は工事現場の土マテリアル `ConstructionDirt` → デフォルト建物マテリアルにフォールバック）

---

## 2. 任意の倒壊片（collapse）

`collapse` パーツ（崩れた躯体・瓦礫の山などの既成モデル）が存在すれば、建物底面ポリゴンに合わせて1つ載せる。パーツの解決は他の工事系パーツと同じ `a{variant}` → `b{bd_type}` → `common` のフォールバックで、**無ければ瓦礫マウンドのみで成立する**（オプショナル）。

- **XZ**: モデルの XZ バウンディングボックスを footprint の AABB（× `COLLAPSE_FRAGMENT_FILL` の充填率で内側に余白を残す）へ**非一様スケール**でフィットさせる。任意ポリゴンでも AABB に収めるので大きくはみ出さない
- **Y**: 実寸を基本としつつ `COLLAPSE_FRAGMENT_MAX_HEIGHT` で上限クランプし、瓦礫を低く保つ（無闇に引き伸ばさない）
- **位置**: モデルの XZ 中心を footprint AABB の中心へ、下端を地面（ローカルY=0）へ合わせる
- `MODEL_MODULAR_GROUND`（畑・庭）・`MODEL_PORT`（岸壁）・`MODEL_OPEN_PIT`（露天掘り）には躯体片を載せない（瓦礫マウンドのみ）

---

## 3. コライダー

瓦礫は低いので、建物底面ポリゴン（区画しか無ければ区画）を瓦礫のおおよその天端（`CONSTRUCTION_RUBBLE_THICKNESS + CONSTRUCTION_RUBBLE_BUMP_AMPLITUDE`）まで押し出した低い箱をコライダーとする。倒壊片のはみ出しはクリック対象外で許容する（工事中のクレーンはみ出しと同じ思想。[[F5_工事中建物のメッシュ生成]] §7）。
