# 倒壊建物のメッシュ生成（STATUS_COLLAPSED）

倒壊した建物は、`model_type` によらず完成形を描かず、敷地を覆う瓦礫の盛り上がりとして描く。盛り上がりは工事中の土（[F5_工事中建物のメッシュ生成](F5_工事中建物のメッシュ生成.md)）と同じ作り方で、土より厚く荒くする。焼失（`status_reason` が `REASON_FIRE`）した建物は、焦げた瓦礫のマテリアルで描き分ける。

`collapse` パーツ（崩れた躯体などの既成モデル。`{prefix}` → `common` の順に探す）があれば、底面に合わせて低く1つ載せる。地面型・オープンスペース・港・車両基地・露天掘りには載せず、瓦礫だけで描く。
