# 火災エフェクトの描画

建物の火災(`ALERT_AGENT_ON_FIRE`)は、アイコンではなく3D空間の炎・火の粉・黒煙と、明滅する点光源で描く。そのエポックで焼け落ちた建物(`STATUS_COLLAPSED`)は、瓦礫がくすぶる細い白煙にする。失火(`ALERT_AGENT_ACCIDENTAL_FIRE`)は3Dに描かない。火災はエポック限りの出来事なので、炎と煙も火災が起きたエポックの間だけ表示し、次のエポックでビットが落ちると消える。ビットの意味と配信は [アラートフラグ管理](../programs/アラートフラグ管理.md) を参照。

## データと表示

専用のAPIは持たず、`AlertManager` がアラート一覧を取得した結果を `FireEffectManager` が受け取る。火災のビットは共有定数 `ALERT_AGENT_VFX_BITS` としてアイコンの対象から分けてあり、表示パネルのアラートの表示切り替えは炎と煙にも効く。

炎と煙は建物のGameObjectとは独立に建物の足元へ置き、規模を建物の底面の広さと高さから決める。テクスチャは起動時にコードで生成し、画像アセットは使わない。

## 爆破操作の単発エフェクト

プレイヤーが建物を爆破すると、UIは爆破のAPIが成功した後に `building:exploded` をUnityへ送る([IPC連携の整理](../programs/IPC連携の整理.md))。Unityは対象の建物を取り直して瓦礫([倒壊建物のメッシュ生成](F8_倒壊建物のメッシュ生成.md))に切り替え、同じ場所で一度だけの炎・煙と爆発音を再生する(`VisualEffectManager`)。
