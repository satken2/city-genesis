# Q. 駅舎パスのメッシュ生成

駅舎パス(パスマスターの type=7、`model_type: "station_house"`)の描画仕様。駅舎パスは「線に沿った連絡橋」と「両終端の専有エリアに置かれる建屋」で構成される。

## 1. 構成要素

| 要素 | 形状 | 位置 |
| --- | --- | --- |
| 連絡橋(桁) | パスの折れ線に沿った帯(幅=マスターの `width`) | 地形 + マスターの `height`(デッキの地上高) |
| 柱 | `pillar_spacing` 間隔で桁から地面へ | 桁の下 |
| 建屋 | `house_width` × `house_depth` の矩形 | 線の両終端(線路を避けてスライド。§2) |

- 駅舎パスは `curve_allowed: false` のウェイポイント付き折れ線で、`single_span: true`(桁はアンカー間で水平に架かり、地形の起伏に追従しない)。
- 桁・柱のプレハブ解決とスプライン生成は道路メッシュ([G_道路メッシュの生成](G_道路メッシュの生成.md))の共通ヘルパーを再利用する。プレハブは `Models/Paths/p{path_variant}/` → `p7/` フォールバック。
- 建屋のモデルは `Models/Stations/{path_variant}` から解決し、実寸で配置する(スケールしない)。

## 2. 専有エリア(建屋フットプリント)の算出

専有エリアの位置は保存されず、**パスの形状と周辺の線路から決定的に導出する**。バックエンド(土地占有・収用の判定)とグラフィック(建屋の描画)が同一のアルゴリズムを実装しており、片方だけ変えると土地の占有と見た目が食い違う。

線の両終端それぞれについて:

1. **外向き方向**: アンカー列(始点・ウェイポイント・終点)から、終端の外向き単位ベクトル `dir` を求める。終端に一致する点が連続する場合は、距離が出るアンカーまで遡る。
2. **座標系**: 終端 `tip` を原点、`dir` を +s 軸、`perp = (-dir.z, dir.x)` を横軸とする。
3. **線路の占有区間の収集**: 終端から `STATION_HOUSE_TRACK_SEARCH_RADIUS`(150m)以内にある軌道系パス(鉄道・モノレール)の中心線セグメントを対象に、
    - 線路ごとのクリアランス `c = width/2 + platform_width(あれば) + STATION_HOUSE_TRACK_CLEARANCE_MARGIN(1m)` を求める。`platform_side` による非対称は見ず、両側に `platform_width` を見込む保守的な近似とする。
    - セグメントを横方向コリドー `|lat| <= house_width/2 + c` にクリップし、クリップ後の s 範囲を `c` だけ広げた区間 `[s_min - c, s_max + c]` を占有区間として収集する。駅舎パス自身は対象にしない。
4. **スライド距離の決定**: 占有区間を昇順マージし、矩形(奥行き `house_depth`)の中心 `s0` を、候補「`s0 = 0`(終端そのもの)」および「各マージ済み区間の終端 + `house_depth/2`」のうち、どの区間とも重ならない最小の `s0 >= 0` とする。区間は有限個なので必ず解がある。
5. **矩形の確定**: 中心 = `tip + dir * s0`、向き = `dir`(Y軸回転 = `Atan2(dir.x, dir.z)`)、寸法 = `house_width`(横=`perp`方向) × `house_depth`(奥行き=`dir`方向)。

`house_width` / `house_depth` がマスターに無い場合は `STATION_HOUSE_DEFAULT_WIDTH` / `STATION_HOUSE_DEFAULT_DEPTH` にフォールバックする。

この定義により、終端が線路の直前にあれば建屋は線路の向こう側(線の外側)へ押し出され、線が線路群を大きく越えて引かれていれば建屋は終端の位置にそのまま建つ。線路が後から増設されると占有区間が変わり、建屋の位置も自動的に再導出される。

## 3. 干渉と交差の規約

- 駅舎パスの線(橋)は上空を通るため、道路・線路・他のパスと自由に交差できる。ノード生成・パス分割・立体交差検証の対象外である([J_パスの交差処理](J_パスの交差処理.md)の適用外)。
- 地上を占有するのは両終端の専有エリアだけで、区画作成・建物の直接配置・地表パスの着工はこの矩形とだけ干渉する。
- 敷設プレビューでも同じ生成器・同じフットプリント算出が走る(プレビュー中のパスは自パス除外の対象にならないだけで、結果は確定後と一致する)。
