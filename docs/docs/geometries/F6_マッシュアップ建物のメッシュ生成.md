# マッシュアップ建物のメッシュ生成（MODEL_MASHUP）

学校（校舎と体育館）や変電所（管理棟と変圧器）のように、1つの施設を複数の棟（サブ建物）で描く方式である。棟の配置はコアが決めて `sub_buildings` で渡し、Unity は配置を計算しない。共通の約束は [F_建物メッシュの生成](F_建物メッシュの生成.md) による。

## 配置データ

コアは区画を接道辺に沿った格子で一辺 `MASHUP_CELL_SIZE` のセルに分け、棟を割り付ける。棟の大きさはサブ建物マスターの `width`（幅）×`height`（奥行き）で、単位はセルの数である。`position` は建物の `center_point` を原点とする棟の中心の XZ、`rotation` は XZ 平面で +X から反時計回りの角度（度）で、棟の幅がこの向きに沿い、正面が接道側を向く。棟の階数は保存されず、親の建物の階数をサブ建物マスターの階数の範囲に収めた値になる。配置はプレイヤーが後から編集できる。

## 棟の組み立て

棟は `mashup-{model_prefix}-base-prebuilt` などのパーツを既成建物（[F3](F3_既成建物のメッシュ生成.md)）と同じように積む。ただし、どの段も伸縮させず、段の高さは下の段の実寸の天端で決まる。閾値フォルダはパーツごとに選ぶ。各棟は自分の位置の地形標高に接地するので、広い区画が斜面にまたがっても棟は浮かない。クリック判定は区画の形を最も高い棟の天端まで押し出した形にし、区画のどこを押しても施設を選べるようにする。遠景は棟ごとの遠景モデルを同じ配置で置く。
