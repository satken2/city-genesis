# オープンスペースのメッシュ生成

駐車場（`MODEL_PARKING`）・駅前ロータリー（`MODEL_ROTARY`）・公園（`MODEL_PARK`）の方式である。区画の形から配置計画を作り、地形に沿う面（舗装・芝・路面標示・縁石で上げた歩道など）と、実寸の小物（車止め・上屋・街灯・ベンチ・樹木など）を組み合わせる。完成したモデルを引き伸ばすことはしない。オープンスペースの種別でも、`model_type` が地面型やモジュラーのもの（舗装広場・立体駐車場など）は [F2](F2_地面アセットのメッシュ生成.md)・[F1](F1_モジュラー建物のメッシュ生成.md) の方式で描く。共通の約束は [F_建物メッシュの生成](F_建物メッシュの生成.md) による。

配置計画は接道辺を基準にした区画内の格子から作り、小物の選び方と形の揺らぎを `visual_variant2` で決める。区画の形と外観の値だけで決まり、建物 ID・ロード順・描画LOD には左右されない。駐車枠・園路・植栽は見た目だけのもので、駐車や通行のシミュレーションには使わない（公園も区画の全体を通行できる。[地区と土地区画](../economics/4_地区と土地区画.md)）。

パーツは `site_asphalt`・`site_grass` などの面のマテリアルの参照と、`site_bench`・`site_tree` などの小物のモデルである。駅前ロータリーは配置計画の舗装面と接道辺が交わる範囲を道路への間口にする。工事中・解体中・倒壊は土・瓦礫だけで表す。
