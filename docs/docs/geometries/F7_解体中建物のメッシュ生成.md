# 解体中建物のメッシュ生成（STATUS_DEMOLISHING）

解体中の建物は、`model_type` によらず完成形を描かず、工事中（[F5_工事中建物のメッシュ生成](F5_工事中建物のメッシュ生成.md)）と同じ構成の現場として描く。違うのはパーツと建機だけである。

| 役割 | 工事中 | 解体中 |
| --- | --- | --- |
| 足場 | `scaffold-wall`・`scaffold-corner` | `demo-scaffold-wall`・`demo-scaffold-corner` |
| 施工済みの階の天面 | `ceil` | `demo-ceil` |
| 建機 | タワークレーン `crane-*`（一定以上の階数の建物だけ） | ショベルカー `excavator`（階数によらず1台を土の上に置く） |

パーツの探し方（`{prefix}` → `common`）、足場の並べ方、土の盛り上がりだけで表す方式は工事中と同じである。足場の段数も `construction_progress` から工事中と同じ規則で決めるが、コアは解体の進み具合では建物の version を上げないので、進捗に合わせた描き直しは起きない。
