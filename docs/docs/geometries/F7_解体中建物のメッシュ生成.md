# 解体中建物のメッシュ生成（STATUS_DEMOLISHING）

## 概要

status が `STATUS_DEMOLISHING`（取り壊し中）の建物は、`model_type` に関わらず完成品のメッシュを生成せず、専用の「工事現場」メッシュ（土マウンド + 足場 + 建機）で描画される。

**解体中の生成ロジックは建設中（[[F5_工事中建物のメッシュ生成]]）と全く同じ**で、使用するパーツと建機の種別だけが違う。実装も同じビルダー（`ConstructingBuildingMeshBuilder`）を共用し、状態差分だけを `ConstructionSiteProfile`（`Construction` / `Demolition` の2プリセット）に集約している。分岐は `BuildingMeshBuilder.Generate` の冒頭（model_type 分岐より先）にあり、建設中と同様に全生成経路をカバーする。

本ドキュメントは F5 との差分のみを記述する。土マウンド・足場配置・進捗の取り込み・パーツのフォールバック（common）・天面・コライダーの仕様はすべて [[F5_工事中建物のメッシュ生成]] と共通である。

---

## 1. パーツの差分

建設中との違いは、足場・天面・建機に使うパーツ名だけである。いずれも建設中と同じ
`a{variant}` → `b{bd_type}` → `common` のフォールバックで解決され、無ければスキップ（足場は壁が無ければ全体スキップ、建機はスキップ）される。

| 役割 | 建設中パーツ | 解体中パーツ |
| --- | --- | --- |
| 足場・壁 | `scaffold-wall` | `demo-scaffold-wall` |
| 足場・角 | `scaffold-corner` | `demo-scaffold-corner` |
| 天面 | `ceil` | `demo-ceil` |
| 建機 | `crane-base` / `crane-mid` / `crane-top`（タワークレーン） | `excavator`（地上のショベルカー） |

足場は建設中と同じ配置ロジック（[[F5_工事中建物のメッシュ生成]] §4）で、専用の `demo-*` パーツにより色や形を解体現場向けに変えられる。

---

## 2. 建機（ショベルカー）

建設中のタワークレーン（[[F5_工事中建物のメッシュ生成]] §5）と異なり、解体中は**地上の建機を1台だけ**据える。

- タワークレーンのような段積み・階高スケールは行わず、`excavator` パーツを**実寸のまま1台**、マウンド上面（土の基本厚み付近）に接地させる
- **論理階数によるゲートは無い**（クレーンは既定4階以上でのみ立つが、ショベルカーは階数に関わらず出す）
- 位置は footprint 重心 + `visual_variant2` シードのオフセット、向きは最初の辺に合わせた Yaw（クレーンと同じ決め方）
- `excavator` パーツが無ければ建機はスキップ（足場と土だけの現場になる）

---

## 3. 進捗の扱い

進捗は建設中と完全に同一のロジック（`construction_progress` → `builtFloors`。[[F5_工事中建物のメッシュ生成]] §1）で、足場段数を駆動する。解体でも同じフィールド・同じ式を用いる（将来バックエンドが解体専用の進捗を出す場合はこの取り込み箇所が差し替え点になる）。
