# 17. 教育

教育は、学校に通う市民のスキルを伸ばす仕組みである。スキルの種類と賃金ティアは[16_労働市場](16_労働市場.md)を参照。

## 17.1. 教育の境界

スキルの無教育境界は基礎教育で、高スキル境界は高等教育でしか越えられない。基礎教育はすべてのスキルを伸ばし、高等教育は専攻の1つのスキルを境界のわずか上まで伸ばす。就労による成長は境界の手前で止まるので、スキルの値がそのまま教育の履歴になる。高等教育を修了したかどうかは、いずれかのスキルが高スキル境界以上かどうかで判断する。

## 17.2. 学校

学校は `TYPE_EDUCATION` の経済主体で、マスターの `is_higher_education` で基礎教育と高等教育を分ける。入学できる年齢と卒業年齢は学校の種類ごとに決まっている。就学年齢の市民は通える範囲で空きのある最寄りの学校に入り、卒業年齢を過ぎると退学する。高等教育に入れるのは基礎教育を修了した市民だけで、大学は初等教育の代わりにならない。

総定員は延床面積に比例する。高等教育の学校は専攻スキルごとの受け入れ枠(`education_type`)を持ち、プレイヤーが配分を変えられる。この値は、更新で送るときは専攻ごとの配分の重み(`SKILL_BASE` はキーにしない)、取得で返るときは重みで総定員を按分した定員である。

## 17.3. 高度人材の育成

高度人材の移民は既定では来ない([18_移民](18_移民.md))ので、高度人材が欠かせない施設の人材は大学で育てる。大学を建ててから最初の修了者が出るまで、その分野の高度人材が欠かせない施設は稼働できない。専攻は都市全体で空き枠が最も大きいスキルから選ばれるので、受け入れ枠の配分で、どの分野の高度人材を先に育てるかを決められる。

教育統計の教育水準は、修了の記録ではなくスキルの値から数え、在籍中の市民は在籍する学校の水準に数える。
