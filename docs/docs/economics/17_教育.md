# 17. 教育

教育は市民のスキルを伸ばし、都市で働ける人材の幅を広げる。スキルの種類と仕事との関係は[労働市場](16_労働市場.md)を参照。

## 17.1. 基礎教育と高等教育

基礎教育は、幅広い仕事の土台となるスキルを育てる。高等教育は、基礎教育を受けた市民が専門分野のスキルを伸ばし、高度人材になるための教育である。

就労経験による成長にも限界があるため、学校と大学はそれぞれの段階で必要になる。

## 17.2. 学校と専攻

学校は教育を担う経済主体(`TYPE_EDUCATION`)である。市民が教育を受けるには、年齢に合い、通学でき、空きのある学校が必要になる。

大学では、プレイヤーが専攻ごとの受け入れ枠を配分できる。専攻の配分は、都市でどの分野の高度人材を育てるかという選択になる。

## 17.3. 教育と都市の発展

高度人材は、都市内の高等教育で育てることが基本になる。大学を建てても人材が育つまでには時間がかかるため、医療や高度な産業を支えるには先を見越した教育が必要である。

移民による人材の受け入れについては[移民](18_移民.md)を参照。
