# 18. 移民

## 18.1. 世帯の流入

都市の「暮らしやすさ」と「雇用機会」に応じて、都市外部から新たな世帯が流入する。

### 移民グループ

移民の流入は、市民を「最も得意なスキル（6種） × 賃金ティア（無教育・標準・高度、[[16_労働市場]]）」で分類した**グループ単位**で決まる。「医療の高度人材にとって暮らしやすく、医療人材の求人がある都市には、医療の高度人材が集まる」という同類吸引を表現するためである。流入した世帯の世帯主は、応募元グループに整合したスキルを持ってスポーンされる。

### 流入の2つのチャネル

各グループの流入希望世帯数は、以下の2チャネルの和に、後述の魅力度（スコア）を乗じて決まる。

| チャネル | 内容 |
| --- | --- |
| **評判チャネル** | そのグループの既存市民が多いほど、口コミ・縁故で同類の移民が流入する。グループのティアの失業率が高いほど減衰し、閾値以上で停止する |
| **求人プルチャネル** | 都市内の企業・施設の**未充足求人**（人手不足）に引かれて移民が流入する。求人はスキル別に集計され、高スキル人材が不可欠な企業の未充足分は高度人材グループを、それ以外の不足は標準人材グループを引き付ける |

求人プルチャネルは既存人口に依存しないため、**人口がゼロの開拓期でも、施設を建てて求人が生まれれば移民が流入する**。逆に求人も評判もない更地には移民は来ない。

ただし高度人材は世界的な獲得競争の対象であり、求人1件あたりの充足速度は標準人材より大幅に遅い。高度人材の欠員を移民だけで埋めるには長い時間がかかるため、計画的な人材確保には都市内の高等教育（[[17_教育]]）による自前育成が必要になる。

### 魅力度（住環境・生活水準スコアとの比較）

各グループについて、そのグループに属する市民の世帯の**住環境スコア**（`env_score`、[[19_環境]]）と**生活水準スコア**（`qol_score`）の平均を「外部世界の標準的な生活水準」と比較し、標準を上回った分に比例して移民が応募する。標準以下のグループには移民は来ない。

- `env_score = 1.0` は「収入の3割を住居コストに使う標準的な暮らし」を表すため、外部基準として `1.0` を用いる。都市での暮らしが外の世界より割安・快適なグループほど、その評判を聞いて同類の移民が集まる。
- **高度人材の基準は標準・無教育人材より高い。** 高度人材は外部世界でも好待遇を得られるため、都市の暮らしが外部標準を大きく上回って初めて移住の動機になる。
- そのグループの世帯がまだ都市にほとんどいない場合は、**仮想スコア**で代替する。住環境スコアはティア別の平均賃金・失業率・都市の平均住居負担から「もしそのグループの世帯が来たらどうなるか」を推定する。生活水準スコアは、標準・無教育人材はまだ現地の暮らしを経験していないため楽観視するが、**高度人材は既存住民全体の実際の生活水準の評判を確認してから来る**（移住先を吟味できる立場のため、医療・娯楽などの生活インフラが貧弱な都市には高度人材は来ない）。都市に世帯が1つも存在しない場合は、開拓期の立ち上げのためどのグループも現地の生活水準を楽観するものとして扱う。

この仕組みにより、流入 → 住宅逼迫 → 家賃上昇 → スコア低下という既存のフィードバックでスコアが基準値に収束するあたりで流入は自然に減速する。また「求人はあるが住環境が悪くて人が来ない」都市では、人手不足による賃金上昇（[[16_労働市場]]）が収入を押し上げてスコアを回復させるため、賃金メカニズムを通じて自己修復する。

### 開拓移民（最低流入数）

全グループの応募数合計が下限値に満たない場合、最も魅力度の高いグループに投機的な開拓移民が補填される。ただし全グループの魅力度がゼロ（外部世界の標準未満）の都市には開拓移民も来ない。また、開拓移民に高度人材は含まれない（確実な職と生活水準の見込みなしに未開の都市へ来る高度人材はいない）。

ここで計算された数は「移民の応募希望世帯数」であり、後述の移民規制による審査を経て実際にスポーン（許可）される世帯が決まる。応募数と許可数はエポック実行結果で確認できる。

### 移民規制（プレイヤー政策）

市長は都市への移民受け入れ条件を政策として設定できる。応募してきた移民世帯は以下の条件で審査され、条件を満たさない世帯は不許可（スポーンされない）となる。審査は世帯主の属性で行う。

| 規制 | 内容 |
| --- | --- |
| 世帯主の年齢範囲 | 世帯主の年齢が指定範囲内であること |
| 世帯構成 | 単身世帯・夫婦世帯（子供なし）・子持ち世帯のそれぞれを許可するか選択 |
| 性別（世帯主） | 制限なし・男性のみ・女性のみ |
| スキル要件 | 6種のスキルごとに最低値を設定。閾値を設定したスキルのいずれかを世帯主が満たせば許可（OR条件）。全て0の場合はスキル要件なし |
| 受け入れ上限人数（クオータ） | 1エポックあたりの受け入れ人数上限。0は無制限。応募が多くてもこの人数に達すると打ち切り |

スキル要件が意味を持つよう、成人移民のスキルは流入時に分布から付与される。**世帯主のスキルは応募元の移民グループ（最得意スキル×賃金ティア）に整合するよう生成される**（高度人材グループの応募なら該当スキルが高スキル境界以上になる）。配偶者は基礎教育履修を前提とした一般分布で生成され、一定割合で高等教育修了者が含まれ専攻スキルが高くなる。**配偶者が高等教育修了者である割合は都市の教育水準に連動する**（高スキル人材の多い都市ほど高学歴の配偶者を伴う移民が来る）。子供は未就学のためスキルを持たない。

**移民のスキルには上限がある。** 高度人材の移民も、その専攻スキルは高スキル境界（1.5）をわずかに超えた「即戦力」の水準に留まる。それ以上の熟練度には都市内での就労経験によるスキル成長（[[16_労働市場]]）が必要であり、高等教育で人材を育成し長期に雇用し続けた都市だけが、業種ごとのスキル上限に迫る最高水準の生産性を実現できる。

### 世帯構成

各世帯の構成はランダムに決定される。単身世帯と夫婦世帯が混在し、夫婦世帯には子供がいる場合がある。各市民の犯罪性向（[[19_環境]]）もランダムに与えられる。

### 移民フラグ（is_immigrant）

外部から流入してきた移民市民には、一生消えないフラグとして `is_immigrant` が **True (1)** に設定される。これに対し、都市内で生まれた新生児（出生イベントによる市民）には **False (0)** が設定される。このフラグは市民の属性情報として保持され、将来的な統計処理や市民ごとの行動ロジックの差分化に活用できる。

### スポーン方法と転居

スポーンされた世帯は、ランダムに選ばれた地区に仮入居（`is_evicted=True`）状態で作成され、同エポック内の転居マッチング（[[13_不動産市場]]）を経て実際の住宅に入居する。

### 初期資産

スポーン直後の世帯の `reserves` は **0** である。

## 18.2. 世帯の流出

都市での生活が悪化した世帯は、都市外部へ流出する。

### 判定の単位

流出の意思決定は**世帯単位**で行われ、流出時は子供を含む全構成員が一緒に都市を去る。同居している家族が別々に残ることはない。

### 移民世帯と国民世帯

世帯は成人構成員の移民フラグ（`is_immigrant`）によって2種類に分類され、流出のしやすさが大きく異なる。

| 分類 | 条件 | ふるまい |
| --- | --- | --- |
| **移民世帯** | 成人全員が移民 | 外部世界に生活基盤や代替の選択肢を持つため、生活条件が悪化すると高い確率で早期に流出する |
| **国民世帯** | 成人に都市生まれの市民を1人でも含む | 都市に生活の根を張っているため、同じ悪条件でも低い確率でしか流出しない |

「移民はすぐ逃げる、国民は粘る」という非対称により、移民依存で人材を確保した都市は不況や住環境悪化で人材が急速に流出する脆さを持ち、教育（[[17_教育]]）で市民を自前育成した都市は耐性を持つ。親が移民でも、都市生まれの子が成人して同居していれば国民世帯として扱われる（未成年の子は分類に影響しない）。

### 流出の条件

以下のいずれかを満たす世帯が流出候補となり、分類ごとの確率で毎エポック流出が発生する。悪条件が続くほど累積的に流出が進む。

- **住環境の悪化**: 住環境スコア（`env_score`、[[19_環境]]）が基準を下回る（収入に対して住居コストが過大）
- **生活水準の悪化**: 生活水準スコア（`qol_score`）が基準を下回る（栄養・医療・娯楽の充足が長期に欠乏。収入が絶たれた困窮世帯もこちらで捕捉される）

### 転出猶予期間

着任して間もない世帯は、初期資産ゼロから生活が軌道に乗るまでの一時的な低満足度を理由に流出することはない。着任から一定期間が経過した世帯だけが流出判定の対象になる。

### 統計

流出した世帯の人数は都市全体および地区別に集計され、エポック実行結果と人口統計で確認できる。
