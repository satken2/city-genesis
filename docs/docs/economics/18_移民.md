# 18. 移民

## 18.1. 受け入れと人口増加

移民は、都市の外から世帯単位で移り住んでくる住民である。市長は、受け入れるかどうかと受け入れの条件(移民規制)を政策として決める。

受け入れている間は、移住を希望する世帯が人口に応じた数だけ応募し続ける。雇用や生活水準が悪くても応募は止まらない。ただし入居には空き床・支払える家賃・移民規制の条件が必要なので、受け入れていても毎エポック人口が増えるとは限らない。

受け入れを止めると新しい応募がなくなり、まだ入居していない応募世帯は撤回される。入居済みの住民は残る。静止人口モード([15_世帯](15_世帯.md))の都市では、受け入れ設定にかかわらず応募は無い。

### 応募者の技能

移民として来るのは、原則として無教育人材と標準人材である。応募者の技能の内訳は、都市の求人に応じて変わる。高度人材を呼び寄せるかどうかは都市パラメータで決まり、既定では呼び寄せない。そのため高度人材は、都市内の高等教育([17_教育](17_教育.md))で育てるのが基本になる。高度人材を必要とする施設は、大学から最初の卒業生が出るまで稼働できない。

### 移民規制

応募してきた世帯は世帯主の属性で審査され、条件を満たさない世帯は受け入れない。

| 規制 | 内容 |
| --- | --- |
| 世帯主の年齢範囲 | 世帯主の年齢が範囲内であること |
| 世帯構成 | 単身・夫婦(子なし)・子持ちのそれぞれを許可するか |
| 世帯主の性別 | 制限なし・男性のみ・女性のみ |
| スキル要件 | スキルごとの最低値。設定したスキルのいずれかを満たせば許可 |
| 受け入れ上限人数 | 1エポックに受け入れる人数の上限。0は無制限 |

受け入れを止めても、その他の規制の値は保持される。

### 住宅待ちと人口への計上

応募した世帯は、住宅を待つ地区を選んで待機する。待つ地区は、住める広さの空きがあり、家賃と通勤の負担が小さく住環境の良い地区から選ばれる。住宅待ちの世帯がいる地区には住宅の建設需要が立つので、雇用のある地区へ通いやすい地区から住宅が建っていく。

移民は住宅待ちの間は人口に含まれず、住宅へ入居した時点で住民になる。人口・施政スコア・住民統計・社会保障は、入居後の住民が対象である。長く入居できなかった応募は撤回されるが、人口に含まれていなかったので人口は減らない。

エポックの結果に出る応募数は応募した世帯の数、流入人数は入居まで済んだ人の数で、単位も数える時点も異なる。

## 18.2. 定住住民は転出しない

入居した住民は、失業や生活環境の悪化、住宅待ちの長期化を理由に都市から出ていくことはない。人口は出生と死亡でも変化する([15_世帯](15_世帯.md)、[19_環境](19_環境.md))。
