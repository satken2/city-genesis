# 18. 移民

## 18.1. 受け入れと人口増加

市長は「移民を受け入れる」を切り替えられる。ONでは移住希望世帯が継続的に応募し、入居可能な住宅が供給されると住民が増える。雇用や生活水準の低さだけで応募が停止することはない。空き床、支払える家賃、受け入れ規制を満たした世帯が入居するため、ONが毎エポックの人口増加を保証するわけではない。

OFFでは新規応募を止め、次のシミュレーション開始時に未入居の応募世帯を撤回する。入居済み住民は残る。求人は応募者の技能構成に影響する。

移民停止後は出生と死亡で人口が変化する。通常の衛生状態では長期的な世代維持・微増を基本とするが、年齢構成による波や少人数での偶然変動はある。著しい衛生悪化や事故による人口減少は起こり得る。

### 高度人材と移民

移民として流入するのは、原則として無教育人材と標準人材である。高度人材（いずれかのスキルが高スキル境界1.5以上。[[16_労働市場]]）の世帯主は、稼働中の施設が高度人材の欠員を抱えているときにだけ、その欠員に応じて応募してくる。この誘引の強さは都市パラメータ `IMMIGRATION_HIGH_SKILL_PULL_RATE` で決まり、既定値の0では高度人材は移民として来ない。まだ建っていない企業が高度人材を呼び寄せることもない。

したがって既定では、高度人材は都市内の高等教育（[[17_教育]]）でしか育成できない。移民の受け入れは人口を増やす代わりに教育水準の低い人材だけをもたらす。高度人材を必要とする業種は、病院だけでなく食品工場を含む多くの工場やオフィスに及び、大学から最初の卒業生が出るまでは新たに参入できず、建てた施設も稼働できない。

### 移民規制（プレイヤー政策）

市長は都市への移民受け入れ条件を政策として設定できる。応募してきた移民世帯は以下の条件で審査され、条件を満たさない世帯は不許可（スポーンされない）となる。審査は世帯主の属性で行う。

| 規制 | 内容 |
| --- | --- |
| 世帯主の年齢範囲 | 世帯主の年齢が指定範囲内であること |
| 世帯構成 | 単身世帯・夫婦世帯（子供なし）・子持ち世帯のそれぞれを許可するか選択 |
| 性別（世帯主） | 制限なし・男性のみ・女性のみ |
| スキル要件 | 6種のスキルごとに最低値を設定。閾値を設定したスキルのいずれかを世帯主が満たせば許可（OR条件）。全て0の場合はスキル要件なし |
| 受け入れ上限人数（クオータ） | 1エポックあたりの受け入れ人数上限。0は無制限。応募が多くてもこの人数に達すると打ち切り |

スキル要件が意味を持つよう、成人移民のスキルは流入時に分布から付与される。**世帯主のスキルは応募元の移民グループ（最得意スキル×賃金ティア）に整合するよう生成される**（高度人材グループの応募なら該当スキルが高スキル境界以上になる）。配偶者は基礎教育履修を前提とした一般分布で生成される。**配偶者が高等教育修了者になるのは、高度人材の世帯主に同伴する場合だけである**（同類婚）。その割合は都市パラメータ `IMMIGRATION_SPOUSE_HIGHER_EDUCATED_RATIO` で決まる。子供は未就学のため、全スキルが初期下限（0.3。[[17_教育]]）の状態で流入する。

**高度人材の移民は新卒と同じ水準から始まる。** 高度人材の移民の専攻スキルは、高等教育を修了したばかりの市民と同じく高スキル境界（1.5）をわずかに超えた値である。それ以上の熟練は、新卒と同じく都市内での就労経験によるスキル成長（[[16_労働市場]]）でしか得られない。

### 世帯構成

各世帯の構成はランダムに決定される。単身世帯と夫婦世帯が混在し、夫婦世帯には子供がいる場合がある。各市民の犯罪性向（[[19_環境]]）もランダムに与えられる。

### 移民フラグ（is_immigrant）

外部から流入してきた移民市民には、一生消えないフラグとして `is_immigrant` が **True (1)** に設定される。これに対し、都市内で生まれた新生児（出生イベントによる市民）には **False (0)** が設定される。このフラグは市民の属性情報として保持され、将来的な統計処理や市民ごとの行動ロジックの差分化に活用できる。

### 入居と住宅待ち

移民は住宅待ちの間、人口に含まれない。実際の住宅へ入居した時点で定住住民となり、流入人数に加算される。人口・施政スコア・住民統計・社会保障は定住後が対象。長期間入居できなかった応募者は撤回するが、もともと人口に含まれないため人口減少にはならない。

独立・婚姻・立退きによって既存住民が住宅待ちになった場合は、引き続き人口に数える。実建物の空き床を超えて無償入居する仕組みではなく、仮入居の台帳で住宅需要を維持する。

## 18.2. 定住住民は転出しない

失業、住環境や生活水準の悪化、住宅待ちの長期化を理由に、定住世帯を都市外へ削除しない。医療は主に寿命、下水・ごみ処理による衛生は全年齢の生存に影響する（[[15_世帯]]、[[19_環境]]）。

## 18.3. UI・APIの契約

`GET/PATCH /api/v1/city/regulations` の `immigration_enabled`（boolean）で受け入れ全体を制御する。Tauriの移民タブは世帯構成とは別の先頭チェックボックスで表示し、`IMMIGRATION_SCALAR_KEYS` に含めて変更検知と保存を行う。OFFにしても他の規制値は保持する。流入人数は入居完了人数、応募数は世帯数で、単位と段階が異なる。
