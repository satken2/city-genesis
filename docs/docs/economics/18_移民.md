# 18. 移民

## 18.1. 移民の受け入れ

移民は、都市の外から世帯単位で移り住んでくる人々である。市長は受け入れの可否と、年齢・世帯構成・技能などの受け入れ条件を政策として決める。

受け入れている間は移住希望者が応募するが、住宅の空きや家賃、規制の条件によっては入居できない。受け入れを許可するだけで、必ず人口が増えるわけではない。

## 18.2. 住宅待ちと定住

応募した世帯は住宅を探し、入居すると都市の住民になる。住宅待ちの移民は人口に含まれず、住民向けの社会保障なども定住後の対象となる。住まいが見つからないまま長く待った応募は撤回される。

住宅を求める世帯の存在は、民間の住宅建設につながる。移民の受け入れには、住宅とともに、仕事や交通、生活を支える施設の整備も重要になる([不動産市場](13_不動産市場.md))。

## 18.3. 技能と人口

移民として来るのは、原則として無教育人材と標準人材である。高度人材の受け入れは都市の設定によるため、都市内の高等教育で育てることが基本になる([教育](17_教育.md))。

定住した住民は、失業や生活環境の悪化を理由に都市から転出しない。移民に加え、出生と死亡も人口を変化させる([世帯](15_世帯.md))。
