# 23. 満足度と施政スコア

住民世帯の満足度は、経済的豊かさ・娯楽と余暇・健康・生活の快適さの4軸を等しい重みで平均する。各軸と世帯満足度は0〜1で、統計画面では100点換算して表示する。観光客は住民とは別の旅の満足度を持つ。

## 23.1. 経済的豊かさ

生活需要を優先する既存の予算配分を使い、実際に調達した衣料・家電・嗜好食品・高級衣料・宝飾品などから評価する。購入額自体は加点せず、固定した基準量に対する消費量を評価する。同じ財が値上がりしただけで豊かさは増えない。消費が増えるほど評価は上がるが、追加消費の効果は逓減する。基準量への到達で成長が止まるわけではない。

## 23.2. 娯楽と余暇

外食・娯楽・通信・ソフトウェア・フィットネス・美容などは一つのまとまりとして評価し、相互に代替できる。市民は睡眠・基本生活、労働・通学、往復の通勤・通学を除いた時間を余暇へ充てる。所定労働時間や通勤時間が長いと、世帯のレジャー需要計画が小さくなり、実際の消費を通して満足度に影響する。需要計画を減らしても評価用の基準量は減らさない。

## 23.3. 健康

健康は市民ごとに保存する状態で、世帯内の平均を評価する。栄養不足・衛生悪化・大気汚染・長時間労働が状態を悪化させ、十分な栄養や必要な医療が回復を支える。年齢も悪化・回復へ影響する。医療の購入自体は満足度へ加点せず、必要な診療が届いて健康を維持できることを評価する。

強い負荷は30日程度で変化が見え、軽い継続負荷も数か月から数年で現れる。負荷を取り除いた後も回復には時間がかかる。死亡リスクも健康状態に応じて変化する。

## 23.4. 生活の快適さ

必要な住宅面積に対する広さ、騒音の少なさ、日当たり、治安を評価する。広さの追加効果は逓減し、著しい住宅不足を周囲の環境だけでは相殺できない。家賃・所得・通勤時間はこの軸に含めない。大気汚染は健康へ作用する。

転居先選びでは、満足度とは別に家賃・通勤負担と所得を比較するenv_scoreを使う。住民のqol_scoreは4軸を統合した満足度である。

## 23.5. 所定労働時間

所定労働時間は都市政策で、規制画面の「労働時間」から1〜16時間の範囲で設定できる。初期値は8時間。変更は次のシミュレーションから作用し、都市のセーブデータに保存される。

労働量は8時間基準で単純比例し、16時間なら2倍、4時間なら半分となる。労働時間による生産効率の逓減はない。ただし生産には設備・原料などの制約もある。長時間労働は余暇を減らし、8時間を超える労働が続くと健康に負荷を与える。

## 23.6. 都市集計と表示

評価済みの定住住民世帯を対象に集計する。未定住の移民・観光客・当エポックに生成された未評価の世帯は含めず、定住後に住宅待ちとなった世帯は含める。世帯ごとの重みは同じで、人口加重平均ではない。

city_scoreは世帯満足度の合計を2倍して従来の単位に合わせ、事故死のペナルティを引いた施政スコアである。city_score_per_householdはその世帯平均で0〜2。事故死ペナルティは都市評価だけの減点で、世帯満足度そのものには混ぜない。

city_score_qolは四軸平均の合計、city_score_envは快適さの合計を保持する診断用の値で、この2つを足して総合スコアを作るものではない。

統計の「余暇」「住環境」「満足度」は直近240エポックの都市平均を表示する。各指標と世帯満足度を同じグラフへ重ね、時間と満足度は別の軸で表示する。「満足度」の円グラフは各軸の平均値に25%を掛けた貢献点の構成を表す。世帯がない時点の値は0でなく欠測となる。既存の「所得」「保健衛生」は原因や状況を調べるための別の統計である。

満足度の構成ドーナツは満点100点で一周となる。満足度29.8点なら円周の29.8%だけを四軸の貢献点で色分けし、残り70.2%を背景色で表示する。健康は消費実績を評価できた市民だけを集計し、計画前の仮の充足度は初回健康評価に使わない。
