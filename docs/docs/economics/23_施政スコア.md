# 23. 施政スコア

施政スコアは、プレイヤーが都市をどれだけ豊かで住みよく育てられているかを定量的に表す指標である。エポック終了時に全世帯の満足度を集計して確定し、プレイヤーが施政の方向性を判断するための主要な基準となる。

## 23.1. スコアの設計思想

施政スコアは「個々の市民が快適に生活できているか」を世帯単位で積み上げる形で都市全体を評価する。各世帯の生活満足度がそのまま都市への貢献度となり、世帯数が多いほど都市全体のスコアも高くなる設計である。これは「豊かな都市とは、そこに住む人々の暮らしが豊かな都市だ」という本ゲームの基本理念を反映している。

## 23.2. 世帯スコアの種類

各世帯は、毎エポック更新される以下の2種類のスコアを持つ。

| プロパティ | 名称 | 値域 | 説明 |
| --- | --- | --- | --- |
| `env_score` | 住環境スコア | 0.0〜（上限なし） | 家賃・通勤コストに対する収入の余裕度と立地の良さを表す |
| `qol_score` | 生活水準スコア | 0.0〜1.0 | 栄養・医療・娯楽の充足度を加重平均した生活満足度を表す |

## 23.3. 住環境スコア（env_score）

住環境スコアは、「住居費と通勤にかかるコストが、収入に対してどれほど手頃か」を表す指標である。`env_score = 1.0` が標準的な状態を意味し、値が大きいほど余裕がある。

### 立地の影響

同じ家賃・同じ収入であっても、住環境マルチプライヤー（`living_multiplier`）が高い場所に住む世帯はスコアが高くなる。住環境マルチプライヤーの詳細は[[19_環境]]を参照。

### スコアの意味

`env_score` が 1.0 を大きく超える世帯は低いコストで良質な住環境を享受できており、1.0 を下回る世帯は住居費の負担が重い状態にある。

## 23.4. 生活水準スコア（qol_score）

生活水準スコアは、「生活に必要なモノ・サービスがどれだけ充足しているか」を 0.0〜1.0 の範囲で表す指標である。

### 充足度の計算

各充足度は、マスターデータで定義された基準需要量に対して実際にどれだけ調達できたかの比率として計算される（詳細は [10. 消費活動](10_消費活動.md) を参照）。
生活水準スコアは以下の3種類の充足度を加重平均して算出される。

| 充足度 | プロパティ | 対象商品群 |
| --- | --- | --- |
| 栄養充足度 | `satis_nutrition` | 食料・加工食品・飲食サービス |
| 医療充足度 | `satis_healthcare` | 医薬品・医療サービス |
| 娯楽充足度 | `satis_entertainment` | 娯楽・インターネット・フィットネス・美容など |

### ウェイトによる優先度

3つの充足度には相対的な重みが設定されている。既定では栄養と医療の重みが娯楽より高く、生命維持に直結する需要が重視される。

## 23.5. 都市スコアの集計

エポック終了時に全世帯の `qol_score` と `env_score` が集計され、都市全体のスコアが確定する。
集計対象は都市に実際に居住している世帯である。転居先が決まらず仮入居中の新規流入世帯（[[18_移民]]）は都市の住民ではないため、スコアにも人口にも数えない。

### 集計の考え方

住環境スコアは基準値で正規化して0〜1の範囲にそろえてから、生活水準スコアと単純合計する。各世帯が最大限充足した場合、1世帯あたり最大2.0点を都市に貢献する。

### スコアの解釈

都市スコア（`city_score`）は世帯数が多いほど高くなる絶対量であり、都市の規模を含んだ総厚生を表す。一方、施政の良し悪しそのものを表すのは、これを世帯数で割った1世帯あたりスコア（`city_score_per_household`）である。

| 指標 | 値域 | 表すもの |
| --- | --- | --- |
| `city_score` | 0.0〜（世帯数×2.0） | 都市全体の総厚生。人口規模を含む |
| `city_score_per_household` | 0.0〜2.0 | 住民ひとりひとりがどれだけ豊かに暮らせているか。人口規模と独立 |

1世帯あたりスコアは人口と独立なため、「人口を増やせばスコアが上がる」形の指標にならず、その時点の施政の質をそのまま表す。都市の規模を知りたい場合は人口やGDPを参照する。

エポックをまたぐ累積スコアは存在しない。

### City クラスへの格納

エポック終了時の集計では、以下の値が `City` クラスに記録される。

| 属性 | 説明 |
| --- | --- |
| `city_score` | 当エポックの都市スコア（倒壊ペナルティ適用後の最終値） |
| `city_score_qol` | 当エポックの生活水準スコアの全世帯合計 |
| `city_score_env` | 当エポックの住環境スコア（正規化後）の全世帯合計 |
| `city_score_household_count` | 集計対象の世帯数（仮入居中の世帯を除く） |
| `city_score_per_household` | 1世帯あたりの都市スコア（`city_score` ÷ 世帯数。0.0〜2.0） |

## 23.6. 倒壊ペナルティ

### 概要

建物の倒壊によって市民が死亡した場合、都市は深刻な市民感情の悪化に直面する。そのエポックの施政スコアは、通常の集計結果から一定の割合を減点するペナルティが課される。ペナルティの根拠となる事故死者数（`accident_death_count`）は建物倒壊処理で記録される（詳細は[[20_事故と災害]]）。

### ペナルティの特性

- **初動の大きさ**: 最初の死者が出た時点でスコアが減点される
- **逓減性**: 死者数が増えるほど1人あたりの追加減点は小さくなる
- **上限**: 当エポックスコアの最大50%を超える減点にはならない
- **非負保証**: ペナルティ後のスコアはマイナスにならない

### 記録される属性

| 属性 | 説明 |
| --- | --- |
| `city_score_collapse_penalty` | 当エポックに差し引かれた倒壊ペナルティの絶対量 |

## 23.7. 人口動態統計

施政スコアに直接関係する指標のほか、都市は毎エポックの人口動態を統計として記録する。過去数エポック分の履歴を参照できる。

| 属性 | 説明 |
| --- | --- |
| `birth_count` | 当エポックの出生数 |
| `death_count` | 当エポックの自然死亡数（事故死を除く） |
| `avg_death_age` | 当エポックの自然死亡者の平均年齢 |
| `marriage_count` | 当エポックの婚姻成立数 |
| `accident_death_count` | 当エポックの事故死数（建物倒壊による） |
