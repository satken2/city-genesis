# 23. 満足度と施政スコア

## 23.1. 世帯満足度

住民世帯の満足度は、次の4つの軸を等しい重みで平均した値である。各軸と満足度はどれも0〜1で、画面では100点に換算して見せる。

- 経済的豊かさ: 衣料・家電・嗜好品などを、世帯の基準量(最大需要量)に対してどれだけ買えたか。
- 娯楽と余暇: 外食・娯楽・通信などを、同じく基準量に対してどれだけ買えたか。労働・通学・通勤で余暇が減ると、レジャーの購入が減る。
- 健康: 市民の健康状態の世帯平均。栄養不足・衛生悪化・大気汚染・長時間労働で悪化し、栄養と医療で回復する。変化には時間がかかり、死亡の確率にも効く([15_世帯](15_世帯.md))。
- 生活の快適さ: 必要な広さに対する住まいの広さと住まいとしての質、静けさ、日当たり、治安。家賃・所得・通勤時間は含めない。

消費の2軸は買った量で測り、値上がりや医療の購入そのものでは上がらない。世帯の `qol_score` は満足度である。`env_score` は転居先を選ぶときに家賃・通勤の負担を所得と比べる値で、満足度にも施政スコアにも入らない。観光客は住民とは別の旅の満足度を持つ([31_観光](31_観光.md))。

所定労働時間は市長が決める都市政策で、働く人の実質労働力はこれに比例する。長くすると余暇が減り、標準を超えると健康を損なう。

## 23.2. 施政スコア

施政スコア(`city_score`)は、住民の暮らしを都市全体で評価した値で、世帯満足度の合計の2倍から、そのエポックの事故死(交通事故・建物の倒壊と火災)による減点を引いたものである。世帯数に比例して都市の規模を含むので、施政の良し悪しは世帯数で割った1世帯あたりの値(0〜2)で見る。API の内訳は、減点前の値(`city_score_qol`)から減点(`city_score_collapse_penalty`)を引くと施政スコアになる形で返る。生活の快適さは満足度の4つの軸の1つとして減点前の値に含まれ、別の加点にはならない。

減点は都市の評価だけに掛け、世帯満足度には混ぜない。

集計の対象は、満足度を評価済みの定住住民の世帯で、1世帯を同じ重みで数える。未定住の移民と観光客、そのエポックに生まれたばかりの世帯は含めない。対象の世帯がいないとき、満足度の統計は欠測(null)になり、1世帯あたりのスコアは0になる(集計した世帯数 `city_score_household_count` で見分ける)。
