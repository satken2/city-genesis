# 15. 世帯

市民のライフイベントや通勤・通学・教育について。

都市内の人口動態を制御し、出生・死亡・結婚・独立などのライフイベント、および通勤・通学による交通負荷計算と教育システムを管理する。毎エポック、各市民の状況を更新し、都市の人口構成と経済活動に動的な変化をもたらす。

## 15.1 世帯と市民の考え方

### 世帯と市民の関係

世帯は `type=household` の経済主体として管理される。各世帯には複数の市民（Citizen）が属する。市民は `citizen_type` として `MEMBER_SINGLE`（単身）または `MEMBER_MARRIED`（既婚）のいずれかを持ち、婚姻成立時に `MEMBER_MARRIED` に更新される。

### 市民の属性

市民は `Citizen` エンティティとして管理され、以下の主要な属性を持つ。

- `age` ... 年齢
- `gender` ... 性別
- `citizen_type` ... 配偶関係（`MEMBER_SINGLE` / `MEMBER_MARRIED`）
- `household_agent_id` ... 所属する世帯の経済主体ID
- `employer_agent_id` ... 雇用先の経済主体ID（無職の場合は未設定）
- `school_agent_id` ... 在籍中の学校の経済主体ID（非学生の場合は未設定）
- `skills` ... スキル群（最大6種のスキル値を保持）
- `education_skill` ... 高等教育で習得中の専攻スキル
- `is_immigrant` ... 移民かどうかを示すフラグ（True=外部からの移民、False=都市内生まれ）

## 15.2 市民ライフイベント

市民のライフイベントは毎エポック実行される。各イベントは独立したフェーズとして処理され、年齢更新→死亡→独立→婚姻→出生の順に実行される。

### 年齢更新

ゲーム内暦で年が変わるタイミングで、全生存市民の `age` を +1 する。エポックが年をまたがない場合は更新されない。

### 死亡

市民の死亡には以下の3つの要因がある。

| 死亡要因 | 条件 | 確率計算 |
| --- | --- | --- |
| 孤児化 | 所属する世帯が不正または存在しない | 即時削除 |
| 栄養不足 | 所属世帯の `satis_nutrition` が閾値未満 | 栄養不足度に応じた日次確率 |
| 加齢・疾病 | 全市民が対象 | 年齢と医療充足度に基づく日次確率 |

**加齢・疾病による死亡確率**は、年齢が高いほど指数関数的に上昇する。所属世帯の `satis_healthcare`（医療充足度）が高いほど死亡確率が低減する。医療が充実した都市ほど市民は長生きする。

**栄養不足による死亡**は、所属世帯の `satis_nutrition` が閾値を下回った場合に発生する可能性がある。栄養不足の度合いが大きいほど日次死亡確率が高くなり、エポック日数分の試行を経て死亡が判定される。

死亡処理後、構成員が0人になった世帯は自動的に削除される。

### 出生

出生は、既婚かつ出産可能年齢の女性市民（`MEMBER_MARRIED`、`gender` が女性、年齢が出産適齢範囲内）が属する世帯を対象に行われる。

都市全体で目標とする合計特殊出生率に基づいて、1エポックあたりの出生目標数が決まり、対象となる既婚女性が属する世帯に出生確率が割り当てられる。世帯内の未就学児童数が少ないほど出生しやすくなる。ただし、世帯内に既婚者が2人以上いなければ出生の対象とならない。

出生が成立した場合、0歳の新生児（`citizen_type` = `MEMBER_SINGLE`）が世帯に追加される。

### 独立

3人以上の世帯に属する成人の単身市民（`MEMBER_SINGLE`）が独立の対象となる。各世帯ごとに最年少の単身成人1名が候補となり、確率判定に通過した場合に独立が成立する。

独立成立時、親世帯と同じ地区に新規世帯を作成して移籍する。親世帯の保有資金は独立前の世帯人数で按分され、その分が新世帯に移転される。

### 婚姻

単身市民（`MEMBER_SINGLE`）同士の婚姻は、適齢範囲内の異性ペアで行われる。

各世帯から1エポックに代表者1名のみが婚姻候補となり、男女それぞれの候補からランダムにペアが形成される。ペアの資産差が大きいほど成立確率が低下し、資産差が大きすぎるペアは不成立となる。

成立したペアは新規世帯を作成し、両者の `citizen_type` を `MEMBER_MARRIED` に更新する。資産移転では、元世帯に他の構成員が残る場合は一定割合のみ移転し、元世帯が1人だけの場合は全額移転する。

## 15.3 通勤・通学

市民の通勤・通学に伴う交通負荷を道路ネットワークに反映する。

### 通勤

雇用先を持つ市民（`employer_agent_id` が設定されている市民）は、居住地区から勤務先地区への経路に交通負荷を加算する。1市民あたり1日1トリップ、エポック日数分の負荷となる。幹線道路（地区間経路）と地区内経路の両方に負荷が反映される。

移動手段は所属世帯の `has_automobile` に応じて決まる。自動車を保有する世帯の市民は自動車経路を使用し、保有しない世帯の市民は徒歩経路を使用する。

通勤先地区には昼間人口が加算され、世帯の訪問履歴（`household_visit_map`）も更新される。

### 通学

学校に在籍する市民（`school_agent_id` が設定されている市民）についても、居住地区から通学先地区への交通負荷を同じ仕組みで計算する。移動手段の決定も通勤と同様に世帯の `has_automobile` に基づく。

## 15.4 教育

就学年齢に達した市民は学校（`TYPE_EDUCATION` の経済主体）へ入学し、通学を通じてスキルが成長する。基礎教育・高等教育の区分、入学・卒業・退学の条件、スキル成長の仕組みは[[17_教育]]を参照。
