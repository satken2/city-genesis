# 15. 世帯

市民と世帯、人口の増減、通勤・通学と昼間人口について。教育は[17_教育](17_教育.md)、仕事と賃金は[16_労働市場](16_労働市場.md)、移民は[18_移民](18_移民.md)を参照。

## 15.1. 世帯と市民

住民は、世帯(`TYPE_HOUSEHOLD` の経済主体)に属する市民として表す。収入・資産・消費・住まいは世帯が単位で、年齢・就業・通学・スキル・健康は市民が単位である。市民の配偶関係は単身(`MEMBER_SINGLE`)と既婚(`MEMBER_MARRIED`)だけで、親子などの続柄は持たない。

人口に数えるのは定住した住民である。まだ住宅に入っていない移民と観光客([31_観光](31_観光.md))は数えず、独立・婚姻・立退きで住宅待ちになった世帯は数える。

## 15.2. 人口の増減

人口は出生・死亡・移民で変わり、定住した住民は都市から出ていかない。出生は出産年齢の女性の年齢構成と固定の出生率で決まり、人口が減っても増えないので、世代ごとの波ができる。死亡は年齢と健康状態で決まり、健康は栄養・衛生・大気汚染・労働時間・医療で変わる([23_施政スコア](23_施政スコア.md))。世帯は独立と婚姻で分かれ、新しい世帯は住宅待ちから始まる。

死亡の統計は、衛生悪化・病気と老衰・事故などの死因に分けて数える。

## 15.3. 通勤・通学と昼間人口

就業者と学生は毎日、住まいと勤務先・学校を1往復し、その移動が道路と公共交通の交通量になる。自動車を持つ世帯は車で、持たない世帯は徒歩と公共交通で移動する([10_消費活動](10_消費活動.md))。

昼間人口は、定住した住民を日中の主な居場所(勤務先・学校・住まいの順)の地区で1人1回数えた人口で、全地区の合計は人口と一致する。買い物などの一時的な訪問は含めない。

## 15.4. 静止人口モード

静止人口モードは、人口を育てた都市を凍結して都市開発に集中するシナリオにするための、シナリオ制作者向けの都市パラメータである。有効な間は人口・世帯構成・市民のスキルが変わらず(事故や倒壊でも死者は出ない)、経済などそれ以外は通常どおり動く。
