# 8. 商品市場

## 8.1. 商品とは

商品（product）は経済主体の間で取引される財とサービスの単位で、商品IDで区別する。商品は次の6種類に分かれる。

| 種類 | 定数 | 説明 |
| --- | --- | --- |
| 天然資源 | `GOODS_RESOURCE` | 土地区画の位置に応じて分配される原材料（[21_天然資源](21_天然資源.md)） |
| 工業原料 | `GOODS_MATERIAL` | 生産の原材料になる中間財。トラックで運ぶ |
| 小売財 | `GOODS_RETAIL` | 世帯が消費する最終消費財。買い手が店まで出向いて買う |
| サービス財 | `GOODS_SERVICE` | 運ぶ費用がかからないサービス。施設によっては届く範囲が限られる |
| インフラ財 | `GOODS_INFRASTRUCTURE` | 専用のインフラ網だけで配送される中間財（[26_インフラ網](26_インフラ網.md)） |
| 公共交通車両 | `GOODS_TRANSIT` | 車両基地から路線へ配送される車両（[6_公共交通機関](6_公共交通機関.md)） |

商品市場で売買されるのは工業原料・小売財・サービス財で、ほかの3種類は市場を通さずに配られる。天然資源とインフラ財の配分にはお金のやり取りが無く、公共交通車両は路線が車両基地にリース料を払う。

## 8.2. 需要と供給

経済主体は商品ごとに需要量（`demand_amount`）を持つ。需要はエポックの終わりに次のエポックに向けて計画され、商品市場での調達で減っていく。満たされなかった需要は持ち越さず、毎エポック計画し直す。

獲得量（`received_amount`）はそのエポックに手に入れた量で、市場での調達・自家供給・配送・天然資源の分配を合わせて数え、消費しても減らない。在庫（`remain_amount`）は消費した後に手元に残っている量で、獲得量とは別の値である。小売財・サービス財・インフラ財はそのエポックのうちに使い切る財で、在庫はエポックの初めに0に戻る。天然資源と工業原料は、生産で使われるまで在庫として持ち越す。

商品を供給するのは一般施設（`TYPE_STANDARD`）と輸出入拠点（輸入）である。供給量（`supply_amount`）は次の市場に出す在庫で、売れ残りの持ち越しにそのエポックの生産量を加えた量である。売値（`supply_price`）は施設が原価をもとに決め（[9_生産活動](9_生産活動.md)）、税を含まない。地区の平均価格（`zone_average_prices`）はその地区の供給者の売値の平均（小売財は消費税込み）で、供給者のいない地区や商品では、近くの地区の価格や輸入品の価格などから見積もる。都市の平均価格（`average_prices`）は地区の平均価格の平均である。

自家供給は、市場で満たせなかった需要と世帯の最低需要の不足を、商品ごとの上限まで無償で満たす仕組みで、お金の無い世帯の最低限の暮らしを市場の外で支える（[10_消費活動](10_消費活動.md)）。経済統計の注文量は輸出入拠点を除く需要者が計画した需要の合計で、この補填と、取引に伴って市場の中で生まれる輸送サービスの需要を含まないので、実際に手に入れた量（実消費量）が注文量を上回ることもある。

## 8.3. 需給マッチング

商品市場はエポックごと、商品ごとに需要者と供給者を引き合わせる。需要者は、売値に輸送コストを足して供給者の魅力（`attraction`。立地と知名度で決まり、設備の充実度は含まない）で割った評価の良い供給者から買う。マッチングは1エポックに何回かに分けて行い、売り切れで買えなかった需要者は、次の回に在庫の残る別の供給者から買う。

輸送コストは商品の種類で異なる。工業原料はトラックで運び、重さと道路の混雑を反映した所要時間に比例する費用が、輸送業者の売る輸送サービスの需要になる。ただし需要者と供給者の土地区画が近い（同じ建物を含む）ときは、配管やコンベアで運ぶものとして輸送コストも道路の交通も生じないので、工場や貨物の積み下ろしの施設（[33_貨物輸送](33_貨物輸送.md)）は寄せて置くとよい。小売財は買い手が店まで出向く時間を賃金で換算した費用で、自動車を持つ世帯は自動車の、持たない世帯は徒歩と公共交通の所要時間で測る。サービス財に輸送コストはかからない。

消防サービスのように届くのに時間がかかると意味をなさない商品には距離減衰があり、供給者までの所要時間が長いほど頼める量が急に小さくなる。頼まれなかった分の在庫は、近い需要者に残る。

取引に伴う移動は道路の交通量に計上される。小売の買い物の往復は、公共交通の乗車と運賃（[6_公共交通機関](6_公共交通機関.md)）と、自動車で来た客の駐車にも数える。

### サービス財の供給範囲

変電所・下水処理場・電波塔のように届く範囲が限られるサービス財の施設は、施設ごとに決まる効果範囲の中の土地区画にしか財を供給できない。範囲の中でも、施設の供給量が足りなければ財は届かない。範囲は施設の稼働状況には左右されない。水道ポンプ・下水処理場・ゴミ処理場・変電所は、敷地の接道から道路に沿った道のりが施設マスターの効果半径以内の区画に届き、近くても道路でつながっていない区画には届かない。そのため道路の完成・撤去や区画の変更で範囲が変わる。電波塔は、都市を作ったときの地形に遮られずに見通せる場所（建物の高さも含めて測り、海の上は海面の高さで判定する）に届き、造成には左右されない。そのほかの施設は効果半径の円である。効果範囲を持たないサービス施設は、都市全域へ供給する。

効果範囲の API は、その財を供給する施設すべて（状態を問わない）の範囲と、範囲内・範囲外の建物を返す。範囲内・範囲外は、稼働中の建物を、敷地が稼働中の施設の範囲に入るかで分けたもので、計画中・建設中の施設の範囲は判定に含めない。

## 8.4. 決済と課税

取引が成立すると、買い手は売値に税を加えた額を払い、売り手は売値の分を受け取る。消費税は小売財の取引にだけかかり、輸入品には消費税の代わりに輸入関税がかかる。公共施設の調達が予算にどう縛られるかは、[22_予算管理](22_予算管理.md) を参照。

## 8.5. 輸入と輸出

輸出入は輸出入拠点（`TYPE_TRADE`）が担い、1つの拠点が供給者として輸入を、需要者として輸出を行う。拠点には、港、国際貨物駅、国境検問所に入居する陸路輸送（[12_建物](12_建物.md)）、序盤の最低限の輸出入のために市庁舎に置かれる支援拠点がある。取扱能力は重さ（t）で数えて床面積に比例し、輸入と輸出がそれぞれ同じ能力を持つ。国際貨物駅の能力は、国際貨物輸送路線で届いた枠でも縛られる（品目の重さの数え方と国際貨物は[33_貨物輸送](33_貨物輸送.md)）。

輸出入は外国の価格（域外価格。ゲーム中は変わらない）で行う（[7_金融システム](7_金融システム.md)）。輸入価格は域外価格に輸送費（都市パラメータの輸送費率）を上乗せした値で、買い手はこれに輸入関税を加えて払う。輸出の受取上限は、域外価格から輸送費を割り引いた値である。両者の間には輸送費の往復ぶんの差があるので、同じ商品を輸入しながら輸出することは割に合わない。

拠点は国内の需要に応じた量を輸入として売り、国内の需要者が買い終えた後に、国内で売れ残った在庫を輸出として買う。国内で売れる商品が輸出に回り、その穴を輸入が埋めることはない。拠点が買うのは売値と輸送コストの合計が受取上限以下の在庫で、支払いは受取上限の単価で行うので、安く作れる生産者ほど輸出の利幅が大きい。輸出の対象は輸出入できる商品（商品マスターの `trade`）だけで、拠点が自身の稼働や工事に使う物は、国内の需要者と同じ条件で買う。
