# 8. 商品市場

## 8.1. 商品とは

商品(product)は、経済主体が生産・消費する財とサービスである。次の6種類に分かれる。

| 種類 | 定数 | 説明 |
| --- | --- | --- |
| 天然資源 | `GOODS_RESOURCE` | 土地から採取する原材料([天然資源](21_天然資源.md)) |
| 工業原料 | `GOODS_MATERIAL` | 生産の原材料になる中間財。トラックなどで運ぶ |
| 小売財 | `GOODS_RETAIL` | 世帯が消費する財。買い手が店へ出向く |
| サービス財 | `GOODS_SERVICE` | 医療・消防などのサービス。届く範囲が限られるものもある |
| インフラ財 | `GOODS_INFRASTRUCTURE` | 専用網で運ぶ電力・水など([インフラ網](26_インフラ網.md)) |
| 公共交通車両 | `GOODS_TRANSIT` | 車両基地が路線へ貸し出す車両([公共交通機関](6_公共交通機関.md)) |

商品市場で売買されるのは工業原料・小売財・サービス財である。天然資源とインフラ財は市場を通さずに供給され、公共交通車両はリースされる。

## 8.2. 需要と供給

経済主体は、生産や暮らしに必要な商品を求め、一般施設や輸出入拠点がそれを供給する。

| 用語 | 意味 |
| --- | --- |
| 需要量(`demand_amount`) | 調達しようとする量 |
| 供給量(`supply_amount`) | 売り手が市場へ出す量 |
| 獲得量(`received_amount`) | そのエポックに手に入れた量 |
| 在庫(`remain_amount`) | 消費後に手元に残っている量 |

獲得量と在庫は異なる。原材料には次の生産まで蓄えられるものがある一方、小売財やサービスなどはそのエポックの消費として扱う。最低限の生活の一部は、市場外の自家供給でも支えられる([消費活動](10_消費活動.md))。

## 8.3. 取引と移動

買い手は、価格だけでなく、移動や輸送の負担、売り手の魅力も考慮して取引先を選ぶ。売り手が近いことや、道路・公共交通が整っていることは、取引のしやすさにつながる。

工業原料は主に貨物として運び、小売財は買い手が店まで出向く。この移動が都市の交通を生む。近接した施設間の構内物流や専用網による輸送については[貨物輸送](33_貨物輸送.md)を参照。

サービスには、都市全域に提供できるものと、近くにしか届かないものがある。消防のように到達時間が重要なサービスもあれば、道路のつながりや地形によって供給範囲が決まるものもある。範囲内でも、供給力が足りなければ需要を満たせない。

## 8.4. 価格と税

商品の売値は、生産にかかる費用や需給を反映する。公共サービスには、市長が価格を決めるものもある([生産活動](9_生産活動.md))。

小売財の取引には消費税、輸入品には輸入関税がかかり、市の財源となる。

## 8.5. 輸入と輸出

輸出入拠点は、都市で不足する商品を輸入し、国内で売り切れない商品を輸出する。港や国際貨物駅などが窓口となり、それぞれに取扱能力がある。

貿易は域外価格を基準とし、国外との運賃や関税の影響を受ける。重くて安い商品は輸送の負担が大きく、地元で生産する方が有利になりやすい。軽くて高い商品は遠くと取引しやすい。貿易による資金の出入りは[金融システム](7_金融システム.md)を参照。
