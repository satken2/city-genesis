# 22. 予算管理

市政府(プレイヤー)の財政は、税などの歳入と、公共施設の運営・建設・修繕・社会保障などの歳出から成る。プレイヤーは金額ではなく、予算カテゴリごとに「必要額に対する比率」を決め、予算額は必要額と比率から毎回導かれる。

## 22.1. 歳入

税は、小売財の購入にかかる消費税、輸入にかかる輸入関税、給与から差し引く所得税、一般施設(`TYPE_STANDARD`)の黒字にかかる法人税である。公営施設の事業収入(公共サービスの売上や公営住宅の家賃)も歳入で、支出と同じ予算カテゴリのキーで記録する。市有地を民間に払い下げた代金は中央銀行が受け取り、市の歳入にはならない([7_金融システム](7_金融システム.md))。

## 22.2. 予算カテゴリ

| カテゴリ | 定数 | 対象 |
| --- | --- | --- |
| 市政 | `LEDGER_CITYHALL` | 市役所の運営 |
| 医療 | `LEDGER_MEDICAL` | 病院などの運営 |
| 教育 | `LEDGER_EDUCATION` | 学校の運営 |
| 治安 | `LEDGER_SECURITY` | 警察の運営 |
| 消防 | `LEDGER_FIRE` | 消防の運営 |
| インフラ | `LEDGER_INFRASTRUCTURE` | インフラ施設の運営 |
| その他 | `LEDGER_OTHER` | その他の公共施設の運営 |
| 公共交通 | `LEDGER_TRANSPORT` | 車両基地・路線の運営 |
| 建設 | `LEDGER_CONSTRUCTION` | 公共の建物・パスの新設と解体 |
| 修繕 | `LEDGER_MAINTENANCE` | 公共の建物・パスの修繕 |
| 社会保障 | `LEDGER_WELFARE` | 世帯への給付 |
| 用地買収 | `LEDGER_LAND_PURCHASE` | 道路計画と重なる民間区画の買収([3_道路網](3_道路網.md)) |
| 貯蓄 | `LEDGER_RESERVE` | 支出の枠ではなく、どこにも配らずに残した現金 |

公共施設がどのカテゴリから支出するかは業種ごとに決まっていて、稼働前の施設の工事費は建設、稼働中の施設の工事費は修繕に入る。市が民間の土地区画を収用したときの補償は、予算カテゴリではない `LEDGER_LAND_ACQUISITION` のキーで支出の実績に記録する。

## 22.3. 予算の決まり方

必要額(`projected_required`)は、そのカテゴリの公共施設と案件が今の計画どおりに進んだときの1エポックの費用で、前のエポックの実績ではない。稼働できない施設の材料費のように、実際には使われない費用は含めない。予算(`budgets`)は必要額に比率(`category_ratio`。上限は共有定数 `MAX_CATEGORY_RATIO`)を掛けた額で、比率はプレイヤーが変えるまで保たれる。都市が育って必要額が伸びれば、予算も一緒に伸びる。

予算はシミュレーションを始める直前に導くので、エポックの間に行った発注や設定の変更は直後のエポックの予算に入る。比率を変えたときも、その場で導き直して公共施設の計画を立て直す。

予算の合計が配れる現金(現預金から貯蓄目標 `savings_target` を引いた額)を超えると、維持優先度(`budget_tiers`。1が最後まで残り、4が最初に削られる)の低いカテゴリから比率を下げて収める。このとき `budget_auto_adjusted` が立ち、調整後の比率は `effective_category_ratio` に入る。市政府が債務超過(現預金が0以下)なら、全カテゴリの予算が0になる。どこにも配らなかった現金は貯蓄(`savings`)になる。

## 22.4. 予算の効き方

運営のカテゴリでは、予算は公共施設の計画(雇用枠・生産目標・調達量)に効く。比率を下げると計画がほぼ比例して縮み、人員は労働市場で解雇される。計画した支出は執行時に削らずに払い、予算を超えた分は市の貯蓄を取り崩し、尽きれば市政府の借金になる。待機の余力を持って運転する施設([9_生産活動](9_生産活動.md))では、比率を1より上げると待機の生産と雇用を上乗せできる。

建設・修繕・用地買収・社会保障では、予算はその場の支出の上限として効く。比率を下げると工事は総額を変えずに工期が延び、成立する買収が減り、給付は同じ割合で減る。比率0で止まる。

施設・道路ごとの稼働率目標(`utilization_target`)は予算とは別に効く。稼働中の施設では稼働率、建設中の建物・道路では建設スピードの倍率(上限は共有定数 `MAX_CONSTRUCTION_SPEED_FACTOR`)である。

## 22.5. 社会保障

社会保障は市政府から定住した住民の世帯への現金の給付で、職も学校も無い就労年齢の人への失業給付、退職年齢以上の人への年金、手持ちの現金と給付を足しても最低生活費に届かない世帯への生活扶助がある。退職年齢と給付率は市長が決める都市の政策で、失業給付と年金の給付率は住む地区の標準賃金に対する割合である。必要額は失業・高齢化・困窮に応じて増減する。

## 22.6. 公共施設の会計

公共施設は市政府の一部で、残高は毎エポック市政府へ移す(黒字は吸収し、赤字は肩代わりする)。建設中や取りやめ・取り壊しで消える施設も同じで、公共施設の支出は常に市の負担になる。輸出入拠点だけは、残高が都市の貿易収支を表すので市政府へ移さない([7_金融システム](7_金融システム.md))。

## 22.7. 公共工事の発注時の資金審査

市政府が発注する公共工事(公共の建物・パスの新設、パスの造り替え、造成)は、事業費の全額を未拘束の現金で賄えるときだけ受理する。未拘束の現金は、現預金から貯蓄目標と、すでに抱えている工事と用地買収の残りの費用を引いた額で、資金の無いまま発注して進まない案件を作らせないための審査である。足りない発注は `INSUFFICIENT_FUNDS` で拒否され、建設費のプレビューも同じ判定(`affordable` など)を返す。審査を行わないプレイモード([プレイモード](../programs/プレイモード.md))では `unlimited` が真になる。価格は発注時点の値で見積もるので、着工後の値上がりで調達が足りなくなることはある。
