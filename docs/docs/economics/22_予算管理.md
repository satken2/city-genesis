# 22. 予算管理

## 22.1. 市の財政

市政府の財政は、税や公営事業などの歳入と、公共施設の運営・建設・修繕・社会保障などの歳出から成る。公共施設の収支は市政府の会計にまとまり、施設の赤字も市が負担する。

税には消費税・輸入関税・所得税・法人税がある。土地や中央銀行との資金の関係については[金融システム](7_金融システム.md)を参照。

## 22.2. 予算カテゴリ

プレイヤーはカテゴリごとに、必要額に対する予算の比率を決める。都市の成長によって必要額が変わると、同じ比率でも予算額は変化する。

| カテゴリ | 定数 | 対象 |
| --- | --- | --- |
| 市政 | `LEDGER_CITYHALL` | 市役所の運営 |
| 医療 | `LEDGER_MEDICAL` | 病院などの運営 |
| 教育 | `LEDGER_EDUCATION` | 学校の運営 |
| 治安 | `LEDGER_SECURITY` | 警察の運営 |
| 消防 | `LEDGER_FIRE` | 消防の運営 |
| インフラ | `LEDGER_INFRASTRUCTURE` | インフラ施設の運営 |
| その他 | `LEDGER_OTHER` | その他の公共施設の運営 |
| 公共交通 | `LEDGER_TRANSPORT` | 車両基地・路線の運営 |
| 建設 | `LEDGER_CONSTRUCTION` | 公共の建物・パスの新設と解体 |
| 修繕 | `LEDGER_MAINTENANCE` | 公共の建物・パスの修繕 |
| 社会保障 | `LEDGER_WELFARE` | 世帯への給付 |
| 用地買収 | `LEDGER_LAND_PURCHASE` | 公共事業の用地買収 |
| 貯蓄 | `LEDGER_RESERVE` | 予算に配分せず残す現金 |

## 22.3. 予算と都市の活動

公共施設の運営予算は、雇用や生産、調達の規模を支える。予算を減らすと施設の供給力も縮み、住民が受けられるサービスに影響する。

建設や修繕の予算を減らすと、工事に使える量が減って完成が遅くなる。用地買収や社会保障の予算不足は、買収や給付を制限する。

資金が足りないときは、プレイヤーが指定した維持優先度に応じて予算が縮小される。貯蓄は、支出の変動や将来の事業に備える役割を持つ。

## 22.4. 社会保障

社会保障は、定住した住民の世帯への現金給付である。失業者への給付、高齢者への年金、最低限の暮らしを支える生活扶助がある。

給付の水準や退職年齢は都市の政策で、失業・高齢化・困窮が進むと必要な支出も増える。

## 22.5. 公共工事

公共の建物・道路・造成などの発注には、事業費を賄える資金の確保が必要になる。新しい計画だけでなく、すでに進めている工事や用地買収も市の資金を使う。

工事の進み方は[建設作業量と施工能力](25_建設作業量と施工能力.md)を参照。
