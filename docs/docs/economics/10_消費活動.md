# 10. 消費活動

世帯は、生活に必要な財やサービスを商品市場で調達する。消費できる量は、世帯の資金、商品の価格、都市の供給力によって変わる。

## 10.1. 消費の予算

可処分所得(`discretionary_income`)は、世帯が市場で使える予算を表す。手元の資金から家賃や生活の備えを確保し、残りを消費に使う。貯蓄があれば、失業してもすぐに暮らしが立ち行かなくなるわけではない。

市場で買えない最低限の需要の一部は、自家供給によって補われる([商品市場](8_商品市場.md))。

## 10.2. 需要の種類

商品の需要は、生活上の優先度によって3つのティアに分かれる。

| ティア | 内容 |
| --- | --- |
| `DEMAND_TIER1` | 生活必需品 |
| `DEMAND_TIER2` | 一般消費財 |
| `DEMAND_TIER3` | 娯楽・高級品 |

世帯は最低限の暮らしを優先し、余裕が生まれるほど豊かな消費へ向かう。需要は世帯人数だけでなく、年齢や健康、余暇の多さによっても異なる。

## 10.3. 充足度

充足度は、必要な財やサービスをどの程度得られたかを表す。

| 充足度 | 内容 |
| --- | --- |
| 栄養(`satis_nutrition`) | 食事が十分に取れているか |
| 医療(`satis_healthcare`) | 必要な医療を受けられているか |
| 観光体験(`satis_tourism`) | 観光体験の需要が満たされているか |
| 娯楽・余暇(`satis_leisure`) | 娯楽や余暇を楽しめているか |
| 経済的豊かさ(`satis_wealth`) | 暮らしを豊かにする商品が得られているか |

栄養や医療は健康に、娯楽や経済的豊かさは生活の満足度に関わる([満足度と施政スコア](23_施政スコア.md))。

## 10.4. 自動車の利用

自動車は継続的に費用を払うレンタルとして扱う。世帯は、自動車による移動の便利さと費用を考慮して利用を選ぶ。利用には資金と車両の供給が必要で、公共交通の利便性も選択に影響する。

自動車を保有する世帯は通勤・通学・買い物に車を使い、保有しない世帯は徒歩と公共交通を使う([公共交通機関](6_公共交通機関.md))。
