# 10. 消費活動

世帯は、エポックの終わりに次のエポックに買う量を計画し、次のエポックの商品市場で調達して、その結果で充足度を更新する。

## 10.1. 可処分所得

可処分所得（`discretionary_income`）は、世帯が次のエポックに市場で使える予算で、現預金から生活防衛資金と家賃を引いた額（マイナスなら0）である。世帯はこの範囲でしか注文しない。予算を収入ではなく現預金で決めるのは、エポックを進める前には次の収入が分からないためで、失業しても貯蓄がある間は暮らしを保てる。生活防衛資金は最低限の消費と家賃の数エポック分の蓄えで、就業者のいない世帯は多く残す。お金が尽きた世帯でも、最低需要のうち市場で買えなかった分は、商品ごとの上限まで自家供給で無償で補われる（[8_商品市場](8_商品市場.md)）。

## 10.2. 需要ティア

各商品は、商品マスターの `demand_tier` で3つのティア（`DEMAND_TIER1`〜`DEMAND_TIER3`）に分かれる。ティア1は生活必需品、ティア2は一般消費財、ティア3は娯楽・高級品である。商品マスターの次の値は1人1日あたりの基準で、世帯人数とエポック日数を掛けて使う。

- `demand_min`: 最低需要量。優先して確保する。
- `demand_max`: 最大需要量。ティア1・2では買う量の上限（価格が高い商品ほど手前で止まる）で、ティア3では上限にならず、充足度の基準になる。
- `demand_weight`: 予算が足りないときに、商品のあいだで予算を分ける重み。
- `demand_atom`: 真の商品（自動車など）は整数単位でしか買わない。

予算は、まず全ティアの最低需要に、次にティア1・2の買い増しに配り、残りをティア3へ上限なく配る。ティア3に使える額は現預金ではなく平均収入の余りで抑えるので、貯蓄があっても収入の少ない世帯は贅沢をせず、収入が増えるほど娯楽・高級品の消費が増え続ける。価格は世帯の住む地区の平均価格を使う。娯楽・余暇の商品は自由な時間が少ないほど買う量が減り、医療・医薬品は構成員の健康状態と年齢に応じて増減する。観光客の世帯（[31_観光](31_観光.md)）は、住民とは別の需要量を持つ。

## 10.3. 充足度

調達の結果から、次の充足度（0〜1）を更新する。

| 充足度 | 対象の商品 | 1になる量 |
| --- | --- | --- |
| 栄養（`satis_nutrition`） | 食料品・加工食品・外食 | 最低需要量 |
| 医療（`satis_healthcare`） | 医療サービス | 健康状態と年齢から求めた必要量 |
| 観光体験（`satis_tourism`） | 観光体験 | 最大需要量 |
| 娯楽・余暇（`satis_leisure`） | 外食・高級外食・娯楽・インターネット・ソフトウェア・フィットネス・美容 | 商品ごとの最大需要量（比率の平均） |
| 経済的豊かさ（`satis_wealth`） | 衣料品・加工食品・酒類・家電・高級衣料品・宝飾品 | 商品ごとの最大需要量（比率の平均） |

基準の量にはマスターの値を使うので、予算が無くて注文しなかった世帯の充足度は1にならない。食料品の自家供給の上限は最低需要より小さいので、食料を市場で買えない世帯の栄養充足度は1未満になる。対象の商品の需要を持たない世帯（観光体験に対する住民など）は1とする。栄養と医療は健康を通じて死亡率に効き（[15_世帯](15_世帯.md)）、娯楽・余暇と経済的豊かさは、健康・快適さとともに生活水準スコア（`qol_score`）の4軸になる（[23_施政スコア](23_施政スコア.md)）。

## 10.4. 自動車保有判定

自動車は買い切りではなく、エポックごとのレンタル契約である。保有を希望した世帯だけが、次のエポックに自動車（`PRODUCT_AUTOMOBILE_RETAIL`）を世帯あたり1台とガソリン（`PRODUCT_GASOLINE_RETAIL`）を注文し、市場で1台以上調達できたエポックだけ自動車を保有している（`has_automobile`）。供給不足や予算不足で調達できなければ、希望していても保有にならない。

保有を希望するかは、自動車で節約できる時間の金銭価値と、自動車の費用（レンタル料とガソリン代）の比較で決まる。節約できる時間は、通勤・通学と買い物の往復ごとの「徒歩と公共交通」と「自動車」の所要時間の差で、長く歩く移動ほど重く見る。時間の価値は就業者1人あたりの所得から求めるので、所得が高いほど自動車を選びやすい。公共交通で自動車と変わらない時間で行ける世帯は、所得が高くても自動車を持たない。運賃は判定に含めない。保有中の世帯は手放す判断を緩くし、毎エポックの入れ替わりを抑える。観光客の世帯は自動車を持たない。

保有している世帯の市民は通勤・通学に自動車を使い、買い物の店選びも自動車の所要時間で評価する。保有していない世帯は徒歩と公共交通で移動し、公共交通の運賃を払う（[6_公共交通機関](6_公共交通機関.md)）。
