# 10. 消費活動

世帯が商品を消費する一連の流れについて。消費活動は「需要計画の策定」「市場での調達」「消費結果の評価」「スコア更新」という4つのステップから構成される。需要計画はエポックの冒頭で行われ、商品市場でのマッチングを経て、エポックの末尾で消費結果が評価される。その後、充足度をもとに生活水準スコア（`qol_score`）が更新される。

## 10.1. 可処分所得

### 現預金ベースと収入ベースの併用

世帯の需要計画は、現預金（`reserves`）をベースとした「可処分所得（`discretionary_income`）」を基本予算としつつ、娯楽・高級品（Tier 3）の消費については平均収入（`avg_revenues`）に基づく制限を行う。

- **生活必需品（Tier 1）と一般消費財（Tier 2）**:
  現預金を基準とする。本ゲームのエポックが非同期であり次エポックの所得を確定的に予測できないため、現在の現預金額から生活防衛資金と家賃を差し引いた「可処分所得（`discretionary_income`）」を消費予算とする。これにより、失業等で一時的に収入が途絶えた世帯でも、貯蓄がある限り家賃の支払いや基本的な生活水準を維持できる。
- **娯楽・高級品（Tier 3）**:
  平均収入（`avg_revenues`）を基準とする。現預金に余裕があっても、収入がない、あるいは少ない世帯が過度な贅沢を行い急激に貯蓄を使い果たすことを防ぐため、平均収入から家賃および Tier 1・Tier 2 の消費コストを差し引いた余剰分を上限として消費が制限される。

### 生活防衛資金

生活防衛資金（`protected_reserve`）は、世帯が最低限の生活を維持するために確保すべき現預金である。全ティアの最低需要（`demand_min`）のコスト合計に家賃（`rent`）を加えたものが「1エポックあたりの基本生活費」となり、それに月数を掛けたものが生活防衛資金となる。

月数は世帯の就業状況によって異なり、無職世帯は就業世帯（構成員に1人でも就業者がいる世帯）より多くの月数分を生活防衛資金として残す。失業中は次の収入源が不確実であるため、より多くの防衛資金を必要とするという考えに基づく。

### 可処分所得の計算

可処分所得は「現預金 − 生活防衛資金 − 家賃」として計算される。この値が負になる場合、可処分所得はゼロとなり、その世帯は次エポックで市場からはほとんど購入できない。世帯の市場注文は常に予算（可処分所得）の範囲内で計画され、支払い能力を超える量は注文しない。ただし、最低需要（`demand_min`）のうち市場で調達できなかった不足分は、商品ごとに定められた自家供給の上限（`self_sustain`）まで無償で補われるため（[[8_商品市場]]）、資金が尽きた世帯も自給可能な財については生存最低限を維持できる。

## 10.2. 需要ティア

世帯の消費需要は、3つのティア（`DEMAND_TIER1`、`DEMAND_TIER2`、`DEMAND_TIER3`）に分類される。各商品はマスターデータの `demand_tier` によっていずれかのティアに属する。ティアが低いほど優先度が高く、消費予算はティア1から順に配分される。

各商品は、1人あたりの基準値として以下の3つのパラメータを持つ。

- `demand_min` ... 最低需要量。この量は生活に必要不可欠であり、優先的に確保される。栄養充足度など「最小需要基準」の充足度計算では、この値が充足度1.0の基準となる（10.4節参照）。
- `demand_max` ... 最大需要量の基準値。ティア1・2では消費の上限として機能する。ティア3では「充足度計算の参照水準」として使用され、消費の絶対上限にはならない（後述）。
- `demand_weight` ... 配分の重み。予算が不足して全量を購入できない場合に、商品間で予算を配分する際の優先度を表す。

実際の需要量は、これらの1人あたり基準値に世帯人数を掛けて算出される。

観光客世帯（[[31_観光]]）は住民とは別の1人あたり基準値（観光客の需要量）を持ち、世帯人数の代わりに1組の人数を掛ける。食料品を買わず、外食・娯楽・観光体験・玄関口の往復に偏った需要になる。

### 世帯の需要ティア

各世帯が需要計画フェーズにおいて、どの需要ティアの商品まで要求（計画）しているかを `demand_tier` プロパティに記録する。このプロパティには、計画需要（`demand_amount`）として 0 より大きい量が割り当てられた商品が存在する最高ティア（0〜3）が設定される。

- **ティア 0**: 予算が極端に不足しているなどの理由により、いずれの商品に対しても計画需要が発生しなかった状態。
- **ティア 1**: ティア1の商品（生活必需品）にのみ計画需要が発生し、ティア2以降には予算が回らなかった状態。
- **ティア 2**: ティア2の商品（一般消費財や自動車など）まで計画需要が発生したが、ティア3までには予算が回らなかった状態。
- **ティア 3**: ティア3の商品（娯楽・高級品）まで計画需要が発生し、最も高い水準の消費活動を計画できている状態。

この値は、各世帯が現在どの水準の消費活動を行えているかを把握するための指標として機能する。

### ティア3の消費の特性

ティア3（娯楽・高級品）は、ティア1・2とは異なる消費メカニズムを持つ。ティア1・2においては `demand_max × 世帯人数` が消費の絶対上限となるが、ティア3ではこの上限を設けない。ティア1・2の最大需要がすべて満たされた後も、残予算がある限りティア3商品へ `demand_weight / price` 比に従って継続的に比例配分される。これにより、収入が増えるほどティア3消費も増え続け、高所得世帯の購買力が経済内で循環し続ける。

`demand_max`（ティア3）は「充足度計算の参照水準」としてのみ機能する。実際の調達量が `demand_max × 世帯人数` に達した時点で充足度 `satis=1.0` となるが、消費自体はそれ以降も続く。

### 条件付き需要

一部の商品は、世帯の保有状態によって需要が変動する。たとえばガソリン（`PRODUCT_GASOLINE_RETAIL`）は、世帯が自動車（`has_automobile`）を保有している場合にのみ需要が発生する。自動車を保有しない世帯のガソリン需要はゼロになる。

### 整数単位の商品（atom）

`demand_atom` が設定された商品は、端数での購入を許さず、整数単位でのみ購入できる。自動車（`PRODUCT_AUTOMOBILE_RETAIL`）のように、1台の何分の一かを購入するということが現実的に不可能な財に適用される。

## 10.3. 予算配分

### 配分の順序

予算配分は以下の順序で行われる。

1. **ティア1の最低需要を確保** ... ティア1に属する全商品の最低需要を満たすためのコストを計算し、予算（現預金ベースの可処分所得）から配分する。
2. **ティア2の最低需要を確保** ... 残予算でティア2の最低需要を配分する。
3. **ティア3の最低需要を確保** ... 残予算でティア3の最低需要を配分する。ただし、10.1節の通り、ティア3への配分は平均収入に基づく余剰予算の範囲内に制限される。
4. **ティア1の追加需要を配分** ... 残予算があれば、ティア1の最大需要（`demand_max`）に向けて追加購入する。
5. **ティア2の追加需要を配分** ... 同様にティア2の最大需要に向けて追加購入する。
6. **ティア3の追加需要を配分（残予算使い切り）** ... ティア1・2と異なり、ティア3は `demand_max` を上限としない。残予算がある限り、各商品の `demand_weight / price` 比に従って比例配分を継続する。この配分も平均収入に基づく余剰予算の範囲内に制限される。

この順序により、まず必需品と一般生活財が現預金を取り崩してでも確保され、その上で「収入に十分な余裕がある世帯」のみが娯楽・高級品を購入するという現実的な消費行動を表現する。また、高所得世帯が `demand_max` に達した後も引き続き消費を続けることで、余剰資金が市場に還流し続ける。

### 重み付き比例配分

予算が不足して全量を購入できない場合、各商品の `demand_weight` を用いた重み付き比例配分が行われる。重みが大きい商品ほど多くの予算が配分される。

### 価格の参照

商品の価格は、世帯が属する地区の地区平均価格（`zone_average_prices`）を優先して参照する。地区平均価格が未確定またはゼロの場合は、都市全体の平均価格（`average_prices`）にフォールバックする。

## 10.4. 消費結果の評価

### 充足度の計算

商品市場での調達が完了した後、各世帯は獲得した物資に基づいて充足度を更新する。充足度は調達量を基準需要量で割った値として計算され、0.0〜1.0の範囲にクリップされる。分母には計画需要量ではなくマスター値を使用することで、予算制約で需要がゼロになった貧困世帯が誤って充足度1.0と判定されることを防ぐ。

指標ごとに「最小需要基準」と「最大需要基準」を使い分ける。これは、各指標が表す生活要素によって「十分に満たされている」の基準が異なるためである。

- **最小需要基準** ... 調達量を「マスターの `demand_min × 世帯人数 × simulation_days`」で割る。最低限の生存需要を満たせれば充足度1.0となる。現代社会において、最低限の生物学的需要が満たされていれば実質的に充足状態とみなせる生活要素（栄養など）に適用する。`demand_min` が0の商品を含む指標には適用できない（分母がゼロになるため）。なお、自家供給（[[8_商品市場]]）は最低需要の不足分を商品ごとの上限まで補うため、自家供給の上限が最低需要以上の商品では充足度が市場と無関係に常に1.0となる。食料品の自家供給上限は最低需要より小さく設定されており、食料を市場で調達できない世帯の栄養充足度はその比率まで下がる。
- **最大需要基準** ... 調達量を「マスターの `demand_max × 世帯人数 × simulation_days`」で割る。需要の上限に対する達成率を測る、より厳しい基準。`demand_min` が0（任意消費）の商品を含む指標（医療・娯楽など）に適用する。

いずれの基準でも、参照水準（分母）が本当にゼロ（需要概念が存在しない）の世帯は充足度1.0とする。

充足度は3つの指標に分類され、それぞれ関連する商品群の充足度を合算して算出される。

| 指標    | プロパティ                 | 対象商品群                            | 計算基準   |
| ----- | --------------------- | -------------------------------- | ------ |
| 栄養充足度 | `satis_nutrition`     | 食料、加工食品、飲食サービス                   | 最小需要基準 |
| 医療充足度 | `satis_healthcare`    | 医薬品、医療サービス                       | 最大需要基準 |
| 娯楽充足度 | `satis_entertainment` | 娯楽、インターネット、ソフトウェア、フィットネス、美容、高級飲食 | 最大需要基準 |

これらの充足度は、市民の死亡判定（栄養不足や疾病）、生活水準スコアの算出、転居判断など、多くのゲームシステムに影響を与える。

### 生活水準スコア（qol_score）の計算

3つの充足度を加重平均して生活水準スコア（`qol_score`）を算出する。`qol_score` は世帯の転居判断や住環境評価に用いられる総合指標であり、エポック末尾に全世帯分が集計されて都市スコアに反映される。詳細は [23. 施政スコア](23_施政スコア.md) を参照。

### 家計の逼迫判定

世帯の可処分所得（`discretionary_income`）と所得（`revenues`）の比率に基づいて、家計の逼迫度合いを判定する。

- **逼迫状態** ... 可処分所得が所得に対して一定割合を下回る状態。連続して逼迫が続くと、より安い住居への転居イベントが発生する可能性がある。
- **余裕状態** ... 可処分所得が所得に対して一定割合を上回る状態。連続して余裕が続くと、より良い住居への転居イベントが発生する可能性がある。

逼迫または余裕の連続エポック数は `tight_budget_count` / `surplus_budget_count` として記録され、所定の閾値に達すると転居やスラム化のイベントがトリガーされる。

## 10.5. 自動車保有判定

### 自動車のレンタルモデル

本ゲームにおいて、自動車は耐久消費財ではなく、月額レンタル契約としてモデル化されている。世帯は自動車を一度購入して永続的に保有するのではなく、毎エポックごとにレンタル契約を更新する形で自動車を利用する。この仕組みにより、自動車の保有・非保有を柔軟かつ動的に切り替えることができる。

自動車レンタルは需要ティア2の商品（`PRODUCT_AUTOMOBILE_RETAIL`）として消費予算から支払われる。また、自動車を保有する世帯は、ガソリン（`PRODUCT_GASOLINE_RETAIL`、需要ティア1）の追加消費も発生する。

### 判定の考え方

現実の自動車保有は「一定の所得を超えたら必ず買う」という単純なものではない。むしろ「徒歩や公共交通では不便な場所に住んでいるから車が必要になる」という動機が主流である。本ゲームでは、この現実的な消費行動を再現するため、交通利便性に基づいた自動車保有判定アルゴリズムを採用する。

具体的には、世帯が実際に訪問する経路（通勤・通学・買い物）について徒歩と自動車の所要時間を比較し、自動車が大幅に速い場合にのみ自動車の保有を検討する。所得がどれだけ高くても、住んでいる地区の交通網が充実しており徒歩でも不便がない世帯は、自動車を保有しない。

### 判定の流れ

1. **所要時間の比較**: 世帯が訪問する全経路（通勤・通学・買い物）について徒歩と自動車の所要時間を比較する
2. **時間比率による希望判定**: 徒歩が車より大幅に遅い（比率が閾値を超える）世帯が自動車を希望する。既存保有者には緩和された閾値（ヒステリシス）を適用し、頻繁な保有・非保有の反転を防ぐ
3. **支払能力判定**: 可処分所得が自動車価格以上の場合のみ保有を許可する

### 判定結果の影響

自動車保有判定の結果（`has_automobile`）は、世帯の以下の行動に反映される。

- **消費需要**: 自動車保有世帯にはガソリン（`PRODUCT_GASOLINE_RETAIL`）の需要が発生する。未保有世帯のガソリン需要はゼロとなる。自動車本体（`PRODUCT_AUTOMOBILE_RETAIL`）の需要も保有状態に応じて変動する。
- **移動手段**: 保有世帯の通勤・通学は自動車で、未保有世帯は徒歩（公共交通を含む）で行われる。
- **買い物先の評価**: 小売商品の調達において、保有世帯は自動車での所要時間で店舗までの距離を評価する。地区内の移動時間の評価も保有状況に応じて切り替わる。
