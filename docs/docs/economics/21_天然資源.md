# 21. 天然資源

## 21.1. 天然資源とは

天然資源は、マップ上に置かれた鉱脈・油田・水源などの埋蔵資源である。それぞれが多角形の範囲を持ち、範囲に重なる土地区画([4_地区と土地区画](4_地区と土地区画.md))に立つ経済主体へ、資源の種別ごとに決まった物資を市場を通さずに直接配る。土地区画の `resource_id` は、その区画に重なる資源のIDを資源の種別ごとに持つ(0は資源なし)。

| 項目 | 意味 |
| --- | --- |
| `current_amount` | 現在の埋蔵量 |
| `max_amount` | 埋蔵量の上限。回復はここまで |
| `recovery_rate` | 埋蔵量の上限に対する1日あたりの回復の割合。0は回復しない資源(鉱脈・油田など) |

埋蔵量は、採取施設の産出物の単位で数える(採取施設は資源1単位から産出物1単位を作る)。石油資源は原油のバレル、水資源は高圧水道のKL(m³)、鉱石資源は鉱石のkgである。

## 21.2. 採取と回復

エポックごとに、範囲内の施設のうちその物資を原材料として需要するものへ、埋蔵量の範囲で配る。需要が埋蔵量を超えるときは需要の比で按分する。配った分だけ埋蔵量が減り、そのあと回復率に応じて上限まで回復する。回復は採取の後なので、1エポックに採れるのは、そのエポックの初めの埋蔵量(最大でも上限)までである。

天然資源を原材料に持つ施設は、資源のある区画でしか生産できず、残りの割合が低くなると生産効率が急に落ちる(立地倍率。[4_地区と土地区画](4_地区と土地区画.md))。原油や鉱石を市場へ出す施設も、高圧水道やパイプライン原油をインフラ網へ送る施設([26_インフラ網](26_インフラ網.md))も同じである。天然資源を原材料に持たない施設(電力だけで水を作る海水淡水化プラントなど)は、資源の無い場所にも建てられる。

## 21.3. 埋蔵量と採取量の推移

資源の詳細を取得すると、`current_amount` は各エポックの終わり(回復の後)の埋蔵量、`consumption_amount` は各エポックに配った採取量の推移になり、どちらも新しい順(直近のエポックが先頭)のリストで返る。一覧の取得では `current_amount` は現在の埋蔵量の1つの値である。

## 21.4. 資源の配置

天然資源の初期配置はシナリオが持ち、資源を置き・変え・消せるのは[テンプレート作成モード](../programs/プレイモード.md)だけである。取り込んだばかりの標高ファイルには資源が無く、地形エディタは資源を編集しない([D_地形形状](../geometries/D_地形形状.md))。シナリオから都市を始めるとシナリオの資源が都市の初期の資源になり、以後の埋蔵量の増減はセーブデータに残る。

## 21.5. 露天掘りによる地形の変化

露天掘り(`model_type` が `MODEL_OPEN_PIT`)の施設は、鉱石などの固体の資源を採った分だけ、立つ土地区画の地形を掘り下げる。接道側の前庭は掘らずに設備を並べ、その奥を、区画の境界・設備・区画にかかるパスから余白を残して、縁から段々に下る穴として掘る。底は海面より上で止まり、施設が無くなっても埋め戻されない。地形の書き換えは地形セルの版の更新として現れ、Unity は変わったセルを取り直して穴を描く([F11_露天掘りのメッシュ生成](../geometries/F11_露天掘りのメッシュ生成.md))。
