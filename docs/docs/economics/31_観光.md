# 31. 観光

観光客は、都市の外から訪れて滞在し、都市の飲食店・娯楽施設・観光地で消費する。住民ではないが、住民と同じ商品市場・不動産市場・人流の上で動き、観光客専用の訪問先や経路は持たない。

## 31.1. 観光客とは

観光客は世帯(`TYPE_HOUSEHOLD`)のバリアント「観光客」(`VARIANT_TOURIST`)の経済主体で、1つの経済主体が観光客の1組を表す。市民を持たず、輸出入拠点から受け取る旅費(都市の外から持ち込むお金)で消費し、ホテルの宿泊フロア(`SPACE_LODGING`)に泊まる。食料品は買わず、外食・娯楽・観光体験・玄関口との往復を需要する。満足度は、娯楽と余暇の充足と観光体験の充足(`satis_tourism`)で決まる。

現実の観光客は数日で別の観光客と入れ替わるが、本ゲームでは観光客を滞在し続ける世帯として表す。入れ替えても滞在し続けても、ホテルと観光地・店・玄関口の間の人流は同じになるためである。

観光客は人口・施政スコア・社会保障・配当・所得統計などの住民の集計に含まれない。一方、商品の購入(消費税を含む)、宿泊費の支払い、昼間人口、道路の交通量には住民と同じように乗る。

## 31.2. 観光地と玄関口

観光客が来るには、観光地と玄関口の両方が要る。

- **観光地**は商品「観光体験」を供給する施設で、市長が建てる美術館・展望台と、シナリオにあらかじめ置かれる観光名所がある。観光名所は名所ごとに都市に1つまでの象徴的な施設で、どの名所かは建物の `landmark` で表す([12_建物](12_建物.md))。名所ごとの集客の補正は無く、受け入れの大きさは延床面積で決まる。住民も少しだけ観光体験を需要する(日帰りのレジャー)。
- **玄関口**は商品「都市間旅客輸送」を供給する施設で、市長が沿岸に建てる客船ターミナルと、シナリオが国境検問所などの建物に置く都市外旅客輸送拠点(鉄道・空港・高速バスなどを抽象化したもの)がある。観光客だけが需要し、ホテルとの往復が人流として現れる。料金は取らず、観光客の移動にお金がかかるのは玄関口までの公共交通の運賃だけである。

観光体験と都市間旅客輸送は、どちらも価格を統制する規制対象の商品で、民間企業は供給しない。

## 31.3. 観光客数の決まり方

観光地と玄関口の供給能力(床面積から決まる)を観光客1人の需要で割り、小さい方が都市の受入可能人数になる。観光地か玄関口のどちらかが無い都市には観光客は来ない。受け入れの余地と滞在中の観光客の評判から応募が生じ、滞在中の観光客の満足度(宿泊費の負担の軽さと、娯楽・観光体験の充足)が低いほど応募は減る。

応募した観光客は、観光地・玄関口の供給能力に応じて選んだ地区で宿泊先を待ち、ホテル(宿泊フロアを持つ共有建物)の空きへ入居する。宿泊先を待つ観光客の支払意思額はホテルの建設を促すので、ホテルは観光地や玄関口の近くに建つ。長く宿泊先が見つからない観光客は都市を去る。

滞在中の観光客は毎エポック旅費を受け取り、旅費は貿易収入(サービスの輸出)として数える([7_金融システム](7_金融システム.md))。満足度の低い観光客は確率で帰国し、残金は輸出入拠点へ戻る(貿易支出)。観光地が閉鎖しても観光客は強制的には減らず、満足度が下がって帰国していく。

## 31.4. 統計

観光客数と到着は宿泊フロアへ入居した観光客の人数で数え、宿泊先を待つ観光客は含まない。応募は人数ではなく組の数で、観光収入は旅費から帰国時の持ち帰りを引いた純額である。

人流の内訳(どの観光地や店を訪れたか)と地区別の集計は持たない。
