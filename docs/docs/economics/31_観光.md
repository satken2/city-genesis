# 31. 観光

## 31.1. 観光客とは

観光客は、都市の外から訪れ、ホテルに泊まり、飲食店・娯楽施設・観光地で消費する人々である。1組を世帯の経済主体として表すが、都市の住民とは区別する。

観光客は住民と共通の商品市場・不動産市場・交通網を使う。ホテルや観光地への移動は交通を生み、消費は都市の事業を支える。

実際の旅行者の入れ替わりは個別に追わず、継続して滞在する観光客の集団として表す。

## 31.2. 観光を支える施設

| 施設 | 役割 |
| --- | --- |
| 観光地 | 美術館・展望台・観光名所など、訪れる目的を提供する |
| 玄関口 | 客船ターミナルや都市外旅客輸送拠点など、都市外との往来を支える |
| ホテル | 観光客が滞在する宿泊フロアを提供する |

観光客の受け入れには、観光地と玄関口の両方が必要である。宿泊需要は民間のホテル建設にもつながる。

## 31.3. 評判と都市への収入

観光地や玄関口の供給力、宿泊先の空きは、受け入れられる観光客の規模を制約する。滞在中の体験や宿泊費の負担は満足度に影響し、評判や観光客の増減につながる。

観光客が持ち込む旅費は、都市外から得る収入である。観光は都市内の需要を増やすだけでなく、外から資金を呼び込む産業でもある([金融システム](7_金融システム.md))。
