# 7. 金融システム

## 7.1. 資金循環と借入

経済主体はそれぞれ現金残高(`reserves`)を持つ。支払いでは、払う側から受け取る側へ同じ額のお金が移る。都市内の取引だけでは、お金の総量は変わらない。

残高がマイナスになることは借入を表す。民間の事業は借入によって開業や建設を行えるが、担保や都市の経済規模に応じた限度がある。都市が成長すると、より大きな工場や建物への投資が可能になる。

## 7.2. 中央銀行

中央銀行は、撤退した民間の経済主体が残した資産や負債を引き受ける。引き受けた残高は時間をかけて経済全体へ還元・分担されるため、大きな破綻の負担が一度に広がることを抑える。

土地の清算や市有地の民間への払い下げに伴う資金も、中央銀行を通じて経済全体へ戻る。一方、公共施設の資金は市政府の会計にまとまる([予算管理](22_予算管理.md))。

## 7.3. 都市外とのお金の出入り

都市は外国と同じ通貨を使う一地域で、貿易では都市の外で決まる価格を受け入れる。輸出は都市へお金をもたらし、輸入は都市からお金を流出させる。観光客が持ち込む旅費も、都市外からの収入になる。

都市の中のお金の総量は、貿易収支と達成クエストの交付金によって変わる。貿易赤字による流出を、市政府や中央銀行が自動で埋め合わせることはない。取引については[商品市場](8_商品市場.md)、観光については[観光](31_観光.md)を参照。

## 7.4. 経済規模と物価の指標

| 指標 | 意味 |
| --- | --- |
| 名目GDP(`gdp`) | 都市が生み出した付加価値を、その時点の価格で表す |
| 物価指数(`price_index`) | 都市内の生産物の価格水準を、域外価格と比べて表す |
| 実質GDP(`real_gdp`) | 物価の影響を除いた経済規模を表す |

名目GDPと実質GDPを分けることで、金額の増加が生産の拡大によるものか、物価の上昇によるものかを捉えられる。
