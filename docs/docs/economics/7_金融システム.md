# 7. 金融システム

この文書では、都市における資金の循環、現金残高を用いた信用創造の仕組み、および貿易によるお金の出入りなどのマクロ経済的な仕様について説明する。

## 7.1. ゼロサム資金循環の原則

金融活動は、各経済主体の「現金残高」の増減によって管理される。

### 資金の保存則と初期状態

新たに作成された経済主体（建物、企業など）の現金残高は「ゼロ」から開始される。
ある経済主体が別の経済主体へ支払いを行った場合、支払い元の残高が減少し、支払い先の残高が同額増加する。これにより、**世界に存在する全経済主体の現金残高の合計値は常に一定を維持する**という絶対法則がある。

### マイナス残高による信用創造

各経済主体は、現金残高が「マイナス」になることを許容されている。
資金を持たない主体が支払いを実行して残高がマイナスになる挙動は、「信用創造」と同等の役割を果たす。資金を受け取った側はプラスの残高（資産）を得るため、都市全体の経済活動を停滞させることなく資金を循環させることができる。

### 負債上限（信用枠）

民間の建物には負債上限がある。上限は「担保価値 × 掛目（`LOAN_LTV_RATIO`）」で毎エポック再計算され、担保価値は建物の残存価値（家賃 × 延床面積 × 割引後の残存実効日数）と、建物が自己所有する土地区画の地価の合計である。建物が発注する修繕の支出は「負債上限 + 現在残高」（残りの与信枠）で買える量までに縮小され、与信枠を使い切った建物は修繕が進まなくなる。家賃が上がり担保価値が伸びれば与信枠も広がるため、都市の成長とともに信用枠は拡大する。新築の融資は建設を決めた時点の採算（見込み家賃による収益が建設費と土地代を上回ること。[12_建物](12_建物.md)）で決まり、着工した工事は与信枠に関わらず竣工まで進む。解体も与信枠に関わらず進む。

新しい事業の創業（[2_経済主体](2_経済主体.md)のスポーン）にも与信の制約がある。想定初期資本（建設費＋運転資金）が、都市に蓄積された民間預金総額に対する単一案件への与信集中限度を超える案件は参入できない。信用創造の原資は都市内の預金であり、外部から無限に借りられるわけではない。

### 主体の清算と中央銀行による緩衝

店舗が閉鎖したり建物が取り壊されるなどして経済主体が削除される際、その主体が持っていた現金残高（プラスの資産またはマイナスの負債）は、**中央銀行**という特別な経済主体がそのまま引き受ける。これは削除される主体から中央銀行への残高移転であり、全経済主体の現金残高の合計は変わらない。ただし公共施設は市政府の一部なので、削除される公共施設の残高は中央銀行ではなく市政府へ移る（[22_予算管理](22_予算管理.md)）。市政府の支出を中央銀行経由で経済全体に肩代わりさせないためである。

中央銀行は現金残高だけでなく、**土地**の受け皿でもある。清算により所有者を失った土地区画（無主地）は中央銀行に帰属し、市有地に民間の建物が着工する際の土地代（払い下げ代金）も中央銀行が受け取る（[12_建物](12_建物.md)）。公共施設の敷地は市有地なので、公共施設を取り壊しても中央銀行には渡らない。土地に由来する資金はいずれも市政府の財源にはならず、下記の緩衝メカニズムを通じて経済全体へ還流する。市政の収入源はあくまで税と公営事業であり、土地の売却益で市財政が潤うことはない。

中央銀行は、引き受けた残高を一度に都市へ転嫁するのではなく、**複数エポックをかけて平準化しながら自身の残高をゼロへ近づける**緩衝役として働く。

- **中央銀行の残高がマイナス（負債を肩代わりしている状態）**：都市の経済主体から少しずつ資金を**徴収**して残高を埋めていく。これは、破綻処理のための公的資金を時間をかけて回収することに相当する。
- **中央銀行の残高がプラス（資産を引き受けている状態）**：都市の経済主体へ少しずつ資金を**払い出し**て残高を放出していく。これは、清算財産を時間をかけて分配することに相当する。

徴収・払い出しは、各経済主体のそのエポックの収益に応じて按分される（よく稼いでいる主体ほど多く負担し、多く受け取る）。徴収額が時間的に平準化されるため、大きな破綻が起きても徴収額が負債に連動して跳ね上がらず、経済が急変動しにくい。中央銀行は市政府と同様にゲーム開始時に自動的に生成され、プレイヤーが削除することはできない。

中央銀行は物理的な事業所を持たない会計上の存在だが、その所在地は**市庁舎（市政府建物）への入居**として表現される（[12_建物](12_建物.md) 12.11）。これは所在を示す台帳上の紐付けであり、市庁舎のフロアを占有したり家賃を支払ったりはしない。市庁舎の詳細ウィンドウで入居主体として確認できる。

## 7.2. 貿易とお金の出入り

都市は外国と同じ通貨を使う一地域として扱われ、通貨は1つである。都市と外国との間では、輸出入拠点を通して商品の輸出入が行われる。1つの拠点が輸入（外国の商品を国内市場へ供給）と輸出（国内の生産物の買い取り）の両方を担う。

都市は外国の価格（域外価格。ゲーム中は変わらない）で取引する価格受容者であり、輸入には域外価格に輸送費を足した価格を払い、輸出では域外価格から輸送費を引いた価格までしか受け取れない（[8_商品市場](8_商品市場.md) 8.5）。都市の生産者のうち、原価がこの受取上限を下回るものだけが輸出で売り上げを伸ばせる。

### 貿易収支の表現方法

外国との取引を担う輸出入拠点も、他の経済主体と同様に単一通貨のゼロサム資金循環の原則が適用され、個別に現金残高を持つ。拠点の現金残高は外国との間の台帳であり、都市の中のお金には数えない。

- **輸入**：都市の買い手が拠点に払った代金（輸入関税を除く）は拠点の残高に入る。都市からお金が出ていく。
- **輸出**：拠点が都市の生産者に払った代金は拠点の残高から出る。都市にお金が入ってくる。

都市全体の貿易収支は、エポックごとの「輸出額 − 輸入額」である。観光客が持ち込む旅費は輸出に、帰国する観光客が持ち帰る残金は輸入に含まれる（[31_観光](31_観光.md)）。

- **貿易黒字**：輸出が輸入を上回り、都市の中のお金が増える。
- **貿易赤字**：輸入が輸出を上回り、都市の中のお金が減る。

エポックごとの輸入額・輸出額・貿易収支は、貿易統計（`GET /api/v1/stats/trade`）として外部から観測できる。

赤字で都市から出ていったお金を中央銀行や市政府が埋め合わせることはない。全拠点の残高の合計がプラスなら、都市はこれまでに外国へお金を払い越しており、マイナスなら受け取り越している。拠点の残高は、中央銀行の平準化・借入金利・法人税・配当・公共施設の会計統合のいずれの対象にもならず、エポックごとに全拠点の間で均等にならされるだけである。

## 7.3. 通貨の総量

主体間の支払い、主体の清算（中央銀行による引き受け）、中央銀行の平準化は、いずれも全経済主体の現金残高の合計を変えない。輸出入拠点を除いた都市の中のお金が増減するのは、次の2つである。

- **貿易**：貿易収支のぶんだけ増減する（7.2）。
- **達成クエストの交付金**：対価のない通貨創造として市政府の現預金を増やす（[24_達成クエスト](24_達成クエスト.md)）。

## 7.4. 国内総生産（GDP）の算出

都市全体の経済規模や物価変動を把握するため、エポックごとに名目GDP、GDPデフレーター、実質GDPが算出される。これらは統計として外部から観測できる。

### 名目GDP

名目GDPは、国内の稼働中の経済主体（`status` が `STATUS_ACTIVE`）が当エポックに創出した付加価値の総計に、間接税（消費税・輸入関税）を加算したものである（生産アプローチ）。一般施設は生産活動による付加価値（総生産額から原材料費を差し引いたもの）を、共有建物は空間の提供による利潤を、それぞれ都市のGDPに貢献する。所得税などの直接税は、付加価値の分配過程で支払われるため二重計上を防ぐ目的で含まれない。

市場価格の概念を持たない財（高圧電力などのインフラ財と公共交通の車両。専用網で金銭のやり取りなしに配送される）の生産は、対価の裏付けがないため付加価値に計上されない。これらを生産・配送するインフラ施設の経済活動は、市予算からの運営費支出（賃金など）としてGDPの他の項目に現れる。

### GDPデフレーター

物価変動の傾向を測定する指標である。国内で生産された商品について「国内平均価格が域外基準価格に対してどれだけ高いか」を、生産量で重み付けして集計したものである。

国内物価が域外基準価格を上回るインフレ局面ではGDPデフレーターは 1.0 を上回り、デフレ局面では 1.0 を下回る。なお、生産が行われなかった場合など、計算に必要なデータが不足している場合はデフレーターの値は未定義（`None`）となる。金融統計（`GET /api/v1/stats/finance`）の物価指数（`price_index`）はこのGDPデフレーターで、未定義のエポックは 1.0 とする。

### 実質GDP

物価変動の影響を除去した実質的な経済規模を表す。

```
実質GDP = 名目GDP / GDPデフレーター
```

GDPデフレーターが未定義（`None`）または 0 以下の場合は、物価変動の調整が行えないため、名目GDPの値をそのまま実質GDPとする。
インフレーションが発生している局面（GDPデフレーター > 1.0）では、実質GDPは名目GDPを下回る。
