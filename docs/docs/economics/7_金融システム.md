# 7. 金融システム

## 7.1. ゼロサム資金循環の原則

経済主体はそれぞれ現金残高（API の `reserves`）を持ち、新しく作られた主体の残高は0から始まる。支払いでは払う側の残高が減り、受け取る側の残高が同じだけ増えるので、全経済主体の残高の合計は変わらない。残高はマイナスになってよく、お金を持たない主体の支払いが借入（信用創造）の役割を果たすので、手元にお金が無くても経済活動は止まらない。

借入には上限がある。民間の建物は、担保価値（建物の残存価値と自己所有する土地の地価）に応じた上限まで借りると修繕が進まなくなる。新しい事業の創業（[2_経済主体](2_経済主体.md)）と民間の建物の新築には1件に貸せる額の上限（与信集中限度）があり、都市の年間の名目GDP（7.4）に比例する。そのため小さな都市には大型の工場や建物の資金が付かず、経済の成長とともに大きな案件が可能になる。着工した工事と解体は、上限に関係なく最後まで進む。

### 主体の清算と中央銀行

閉店や取り壊しで経済主体が削除されるとき、その残高（プラスの資産またはマイナスの負債）は**中央銀行**（`TYPE_CITY`・`VARIANT_CENTRAL_BANK`）がそのまま引き受ける。公共施設の残高は市政府へ移る（[22_予算管理](22_予算管理.md)）。中央銀行は引き受けた残高を何エポックもかけてゼロへ近づけ、マイナスなら民間の経済主体から徴収し、プラスなら払い出す。徴収と払い出しは各主体のそのエポックの収益に比例して割り振るので、大きな破綻が起きても負担が一度に跳ね上がらない。

統計ウィンドウの「金融」タブに表示する中央銀行の残高は、マイナスなら肩代わりしている負債、プラスなら引き受けた資産を表し、徴収額はプラスなら徴収、マイナスなら払い出しである。

清算で所有者を失った土地は中央銀行の所有になり、市有地に民間の建物が着工するときの土地代も中央銀行が受け取る（[12_建物](12_建物.md)）。土地に由来するお金は市の財源にならず、中央銀行を通じて経済全体へ戻る。中央銀行は都市の作成時に作られて削除できず、所在は市庁舎への入居として表す（床は使わず、家賃も払わない）。

## 7.2. 貿易とお金の出入り

都市は外国と同じ通貨を使う一地域で、外国の価格（域外価格。ゲーム中は変わらない）で取引する価格受容者である（[8_商品市場](8_商品市場.md) 8.5）。輸出入拠点（`TYPE_TRADE`）の残高は外国との間の台帳で、都市の中のお金に数えない。輸入代金（関税を除く）は都市から出ていき、輸出代金は都市に入る。

貿易統計の輸出入額はエポックごとの額で、観光客が持ち込む旅費は輸出に、帰国時に持ち帰る残金は輸入に含む（[31_観光](31_観光.md)）。貿易収支がプラスなら都市の中のお金が増え、マイナスなら減り、赤字で出ていったお金を中央銀行や市政府が埋め合わせることはない。

## 7.3. 通貨の総量

支払い・清算・中央銀行の平準化は、いずれも残高の合計を変えない。輸出入拠点を除いた都市の中のお金が増減するのは、貿易収支（7.2）と、対価のない通貨創造である達成クエストの交付金（[24_達成クエスト](24_達成クエスト.md)）だけである。

## 7.4. 国内総生産（GDP）

金融統計の名目GDP（`gdp`）は、稼働中の経済主体がそのエポックに生んだ付加価値の合計に、間接税（消費税と輸入関税）を加えたものである。付加価値は、民間の一般施設では生産額から原材料費と借りている床の家賃を引いた額、共有建物では受け取った家賃、公共施設では払った人件費である。市場で売買されないインフラ財と公共交通の車両は生産額を数えず、それらを作る公共施設の人件費として入る。

物価指数（`price_index`）はGDPデフレーターで、国内で生産された商品の国内平均価格が域外価格に対してどれだけ高いかを、生産量で重み付けした比である（計算できないエポックは1.0）。実質GDP（`real_gdp`）は、名目GDPを物価指数で割った値である。
