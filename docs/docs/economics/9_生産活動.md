# 9. 生産活動

## 9.1. 生産の流れ

一般施設（`TYPE_STANDARD`）は、エポックの終わりに次のエポックの計画（生産目標・原材料の発注・雇用枠・売値）を立て、次のエポックの商品市場で原材料を調達してから生産する。生産量は、生産目標と、床面積で決まる生産能力・雇っている従業員の実質労働力（[16_労働市場](16_労働市場.md)）・手元の原材料のうち、最も小さい量で決まる。実質労働力は都市政策の所定労働時間（`work_hours`）に比例し、8時間を基準とする。インフラ財（[26_インフラ網](26_インフラ網.md)）を供給する施設だけは、配送の直前に、配った結果に合わせて生産する。

生産目標は需要に追従し、売れ残りが多ければ減らし、売り逃した量だけ増やす。貿易可能財を輸出で売り切る施設は、床の能力まで一段ずつ増産する。高度人材が必要な業種は、必要な数がそろうまで生産しない。

稼働率（`utilization`）は、実際の生産量を生産能力（床の制約が無い施設では生産目標）で割った値（0〜1）である。作った商品は在庫として持ち越すが、生産能力の一定倍を超える在庫は廃棄する。利益率（`profit_rates`）は、設備投資の支出を差し引く前の利益を売上で割った値で、±100%の範囲に収め、売上が無く支出だけのエポックは−100%になる。赤字が続く施設は市場から退出する（[2_経済主体](2_経済主体.md)）。

## 9.2. 公共施設の運転方式

施設マスターの余力倍率（`production_headroom`）は公共施設の生産目標の決め方を表し、0なら民間施設と同じく需要に追従する。正の値は直近の需要に余力倍率を掛けて生産する余力運転で（1を超えるぶんが待機の余力）、電力・水道のように需要が安定したインフラに使う。負の値は生産能力いっぱいを常に生産する定量運転で、消防・警察のように平時の需要がほとんど無く、有事に急増するサービスに使う。

余力運転・定量運転の施設は、施設ごとの稼働率目標（`utilization_target`）で生産量を調整でき、余力運転の施設にはカテゴリ別の予算比率（[22_予算管理](22_予算管理.md)）も乗率として働く。

## 9.3. 売値

売値（`supply_price`）は「原価 × (1 + 利幅)」で決まる。原価は生産1単位にかかる原材料費・人件費・家賃で、教育で生産性が上がったり設備が充実したりすると下がる。利幅は販売実績に応じて上下限の範囲を動き、売れ残りが多ければ下がり、品不足や費用割れでは上がる。上限で止まった後の品不足は、店舗の増床や新規参入を呼ぶ。インフラ財と公共交通車両を供給する施設の売値は、原価に固定される。

### 公共サービスの価格

マスターの `public_service` が真の製品（医療・水道・電力・通信・消防など）の売値は、市長（プレイヤー）が「固定価格」か「原価比率」（施設の製造原価 × 比率。1.0で収支が釣り合う）で決める。`regulated` は民間の参入を禁じる別の性質で、公共サービス以外の製品にも付く。都市の作成時は製造原価の見積もり（域外価格）の固定価格で始まり、消防・治安維持・医療・下水処理・廃棄物処理などは無償（0円）で始まる。0円のサービスは世帯の予算を使わないので、届く範囲の世帯は所得に関係なく必要な量まで受ける。固定価格は原価が変わっても動かず、原価との差は市政府の損益になる。価格の変更は、エポックを進めなくてもすぐに売値と製造原価に反映される。公共交通の車両リースは路線にとっての原価なので、原価比率1.0で車両基地の原価に従う（[6_公共交通機関](6_公共交通機関.md)）。

## 9.4. 立地・設備・気候の効果

`attraction` は、立地倍率（交通量・集積）と長期稼働のボーナス（知名度）からなる「顧客から見た施設の魅力」で、工業原料を作る施設では生産量に掛かり、小売財を作る施設では市場での選ばれやすさに効く（[8_商品市場](8_商品市場.md)）。施設は業種ごとの投資財（施設マスターの `investments`。機械やソフトウェア、業種に対応するオフィスの本社機能など）を設備として積み上げ、生産の効率を上げる（工業原料を作る施設では生産量が増え、それ以外では同じ人数で多く捌ける）。設備は目減りし、効果は次第に小さくなる。設備は顧客の店選びには関係しない。新しく開業する施設は、同じ地区・同じ業種の平均的な設備水準を引き継ぐ。

### 気候による生産変動

太陽光発電・風力発電・農業など気候に依存する施設は、日照・気温・降水・風速によって生産量が変わる。これらの値はエポックの初めに都市全体で1組だけ決まり（気温・日照・降水は[気候設定](../programs/気候設定.md)のその月の平均に、風速は共通の平均に揺らぎを加える）、そのエポックの間は変わらない。

施設ごとに最大出力に必要な日照・降水・風速と、適温の範囲が決まっていて、それに足りない（風速の不足は3乗で効く）か適温から外れるほど出力が下がる。要素ごとの倍率は0〜1で、その積が施設の気候による生産倍率である。気候は収量だけを変え、原材料不足・労働力不足や生産能力とは別に扱う。区画ごとの影や、Unity が描画している天気・時刻は使わない。
