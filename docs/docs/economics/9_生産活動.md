# 9. 生産活動
## 9.1. 生産活動の概要

一般施設（`TYPE_STANDARD`）は、1エポックの中で「生産計画の策定」「原材料の調達」「生産の実行」という一連のプロセスを経て商品を生産する。
生産量は主にスペース・労働力・原材料の3つの制約によって上限が決まる。

## 9.2. 生産計画の策定

各一般施設は、エポックの冒頭で次の生産目標（`supply_target_amount`）を決定する。
生産目標は市場の需要動向に基づいて自動調整される。

### 販売率に基づく目標調整

直近エポックの販売率（`sold_rate` = 売上量 / 生産量）を計算し、目標販売率と比較する。
- 販売率が目標販売率を大きく上回り、実質的な品切れ（売り逃し）が起きている場合、売り逃した量に応じて次エポックの生産目標を増やす。
- 販売率が目標販売率を下回る場合、次エポックの生産目標を減らす。
- それ以外（目標販売率は満たしているが品切れではない）の場合は現状の水準を維持する。増産幅を実際の売り逃し量に比例させることで、生産と雇用が需給の小さな揺らぎに過敏に反応して振動しないようにしている。

過剰な需要予測による目標の極端な変動を防ぐため、原材料不足による上限抑制、在庫量に基づく生産抑制、最低生産下限（フロア）の設定などが適用される。

### 公共施設の余力運転（production_headroom）

消防署や発電所のような定常型の公共施設も、民間施設と同じく需要に追従して生産量を決める。ただし、これらの施設はマスターデータの **余力倍率（`production_headroom`）** に基づき、「過去一定期間の平均需要 × 余力倍率」を生産目標とする。

- 倍率が 1 を超えるぶんが待機余力になる。需要が安定しているインフラ施設は小さめの倍率で運転し、消防のように平時の需要が細く有事に急増するサービスは大きな倍率で常に余力を確保する。
- 需要が減ればそれに応じて生産・雇用・原材料調達も縮小するため、需要と無関係に一定量を生産し続けることはない。
- 施設ごとの稼働率目標（`utilization_target`）は、この余力込みの生産目標に対する乗率としてそのまま機能する。カテゴリ別の予算比率も余力運転する施設には乗率として働き、100% 超に設定すると標準余力の上にさらに待機生産を上乗せできる（[[22_予算管理]]参照）。

### 供給価格の決定

供給価格（`supply_price`）は、生産コストの床に基づいて設定される。
コストの内訳は原材料費、人件費、家賃の3つである。これらを合計したコストを下限として供給価格が決定される。

### 公共サービスの価格統制（regulated 製品）

医療・水道・電力・通信・消防といった「価格統制対象（regulated）」の製品は、民間企業ではなく公共施設だけが供給する。これらの製品には市場の需給による自動的な価格変動を適用せず、プレイヤーが選んだ価格方式で統制される。価格方式は次の2種類である。

- **固定価格**: プレイヤーが指定した金額を供給価格とする。原価を下回る価格（赤字覚悟の政策料金）も設定できる。
- **原価比率**: 供給価格を「製造原価 × プレイヤー指定の比率」とする。比率1.0で原価ちょうど（収支トントン）、比率を上げれば利幅を確保し、下げれば赤字補填が必要になる。施設ごとにコスト構造が違っても、同じ比率なら都市全体で同じ利幅方針を適用できる。

## 9.3. 生産の実行

商品市場で原材料の調達が完了した後、各施設の実際の生産が実行される。

### 生産量の決定

生産量は、スペース・労働力・原材料の3つの制約と生産目標のうち最も小さい値として決まる。

- **スペース制約**: 施設の生産能力（`production_capacity`）による上限
- **労働力制約**: 雇用している労働力と、variant ごとの1単位あたり必要労働力（`labor_need`）から算出される上限
- **原材料制約**: 市場で調達した原材料の量と、1単位あたりの原材料所要量から算出される上限

### 立地倍率とattractionの影響

`attraction` は「顧客から見た施設の魅力」を表す倍率であり、立地倍率（交通量・集積効果）と長期稼働ボーナス（知名度）から決まる。設備の充実度は顧客の店選びには関係しないため `attraction` には含まれない（設備の効果は後述の設備効率を参照）。

`attraction` の効き方は、商品の種類によって異なる。

- **工業原料（`GOODS_MATERIAL`）を生産する施設**: `attraction` が生産量に乗算される。原材料消費はベース生産量に基づくため、立地の良い工場は原材料効率が良い。
- **小売財（`GOODS_RETAIL`）を生産する施設**: `attraction` は生産量そのものには影響せず、商品市場での評価に影響する（[[8_商品市場]]を参照）。

### 長期稼働ボーナス（longrun_boost）

施設が長期間稼働し続けると、`longrun_boost` により `attraction` が増加する。ボーナスは徐々に頭打ちになり、無限には増えない。これにより、新規開業した施設よりも長く営業している施設の方が、生産効率または販売力が高くなる。

### 設備効率（investment_boost）

各 variant は投資財（`investments`）を定義できる。設備投資の効果は単一エポックで消滅せず、店舗ごとに蓄積される「設備値（資本ストック）」として維持される。

- 設備値は毎エポック調達された投資財量だけ積み上がり、同時に減価償却（目減り）が進む
- 投資を重ねるほど生産効率は向上するが、追加投資の効果は徐々に小さくなる（収穫逓減）
- 設備充足率の評価には持続可能な上限があり、生産目標が一時的に小さくなっても効率が無制限に高く評価されることはない
- 各施設が設備投資に回す予算は、その施設の利益や資金の余裕に応じて自動的に決まる

設備効率は生産側にのみ働き、顧客の店選び（商品市場での評価）には影響しない。効き方は業種によって異なる。

- **工業原料を生産する施設**: 生産量が増幅される（同じ原材料からより多くの製品を生産できる）
- **それ以外の施設（小売店など）**: 労働効率が向上する（同じ従業員数でより多くの商品を捌ける）

設備値は過去の蓄積であるため、それを全く持たずに新規開業する施設は既存の施設に対して不利になる。これを避けるため、新規にスポーンする施設には、同じ地区で同じ業種を営む既存施設の平均的な設備水準を「過去の蓄積」として引き継がせる。これにより、新規開業した施設も創業時の規模に見合った設備充足率からスタートでき、地区に長く根付いた業種であるほど新規参入者も相応の効率で操業を始められる。

## 9.4. 稼働率と在庫管理

### 稼働率

各エポックで実際の生産量を生産能力または生産目標で割った値が**稼働率**（`utilization`）として記録される。
稼働率は 0.0 ～ 1.0 の範囲にクリップされ、時系列データとして蓄積される。

### 在庫制限

生産された商品は在庫として蓄積されるが、生産能力の `STORAGE_RATIO` 倍を超える在庫は廃棄される。
これにより、無制限な在庫の蓄積を防ぐ。

### 生産目標と在庫の関係

生産目標は需要追従型で決まる。施設は「次のエポックでどれだけ売れるか」を見積もり、その量から手元の在庫を引いた分だけを新たに生産する。在庫が十分にあれば新たに作る必要はなく、在庫が少なければ需要分だけ作る。この仕組みにより、在庫レベルに応じて生産量が自然に調整される。ただし、目標販売率のもとで計画どおりに残る想定内の売れ残り分は差し引かず、それを超える過剰在庫だけを差し引く。想定内の在庫まで毎回差し引くと、わずかな売れ残りのたびに生産と雇用が急減し、供給不足と増産を繰り返す振動が起きてしまうためである。

需要が生産能力を恒常的に下回る場合（例えば輸出需要が減少した場合）、施設は需要に合わせて生産を絞る。生産能力に余裕ができても無理に生産はせず、需要が回復すれば再び生産を増やす。需要が長期間回復しない施設は赤字が続き、最終的に市場から退出する。

### 需要の平準化（在庫バッファ）

「建設サービス」のように需要の変動が大きい財では、各エポックで必要な分だけを生産しようとすると、生産量が乱高下してしまう。需要が急増したエポックでは増産が間に合わず、需要が消えたエポックでは過剰生産になり、施設は増産と撤退を繰り返してしまう。

これを避けるため、施設は **過去一定期間に自分が直面した需要（実際に売れた量＋供給不足で売り逃した量）の平均** を生産目標の基準にできる。平均需要を満たし続けることで、需要が薄いエポックには在庫が積み上がり、需要スパイク時にはその在庫が取り崩されて需要を吸収する。すなわち在庫がバッファとして機能し、生産量の振れ幅が小さくなる。

この平準化を何日分の需要で行うか（平準化期間）は、経済主体のサブカテゴリ（variant）ごとにマスターデータで定義される。**既定値は「平準化なし」**であり、その場合は従来どおり直近エポックの実績に基づいて生産目標が決まる。需要変動の大きい財を生産する variant にのみ平準化期間を設定する。

なお、積み上がる在庫は前述の在庫制限（生産能力の `STORAGE_RATIO` 倍）を上限とするため、平準化によって在庫が無制限に膨らむことはない。

### コストの記録

生産に伴うコストは以下の項目ごとに記録される。

- `supply_raw_cost` ... 原材料費
- `supply_labor_cost` ... 人件費
- `supply_space_cost` ... 家賃（専用建物の場合は地区平均家賃を想定家賃として計上）
- `supply_total_cost` ... 上記3つの合計

これらのコスト情報は、次エポックの供給価格の決定や施設の存続判断に利用される。

## 所定労働時間

都市政策work_hoursに応じて、スキル由来の実質労働力を固定基準8時間に対する比率で換算する。生産計画・労働マッチング・実際の生産は同じ労働単位を使う。労働時間による効率の逓減はなく、設備・原料の制約は引き続き適用する。
