# 6. 公共交通機関

## 6.1. 公共交通とは

公共交通は、自動車を保有しない世帯が、徒歩と組み合わせて通勤・通学・買い物に使う移動手段である。路線バス・メトロ・LRT・モノレール・中距離鉄道があり、車両は道路や線路の上を走る。

| 要素 | 役割 |
| --- | --- |
| 停留所 | 乗客が乗り降りする地点 |
| 経由点 | 停車せずに通る地点。路線の経路を指定する |
| 区間パス | 隣り合う停留所を結ぶ運行区間(`PATH_TRANSPORT`) |
| 路線 | 車両を借り、運賃を受け取る経済主体 |
| 駅 | 鉄道系の停留所を置くホームを持つパス |
| 車両基地 | 車両を路線に貸し出す公共施設 |

ロープウェイのように路線の運営を伴わない設備は、[人員搬送設備](30_人員搬送設備.md)として扱う。

## 6.2. 路線と交通網

路線は、停留所と経由点を順に巡る経路を持つ。往復運行も、行きと帰りの停留所を巡って元に戻る1周として表す。住民は徒歩・乗車・乗り換えを組み合わせ、移動時間や待ち時間、運賃の負担から行き方を選ぶ。

路線の運行区間と、その下にある道路・線路は別のものである。道路や線路が失われても別の経路があれば迂回できるが、停留所の間を走れなくなると路線全体が運休する。鉄道には線路の向きや折り返しの制約もある。

駅はホームと駅舎からなり、駅舎が複数のホームと出入口をまとめる。詳しくは[駅と駅舎](29_駅と駅舎.md)を参照。

## 6.3. 車両と運行能力

車両は車両基地から路線へ貸し出される。車両基地には人手や原材料が必要で、基地と路線が道路・線路でつながっていることも必要になる。車両基地の供給力が、都市で運行できる車両数を支える。

プレイヤーは路線の運行間隔と編成の両数を決める。必要な車両がそろわなければ減便となり、運行できる編成がなければ運休する。長い編成には、それを収められるホームが必要である。

乗客に対して輸送力が不足すると混雑し、移動の負担が増える。また、複数の路線は道路や線路の容量を共有するため、車両を増やすだけでは輸送力を伸ばせない。バスや街路を走るLRTは、一般車の渋滞にも影響される。

## 6.4. 運賃と運営

運賃は路線ごとに設定する均一運賃で、乗り換えでは別の乗車になる。運賃や待ち時間が大きい路線は利用されにくくなる。

路線は運賃を受け取り、車両基地へリース料を払う。路線と車両基地はどちらも公共施設で、収支は市政府の財政に含まれる。公共交通の予算が不足すれば、車両基地の運営や路線の便数にも影響する([予算管理](22_予算管理.md))。

## 6.5. シミュレーションと走行描画

公共交通は、経済シミュレーションと3Dの走行描画で共通の経路・所要時間を使う。運行能力や乗車時間と、画面上で走る車両の動きは、この共通の情報に基づく。詳しくは[交通シミュレーションと走行描画の整合](../geometries/T_交通シミュレーションと走行描画の整合.md)を参照。

貨物列車も路線と車両基地の仕組みを使い、旅客列車と線路を共有する。貨物の積み下ろしや輸出入については[貨物輸送](33_貨物輸送.md)を参照。
