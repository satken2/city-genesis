# 28. 自然発生スプロール

都市の建設需要が満たされないまま放置されたとき、市政府の計画とは無関係に道路と土地区画が自然発生し、街が無計画に拡大していく仕組み（スラム化）について。

## 28.1. 概念

このゲームでは通常、プレイヤー（市政府）が道路を敷き、土地区画を整備して初めて民間の建物が建つ（[3_道路網](3_道路網.md)・[4_地区と土地区画](4_地区と土地区画.md)・[12_建物](12_建物.md)）。しかし現実の都市では、住宅需要があるのに正規の宅地供給が追いつかない場合、人々は勝手に道を切り開き、非公式に住み着いていく。

自然発生スプロールはこれを再現するもので、**民間のフロア建設需要が残っているにもかかわらず、その地区に建設可能な空き土地区画が不足している**状態が深刻かつ持続的で、しかも未充足の需要のなかに正規の家賃を負担できない低所得層が含まれる場合に、エポック実行中に未舗装路と小さな土地区画が自然発生する。

- プレイヤーが道路と土地区画を計画的に整備していれば発生しない。整備された都市の端に恒常的にスラムが生えることはなく、一時的・わずかな区画不足では発生しない。
- 資金不足や放置によって宅地整備が需要に追いつかず、その状態が続くと、既存市街の縁からスラム的な路地網が広がっていく。

この挙動は都市パラメータ `SPRAWL_ENABLED`（既定: 有効）で無効化できる。

## 28.2. 発生条件

発生には次の3条件がすべて揃う必要がある。

1. **有意な土地区画の不足。** 地区ごとのフロア建設需要（[13_不動産市場](13_不動産市場.md)・[12_建物](12_建物.md)）のうち、そのエポックの建物スポーンで消化されずに残った量が、地区内の空き土地区画（建物が利用しておらず、横断パスもない通常区画）で供給できる床面積の見込みを、**地区の需要規模に対して有意な割合で**上回っていること。定常的な発展に伴うわずかな不足では発生しない。
2. **不足の持続。** 有意な不足が**一定のエポック数連続**していること。一時的な需要の波が通り過ぎるだけでは発生せず、正規の宅地供給が構造的に失敗し続けている地区でのみ条件が満たされる。
3. **低所得層の存在。** 未充足の住宅需要のなかに、**正規開発の家賃を負担できない低所得の世帯**（一人あたりの所得に対して必要な床面積が大きい多子世帯・単親世帯など）が含まれていること。未充足の需要があってもその全員が正規開発の家賃を払えるなら、それは通常の建設需要として市場に残り続けるだけで、スラム化はしない。

「区画はあるが採算が合わずに建物が建たない」というケースは対象外である。それは経済的な問題であり、物理的に建てる場所が無いこととは区別される。

## 28.3. 自然発生する道路の性質

スプロールで生まれる道路は、街路カテゴリの**未舗装路**バリアント（住民が勝手に踏み固めた道）である。通常の道路と異なり、以下の特別な性質を持つ。

- **最初から完成状態（`STATUS_ACTIVE`）で出現する。** 計画（`STATUS_SCHEDULED_CONSTRUCTION`）→用地取得→建設（`STATUS_CONSTRUCTING`）というパスの建設ライフサイクル（[3_道路網](3_道路網.md)）を経ず、建設サービス財の調達も建設コストの支払いも一切発生しない。
- **物理的な整合は通常の道路と同じ。** 出現時に地形の平坦化（盛土・切土）が行われ、既存道路との交差点にはノードが生成され、交通ネットワークに組み込まれる。所属地区は分岐元の道路の地区を引き継ぐ。
- **既存の資産は一切侵食しない。** 通常の道路建設が持つ買収プロセスを持たないため、既存の土地区画（市有の空き区画を含む）や計画中のパスの上には発生しない。既存の道路に重なって伸びることもない（直角に近い角度で横断することはあり、その場合は交差点が生成される）。急斜面・水面も避ける。ただし既存道路の先端から伸びる場合に限り、その道路の路肩に接する土地区画とごくわずかに重なることはある（買収も削り取りも行われず、区画はそのまま存続する）。

出現後は通常の道路として扱われる。プレイヤーは造り替え（[3_道路網](3_道路網.md)のバリアント変更）で舗装された街路へアップグレードすることも、取り壊すこともできる。ただし造り替えの拡幅は周囲の区画との重複チェックを受けるため、区画が密集したスラムの道路拡張には買収が必要になることが多い。

## 28.4. 拡大のパターン

スプロールは**すでにスラム化した場所から伝染的に拡大**する。新しい路地の起点は優先度順に選ばれる。

1. **既存の未舗装路の先端。** スラムのフロンティアが奥へ奥へと伸びていく（最優先）。
2. **既存の街路上の任意の地点からの分岐。** 地区内にまだ未舗装路が無い場合に、最初のスラムが生まれる入口。
3. **道路網の先端からの外向き延長。** 沿道が土地区画で埋まっていて分岐する余地がない場合、既存道路の先から外側へ向かってそのまま路地が伸びていく。
4. **既存の市街から少し離れた空き地。** 沿道も道路の先端もすべて塞がっている場合の最終手段で、道路網から切り離された飛び地のスラムが発生する。飛び地の路地が後に既存道路と交差すれば、そこで道路網に接続される。

ここでいう**「先端」は行き止まりに限らない**。道路の端点のうち、その先に道が続いていない向き（十字路やT字路の直進方向のように既に道が伸びている向きは除く）はすべて先端として扱われ、市街の外周にある曲がり角からも路地が外へ伸びる。碁盤の目状に整備された街には行き止まりが1つも存在しないため、行き止まりだけを起点にすると飛び地のスラムばかりが生まれてしまう。

1エポックに伸びる路地の本数は、**低所得層の未充足需要量**が大きい地区ほど多くなる（上限あり）。需要が満たされるか、低所得層の困窮が解消されれば拡大は自然に止まる。

## 28.5. 自然発生する土地区画

新しい未舗装路の沿道には、間口・奥行きの小さな土地区画が自動生成される。

- 所有者は市政府だが、地価（`land_price`）は 0 から始まる。これは正規の土地取引を経ていない非公式な占有（スクワッティング）の表現である。以降の地価はエポックごとの評価（[4_地区と土地区画](4_地区と土地区画.md)）で通常どおり更新される。
- 所属地区は接道（`front_path_id`）を通じて未舗装路の地区を引き継ぐ。
- 生成された区画はその後、通常の建物スポーン（[12_建物](12_建物.md)・[13_不動産市場](13_不動産市場.md)）の対象となる。スラム区画は推定家賃が低いため、安価で短命な建物が選ばれやすい。

つまり、スプロールが供給するのは「道と土地」だけであり、建物そのものは通常の経済シミュレーションの帰結として建つ。建設業が存在しない都市では、道と区画だけが生えて建物が建たないこともありうる。
