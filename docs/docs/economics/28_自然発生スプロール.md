# 28. 自然発生スプロール

道路と土地区画の整備が住宅の需要に追いつかない状態が続くと、市の計画とは無関係に未舗装の路地と小さな土地区画とスラムの建物が生まれ、街が無計画に広がっていく(スラム化)。プレイヤーが道路と区画を計画的に整備していれば起きない。

## 28.1. 発生する条件

スプロールは、エポックの実行中に次の3つがそろった地区で起きる。

- 住まいの需要が残っているのに、地区の空き区画では住まいの床が大きく足りない。
- その不足が何エポックも続いている。
- 住まいを探す世帯の中に、正規の家賃を払えない世帯(仕事の無い世帯や、収入に比べて広い床が要る多子・単親の世帯)がいる。

区画はあるのに採算が合わずに建物が建たない場合は対象外である。路地の本数は低所得の世帯の住宅不足が大きい地区ほど多く、需要が満たされるか困窮が解消されれば拡大は止まる。スプロールは都市パラメータで無効にできる。

## 28.2. 生まれる路地と区画と建物

路地は街路の未舗装路で、計画・用地取得・建設の段階を経ず、建設費もかからずに最初から稼働中(`STATUS_ACTIVE`)で現れる。地形の平坦化と交差点の生成は通常の道路と同じように行われる。路地は既存の道路網につながる場所からだけ伸び、すでにスラムになった未舗装路の先端や沿道の隙間から広がる。そうした場所が無ければほかの街路の沿道から分岐し、沿道が区画で埋まっていれば道路網の端から外へ延びる。既存の土地区画・計画中のパス・急斜面・水面の上には伸びない。

路地の両側には小さな土地区画ができる。正規の取引を経ていない占拠なので地価は0から始まる。所属地区は路地の地区を引き継ぎ、沿道には路地がさらに横へ分岐するための隙間を残す。

区画にはそれぞれスラムの建物(マスターの `sprawl_only` が立ったバリアント)が同時に建ち、区画の所有者になる。建物も路地と同じく建設の段階を経ずに最初から稼働中で現れ、用途・容積率・高さの規制を受けない。スラムの建物は通常の建物のスポーンでは建たず、通常プレイの建設パネルにも出ない。採算が合えば、通常の建て替えで普通の建物に置き換わる。

生まれた路地・区画・建物は通常のものと同じに扱われ、プレイヤーは路地を舗装路へ造り替えたり取り壊したりできる。
