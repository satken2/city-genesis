# 25. ゲーム内日付

## 25.1. 仮想暦

ゲーム内の暦は、1か月30日・1年12か月360日の仮想暦である。うるう年や月ごとの日数の違いは無い。

API の日付(`current_date`・`created_date`・`status_from` など)は、1800年1月1日を0とする経過日数の整数で表す。経過日数を360で割った商が1800年からの年数、余りを30で割った商が月(0始まり)、30で割った余りが日(0始まり)である。

確率・割引率・耐用年数のように「年あたり」で決めた量を日数に直すときの1年は365日で、暦の1年(360日)とは別である。

## 25.2. エポックと日付の進行

1エポックで進む日数は都市の `simulation_days` で、ゲームの開始設定で7日か30日に決まる。エポックを実行するたびに `current_date` がこの日数だけ進む。

都市の日付は2029年4月1日から始まり、シナリオから始めたゲームは保存された日付から続く。開始日が月初なので、30日のエポックでは日付が月初にそろう。このときに限り、日付を「年月」だけで表示してよい。
