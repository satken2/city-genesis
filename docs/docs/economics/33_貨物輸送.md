# 33. 貨物輸送

## 33.1. 運び方の全体像

都市の原材料や製品は、道路輸送、近接する施設間の構内物流、パイプラインや貨物列車の専用網によって運ばれる。

| 運び方 | 役割 |
| --- | --- |
| トラック | 商品市場の取引に伴って道路で物資を運ぶ |
| 構内物流 | 近接した施設間で、道路を使わず原材料を受け渡す |
| 専用網 | パイプラインや貨物路線で、まとまった量を運ぶ |
| 港・国際貨物駅など | 都市外との輸出入の窓口になる |

商品の数量にはkg・バレル・台など品目ごとの単位があるが、輸送の規模は重さで扱う。道路の混雑、専用網の容量、拠点の取扱能力が物流を制約する。

## 33.2. 構内物流と専用網

近接した施設同士では、配管やコンベアなどによる構内物流を行える。工場・採掘所・港を近くにまとめることで、道路への負荷や輸送の負担を抑えられる。

原油や鉱石の大口輸送には専用網を使う。物資は積み出す施設から網へ入り、降ろす施設から再び商品市場へ供給される。専用網の接続と容量は、[インフラ網](26_インフラ網.md)と共通の考え方である。

## 33.3. 貨物路線と積み下ろし

貨物列車は旅客列車と同じく路線を持ち、車両基地から車両を借りて走る。旅客路線と線路を共有するため、貨物輸送にも線路の容量が必要になる([公共交通機関](6_公共交通機関.md))。

貨物の種類に対応した専用ホームと、積み下ろしを行う施設を組み合わせる。

```mermaid
graph LR
採掘所 -- 鉱石 --> 積込駅 -- 貨物列車 --> 取卸駅 -- 鉱石 --> 製鉄所
```

積込駅や取卸駅は市政府の公共施設であり、都市の産業と長距離の物流をつなぐ役割を持つ。

## 33.4. 国外との輸出入

海路の港、鉄道の国際貨物駅、道路の陸路輸送拠点が、都市外との取引を支える。

国際貨物路線は、シナリオに用意された都市外の国境貨物駅と、都市内の国際貨物駅を結ぶ。輸出入できる規模は、駅の取扱能力と路線の輸送力に左右される。

取引や価格については[商品市場](8_商品市場.md)を参照。
