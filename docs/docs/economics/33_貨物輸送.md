# 33. 貨物輸送

都市の中で物を運ぶ手段と、国外との輸出入の窓口をまとめる。原料や製品は、トラックで道路を走るほか、
隣り合う施設どうしの構内物流、パイプラインや貨物列車の専用網でも運べる。国外との窓口は、海を通じた港と、
陸を通じた国際貨物輸送路線の2つである。

## 33.1. 運び方の全体像

| 運び方 | 運ぶもの | 道路の負荷 | 運べる量を決めるもの |
| --- | --- | --- | --- |
| トラック（商品市場の輸送） | 工業原料・小売財 | あり | 道路の混雑と所要時間 |
| 構内物流 | 区画の隙間が一定距離以下の施設どうしの工業原料 | なし | 制限なし |
| 専用網（パイプライン・貨物路線） | 貨物（パイプライン原油・鉱石(大口輸送)） | なし | パイプラインの容量、貨物路線の輸送能力 |
| 国外との窓口（港・国際貨物駅） | 輸出入する工業原料 | 拠点から先はトラック | 拠点の取扱能力（t） |

## 33.2. 重さの単位

商品は品目ごとの単位（kg・バレル・台など）で数えるが、運ぶ量は重さで比べる。
商品マスターの `transport_amount` が1単位の重さ（kg）で、次の3つはすべてトンで数える。

- **トラックの輸送コスト**: 運ぶ重さと所要時間に比例する（[8_商品市場](8_商品市場.md)）。
- **輸出入拠点の取扱能力**: 床面積あたりの能力 `capacity_per_space`（t/m²/日）× 占有面積。
  自動車1台（1,000kg）は鉱石1kgの千倍、原油1バレル（159kg）は159倍の能力を使う。重さの定義が0の品目も、
  最低限の重さとして数える。
- **貨物路線の輸送能力**: 1両の積載量（t）で決まる（33.5）。

## 33.3. 構内物流

需要者と供給者の土地区画どうしの隙間（最短距離）が一定距離（既定50m）以下なら、工業原料の取引は配管・
コンベア・引き込み線による構内物流になる。所要時間は0で、輸送コストも道路の交通負荷も生じない。
同じ建物に入居するテナントどうしも含む。詳しくは [8_商品市場](8_商品市場.md) 8.3 の輸送コストを参照。

工場・採掘所・港・積み下ろしの施設（33.6）を寄せて置くと、道路を一度も使わずに原料を流せる。
たとえば「採掘所の隣の鉱石積込駅」から「港の隣の鉱石取卸駅」へ鉱石輸送路線で運べば、輸出まで道路を使わない。

## 33.4. 貨物（専用網で運ぶ物）

インフラ財（[26_インフラ網](26_インフラ網.md)）のうち、持ち越し率 `carry_over_rate` が正のものを**貨物**と呼ぶ。
電力や水道がその場で使い切る流れなのに対し、貨物は原油や鉱石といった物そのものを専用網で運んだものである。

| 貨物 | 1単位 | 運ぶ網 |
| --- | --- | --- |
| パイプライン原油 | 原油1バレル（159kg） | 海底石油パイプラインと石油輸送路線（1つの網） |
| 鉱石(大口輸送) | 鉱石1kg | 鉱石輸送路線 |

国際貨物輸送サービスもインフラ財だが、物ではなく国外との輸出入の枠（1単位=1t）で、持ち越さないので貨物ではない（33.7）。

- **持ち越せる。** 網で運びきれなかった積み出し側の在庫も、受け取ったが使いきれなかった受け取り側の在庫も、
  翌エポックへ持ち越す。
- **原価を引き継ぐ。** 網の中の移動に金銭は伴わないが、貨物には積み出し施設の原価（原料の仕入れ値を含む）が
  価格として付く。受け取り側の施設はこの価格を原材料費として自分の供給価格に上乗せするので、
  仕入れ値より安く売り続けることは起きない。
- **増えない。** 貨物を降ろして市場へ出す施設（鉱石取卸駅・石油取卸駅・石油パイプライン受入基地）は、
  立地や設備による生産の増幅（[9_生産活動](9_生産活動.md)）を受けない。運んだ量より多くの物は市場に出ない。
- **相場を作らない。** 貨物を降ろして市場へ出す施設の売値は、港の輸入品と同じく地区の相場（地区平均価格）の
  計算に入らない。売値は積み出し側の原価から決まり、その原価は相場で評価されるため、相場に入れると売値が
  自分自身の原価に跳ね返って上がり続けてしまう。相場は都市内の生産者か、いなければ輸入価格で決まる。

## 33.5. 貨物路線と貨物PF

公共交通マスターの `freight` が真の路線種別は**貨物路線**で、乗客の代わりに貨物を運ぶ（[6_公共交通機関](6_公共交通機関.md) 6.11）。

1編成の車両数（`cars_per_train`）は機関車を含む総両数で、最低2両とする。4両編成は機関車1両と貨車3両で、積載量は貨車3両分。編成長と車両リースは機関車を含む4両分で決まる。機関車の外観は積載量に影響しない。

| 路線種別 | 運ぶもの | 1両の積載量 |
| --- | --- | --- |
| 国際貨物輸送路線 | 国際貨物輸送サービス | 40t |
| 鉱石輸送路線 | 鉱石(大口輸送) | 50t |
| 石油輸送路線 | パイプライン原油 | 40t |

- **輸送能力は重さで決まる。** 1日あたりの輸送能力 = 1日あたりの便数 × 1編成の貨車数 × 貨車1両の積載量（t）。
  この輸送能力が専用網での区間の容量になり、運行本数や編成を増やせば運べる量が増え、運休すると0になる。
  輸送能力は前のエポックの運行実績で決まる。
- **進行方向にだけ運ぶ。** 区間は路線の進行方向にだけ流れ、往復運行の帰りの区間が行きの容量に足されることはない。
- **1本の路線は1品目だけを運ぶ。** 現実の専用貨物列車（コンテナ列車・ホッパ車・タンク車）と同じである。
- **乗客を乗せない。** 運賃収入は無く、車両のリース料は公共交通予算（`LEDGER_TRANSPORT`）の支出として市政府が持つ。
  列車は貨物列車（`VEHICLE_FREIGHT_TRAIN`）として線路の交通量に載り、旅客路線と線路容量を取り合う。

### 貨物PF

貨物路線が停まるのは、貨物専用のホームである**貨物PF**（パスマスターの `freight_platform` が真のバリアント）だけである。
貨物PFは運ぶ品目ごとに3種あり、貨物路線は品目に合った貨物PFにだけ停まる。

| 貨物PF | バリアント | 停まる路線 |
| --- | --- | --- |
| コンテナ貨物PF | 463 | 国際貨物輸送路線 |
| 鉱石貨物PF | 464 | 鉱石輸送路線 |
| 石油貨物PF | 465 | 石油輸送路線 |

- 旅客路線とほかの品目の貨物路線は停まれないが、通過はできる。
- 乗客が乗り降りしないので駅舎（[29_駅と駅舎](29_駅と駅舎.md)）に所属せず、駅舎が無くても警告は出ない。
- ホームとしての形（敷地の張り出し）と、止まる列車だけがホームの上を向きによらず走れる（そこで折り返せる）規則は旅客のホームと同じである。

## 33.6. 積み下ろしの施設

貨物を網へ積む施設と網から降ろす施設は、市政府が建てる公共施設である。線路の上ではなく、品目に合った貨物PFの
隣に建つ普通の建物で、売買は商品市場、貨物の授受は専用網で行う。

```mermaid
graph LR
採掘所 -- 鉱石(トラックまたは構内物流) --> 鉱石積込駅 -- 鉱石(大口輸送)/鉱石輸送路線 --> 鉱石取卸駅 -- 鉱石(トラックまたは構内物流) --> 製鉄所
```

| 施設 | 仕入れ | 供給 |
| --- | --- | --- |
| 鉱石積込駅 | 鉱石（商品市場） | 鉱石(大口輸送)（専用網） |
| 鉱石取卸駅 | 鉱石(大口輸送)（専用網） | 鉱石（商品市場） |
| 石油積込駅 | 原油（商品市場） | パイプライン原油（専用網） |
| 石油取卸駅 | パイプライン原油（専用網） | 原油（商品市場） |
| 国境貨物駅 | なし | 国際貨物輸送サービス（専用網。33.7） |
| 国際貨物駅 | 国際貨物輸送サービス（専用網） | 国外との輸出入（33.7） |

- **路線とは近さでつながる。** 施設の区画から一定距離（既定50m）以内に停留所がある貨物路線は、その施設とつながる。
  つながり方は容量に制限の無い構内の引き込み線と同じで、線路を施設へ引き込む必要はない。
  複数の路線が同じ施設につながれば、施設を経由して路線から路線へ積み替えられる。
  インフラ網の未接続アラート（[26_インフラ網](26_インフラ網.md) 26.5）もこのつながりで判定する。
- **パイプラインと同じ網になる。** 石油積込駅・石油取卸駅の接続端子にはパイプラインも接続でき、
  洋上石油プラットフォームが流したパイプライン原油も石油輸送路線で運べる。
- **量は下流から決まる。** 取卸駅の売れ行きに合わせて取卸駅が網に求める量が決まり、積込駅は届けた量と
  届けきれなかった量に合わせて生産と原料の買い付けを決める。
- **お金の流れ。** 積込駅の原料の購入費・人件費・電気代は市の予算から出て、取卸駅の売上が収入になる。
  網の中の移動には代金のやり取りが無い（原価の引き継ぎは33.4）。

## 33.7. 国際貨物

国外との輸出入の窓口は、海を通じた港、陸を通じた国際貨物輸送路線、道路の国境を通じた陸路輸送（[8_商品市場](8_商品市場.md) 8.5）の3つで、
互いにつながらない。港と陸路輸送の取扱能力は床面積だけで決まる（港は33.2）。

- **国境貨物駅が枠を出す。** 国境貨物駅は、国際貨物輸送サービス（国外との輸出入の枠。1単位=1t）を供給する公共施設である。
  シナリオの作者がテンプレートモードで、マップの外（都市外地区）のコンテナ貨物PFの隣に置く。プレイヤーは建てられず、
  編集・削除もできない（[地形形状](../geometries/D_地形形状.md)「都市外の背景地形」）。職員も電力も要らず、
  供給できる量は床面積で決まる。ほかの積み下ろしの施設と同じく、近くの停留所で国際貨物輸送路線とつながる。
- **国際貨物駅は受け取った枠の分だけ輸出入する。** 国際貨物駅は港と同じ輸出入拠点（`TYPE_TRADE`）で、都市のコンテナ貨物PFの隣に建てる。
  国際貨物輸送サービスを原材料に持ち、1t 取り扱うのに1t を使う。取扱能力は、床面積で決まる能力と、
  そのエポックに受け取った国際貨物輸送サービスで取り扱える量の小さい方である。
  列車は往復するので、運んできた枠と同じ量を帰りに積めるものとし、輸入と輸出がそれぞれこの量を使える。
  1つの駅で輸入も輸出もできる。
- **開業までの時間。** 路線を開設したエポックに輸送能力が決まり、次のエポックに枠が届いて取扱量が計画され、
  3エポック目から輸出入が始まる。

輸出入拠点の荷役情報（`GET /api/v1/agents/{agent_id}/cargo`）は、次の値を返す。

| プロパティ | 内容 |
| --- | --- |
| `capacity_per_epoch` | 方向別の取扱能力（t/エポック）。原材料を持つ拠点は面積の能力と受け取った原材料の分の小さい方 |
| `area_capacity_per_epoch` | 床面積だけで決まる取扱能力（t/エポック） |
| `material_capacity_per_epoch` | 受け取った原材料で取り扱える量（t/エポック）。原材料を持たない港などは `null` |
| `import_handled_tons` / `export_handled_tons` | 方向別の取扱実績の合計（t） |

## 33.8. マスターデータ

| マスター | キー | 意味 |
| --- | --- | --- |
| 商品マスター | `transport_amount` | 1単位の重さ（kg） |
| 商品マスター | `carry_over_rate` | 持ち越し率。インフラ財で正なら貨物 |
| パスマスター | `infra_products` | パスが運ぶインフラ財。貨物路線の区間パス（1006〜1008）はそれぞれ1品目 |
| パスマスター | `freight_platform` | 貨物PF（貨物路線だけが停まるホーム。コンテナ463・鉱石464・石油465） |
| 公共交通マスター | `freight` | 貨物路線かどうか |
| 公共交通マスター | `vehicle_capacity` | 貨物路線では1両の積載量（t） |
| 経済主体マスター | `capacity_per_space` | 輸出入拠点の床面積あたりの取扱能力（t/m²/日） |
| 経済主体マスター | `materials` | 輸出入拠点では1t 取り扱うのに要る原材料（国際貨物駅は国際貨物輸送サービス1.0） |
| 経済主体マスター | `template_only` | テンプレートモードでだけ置ける施設（国境貨物駅） |
| 一般パラメータ | `ADJACENT_LOGISTICS_GAP_M` | 構内物流と、施設と貨物路線の停留所を結ぶ距離（既定50m） |
