# 33. 貨物輸送

都市の中で物を運ぶ手段と、陸を通じた国外との輸出入の窓口について。原料や製品は、トラックで道路を走るほか、隣り合う施設どうしの構内物流や、パイプライン・貨物列車の専用網でも運べる。

## 33.1. 運び方の全体像

| 運び方 | 運ぶもの | 道路の負荷 | 運べる量を決めるもの |
| --- | --- | --- | --- |
| トラック（商品市場の輸送） | 工業原料・小売財 | あり | 道路の混雑と所要時間 |
| 構内物流 | 区画が近接する施設どうしの工業原料 | なし | 制限なし |
| 専用網（パイプライン・貨物路線） | 貨物（33.4） | なし | パイプラインの容量、貨物路線の輸送能力 |
| 国外との窓口（港・国際貨物駅など） | 輸出入する工業原料 | 拠点から先はトラック | 拠点の取扱能力（t） |

## 33.2. 重さの単位

商品は品目ごとの単位（kg・バレル・台など）で数えるが、運ぶ量は重さで比べる。1単位の重さは商品マスターの `transport_amount`（kg）で、トラックの輸送コストと台数、輸出入拠点の取扱能力、貨物路線の輸送能力、外国との運賃は、どれもこの重さで数える（[8_商品市場](8_商品市場.md)）。

## 33.3. 構内物流

需要者と供給者の土地区画どうしが近接していれば、工業原料の取引は配管・コンベア・引き込み線による構内物流になり、所要時間・輸送コスト・道路の負荷が生じない（[8_商品市場](8_商品市場.md)）。工場・採掘所・港・積み下ろしの施設（33.6）を寄せて置けば、道路を使わずに原料を流せる。

## 33.4. 貨物（専用網で運ぶ物）

インフラ財（[26_インフラ網](26_インフラ網.md)）のうち、パイプライン原油や鉱石(大口輸送)のような物そのものを専用網で運ぶものを貨物と呼ぶ。パイプライン原油は海底石油パイプラインと石油輸送路線（1つの網）で、鉱石(大口輸送)は鉱石輸送路線で運ぶ。電力や水道がその場で使い切る流れなのに対し、貨物は運んだ先で工業原料として商品市場へ出る。

積み出し側は網で運べた分だけを貨物にし、運べなかった分は原料のまま在庫に残る。網の中の移動に代金は伴わないが、貨物は積み出し側の原価を引き継ぎ、降ろす施設の売値はその原価から決まる。降ろす施設は生産の増幅を受けず、その売値は地区の相場（地区平均価格）にも入らない。国際貨物輸送サービスはインフラ財だが、物ではなく国外との輸出入の枠なので貨物ではない（33.7）。

## 33.5. 貨物路線と貨物PF

貨物路線（[6_公共交通機関](6_公共交通機関.md) 6.11）の輸送能力（t/日）が、専用網での区間の容量になる。容量は前のエポックの運行実績で決まり、区間は路線の進行方向にだけ流れる。

貨物路線が停まるのは、品目ごとの貨物専用のホーム（貨物PF。コンテナ・鉱石・石油の3種）だけで、どのホームがどの品目の貨物PFかは、貨物路線の種別の `stop_path_variants` で決まる。ほかの路線は停まれないが、通過はできる。乗客が乗り降りしないので駅舎（[29_駅と駅舎](29_駅と駅舎.md)）には所属しない。ホームとしての形と、止まる列車だけがホームの上で向きを変えられる規則は、旅客のホームと同じである。

## 33.6. 積み下ろしの施設

貨物を網へ積む施設と網から降ろす施設は、品目に合った貨物PFの隣に建つ市政府の公共施設で、売買は商品市場で、貨物の授受は専用網で行う。

```mermaid
graph LR
採掘所 -- 鉱石(トラックまたは構内物流) --> 鉱石積込駅 -- 鉱石(大口輸送)/鉱石輸送路線 --> 鉱石取卸駅 -- 鉱石(トラックまたは構内物流) --> 製鉄所
```

| 施設 | 仕入れ | 供給 |
| --- | --- | --- |
| 鉱石積込駅 | 鉱石（商品市場） | 鉱石(大口輸送)（専用網） |
| 鉱石取卸駅 | 鉱石(大口輸送)（専用網） | 鉱石（商品市場） |
| 石油積込駅 | 原油（商品市場） | パイプライン原油（専用網） |
| 石油取卸駅 | パイプライン原油（専用網） | 原油（商品市場） |
| 国境貨物駅 | なし | 国際貨物輸送サービス（専用網。33.7） |
| 国際貨物駅 | 国際貨物輸送サービス（専用網） | 国外との輸出入（33.7） |

施設の区画の近くに停留所がある貨物路線は、その施設とつながる（線路を施設へ引き込む必要はない）。複数の路線が同じ施設につながれば、施設を経由して積み替えられる。石油の積込駅・取卸駅の接続端子にはパイプラインもつながる。積込駅の原料の購入費・人件費・電気代は市の予算から出て、取卸駅の売上が収入になる。

## 33.7. 国際貨物

国外との輸出入の窓口（輸出入拠点）は、海を通じた港、陸を通じた国際貨物輸送路線、道路の国境を通じた陸路輸送の3つで、互いにつながらない（[8_商品市場](8_商品市場.md)）。

国際貨物輸送路線では、マップの外（都市外の地区）の国境貨物駅が国際貨物輸送サービス（輸出入の枠。1単位=1t）を出し、都市の国際貨物駅（港と同じ輸出入拠点 `TYPE_TRADE`）が受け取った枠の分だけ輸出入する。国境貨物駅はシナリオの作者がテンプレートモードで置き、プレイヤーは建てることも消すこともできない（[地形形状](../geometries/D_地形形状.md)）。国際貨物駅の取扱能力は、床面積で決まる能力と受け取った枠で取り扱える量の小さい方で、列車は往復するので輸入と輸出がそれぞれこの量を使える。路線を開設したエポックから数えて3エポック目に輸出入が始まる（輸送能力の記録、枠の配送と取扱量の計画、取引の順に1エポックずつ進む）。荷役情報のAPIは、床面積で決まる能力と受け取った枠で取り扱える量を分けて返す（枠を持たない港などでは後者が `null`）。
