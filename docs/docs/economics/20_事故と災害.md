# 20. 事故と災害

都市では、建物の倒壊・火災・犯罪と、道路の交通事故が起きる。火災・犯罪・交通事故は、エポックの中で発生から被害の確定まで完結し、結果はアラートと統計に現れる。

## 20.1 建物倒壊と市民被害

建物が倒壊する(`STATUS_COLLAPSED`。[12_建物](12_建物.md))と、その建物に住む世帯の全員と、そこで働く市民が死亡する。パスの倒壊では死者は出ない。事故の死者は倒壊と交通事故の死者の合計で、施政スコアを下げる([23_施政スコア](23_施政スコア.md))。静止人口モード([15_世帯](15_世帯.md))の都市では、事故で死者は出ない。

## 20.2 火災

稼働中の建物は、エポックごとに一定の確率で出火する(不燃の施設を除く)。消防は消防署が供給する「消防サービス」という商品で表し、出火した建物は商品市場を通じて最寄りの消防署から調達する。調達できた割合に応じて被害が抑えられるので、消防署が遠い・途中が渋滞している・火災が多くて供給が追いつかないと、被害が大きくなる([8_商品市場](8_商品市場.md))。

出火のしやすさは構造によらない。構造の差は、建物の種類ごとの火災耐性として被害の上限と燃え移りやすさに現れる。本格的な火災は、隙間の狭い隣の建物へ燃え移りやすく、建蔽率の高い木造の密集地ほど燃え広がる。

火災は建物の耐久度(`durability`)を削るだけで、市民を直接死亡させない。耐久度が下がった建物は通常の倒壊の判定で倒壊し、全焼した建物はそのエポックのうちに焼失(`REASON_FIRE`)する。

## 20.3 交通事故

稼働中の道路では、エポックごとに確率的に交通事故が起きる。道路の形(カーブ・勾配)から無理なく出せる通過速度([3_道路網](3_道路網.md))より制限速度が高いほど、また容量に対して交通量が多いほど起きやすい。事故が起きると、都市全体から選ばれた市民(移動中の誰か)が死亡する。

## 20.4 犯罪

犯罪は、都市全体の件数を先に治安の悪さ([19_環境](19_環境.md))から決め、その件数ぶんの現場を治安の悪い地域の建物ほど多く受ける。そのため建物を増やしても犯罪の総数は増えない。警察は警察署が供給する「治安維持サービス」で、火災と同じく調達できた割合に応じて被害が抑えられる。犯罪は耐久度を削らず、倒壊も死亡も起こさない。

## 20.5 アラートと統計

火災・犯罪・交通事故のアラートは、起きたエポックの間だけ立ち、次のエポックの開始で消える([アラートフラグ管理](../programs/アラートフラグ管理.md))。火災と犯罪は被害の大きさで2段階に分かれ、被害が小さく耐久度が減らなかった火災は失火(`ALERT_AGENT_ACCIDENTAL_FIRE`)、被害の小さかった犯罪は犯罪の兆候(`ALERT_AGENT_CRIME_SIGN`)になる。

統計の件数は発生の回数ではなく、交通事故は事故の起きた道路の数(死者が出なくても数える)、火災と犯罪は被害を受けた建物の数で数える。失火の件数は、本格的な火災になった建物を含めて火の出た建物の総数である。

発生場所の一覧はアラートから作るので、直近のエポックの分しか無い。倒壊の一覧はパスを含み(死者は0)、原因は老朽化と焼失に分かれる。
