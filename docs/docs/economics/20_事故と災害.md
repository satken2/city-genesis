# 20. 事故と災害

都市では、建物の倒壊・火災・犯罪と、道路の交通事故が起きる。被害は建物や人命、住環境に影響し、エポックの結果に現れる。

## 20.1. 倒壊と火災

老朽化や火災によって建物が倒壊すると、住民や働く人に人的被害が生じる。倒壊した建物は廃墟として残り、周囲の住環境にも悪影響を及ぼす。維持や修繕については[建物](12_建物.md)を参照。

火災の被害には、建物の耐火性や周囲との密集度が関わる。木造の密集地などでは延焼しやすく、ひとつの建物の火災が周囲へ広がる。

消防署は消防サービスを供給して被害を抑える。供給力に加えて現場へ届く速さも重要であり、消防署が遠い地域や渋滞の多い地域は被害が大きくなりやすい。

## 20.2. 交通事故

道路の形に対して無理のある速度や、交通の集中は事故の起きやすさにつながる。事故は人的被害を伴い、都市の評価にも影響する([パスとノード](3_パスとノード.md)・[満足度と施政スコア](23_施政スコア.md))。

## 20.3. 犯罪と治安

犯罪は地域の治安に関わり、警察署が供給する治安維持サービスによって被害を抑える。警察の供給力と、各地域へサービスが届くことが重要になる。

治安は住民の暮らしや住まい選びにも影響する([環境](19_環境.md))。
