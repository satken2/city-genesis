# 19. 環境

## 19.1. 住環境倍率

すべての土地区画は、世帯にとっての住みやすさを表す住環境倍率(世帯の立地倍率。[4_地区と土地区画](4_地区と土地区画.md))を持つ。騒音・大気汚染・治安・日照の4つの悪さから毎エポック求め、理想の環境での上限と最悪の環境での下限の間に収まる。世帯は住まいの費用(家賃と通勤などの移動の負担)をこの倍率で割り引いて比べるので、静かで安全な地域に集まり、騒音や犯罪の多い地域からは移っていく([13_不動産市場](13_不動産市場.md))。世帯の住環境スコア(`env_score`)は、収入に対して住まいの費用が軽いほど、住環境倍率が高いほど高くなる。

## 19.2. 4つの要素

- **騒音**: 道路・線路の騒音(パスの `noise`)は自動車・列車・歩行者の交通量から、建物の騒音はバリアントごとの底面積あたりの強さから生じる。
- **大気汚染**: 道路の大気汚染(パスの `air_pollution`)は自動車の交通量から、建物の大気汚染はバリアントごとの強さから生じる。排煙のほか、悪臭や粉じんなど空気の汚れ全般を含める。
- **治安**: 市民は固有の犯罪性向(`potential_criminality`、0〜1)を持つ。世帯の住まいと、その世帯がよく訪れる地区が、構成員の犯罪性向(失業中の成人は加算)に応じて悪くなる。治安の悪さは犯罪の起きやすさにもなる([20_事故と災害](20_事故と災害.md))。
- **日照**: 周りの建物が1日のうちに落とす影の時間の割合で決まる。区画に建つ建物の位置(建物が無ければ区画の中心)で評価し、自分の建物の影は数えない。

騒音・大気汚染・治安は発生源から周囲へ広がり、距離とともに弱まる。完全に地下に埋設されたパスは騒音も大気汚染も出さない。

## 19.3. 区画の値と地図

4つの悪さは都市全体を覆う格子の上で計算して区画ごとに取り出す(水面の区画は評価しない)。区画の値は住環境倍率へ合成する前の悪さで、日照も含めて0が理想、1が最悪であり、エポックを実行するまでは `null` である。都市全体の区画の値をまとめて取るときは、騒音・大気汚染・治安は都市内の最小〜最大を両端とする相対値、日照は0〜1の固定の幅で表す。

地図に重ねる表示用の格子は[都市マップの検索と経路案内](../programs/都市マップの検索と経路案内.md)を参照。表示用の格子はセーブされず、ロードした後は次のエポックまで無い。

## 19.4. 衛生

下水処理・ごみ収集の不足が続くと、住まいの区画に衛生負荷が溜まる。片方の不足をもう片方で補うことはできず、人口のまばらな集落では施設が無くても衛生は悪化しない。衛生は徐々に悪化し、供給を回復すると徐々に戻る。衛生の悪化は健康を損ない、死亡のリスクを上げる。医療は健康の回復を助けるが、下水・ごみ処理の代わりにはならない。

## 19.5. 満足度への作用

騒音・治安・日照は生活の快適さに、大気汚染と衛生は健康に作用する([23_施政スコア](23_施政スコア.md))。費用の比較に使う住環境倍率とは別の評価で、満足度には家賃や通勤を重ねて数えない。
