# 19. 環境

## 19.1. 住環境

住環境は、世帯にとっての土地の住みやすさを表す。区画の住環境倍率は世帯の立地倍率に当たり、家賃や移動の便利さとともに、住まいを選ぶ要因になる([地区と土地区画](4_地区と土地区画.md)・[不動産市場](13_不動産市場.md))。

同じ地域でも、住まいとしての建物の質によって暮らしやすさは異なる。

## 19.2. 住環境を構成する要素

| 要素 | 内容 |
| --- | --- |
| 騒音 | 交通や施設の活動による音 |
| 大気汚染 | 排煙・悪臭・粉じんなど、交通や施設による空気の汚れ |
| 治安 | 地域の安全性。犯罪の起きやすさにも関わる |
| 日照 | 周囲の建物の影による日当たり |

騒音や大気汚染、治安の影響は周辺へ広がるため、住環境は自分の区画だけでは完結しない。住宅と産業の配置や道路の混雑、街の密度が、地域の住みやすさにつながる。

## 19.3. 衛生

下水処理やごみ収集が不足すると衛生が悪化し、住民の健康を損なう。影響は時間をかけて蓄積し、供給を回復させても改善には時間がかかる。

医療は健康の回復を助けるが、下水やごみ処理の代わりにはならない。

## 19.4. 暮らしへの影響

騒音・治安・日照は生活の快適さに、大気汚染や衛生は健康に関わる。住環境は住まい選びだけでなく、住民の満足度や死亡のリスクにも影響する([満足度と施政スコア](23_施政スコア.md)・[世帯](15_世帯.md))。
