# 4. 地区と土地区画

## 4.1. 地区

地区は都市を分けるエリアで、需要と供給の集計や商品の取引は地区を単位に行う。地区は道路の集まりとして定義し、土地区画と経済主体は道路から所属を受け継ぐ。

### 道路の面と所属

道路(パス)は始点から終点へ向かう向きに対して左右2つの面を持ち、面ごとに1つの地区に属する(`left_zone_id` / `right_zone_id`)。両面が違う地区の道路は2つの地区の境界で、両側の地区の道路として数える。地区に属するのは生活道路(`PATH_STREET`)だけである。パスの API の `zone_id` / `zone_name` は両面が同じ地区のときだけその地区を表し、境界の道路と地区に属さない道路では `0` / `null` になる。

土地区画は、接道(`front_path_id`)のうち区画がある側の面(`front_path_side`)の地区に属する。建物は立地する区画の地区に、テナントや世帯は入居する建物の地区に属する。接道の決まらない区画も最寄りの区画の地区に属するので、地区に属さない区画は無い。プレイヤーが接道を選び直すと、区画とそこに立地する経済主体の地区も変わる。

### 地区の範囲

地区の道路は、同じ地区の道路だけを通って互いにつながっていなければならない。また地区の大きさ(区画とその接道区間からなる市街地の広がりと、接道区間の総延長)には上限がある(共有定数 `ZONE_MAX_DIAMETER`・`ZONE_MAX_TOTAL_STREET_LENGTH`)。プレイヤーが道路の面を選んで地区を作る・広げる操作([地区編集パネル](../programs/地区編集パネル.md))はこの2つを満たすときだけ受け付け、新しい道路や沿道の区画は、受け入れられる隣の地区か新しい地区へ自動で割り当てる。区画を足して上限を超えるときは、その区画が面する道路を切って区画側を別の地区にするため、区画の作成で道路が分割されて道路IDが増えることがある。道路の取り壊しなどで地区が分断されると、最大の部分を残して残りを新しい地区に分ける。既存の地区同士が自動で統合されることはない。

都市には常に1つ以上の地区がある。開始時の初期地区は道路を持たず、市庁舎・中央銀行・輸出入拠点が属し、最初に敷いた道路が入る。道路の無くなった地区はやがて削除されるが、最後の1地区は残る。

### 地区の形状

地区のポリゴンは、所属する陸地・沿岸の区画と道路の面の帯から求める派生値で、所属を決めるのには使わない。陸上の区画が無い地区は輪郭を持たない。ポリゴンは単一の外周だけを持って穴を表さないので、内側に囲まれた別の地区と重なることがある。地点から地区を選ぶときはその地点の道路の面の所属を優先し、輪郭で選ぶ場合は内側(面積の小さい方)の地区を優先する。

### 代表エージェント

地区ごとに、建物を持たない3体の代表エージェントがいる。建設代理(`VARIANT_ZONE_CONSTRUCTION`)と修繕代理(`VARIANT_ZONE_CONSTRUCTION_MAINTENANCE`)は、市場に参加できない道路に代わって工事と修繕の資材を調達し、市の建設予算・修繕予算の対象になる([22_予算管理](22_予算管理.md))。道路の需要は面ごとに半分ずつ、その面の地区が受け持つ。転居補助(`VARIANT_ZONE_RELOCATE`)は、入居先の決まっていない世帯・施設の仮入居先である([13_不動産市場](13_不動産市場.md))。

## 4.2. 土地区画

土地区画は土地の所有と利用の単位で、建物はすべていずれかの区画に建つ。区画の形と作り方は[土地形状](../geometries/B_土地形状.md)を参照。

### 所有と地価

区画には所有者がいる。市政府が作った区画は市有で、民間の建物が着工するとその建物の所有になり、建物の所有者と区画の所有者は一致する。市政府が民間の区画を使うには、買収するか、建物の無い区画を収用して所有者に地価を補償する。地価(`land_price`)は、その区画に建てうる建物のうち最も採算の良いものから見た土地の価値である。

### 土地区画の種類（parcel_type）

区画の種類は作成時に海岸線との位置関係から自動で決まり、プレイヤーは選べない。海岸線に接すれば沿岸(`PARCEL_SHORE`)、海の上なら水面(`PARCEL_WATER`)、それ以外は陸地(`PARCEL_LAND`)である。埋立てで海岸線が広がっても、既存の区画の種類は変わらない。建物バリアントは建てられる区画の種類を持ち(港湾施設は沿岸、洋上風力発電所などの海上構造物は水面、多くは陸地)、種類の一致する区画にだけ建つ。

水面の区画は市政府が海上構造物を建てるための敷地で、民間の建物は建たず、地価は常に0である。接道も持たない。

### 建築規制

区画の建築規制は、建てられる建物の種類(`allowed_bd_mask`)・高さ・容積率・建ぺい率の上限である。区画が個別に持たない(`restriction_override` が偽)ときは所属地区の規制に従う。容積率・建ぺい率は比率(1.0 = 100%)で、高さと容積率の 0 は制限なしを表す。規制を変えても既存の建物はそのまま残る。区画の種類による物理的な制約は、建築規制とは別に常に掛かる。

区画の直下の浅い地下や上空をパスが横切る区画は `has_crossing_path` が 1 になり、民間の建物が建たない。公共施設はパスに当たらない高さなら建てられる。

### 立地の条件

区画は覆う範囲の地形の平均勾配(`terrain_slope`、無次元)を持ち、勾配が大きいほど建物の建設・修繕・解体の作業量が増える([12_建物](12_建物.md))。勾配は道路工事や造成で加工した後の地形から測る。

区画と接道の間の距離は、道路網の外を歩いて運ぶ手間として区画への到達時間に加わる。通り抜けのできるオープンスペース(駐車場・駅前広場など。[2_経済主体](2_経済主体.md))が稼働している区画は、この間を埋める通路になる。

入居を待つテナントに必要な床を1棟で用意できる区画が地区に無い状態が続くと、隣り合う市政府か中央銀行の空き区画が自動で結合される。

## 4.3. 立地倍率

区画は経済主体のバリアントごとに立地倍率(`agent_multiplier`)を持つ。その区画にそのバリアントが立地したときの有利さで、1.0 が標準であり、エポックごとに作り直す。小売店は面する道路の交通量と同業種の集積で上がる。工業原料の生産者と天然資源の採取者は集積で上がり、資源の残量が減ると下がる(資源の無い区画では0。[21_天然資源](21_天然資源.md))。世帯の倍率は住環境の良さを表す([19_環境](19_環境.md))。共有建物の倍率は、入居しうるテナントにとっての立地の良さから決まる。

経済主体の `attraction` は、立地倍率に長く営業した施設の知名度を掛けた「客から見た魅力」で、商品市場で買い手が供給者を選ぶときに効く。工業原料の生産者では生産量にも掛かる。設備の充実度は `attraction` に含めず、生産の効率として別に効く([9_生産活動](9_生産活動.md))。
