# 13. 不動産市場

## 13.1. フロアと入居

共有建物(`TYPE_BUILDING`)の床は用途(`SPACE_*`)ごとのフロアに分かれ、世帯や施設(テナント)が床を借りて入居する。特定のバリアントしか入居できない専用フロアもあり、用途ごとの容量と占有量(m²)では、そのバリアントIDが用途の代わりのキーになる。

建物はマスターの `shared_building` で共有と非共有に分かれる。共有建物には複数のテナントが入居し、各テナントの占有面積(`realestate_amount`)は、施設なら生産の規模に、世帯なら必要な広さに合わせて伸び縮みする。非共有建物(一戸建てなど)は1つのテナントが全部を占有し、全部の家賃を払う。

地区の床の供給量(`space_supplies`)は稼働中・休止中・建設中・発注済みの建物の容量の合計で、入居済みの非共有建物だけは占有量で数える。需要量(`space_demands`)は、入居中のテナントの占有量と入居を待つテナントの必要面積の合計である。需要が供給を上回る地区に新しい建物が計画される([12_建物](12_建物.md))。

## 13.2. 家賃

建物の家賃(`rent`)は1日・1m²あたりの単価で、テナントは毎エポック、単価に占有面積・日数・用途ごとの倍率を掛けた額を払う。テナント自身の `rent` は入居したときの建物の単価で、その後の改定では変わらない。

家賃はエポックごとに建物単位で改定され、満室で入居希望が溢れた建物は上がり、空室のある建物は休止中も含めて下がる。建物の無い区画でも、周辺の家賃相場と立地の良さから建てたときの家賃を見込み、建設の判断に使う。

世帯は手元の預金の範囲でしか家賃を払えず、払えなかった世帯は立ち退き対象(`is_evicted`)になって住まいを探し直す。企業は残高がマイナスになっても払い、経営が続かなければ閉鎖で退出する。

## 13.3. 入居先の選択

入居先の決まっていない新しい施設・世帯と、立ち退き対象や手狭な住まいの世帯が、エポックごとに入居先を選ぶ。施設は家賃を立地倍率で割った実質の家賃で、世帯は家賃に勤務先・学校・買い物先へ通う負担を足して住環境倍率で割った負担で建物を比べる。世帯は今より負担が下がり、払う家賃が収入に見合う建物にしか移らない。満室の建物への入居希望は超過需要として家賃を押し上げる。施設は参入した地区の中で入居先を探し、観光客世帯はホテルの宿泊フロアにだけ入る([31_観光](31_観光.md))。

入居先が決まるまでは地区の転居補助エージェントに仮入居して待ち、仮入居は床を占有しない。施設と未入居の移民は一定期間で撤退するが、入れる建物の建設が地区で決まっていれば完成を待つ。住まいを待つ定住住民には期限が無く、待っている間も人口に含まれる([18_移民](18_移民.md))。
