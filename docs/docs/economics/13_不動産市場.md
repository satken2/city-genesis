## 13.1. フロアとスペース

共有建物（`TYPE_BUILDING`）は内部に複数の**フロア**を持ち、各フロアは特定の用途（住居・店舗・工場など）に対応する。
フロアには**容量**（`capacity`）と**占有量**（`occupied`）があり、建物がテナントに入居させるたびに占有量が増える。
各フロアの容量の合計は、建物の延床面積（`floor_area`）と一致する。建物のスポーン時には、地区のフロア建設需要に見合うように物理サイズ（階数）そのものが決定されるため、「物理的には大きいのに貸せる容量がごく小さい」建物は建設されない。

### フロアタイプ

| フロアタイプ | 定数 | 説明 |
| ------- | ----- | --- |
| 住居 | `SPACE_RESIDENCE` | 世帯が入居する居住スペース |
| 店舗 | `SPACE_RETAIL` | 小売業・サービス業が入居する商業スペース |
| 工場 | `SPACE_FACTORY` | 製造業が入居する工業スペース |
| オフィス | `SPACE_OFFICE` | 事務所・オフィススペース |
| 農地 | `SPACE_FARM` | 農業用スペース |
| 専用フロア | variant ID（1000～2099） | 特定の variant しか入居できない専用スペース |

フロアタイプが経済主体のサブカテゴリ（variant）のIDと一致する場合、その variant の経済主体しか入居できない。
例えば、variant 1056（火力発電所）の専用フロアを持つ建物には、火力発電所以外は入居できない。

### 共有建物と非共有建物

建物は**共有建物**（`shared_building = true`）と**非共有建物**（`shared_building = false`）に分かれる。
- **共有建物**: 複数のテナントが同時に入居できる。各テナントは必要な面積（`space_min` 以上）を占有し、居住充足度等に応じて占有面積がエポックごとに動的に伸縮する。
- **非共有建物**: 建物全体を1つのテナントが占有する。容量の全量をそのテナントの占有面積とする。非共有建物に入居しているテナントについては、占有面積の動的な伸縮（縮小・拡張）は適用されず、常に建物の最大容量を占有し続ける。また、非共有建物は1つのテナントが最大容量を占有するため、余剰容量が残っていても他のテナントは追加で入居できない。この性質に基づき、地区別のフロア供給量（`space_supplies`）を集計する際には、すでに入居されている非共有建物の供給量は最大容量（`capacity`）ではなく現在の占有量（`occupied`）として評価される。これにより、利用不可能な空き容量が供給として過剰計上されるのを防ぎ、実際の空き室状況に即した正確な新規建設需要が算出されるようになっている。

## 13.2. 家賃の仕組み

### 家賃の単位

建物の家賃（`rent`）は「1日あたり1面積単位あたりの金額」として表現される。
テナントが支払うエポック全体の家賃は、用途（`space_type`）に応じた家賃倍率を考慮し、以下の式で計算される。

```
総家賃 = rent × テナントの占有面積 × エポック日数 × 用途別家賃倍率
```

用途別家賃倍率はマスターデータで定義され、用途に応じて異なる倍率が設定されている。

### 家賃の調整

各エポックの終盤で、全建物の家賃が自動調整される。
調整は以下のルールに従う。

**調整対象の制限**
- 家賃調整の対象となるのは、稼働状態（`status` が `STATUS_ACTIVE`）の建物エージェントのみである。建設中や一時停止状態（`STATUS_PAUSED`）など、稼働中でない建物の家賃は調整の対象外であり、変動しない。

**初期家賃および再開時の再設定**
- 新規に建設（スポーン）された建物エージェントの家賃の初期値は、該当する土地区画の推定家賃（`estimated_rent`）と絶対下限値の大きい方に設定される。
- 一時停止状態（`STATUS_PAUSED`）から再開（`STATUS_ACTIVE` に遷移）する建物エージェント（シミュレーション中の自動再開、スポーン時の再利用、APIによる手動再開を含む）については、新規建設時と同様に、その時点における所属地区の平均家賃（未算出の場合は都市全体の平均家賃）が再設定される。これにより、再稼働時点での市場相場に適合した家賃での取引が可能となる。

**超過需要あり（満室なのに応募者がいた場合）**
-  家賃を引き上げる。上昇率には上限がある。

**空室あり（キャパシティに対して空きがある場合）**
-  家賃を引き下げる。下落率には上限がある。

**家賃の下限**
- 家賃は建物のランニングコストに基づく下限値、または絶対下限値を下回らない。

### 家賃の支払い

エポックごとに、建物に入居している全テナントから建物エージェントへ家賃が送金される。
テナントの `reserves` から引き落とされ、建物の `reserves` に加算される。

世帯テナントは現預金の範囲内でしか家賃を支払えない。全額を支払えなかった世帯は
滞納として即時に立ち退き対象（`is_evicted`）となり、次エポックの転居処理で
より安い住居への転居を試みる。企業テナントは運転資金としての借入（残高の
マイナス）が許容されるため、この制約の対象外である（経営不振の企業の退出は
利益率に基づく閉鎖判定が担う）。公共施設テナントも残高のマイナスを許容して全額を支払い、
その支出は市の予算実績に計上される（[[22_予算管理]]）。

## 13.3. 推定家賃

**推定家賃**（`estimated_rent`）は、更地を含む全土地区画について算出される、その区画に建物を建てた場合の期待賃料である。
推定家賃は建設フェーズが新築の意思決定に利用する。

推定家賃は「所属地区の家賃相場 × その区画の立地ポテンシャル」として算出される。

- **地区の家賃相場**: 同じ地区内の既存建物の「家賃 ÷ 立地ポテンシャル」を建物の延床面積で加重平均した比率。地区ごとに集計されるため、周辺の家賃水準（好況・衰退）が局所的に反映される。建物が1棟も無い地区では、需要圧に応じて家賃が上昇する転居補助エージェントの家賃がサンプルとなり、相場が形成される。サンプルが無い地区は全市平均へフォールバックする。
- **立地ポテンシャル**: その区画で実現可能な経済主体バリアントの立地優位性倍率のうちの最大値。建築規制（許可建物種類）や土地区画種類（沿岸・陸地）の制約により実現できない用途の倍率は除外される。

## 13.4. 経済主体の転居

エポックごとに、転居を希望する経済主体（仮入居中の新規スポーン施設・世帯、立ち退き対象者、家賃負担や面積に不満がある世帯など）が建物を選択して転居します。

転居希望者は、実質賃料や立地条件などを基に希望する建物へ応募し、建物に空き容量がある限り順次入居が確定します。入居希望があったものの、満室などの理由で入居できなかった需要量は**超過需要**（`surplus_demand`）として建物に記録されます。

超過需要が記録された建物は、次エポックの家賃調整において家賃引き上げの対象となります。これにより、人気の高い建物は家賃が上昇し、不人気の建物は空室率に応じて家賃が引き下げられ、市場全体の需要と供給のバランスが自動的に調整される仕組みとなっています。
