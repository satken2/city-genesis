# 29. 駅と駅舎

## 29.1 駅とは

ホームは駅パス([6_公共交通機関](6_公共交通機関.md))として表すが、プレイヤーが1つの駅と認識する単位はパスと一致しない。大きな駅は何本もの駅パスからなり、延長や分割で1つのホームが複数のパスに分かれる。このずれを埋めるのが駅舎パスで、駅は独立したエンティティではなく駅舎パスそのものである。駅名は駅舎パスの名前(`name`)で、駅は経済主体ではない。

## 29.2 駅舎パス

駅舎パスはパスのバリアントの1つ(パスマスターの `type` が `PATH_STATION_HOUSE`)で、通常のパスと同じ操作・建設で作る。形はウェイポイント付きの折れ線に限られる。線(通路)は道路・線路と物理的に干渉せず、交差してもノードの追加や分割は起きない。地上を占めるのは、両端か片方の端(`house_ends`)に置く建屋だけで、線の下には後からホームや道路を通せる。建屋の位置は[駅舎パスのメッシュ生成](../geometries/Q_駅舎パスのメッシュ生成.md)の規則で決まる。

通路の見せ方(`passage_mode`。上空・地上・地下)は表示だけに効き、地下の通路は描かない。工事・所属・経路・土地の占有は変わらない。

## 29.3 ホームの所属

ホームは、駅舎パスの線と交差していればその駅舎に所属する。既に所属しているホームは後から交差した駅舎へは移らず(先勝ち)、駅舎を撤去すると解放されて、交差する他の駅舎があればそちらへ移る。どの駅舎にも所属しない旅客のホームには、アラート `ALERT_PATH_NO_STATION_HOUSE` が立つ([アラートフラグ管理](../programs/アラートフラグ管理.md))。貨物専用のホームは駅舎に所属しない([33_貨物輸送](33_貨物輸送.md))。

## 29.4 データの持ち方

駅単位の集計(所属するホーム・発着する路線・乗車回数・建屋の範囲)は駅情報(`station-info`)で取得する。駅情報は保存されず、パスの現状からそのつど組み立てられる。どのパスがホームかはパスマスターの `platform_width` の有無で決まり、ホームの所属は駅舎パスのID(`house_path_id`。所属しなければ0以下)で表す。駅情報の建屋の範囲は参考値で、Unity は同じ規則で自前に計算する。乗車回数は前のエポックの値で、記録の無い停留所では null である。

## 29.5 駅の出入口

住民は、駅舎に所属するホームの停留所を、稼働中の駅舎の出入口から利用する。出入口は建屋を置いた端の駅舎パスの端点で、最寄りの歩行者が通れる道路へつながる。両端に建屋を置いた駅は線路の両側から乗り降りでき、乗らずに駅舎を通り抜けることもできる。同じ駅舎のホームの間の乗り換えは、道路へ出ずに出入口を経由する。建設中の駅舎や駅舎に所属しないホームの停留所は、最寄りの道路へ直接つながる。駅舎の変化は次のエポックの経路から反映される。
