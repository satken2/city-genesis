# 29. 駅と駅舎

## 29.1. 駅の構成

駅のホームは、線路の一種である駅パスとして表す。大きな駅は複数のホームからなり、ひとつのホームが複数のパスに分かれることもある。

これらを、プレイヤーが認識する1つの駅にまとめるのが駅舎パス(`PATH_STATION_HOUSE`)である。駅舎パスが駅の名前とまとまりを表し、駅は経済主体としての建物とは区別される。

## 29.2. 駅舎とホーム

駅舎パスは、出入口の建屋とホームを結ぶ通路を表す。通路が横切るホームがその駅に属し、複数の路線やホームを同じ駅としてまとめられる。

貨物専用のホームは、旅客の駅舎には属さない([貨物輸送](33_貨物輸送.md))。

形状や描画については[駅舎パスのメッシュ生成](../geometries/Q_駅舎パスのメッシュ生成.md)を参照。

## 29.3. 出入口と乗り換え

住民は駅の出入口からホームへ向かい、列車に乗り降りする。同じ駅のホーム間では乗り換えもできる。

両側に出入口を持つ駅は、線路の両側から利用でき、駅舎を通り抜ける歩行者の動線にもなる。駅舎の位置と出入口は、駅周辺の歩きやすさに関わる。

路線と停留所の関係は[公共交通機関](6_公共交通機関.md)を参照。
