# 16. 労働市場

## 16.1. 雇用とは

雇用は市民単位で、1人の市民は1つの勤務先で働く。給与は勤務先から市民の世帯へ支払われ、世帯の暮らしを支える。

施設は生産に必要な働き手を求め、市民は賃金や通勤の負担を考慮して仕事を選ぶ。人手の不足や求人の多さは、賃金の動きにも影響する。

## 16.2. スキルと賃金ティア

市民は6種類のスキルを持つ。施設が必要とするスキルは業種によって異なる。

| 定数 | スキル |
| --- | --- |
| `SKILL_BASE` | 基礎教養 |
| `SKILL_PHYSICAL` | 肉体労働 |
| `SKILL_OFFICE` | 事務 |
| `SKILL_RETAIL` | 販売 |
| `SKILL_TECHNOLOGY` | 科学技術 |
| `SKILL_MEDICAL` | 医療 |

働き手はスキルに応じて無教育人材・標準人材・高度人材の賃金ティアに分かれる。より上のティアに進むには教育が必要で、仕事の経験だけでは越えられない境界がある([教育](17_教育.md))。

## 16.3. 人数と実質労働力

施設の雇用枠(`quota`)と雇用済みの労働力(`total_labor`)は、人数ではなく実質労働力を表す。スキルや労働時間によって、同じ人数でも生産を支える力は異なる。

教育による技能の向上は、都市の生産力を高める。医療など高度人材を必要とする業種では、単に人数を集めるだけでは稼働できない。

公共施設の雇用は市の予算にも制約される。所定労働時間を長くすると労働力は増えるが、余暇や健康への負担も大きくなる([予算管理](22_予算管理.md)・[満足度と施政スコア](23_施政スコア.md))。
