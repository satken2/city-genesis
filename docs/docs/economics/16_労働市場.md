# 16. 労働市場

市民の働き手と施設の求人の結びつき、スキルと賃金の関係について。

## 16.1. 雇用の単位

雇用は市民単位で、1人の市民は同時に1つの勤務先にだけ勤める。就労可能年齢以上の市民は誰でも労働市場に参加し、給与は勤務先から市民の世帯へ支払われる。失業率は、就労可能年齢以上の住民のうち勤務先の無い人の割合で、学生と退職年齢以上の住民も含めて数える。

## 16.2. スキルと賃金ティア

市民は6種類のスキルの値を持つ。施設には業種ごとに要求スキル(マスターの `required_skill`)があり、そこで働く人の働きぶりと賃金は要求スキルの値で決まる。

| 定数 | スキル |
| --- | --- |
| `SKILL_BASE` | 基礎教養 |
| `SKILL_PHYSICAL` | 肉体労働 |
| `SKILL_OFFICE` | 事務 |
| `SKILL_RETAIL` | 販売 |
| `SKILL_TECHNOLOGY` | 科学技術 |
| `SKILL_MEDICAL` | 医療 |

スキルの値には無教育境界と高スキル境界があり、要求スキルの値が無教育境界未満なら無教育人材、高スキル境界以上なら高度人材、その間なら標準人材の賃金ティアになる(境界ちょうどは上のティア)。境界は教育でしか越えられず([17_教育](17_教育.md))、就労による成長は境界の手前で止まる。

## 16.3. 実質労働力と賃金

施設の雇用枠(`quota`)と雇用済みの労働力(`total_labor`)は、人数ではなく実質労働力で数える。実質労働力は要求スキルの値と所定労働時間([23_施政スコア](23_施政スコア.md))に比例する。一方、賃金はスキルの値に連動せず、施設が賃金ティアごとに持つ日額(`wage_uneducated`・`wage`・`wage_high`)である。スキルの高い人は同じ賃金でより多く生産するので、教育で蓄えた人的資本がそのまま都市の生産力になる。

業種によっては雇用枠の一定割合(マスターの `skilled_people`)を高度人材で埋めないと生産できず、そのときは高スキル不足のアラート(`ALERT_AGENT_HIGH_SKILL_SHORTAGE`)が立つ。

## 16.4. 就職と賃金の動き

毎エポック、職の無い市民と転職を考える一部の就業者が、賃金から通勤の負担を引いた魅力の高い施設に応募し、人手の足りない施設が採用する。高度人材は、それを必要とする施設に優先して割り当てる。公共施設の雇用枠は予算でも絞られる([22_予算管理](22_予算管理.md))。

賃金はティアごとに需給で上下し、応募が多ければ下がり、人手が足りなければ上がる。失業率が低い間は下がらない。下限は生活必需品の最低量を輸入価格で買う費用から決まるので、都市内の物価では動かない。給与は勤務先の資金が足りなくても全額払われ、不足は勤務先の借金になる([7_金融システム](7_金融システム.md))。
