# 16. 労働市場

この文書では、都市における労働力の供給（市民）と需要（企業・施設）がどのようにマッチングされ、賃金がどう決定されるかについて説明する。

## 16.1. 労働市場の基本原則

本ゲームの労働市場において、雇用の単位は**市民個人**である。各市民は `employer_agent_id` で雇用先の経済主体を参照し、そこに就職する形で労働力を提供する。市民は `household_agent_id` で世帯（`TYPE_HOUSEHOLD`）に所属し、給与は市民個人ではなく世帯に対して支払われる。

- 就労可能年齢以上の市民が労働市場に参加できる。
- 各市民は同時に1つの雇用先にしか所属できない。掛け持ちはない。
- 就職した市民の属する世帯は、雇用主からエポックごとに給与を受け取る。

## 16.2. 実質労働力

労働市場では、労働力を単なる「人数」ではなく**実質労働力**という単位で管理する。実質労働力は市民のスキル値をベースに計算され、スキルが高いほど1人あたりの実質労働力が大きくなる。`skill_multiplier` は雇用主のvariantごとに定義された指数で、1.0より大きければスキルが有利に働く。

実質労働力は企業の**生産性**に影響する。スキルが高い市民ほど同じ人数でより多くの生産を行えるため、教育による人的資本の成長がそのまま都市の生産力向上につながる。企業は雇用量を「何人雇うか」ではなく「どれだけの実質労働力を確保するか（`quota`）」を基準に管理する。

実質労働力は**生産性**にのみ影響し、市民が受け取る**賃金**には影響しない。賃金はスキルではなく後述の賃金ティアによって決まる。これにより「高スキル人材は同じ賃金でもより多く生産する」という人的資本の価値が表現される。スキルが高いだけの労働者がスキルの低い労働者2人分と完全に等価にならず、教育を通じた人的資本の蓄積が経済発展を生み出す。

## 16.3. 労働者スキル

### スキルの種類

各市民は複数のスキル値を持つ。スキルは以下の分野に分かれており、経済主体のサブカテゴリ（variant）ごとに要求されるスキル（`required_skill`）が定められている。

| スキル  | 定数                    | 内容                        |
| ---- | -------------------- | ------------------------- |
| 基礎   | `SKILL_BASE` = 0     | すべての労働の基本となるスキル。          |
| 肉体労働 | `SKILL_PHYSICAL` = 1 | 工場や農場、建設現場などで要求される。       |
| 事務作業 | `SKILL_OFFICE` = 2   | 一般的なオフィス業務で要求される。         |
| 接客   | `SKILL_RETAIL` = 3   | 小売店や飲食店などのサービス業で要求される。    |
| 工学技術 | `SKILL_TECHNOLOGY` = 4 | 高度な機械工場やソフトウェア開発などで要求される。 |
| 医療   | `SKILL_MEDICAL` = 5  | 病院や診療所などの医療機関で要求される。      |

### 賃金ティアと賃金計算

市民が受け取る賃金は**スキル値に連動しない**。代わりに、企業は労働者を3つの**賃金ティア**に分け、ティアごとに独立した賃金水準を持つ。市民は自分のティアに対応する固定額を受け取り、同一ティア内であれば個人のスキル値が異なっても同額となる。

ティアは、その市民の「**雇用主が要求するスキル**」における値で判定される。職に関連するスキルでティアが決まるため、同じ市民でも就く職によって所属ティアが変わりうる。

| ティア | 条件（要求スキル値） | 受け取る賃金 |
| --- | --- | --- |
| 無教育人材 | スキル < 0.5（無教育境界） | 企業の無教育ティア賃金 |
| 標準人材 | 0.5 ≤ スキル < 1.5（高スキル境界） | 企業の標準ティア賃金 |
| 高度人材 | スキル ≥ 1.5 | 企業の高度ティア賃金 |

賃金がスキルに連動せずティア固定になったことで、賃金（労働者への分配）と生産性（労働者の貢献）が分離される。高スキル人材は固定の賃金を受け取りつつ、その高い生産性によって企業に利益をもたらす。

市民の最も得意なスキルと企業の要求スキルが異なる場合、その職では本来より低いティアに分類され、また労働意欲（効用）も下がる。これが**スキルミスマッチ**である。

### 高スキル労働者

ある市民の最大スキル値が、高スキル境界（1.5）以上である場合、その市民は**高スキル労働者**として扱われる（賃金ティアの高度人材と同じ判定基準）。

企業には、最低限必要な実質労働力（`labor_min`）とは別に、**最低高スキル労働力**が設定されている。これは企業の雇用枠（`quota`）に対する割合（`skilled_people`）としてマスターデータで定義される。単に実質労働力の合計が足りていても、高スキル労働者が担う実質労働力がこの水準に満たなければ、企業の生産計画が制約される。雇用枠は需要に応じて変動するため、必要な高スキル労働力も企業の事業規模に連動する。

### スキルの蓄積と成長

市民のスキルは固定ではなく、就業を通じて成長する。ただし就労によるスキル成長には区分的な上限があり、無教育境界（0.5）や高スキル境界（1.5）といった教育の境界は就労（実務経験）だけでは越えられない（境界のわずか手前で頭打ちとなり、境界値には到達しない）。境界以上のスキルへ到達するには学校での教育が必要になるため、教育による底上げが重要になる（[17_教育](17_教育.md)）。

高スキル境界を越えた市民は、就労を通じて雇用先の業種が定めるスキル上限まで成長を続ける。高等教育の修了直後のスキルは境界をわずかに超えた水準で、高度人材の移民（[18_移民](18_移民.md)）も同じ水準で流入する。高度な業種ほど上限が高く、長期に雇用し続けることでこれを大きく上回る熟練が形成される。

## 16.4. 労働マッチング

エポックごとに「働き手を求める企業」と「仕事を探す市民」のマッチングが行われる。

### 高スキル人材の優先マッチング

マッチングは、高スキル人材（最大スキル値が高スキル境界以上の市民）を高スキル人材を不可欠とする企業（`skilled_people` が設定されている企業）へ優先的にマッチングさせたのち、残るすべての求人枠に対して一般のマッチングを行うという2段階で実行される。

- 高スキルの失業者は、専門企業で採用されなかった場合でも一般の職に広く応募できる。就労機会を失うことはない。
- 一方、現在就業中の高スキル労働者が一般職へ転職して職能がダウングレードすることはない。
- 高スキル者の転職は一般よりも起こりやすく、高度産業間で人材が流動しやすくなっている。

### 応募と採用の原則

求職者は自身にとって効用の高い雇用主へ応募し、労働力が不足している雇用主が優先して採用される。同一の求職者が複数企業から同時に重複して採用されることはない。

## 16.5. 労働力の集計

マッチング完了後、全企業の `total_labor`（実質労働力合計）と `labor_surplus`（雇用枠との差分）が再計算される。正の値は人手不足、負の値は過剰雇用を表す。

## 16.6. 賃金の調整

各エポックのマッチング後に、雇用主の**3つのティア別ベース賃金**（無教育・標準・高度）が一括調整される。各ティアの賃金は独立して変動し、調整はそのティアの労働力の需給バランスに基づいて行われる。過剰雇用の解消（レイオフ）は別フェーズが担当する。

ティアごとに独立して賃金が動くことで、賃金がスキルに連動しなくなった環境でも、ティア間の賃金格差が需給に応じて自然に形成される。例えば高度人材が不足すれば高度ティア賃金だけが上昇し、無教育人材が余れば無教育ティア賃金だけが下落する。

### 調整対象の制限
- 賃金調整の対象となるのは、稼働状態（`status` が `STATUS_ACTIVE`）の雇用主エージェントのみである。建設中や一時停止状態（`STATUS_PAUSED`）など、稼働中でない雇用主エージェントの賃金は調整の対象外であり、変動しない。

### 再開時の賃金再設定
- 一時停止状態（`STATUS_PAUSED`）から再開（`STATUS_ACTIVE` に遷移）する雇用主エージェント（シミュレーション中の自動再開、スポーン時の再利用、APIによる手動再開を含む）については、新規雇用主の参入時と同様に、その時点における所属地区の**ティア別平均賃金**（未算出の場合は都市全体のティア別平均賃金）が3ティアそれぞれに再設定される。これにより、再稼働時点での地域の労働市場相場に適合した賃金でのマッチングおよび雇用取引が可能となる。

### 賃金の変動ルール

各ティアについて、そのティアの応募超過（供給過多）と、企業全体の人手不足を需給シグナルとして賃金を上下させる。

| 条件 | ルール |
| --- | --- |
| **そのティアが応募超過** | 労働力供給過多を反映し、そのティアの賃金を引き下げる |
| **企業が人手不足（かつそのティアが応募超過でない）** | そのティアの賃金を引き上げて労働者を誘引する |
| **その他** | 変動なし |

### セーフガード

- 調整後の賃金は最低賃金を下回らない。1エポックあたりの変動には上限がある。
- 引き上げ対象なのに賃金が0の雇用主には、変動率の適用ではなく所属地区のティア別平均賃金（未算出の場合は都市全体のティア別平均賃金）が再設定される。長期の供給過多などで賃金が0まで下がった施設が、労働市場の相場に復帰して募集を再開できるようにするためである。
- 全ティアの賃金には下限がある。下限は「最低生活バスケット（生活必需品の最低需要量 × 域外基準価格。1人1日分）× 為替レート × `MIN_WAGE_BASKET_RATIO`」で毎エポック決まる。都市内の価格ではなく域外基準価格で測るので、都市内の品不足や値上げでは動かず、通貨安のときだけ名目賃金が底上げされる（通貨安で生活必需品の輸入価格が上がっても、賃金がそれ以下に下がり続けることはない）。

## 16.7. 給与の支払い

エポックごとに、就業中の全市民の給与が雇用主から世帯へ支払われる。

### 支払額の計算

各市民の1エポックの給与は、その市民が所属する賃金ティア（無教育・標準・高度）に対応する雇用主のティア別ベース賃金に、エポック日数を掛けたものである。賃金はスキル値には連動しない。同一雇用先に複数の市民が属する世帯の場合、各市民の給与が合算される。

### 所得税

給与の支払い時には所得税（`city.income_tax`）が控除される。税額は支払総額に税率を掛けた額であり、市政府の収入として加算される。

### 支払不能時の処理

雇用主の資金（`reserves`）が不足して給与を支払えない場合、その雇用先の市民は高い確率で辞職する。ただし、スキルの蓄積（成長）は支払いの成否に関わらず、そのエポックに就業していた全市民に対して適用される。
