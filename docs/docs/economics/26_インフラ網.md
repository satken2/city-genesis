# 26. インフラ網

## 26.1. インフラ網とは

インフラ網は、電力・水道などを専用の経路で施設間に届ける仕組みである。ここで運ぶ財をインフラ財(`GOODS_INFRASTRUCTURE`)と呼ぶ。

インフラ財は通常の商品市場で売買されず、網でつながった公共施設の間を流れる。道路が近くにあるだけでは届かず、施設と専用網の接続が必要になる。

## 26.2. 生産から需要家まで

電力は、発電所から送電網で変電所へ送り、変電所から世帯や施設へサービスとして届ける。

```mermaid
graph LR
発電所 -- 高圧電力 --> 送電網 -- 高圧電力 --> 変電所 -- 電力サービス --> 世帯・施設
```

水道も、取水施設などから導水管で水道ポンプへ送り、そこから需要家へ届ける構造である。生産施設、輸送する網、地域に届ける施設がそろって都市を支える。

需要家へのサービスの届き方は[商品市場](8_商品市場.md)を参照。

## 26.3. パスと接続

| パス | 定数 | 役割 |
| --- | --- | --- |
| 送電線 | `PATH_ELECTRICITY` | 電力を送る |
| 水道管 | `PATH_WATER` | 水を送る |
| パイプライン | `PATH_PIPELINE` | 原油などを送る |

施設には網につなぐ接続端子があり、対応するパスを接続する。パスは運べる財によって別々の網を作る。

電化線路は列車の通り道と送電網を兼ねる。鉄道の車両基地などでは、電化線路による接続が車両の供給と受電の両方を支える。

## 26.4. 供給力と不足

施設の生産能力だけでなく、途中のパスの容量や網のつながりも、届けられる量を制限する。発電所に余力があっても、送電経路が細かったり途切れていたりすれば停電する。

太陽光・風力のように天気で出力が変わる施設と、需要に合わせて供給する施設では、都市を支える役割が異なる([生産活動](9_生産活動.md))。

原油や鉱石を運ぶ専用網も、この接続と容量の考え方を使う。詳しくは[貨物輸送](33_貨物輸送.md)を参照。
