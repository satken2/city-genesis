# 建設作業量と施工能力

建物・道路・線路の工事は、どれも同じ建設サービス財(`PRODUCT_CONSTRUCTION_SERVICE`)の作業単位で量る。作業量は物理的な体積ではなく、形状を共通の作業単位へ換算した値で、費用は調達した量に市場の単価を掛けたものになる。進捗(`construction_progress`)は、必要な作業量のうち調達済みの割合である。作業量の決まり方は[12_建物](12_建物.md)の建設コスト、造成工事は[造成](34_造成.md)による。パスの作業量は延長に比例するので、1本で引いても細切れに引いても費用の合計は同じである。

## 建物の工期

建物の現場が1日に進められる作業量(施工能力)は、延床面積が大きいほど大きいが、比例はしない。標準の工期は必要な作業量を施工能力で割った日数で、階数や地形による増分は作業量にだけ入るので、同じ延床面積で作業量が2倍なら工期も2倍になる。造成工事は、範囲の面積を延床面積とみなして同じ考え方で工期を決める。

## パスの工期

パスの標準の工期は延長や幅によらず、面積あたりの作業量の濃さだけで決まるので、道路を分割しても工期は縮まない。長い道路ほど毎エポックの需要が大きくなり、実際の工期は建設業の供給力で決まる。高架・地下・造成で作業量が増えても、工期の伸びは費用の伸びより小さい。

## 調達と完成

標準の工期は、毎エポック必要な分を満額調達できたときの値である。工事は予算・資金・市場の供給の範囲で実際に調達できた分だけ進み、調達した量が必要な量に達すると完成する。建設中の建物・パスは、建設スピード(`utilization_target`。上限は `MAX_CONSTRUCTION_SPEED_FACTOR`)を上げると1エポックの発注量が増える。
