# 建設作業量と施工能力

建物・道路・線路・造成の工事は、共通の建設サービスを使って進む。都市の建設業や輸入がこのサービスを供給する。

## 作業量・施工能力・進捗

| 用語 | 意味 |
| --- | --- |
| 作業量 | 工事を終えるために必要な建設サービスの総量 |
| 施工能力 | 現場で工事を進められる速さ |
| 進捗(`construction_progress`) | 工事がどの程度終わっているか |

作業量は物理的な体積そのものではなく、異なる工事を共通に扱うための単位である。規模の大きな建物や、高架・地下・斜面など施工の難しい場所では工事の負担が増える。

## 工期と供給力

工期の見積もりは、必要な建設サービスを調達できることを前提とする。実際には資金や市の予算、建設業の供給力が制約になるため、計画どおりの速さで進むとは限らない。

多くの工事を同時に進めると、都市全体で建設サービスが不足することもある。工事を進めるには、資金の確保と施工を支える産業の両方が必要である([予算管理](22_予算管理.md)・[生産活動](9_生産活動.md))。
