    地面アセットのメッシュ生成（MODEL_MODULAR_GROUND）

    概要

    MODEL_MODULAR_GROUND は畑や庭など、建物の概念がない地面アセットに適用するモデルタイプである。 建物本体（壁・角・屋根・塔屋・エントランス）は一切描画せず、フェンス・地面パネル・タイルオブジェクトを 土地区画の形状に沿って配置する。

    共通仕様（パーツの命名規則・外観バリアントの選択・フォールバック階層・フェンスの配置と地形追従）は F_建物メッシュの生成 に記述する。本ドキュメントはその差分を記述する。

    実装は ModularBuildingMeshBuilder（敷地装飾の生成は ModularBodyBuilder の共通処理）。

    1. 描画対象

    MODEL_MODULAR_GROUND の場合、以下のパーツのみを描画する。

    • フェンス（fence-w* / fence-c*）
    • タイルオブジェクト（tile）— パーツが存在する場合のみ
    • 地面パネル（floor）— マスターの draw_floor=yes かつ floor パーツが解決できる場合のみ（F_建物メッシュの生成 §8.1）

    建物本体の壁・角・屋根・塔屋は一切描画しない。

    なお、外観バリアントの閾値フォルダに mid-w1 が存在しない場合、他のモデルタイプは白い箱に フォールバックする（F_建物メッシュの生成 §4.3）が、MODEL_MODULAR_GROUND は suffix を 0 として フェンス・地面パネル・タイルオブジェクトの描画を継続する。建物本体を持たないため mid-w1 の有無が 描画可否の判断材料にならないからである。

    2. フェンスと地面パネルの形状

    フェンスと地面パネルは、建物の底面ポリゴンではなく、該当建物が属する土地区画のポリゴン形状に基づいて生成する。 土地区画のポリゴンは BuildingSummary.parcel_id から ParcelManager を介して取得する。

    3. タイルオブジェクトの配置

    tile パーツ（Models/Buildings/{prefix}/{suffix}/tile）が存在する場合、底面エリアにタイル状に敷き詰める。パーツが存在しない場合は無視し、フェンス（と、draw_floor=yes なら地面パネル）のみを描画する。

    配置アルゴリズム:

    1. 底面エリアのポリゴン（フェンス・地面パネルと同じく土地区画ポリゴン）のAABBを計算する
    2. tile パーツのメッシュバウンディングボックスからサイズ（X, Z）を取得する
    3. AABBの端から、タイルサイズを1ステップとしてグリッド上に順次並べる（スケール変更なし）
    4. 各グリッド位置について、タイルの中心点がポリゴン内側にある場合のみ配置する（ray casting による内外判定）
    5. これにより、台形や三角形など任意の形状のポリゴンに対応できる

    配置は平行移動だけで行い、メッシュバウンディングボックスの最小コーナーをグリッドのセル隅 （高さは地面）に合わせる。したがってタイルパーツの原点位置は結果に影響せず、逆に底面を 地中へ延ばすとその延長ぶんモデル全体が浮く（I_建物パーツ作成マニュアル §4.10）。

    グリッドは「タイルが丸ごとAABBに収まる位置」にしか進めないため、AABBがタイル1枚分に 満たない土地区画にはタイルが1枚も置かれない。タイルパーツの著作寸法は、その施設が建ちうる 最小の区画に1枚は載る大きさに抑える必要がある。

    配置順序と地形追従:

    タイルはまず平面上（Y座標を統一して）に配置し、すべて並べ終わった後に、Dynamicセルの場合のみ地形に合わせてメッシュを変形する。配置時に個別に地形高さを適用するのではなく、平面上に並べてから全体を変形する（F_建物メッシュの生成 §9.4 参照）。

    4. コライダー

    クリック判定用のコライダーは、建物の底面ポリゴンではなく土地区画のポリゴン形状で生成する。 高さは floorHeight（F_建物メッシュの生成 §14）とする。
