    港湾岸壁のメッシュ生成（MODEL_PORT）

    概要

    MODEL_PORT は、海岸土地区画（PARCEL_SHORE）に立地する港の建物に適用するモデルタイプである。対象はバルク港401・タンカー埠頭402・コンテナ埠頭403・漁港1001・客船ターミナル1068・石油パイプライン受入基地1073。

    港は 水際（船が着く線）と、その陸側の ヤード（荷役の地面）でできている。水際には荷役設備（port_crane）を並べ、区画の辺0（道路側）には施設モジュール（port_building。ゲートと建物）を置き、その間の空きにその港が扱うヤードの荷を置く（コンテナ埠頭はコンテナ port_container{n} を段積みし、バルク港の野積みの山・タンカー埠頭の油槽・漁港の魚箱のようなそれ以外の荷は port_cargo{n} を並べる）。水際とヤードの決め方は海岸の種類で2通りあり、そこから先の配置の規則（§5）は共通である。

    • 天然の海岸: 区画の中の水際の両端を結ぶ弦を海側へ一定距離だけ平行に移した直線で底面ポリゴンをカットし、厚みのある板（岸壁スラブ）を押し出す（§2〜§4）。水際はカット直線上の辺、ヤードはスラブの範囲。
    • 埋立地の岸壁: 区画が埋立地の上にあってその岸壁に面している港は、水際を埋立地の岸壁に任せてスラブを作らない（§8）。水際は面している岸壁区間、ヤードは区画の陸の部分。

    底面形状は SHAPE_FULL（C_建物形状）、すなわち土地区画ポリゴンそのものである。接地高は建物中心位置の地形標高で、コンクリート基盤（F_建物メッシュの生成 §8.2）は生成しない。

    visual_variant（1）は他の建物と同じく外観バリアントの閾値フォルダ（F_建物メッシュの生成 §4）を選び、visual_variant2 はヤードの荷の配置の乱数の種に使う。visual_variant3 は使わない。

    実装は PortBuildingMeshBuilder（組み立て）と PortLayout（配置計画）。水際は入港船の接岸位置（V_環境演出の乗り物 §V.5）にも使い、PortBuildingMeshBuilder.ResolveWorldWaterlines が建物を描かずに同じ規則でワールド座標の水際を返す。

    1. 入力データ

    • 底面ポリゴン — 建物 Agent の polygon。SHAPE_FULL なので土地区画のポリゴンと一致し、頂点0→1の辺が道路側（C_建物形状）。海岸土地区画のポリゴンは海岸線でクリップされず元の形状のまま保持される（B_土地形状 B.5）ため、海岸線を跨いで海側にはみ出した形状（矩形など）である。
    • 海岸線ポリゴン — GET /api/v1/terrain/coastline で取得する、陸地の境界を表す GeoJSON ライクなポリゴン（ワールド座標、マップ中心が原点。詳細はD_地形形状）。区画の中の水際の両端の特定と、弦に対する海側方向の判定に用いる。海岸線は埋立の完了で広がるので、フロントエンドは session:reload のたびに取り直し、陸地領域は取り直した版ごとに作り直す。
    • 埋立地の岸壁区間 — GET /api/v1/terrain/reclaimed-lands の quays（§8）。
    • パーツ — 通常モデル（無印）の寸法で配置を決め（§5）、描画LODに応じたモデル（§9）を置く。

    2. 水際の両端と海側方向の特定

    底面ポリゴンの外周に区画の中の水際（区画の陸の部分と海の部分の境目）が届く点を求め、そのうち最も離れた2点を岸壁の左端 A・右端 B とする。陸地領域は、海岸線のリング集合（外周と穴を区別しない）を偶奇合成（XOR）したものとする。A・B を結んだ線分を「弦」と呼び、陸地に含まれない底面頂点が弦に対して平均的に存在する側を「海側」とする。A→B は海を左手に見る向きに正規化する。

    水際が外周に届く点は次のように求める。

    • 区画の中に陸（底面と陸地領域の交わり。面積 1m² 以上）がある場合 — その陸の部分の頂点のうち底面外周の上にあり、半径 0.5m の円の中の区画の部分に陸と海がそれぞれ 1% 以上あるものを採る。隣の埋立地（D_地形形状）が区画の辺や角に外から接していても、そこでは海岸線が外周に触れるだけで区画の中に陸が無いので採らない。底面外周と海岸線の交点をそのまま使うと、隣の埋立地の辺の上の点が選ばれて弦が斜めになるためである。埋立の発注検証が許すごくわずかな重なり（0.01m² 以内）で区画の中にできる細い陸も、円の中の割合で除かれる。
    • 区画の中に陸が無い場合（区画が海岸線に外から接しているだけ） — 底面外周と海岸線の交わりの点をそのまま使う。

    水際の端が2点未満（底面が全域陸または全域海）の場合・海側の底面頂点が無い場合・幾何演算に失敗した場合は、カットせず底面ポリゴンをそのまま岸壁フットプリントとして使う（水際は無く、荷役設備とヤードの荷は置かれない）。

    3. 張り出しと直線カット

    A・B を左右とも同じ距離だけ海側方向（弦の法線）へ突き出した2点 A'・B' を結ぶ直線で底面ポリゴンをカットし、陸側を残した形状が岸壁フットプリントとなる。岸壁の海側境界は海岸線の曲線をなぞらず、常に弦と平行な1本の直線になる。

    張り出し距離 = min(QUAY_PROTRUSION, 奥行き上限)
    • QUAY_PROTRUSION — 20m。水際の両端（海岸線の上）から海へ張り出す距離。
    • 奥行き上限 — 弦から、底面の海側最遠頂点までの距離。区画の海側の余白がこれより浅いと、岸壁は区画の海側の辺まで張り出して頭打ちになる。

    カットは底面ポリゴンとの交差なので、岸壁は常に土地区画の範囲内に収まる。区画の海の部分のうち岸壁より先は水面のまま残る（地面パネルも描かない。§7）。

    4. 岸壁スラブ（厚みのある板）の生成

    岸壁フットプリントを上下に押し出して、厚みのあるスラブを作る。

    • 上面 — 岸壁フットプリントを高さ H = 2m（海面基準の固定値。QUAY_TOP_HEIGHT）の水平ポリゴンとして配置する。三角形分割は耳切り法（ear clipping）を用い、失敗時はファン型にフォールバックする（F1_モジュラー建物のメッシュ生成 §1 と同じ）。
    • 側面 — 岸壁フットプリントの各辺について、上面（高さ H）から下面まで垂直な四角形を張る。
    • 下面 — 各頂点の水平位置（XZ座標）での地形標高（＝海底の高さ）を Utils.GetGroundHeight で取得し（F_建物メッシュの生成 §9.4 と同じ取得経路）、その高さまでスラブを下げる。上面より上には来ないようクランプする。

    スラブは陸の部分も覆うので、ヤードの地面の高さは max(地形, H) になる（地形が H より高い所ではスラブは地中に隠れる）。生成する全頂点は center_point 基準の相対座標とする（F_建物メッシュの生成 §2.4 と同じ）。

    5. 陸側の配置（PortLayout）

    配置は PortLayout.Create が決める純データで、通常モデル（無印）の寸法と入力の形だけから求める。接写・遠景へ切り替えても建物や荷の位置は変わらない。

    5.1 施設モジュール（port_building）

    区画の辺0（道路側）の中点に、モデルの道路側の面（ローカル +X の端＝Blender −X）を辺0に揃えて1つ置く。向きは既成建物と同じ（F3_既成建物のメッシュ生成。ローカル +Z が辺0の向き）。占有矩形が区画に収まらなければ置かない。

    置き方は区画と通常モデルの寸法だけで決め、海岸線・埋立地に依存させない。道路への開口の索引（§10）が建物データの登録時に同じ置き方を求めるためである。高さは辺0の中点の地面（天然の海岸ではスラブを含む）で、海面+2m（QUAY_TOP_HEIGHT）より下には置かない（開口の舗装高の下限と揃える）。

    5.2 荷役設備（port_crane）

    水際ごとに等間隔に並べる。

    • 原点 — モデル原点が水際の線上、高さは水際の上面（天然の海岸は H、埋立地は天端）。
    • 向き — ローカル +Z が海側（＝ローカル X が水際に沿う）。スケールはしない（実寸）。
    • 基数と間隔 — 設置間隔 = パーツ実寸幅 × 4.5（PortLayout.CRANE_SPACING_RATIO）。1本の水際の基数 = floor(水際の長さ ÷ 設置間隔)（最低1基）。水際全体に等間隔・両端の余白が等しくなるよう置き、水際の順に置いて合計が 8 基（MAX_CRANE_COUNT）に達したら打ち切る。水際の長さがパーツ1基の幅に満たなければ置かない。
    • 施設モジュールとの干渉 — 占有矩形が施設モジュールに掛かる荷役設備は置かない（浅い区画でモジュールと水際が近いとき、脚が建物を貫かないため。モジュールは開口と一体なので動かさない）。

    ブームが海側へ張り出してもコライダー（§7）には含めない。

    5.3 ヤードの荷（port_container / port_cargo）

    荷役設備が1基以上ある港で、荷のパーツがあるときだけ、ヤードの空きに荷を置く。クレーンと建物の間の荷役の空間を埋めるもので、荷役設備の無い1073には置かない。荷は港が扱う貨物の姿に合わせて港ごとに違い（§6）、置き方は2通りある。

    置き方 パーツ 置き場（格子の1区画） ブロック 段
    段積み port_container{n}（20ft コンテナ 6.06×2.44×2.59m） コンテナの寸法、隙間 0.35m 6列×8個 1〜4段（段の間隔 2.61m）
    並べる port_cargo{n}（野積みの山・油槽など） 全種類の通常モデルの外接箱の和を原点について対称に広げた矩形、隙間 1m コンテナのブロック（約51×17m）に近い個数・列数 積まない
    • 格子 — 主な水際（最長）に長手を揃え、水際から「荷役設備の陸側の端 + 車路 6m（APRON_LANE）」だけ陸側から奥へ、ブロックと 8m の通路で区切る。格子の起点は主な水際の始点から水際に沿ってヤードの縁の余白（1.5m）だけ内側にずらす（始点はヤードの縁にあるので、ずらさないと端の置き場が縁の余白に掛かって必ず欠け、小さな港で荷が無くなる）。
    • 置かない所 — ヤードの縁から 1.5m 以内、各水際のクレーン帯（水際から荷役設備の陸側の端 + 6m）、施設モジュールの周り 3m、ゲート（辺0の中点）から内向きに伸びる幅 12m の構内道路（DRIVE_WIDTH）、塔屋の周り 3m。
    • 置く量 — 置き場ごとに、格子番号と visual_variant2 から引いた乱数で 8 割に置く。乱数は置き場ごとに独立なので、他の置き場の有無や列挙の順に影響されない。1つの港で 800 山まで。
    • 種類 — コンテナは段ごとの色を色違いのパーツから置き場ごとに選ぶ。並べる荷はブロックの1列で同じ種類にする（野積みの山や油槽は品目ごとにまとめて並べるのが普通で、置き場ごとに変えると品目がまだらに混ざるため）。
    • 向き — パーツのローカル +Z を主な水際に沿わせる。ローカル X の正負が海側・陸側のどちらになるかは決めないので、並べる荷は向きで意味の変わる形にしない。
    • 高さ — 山の底は置き場の4隅の地面の最も低い高さ（斜面で浮かないよう高い側を少し沈める）。

    5.4 塔屋（roofprop）

    パーツ roofprop がある場合、ヤードの頂点の平均の位置に、水際に沿う向き（海を左手に見る向き）で1つ置く。高さはその位置の地面。石油パイプライン受入基地1073は、この配置で2基のタンク・ポンプ棟・受入配管を1組置く（設備は22×18m、高さ7.9m。接写版は梯子・タンクの手すり・弁を持つ）。ヤードの荷は塔屋の周り 3m を避ける。

    6. パーツの解決

    パーツは a{variant} の閾値フォルダから visual_variant で走査して解決する（F_建物メッシュの生成 §4）。ヤードの荷と、マテリアル参照の floor・ceil は a{variant} → b{bd_type} の順に探す。ヤードの荷はフォルダごとに port_cargo1, 2, … → port_container1, 2, … の順に1から連番で探し、最初に見つかった1組だけを使う（port_cargo なら並べ、port_container なら段積みする）。荷は港が扱う貨物の姿なので港ごとに違い、各港の a{variant} に置く。b128（貨物を扱う港の bd_type）には置かない（置くと荷を持たない港へフォールバックして、別の港の荷が積まれる）。現行の配置は次のとおり。

    バリアント port_crane（水際） port_building（道路側） ヤードの荷
    401 バルク港 引込みクレーン（グラブ） 計量台つきゲート・事務所・サイロ2基・ばら積み倉庫 野積みの山（鉄鉱石・石炭・石灰石・木材チップ。底面 5.2×10m・高さ2.1〜2.5m の細長い山）。穀物・セメントはモジュールのサイロ、濡らせない荷はばら積み倉庫に入る
    402 タンカー埠頭 ローディングアーム3基の荷役台 ゲート・制御室・ポンプ場・浮き屋根の油槽と防油堤・配管の橋 防油堤（10m角）で囲んだ油槽（浮き屋根の原油タンク・固定屋根の製品タンク・化学品の小型タンク2基・LPGの球形タンク）

    1073 石油パイプライン受入基地 なし なし（塔屋のタンク群） なし（荷役設備が無い）

    7. マテリアル・敷地の地面パネル・コライダー

    • マテリアル — スラブの上面は floor、側面・下面は ceil のマテリアルを流用する（a{variant} → b{bd_type} の順。無ければ建物全体のデフォルトマテリアル）。上面に floor を使うのは、敷地の地面パネルと同一マテリアルにして陸側の敷地と岸壁を一続きの床に見せるためである。
    • 敷地の地面パネル — マスターの draw_floor が有効な建物では、ヤードに地面パネルを描く（floor パーツを a{variant} → b{bd_type} → common で解決。モジュラー・既成建物と共通の敷地装飾処理）。区画の海の部分（岸壁より先）には描かない。ヤードは海岸線をまたいで高さが変わる（埋立地の天端と元の陸、スラブの下の浜）ので、距離によらず地形に追従させる。
    • コライダー — クリック判定のため、ヤードを上面の高さ（天然の海岸は H、埋立地は天端）まで押し出した形状の MeshCollider を生成する（構成は F_建物メッシュの生成 §13 に準じる）。

    8. 埋立地の岸壁に面する港

    埋立地の岸壁は、埋立地の側が天端と垂直の面で描く（D_地形形状）。港の区画が埋立地の上にあってその岸壁に面しているときは、水際を埋立地の岸壁に任せ、§2〜§4 の直線カットとスラブを作らない。水際は面している岸壁区間（区間ごとの外向き法線と、その埋立地の天端の高さ）、ヤードは区画の陸の部分（底面と陸地領域の交わりのうち最大の多角形。陸地が取れなければ底面）で、§5 の配置と §7 の地面パネル・コライダーは天然の海岸と同じ規則で作る。

    • 面しているかの判定 — 底面（SHAPE_FULL なので区画と同じ形）を 0.1m 膨らませた範囲と、各埋立地の岸壁区間（GET /api/v1/terrain/reclaimed-lands の quays。フロントエンドでは求め直さない）の交わりをとる。範囲の縁で途切れた端は区画の外へ張り出した 0.1m を削る。残りが 1m より長く、かつ区画がその岸壁の陸側にある区間があれば「面している」とする。陸側かどうかは、残りの区間から内向き（外向き法線の逆。埋立地の中）に QUAY_PROBE_DISTANCE（0.5m）の帯をとり、区画がその半分以上を覆うかで決める。
    • 面している: 区画が岸壁を横切る場合と、区画の海側の辺が岸壁に重なる場合（どちらも埋立地の上に引いた港）。
    • 面していない: 既存の港の隣を埋め立て、埋立地の辺が港の区画の辺に接する場合。その辺は岸壁になるが、外向き法線は港の水面を向き、区画は岸壁の海側にある。港は §2〜§4 のスラブのままで、弦は §2 の規則で区画の中の水際から取るので斜めにならない。角や頂点で点接触するだけの岸壁も含めない。
    • パーツが1つも解決できずメッシュが空になるときは、底面の簡易な箱にする。

    埋立で港自身の version は変わらないので、Unity は埋立地の中身が変わったときに表示中の港を作り直す（再利用キーに埋立地の版を混ぜる。遠景も同じ）。

    9. 描画LOD

    • 接写（Close） — 同じ配置で、各パーツの {パーツ名}_close を優先して解決する（F_建物メッシュの生成 §3.5）。コンテナは数が多いので接写版を持たない。並べる荷は _close があればそれを使う（402の油槽）。
    • 遠景（Far） — 区画は海へはみ出しているので、底面を押し出した箱（他の建物の遠景）は使わず、同じ配置でスラブ・{パーツ名}_far・コンテナの山ごとの箱を組み立てる。_far が無いパーツは描かない（漁港の魚箱のような小物の荷は遠景で描かない）。地面パネルは描かない（既成建物と同じ）。遠景は共有材質1色で描かれる。
    • *-prebuilt_far（F_建物メッシュの生成）を持つ港はそちらが優先される。現行では1073が、同じ設備と高さ2mの簡易基壇を top-prebuilt_far で表す（動的な岸壁全体は省く）。

    _close・_far のパーツは通常と原点・水平範囲・天端を揃える（I_建物パーツ作成マニュアル §4.8）。

    10. 道路への開口（間口）

    施設モジュールのモデル内の road_access_* マーカー（道路間口マーカー）を、§5.1 と同じ置き方で建物中心基準へ移したものが港の開口になる（F_建物メッシュの生成 §16）。開口の舗装高は開口の地面に追従させ、海面+2m を下限にする（施設モジュールの接地と同じ）。モジュールを置けない区画・マーカーの無いモジュールは開口を返さない。
