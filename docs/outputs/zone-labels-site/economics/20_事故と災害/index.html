    20. 事故と災害

    本章では、ゲーム内で発生する事故・災害イベントと、それに伴う市民への被害について説明する。

    20.1 建物倒壊と市民被害

    建物が老朽化等により倒壊（STATUS_COLLAPSED）した場合、その建物に関係する市民に死亡被害が発生する。建物の老朽化・倒壊の仕組みの詳細は12_建物の「12.8 倒壊」を参照。倒壊による市民の死亡は、エポックの処理の中で自然死とは独立して処理される。 倒壊した建物エージェントに対し、以下の2種類の市民が死亡（DBから削除）する。

    対象 条件
    居住者 倒壊した建物に入居していた世帯（agent.building_agent_id == 倒壊建物ID）に所属する全市民
    従業員 倒壊した建物に就労していた市民（citizen.employer_agent_id == 倒壊建物ID）
    なお、パス（高架道路・橋梁など）の倒壊については市民の直接死亡は発生しない。

    20.2 火災

    都市内の建物には、エポックごとに一定の確率で火災が発生する。火災は そのエポックの中で発生から鎮火（または焼失）まで完結 する。

    発生と被害度

    各建物は毎エポック、ランダムに出火する可能性がある（不燃の施設を除く）。出火した建物は初期被害度（0.0で固定）からスタートする（この時点でも失火としてカウントされる）。消火活動（消防サービスの調達）とランダムなばらつき具合によって被害度は拡大する。 完璧に消火された場合は被害度 0.0 に抑えられるが、消火活動が不十分な場合は被害度が最大 1.0（全焼・全損）まで拡大する。 ただし被害度の上限は建物の 火災耐性（建物種別ごとのマスターデータ。無防備な木造を 0、不燃を 1 とする 0〜1 の値）で頭打ちになる。小屋のような無防備な木造は消火に失敗すると全焼しうるが、RC 造の高層ビルは出火しても局所的な失火で収まり、構造被害を受けない。出火のしやすさ自体は構造によらず一律で、構造の差は「燃えたあとどこまで広がるか」に現れる。 火災として判定される閾値以下の場合は建物の耐久度には影響しないが、この閾値を超えると超過分に応じて構造ダメージ（耐久度 durability の減衰）が発生し、被害度 1.0 で耐久度が 0（全焼）となる。

    消防サービスと消防署

    消防は、消防署（経済主体）が供給する「消防サービス」という商品（8_商品市場の工業原料の一種）として表現される。火災が発生した建物は、一律 1.0 の消防サービス需要を持ち、他の物資と同じように商品市場を通じて最寄りの消防署から調達する。

    この仕組みにより、消防の効き方は都市の構造から自然に決まる。

    • 火災現場の近くに稼働中の消防署があれば、消防サービスが十分に調達でき被害は小さい（失火に抑えられる）。
    • 消防署が遠い、あるいは途中の道路が渋滞していると、消防サービスがほとんど届かず建物は焼失する（遠方からの調達は実効的に大きく減衰する。8_商品市場の「距離減衰」を参照）。
    • 火災が多発する地区では消防署の供給能力が逼迫し、消防サービスが「売り切れ」て充足できない火災が生じる。
    • 需要のない場所に建てた消防署はほとんど稼働しない。

    延焼

    出火した建物が十分に消火されず、最終被害度が一定の閾値を超えた（火災状態になった）場合、周囲の建物へ延焼する。延焼のしやすさは現実の市街地火災と同じく、建物同士の隙間の狭さと受け側の構造で決まる。

    • 延焼確率は、出火元の被害度に比例し、出火元と隣の建物の底面同士の隙間距離に応じて指数的に減衰する。隙間がほぼ無い密集地では高確率で燃え移り、10m ほど離れると大きく下がる。建蔽率の高い建物ほど底面が敷地いっぱいに広がって隣との隙間が縮むため、建蔽率の高い地区ほど延焼しやすい。
    • 受け側の火災耐性が高いほど延焼を受けにくく、受けても被害は小さい。木造密集地は燃え広がり、RC 造の街区は延焼の防波堤になる。
    • 延焼した建物は消防サービスを必要とせず、出火元の最終被害度以下でランダムに被害度が決定する。延焼先でも被害度が閾値を超えた場合のみ耐久度ダメージが発生する。
    • 延焼先が本格的な火災になった場合、そこからさらに周囲へ燃え広がる（二次延焼）。段数には上限があり、同じ建物が二度燃えることはない。木造密集地では 1 件の出火が大火に発展しうるので、消防署の配置と街区の不燃化が防災の手段になる。

    倒壊・市民被害との関係

    火災は建物の耐久度を削るだけで、倒壊や市民の死亡を直接引き起こすことはしない。火災で耐久度が大きく下がった（特に全焼した）建物は、通常の倒壊判定によって倒壊し、その結果として「20.1 建物倒壊と市民被害」と同じ仕組みで居住者・従業員に被害が及ぶ。これにより、火災による死亡も倒壊による事故死として一元的に集計される。

    観測

    火災が発生した建物には、そのエポックの間アラートフラグが立ち、GET /api/v1/alerts から取得できる。最終被害度が閾値以下の場合は「失火（小火）」、閾値を超える深刻な被害になった場合は「火災」としてアラートが区別される。アラートは次のエポックでクリアされる。

    20.3 交通事故

    エポック処理のたびに、稼働中の道路（パス）に対して交通事故が確率的に発生する。事故は「車を1台ずつシミュレートした結果」ではなく、道路の交通状況を表す数値から確率的に判定される近似シミュレーションである。

    事故の起きやすさ

    ある道路で事故が起きる確率は、主に次の2つの要因の掛け合わせで決まる。

    要素 効果
    制限速度と道路形状の乖離 道路には、その形状（カーブの曲線半径、勾配）から物理的に無理なく出せる通過速度がある（3_道路網の線形制約を参照）。プレイヤーが設定した制限速度がこの形状由来の速度を大きく上回るほど、つまり「形状に対して制限速度を高く設定しすぎている」ほど事故が起きやすい。形状に見合った制限速度の道路では事故はほとんど起きない。
    交通量（キャパシティ使用率） その道路の交通量がキャパシティに対して多いほど、事故確率は線形に増加する。交通量がゼロに近い道路では事故は起きにくい。

    両者は掛け合わされるため、「制限速度が道路形状に見合っておらず、かつ交通量が多い」道路がもっとも危険となる。プレイヤーは、急カーブの多い道路や短い道路の制限速度を形状に合わせて適切に下げることで、事故を減らすことができる。

    事故の結果

    • 事故が発生した道路には、そのエポックの間アラートフラグ（交通事故）が立ち、GET /api/v1/alerts から取得できる。アラートは次のエポックでクリアされる。
    • 事故が起きると市民が死亡する。死亡する市民は都市全体からランダムに選ばれ（移動中の市民が事故に遭うイメージ）、特定の道路や地区の市民に限定されない。1件の事故につき基本1名、まれに複数名が死亡する。
    • 死亡した市民は、建物倒壊・火災による事故死とともに事故死総数として集計される。さらに、原因別(交通事故・建物倒壊)の内訳も別々に記録され、事故統計(後述)で原因別の推移を確認できる。

    20.4 犯罪（事件）

    火災と同じ枠組みで、都市内の建物にはエポックごとに犯罪（事件）が発生する。犯罪も そのエポックの中で発生から被害確定まで完結 する。ただし火災と犯罪では「建物の数」と「件数」の関係が逆になっている。火災は建物ごとの確率で出火するため、建物が増えれば火災も増える。これに対し犯罪は 都市全体の件数が先に治安の悪さから決まり、その後でどの建物が巻き込まれるかが決まる ため、建物をいくら増やしても犯罪の総件数は増えない。治安がどのように決まるかは19_環境の「19.4 治安」を参照。

    発生と被害度

    各エポックの犯罪総件数は、都市の治安の悪さ（治安ヒートマップの合計）から決まる。治安が悪い都市ほど件数が多くなるが、建物の数には依存しない。決まった件数だけ「犯罪が起きる場所」が治安の悪い地域に偏って抽選され、各場所の最寄りの建物が犯罪現場となる。したがって犯罪は治安の悪い地域に集中する。同じ建物が複数の犯罪に巻き込まれることもある。犯罪が割り当てられた建物は被害度 0.0 からスタートし、警察（治安維持サービス）が十分に機能すれば被害度は 0.0 に抑えられるが、警察が間に合わなかった割合に応じて被害度は最大 1.0 まで拡大する。

    治安維持サービスと警察署

    治安維持は、警察署（経済主体）が供給する「治安維持サービス」という商品（8_商品市場の工業原料の一種）として表現される。犯罪が発生した建物は一律 1.0 の治安維持サービス需要を持ち、他の物資と同じように商品市場を通じて最寄りの警察署から調達する。

    この仕組みにより、警察の効き方は都市の構造から自然に決まる。

    • 現場の近くに稼働中の警察署があれば、治安維持サービスが十分に調達でき被害は小さい。
    • 警察署が遠い、あるいは途中の道路が渋滞していると、治安維持サービスがほとんど届かず被害が大きくなる（遠方からの調達は実効的に大きく減衰する。8_商品市場の「距離減衰」を参照）。
    • 犯罪が多発する地区では警察署の供給能力が逼迫し、治安維持サービスが「売り切れ」て充足できない犯罪が生じる。
    • 需要のない場所に建てた警察署はほとんど稼働しない。

    倒壊・市民被害との関係

    火災と異なり、犯罪は建物の耐久度（durability）を削らず、倒壊や市民の死亡を直接引き起こすことはない。被害度はあくまで犯罪の深刻さを表す指標として扱われ、後述のアラートと統計に用いられる。治安の悪化そのものは19_環境の住環境マルチプライヤーを通じて、世帯の転居行動などに影響する。

    観測

    犯罪が発生した建物には、そのエポックの間アラートフラグが立ち、GET /api/v1/alerts から取得できる。最終被害度が閾値以下の場合は「犯罪の兆候」、閾値を超える深刻な被害になった場合は「犯罪」としてアラートが区別される。アラートは次のエポックでクリアされる。閾値未満（犯罪の兆候）と閾値超（犯罪）の発生件数はそれぞれ別々にエポックごとの履歴として集計される。

    20.5 事故統計

    事故・災害に関する統計は GET /api/v1/stats/accidents から取得できる。以下の情報が得られる。

    過去推移(エポックごとの履歴、3種)

    情報 内容
    事故死者数の推移 過去のエポックごとの事故死者数。交通事故死と倒壊死の原因別内訳を持ち、両者の和が事故死総数に等しい。
    火災発生件数の推移 過去のエポックごとの火災発生件数(本格火災になった建物数)。失火(小火)は含まない。
    交通事故件数の推移 過去のエポックごとの交通事故発生件数(事故が発生した道路数)。

    発生件数の推移は死者数とは別軸の指標である。火災は必ずしも死者を出すとは限らず(耐久度を削るだけで倒壊に至らない場合がある)、交通事故も死者数とは独立に件数が計上される。これらの件数も死者数と同様にエポックごとの履歴として蓄積される。

    直近エポックの発生一覧(3種)

    情報 内容
    交通事故一覧 直近エポックに交通事故が発生した道路の一覧(道路名・種類)。
    火災一覧 直近エポックに火災が発生した建物の一覧(建物名・種類)。
    倒壊一覧 直近エポックに倒壊した建物・高架道路等の一覧(対象名・死者数)。

    交通事故の一覧・火災の一覧は、それぞれ対応するアラートフラグ(ALERT_PATH_ACCIDENT / ALERT_AGENT_ON_FIRE)が立っている対象から構築されるため、当エポックで発生したもののみが表示される。倒壊一覧は建物のステータス遷移に基づくイベント記録から構築される。
