    既成建物のメッシュ生成（MODEL_PREBUILT）

    概要

    洋上設備の原点は海上区画の基準標高へ配置する。水中脚は固定長のモデルで、海底へ追従しない。

    通常の建物とは全く異なる形状（電波塔、オブジェ、銅像、観覧車など）や、モジュラー組み立てに向かない完成済みモデルの建物に適用する。 base-prebuilt / mid-prebuilt / top-prebuilt の3種類のパーツを下から積み上げて組み立てる。

    共通仕様（パーツの命名規則・外観バリアントの選択・地面パネル・フェンス）は F_建物メッシュの生成 に記述する。本ドキュメントはその差分を記述する。 パーツの制作規格は I_建物パーツ作成マニュアル を参照。

    接地高は建物中心位置の地形標高であり、コンクリート基盤（F_建物メッシュの生成 §8.2）は生成しない。

    観光名所（landmark > 0）もこの方式で描画する。名所は一点物なのでパーツフォルダだけが名所ごとに分かれ （landmark-{model_prefix}。F_建物メッシュの生成 §3.2）、積み上げ規則は通常の既成建物と変わらない。

    実装は PreBuiltBuildingMeshBuilder。

    遠景モデル

    全建物のFarは、共通のprefix解決で選ぶフォルダの閾値0から base/mid/top-prebuilt_far を探す。同じ階高・原点で既成パーツとして積み上げ、敷地装飾を省略する。通常の生成方式がモジュラーでも、この形式で遠景を提供できる。base・mid・topの一部だけでも有効である。

    条件 遠景表示
    遠景用prebuiltあり 既成パーツを組み立てる
    マッシュアップの共通遠景なし 棟ごとの遠景パーツを通常と同じ配置で組み立てる。描ける棟が無ければ簡易形状
    港の共通遠景なし 岸壁と遠景パーツを通常と同じ配置で組み立てる
    露天掘り 設備を描かず、穴は地形で表す
    その他の遠景モデルなし フットプリントを階数×階高で押し出す。地面用途は0.3m板
    工事・解体・倒壊 状態ごとの簡易形状。工事・解体は1階分、倒壊は0.5階分

    名所も同じ経路を使い、landmark-{model_prefix}/0/ に通常・接写・遠景を置く。原点・配置寸法は制作規約に従う。棟と港の構成はマッシュアップ・港湾岸壁を参照する。

    貨物駅（404・1077〜1081）

    貨物PFの隣に建てる積み下ろしの施設（貨物輸送 33.6・33.7）は、敷地全体を1つの top-prebuilt で持つ。 底面は固定（resizable=no）で、国際貨物駅404・国境貨物駅1081が間口150m×奥行き60m、鉱石・石油の積込駅・取卸駅1077〜1080が120m×50m。 モデルの外形はマスターの default_width（間口）×default_height（奥行き）と一致させる。 道路側（前面の辺の外側。Blender -X）にトレーラーの出入口・ゲート・計量所と構内道路、貨物PF側（Blender +X）に荷役設備を置き、柵は貨物PF側を開けておく。

    バリアント 構成
    404 国際貨物駅 入構4車線のゲートと大屋根、3階建ての税関、トレーラー待機場、トラックドックとコンテナドックを持つ積み替え上屋、コンテナ置場とタイヤ式門型クレーン
    1081 国境貨物駅 6車線の検査場の大屋根とブース、税関庁舎、トレーラーが貫通するX線検査棟、レール式門型クレーンのコンテナ積み替え置場
    1077 鉱石積込駅 ダンプが通り抜ける荷下ろし棟、バケットエレベータと3基のサイロ、貨物PF側の中継塔、予備の貯鉱
    1078 鉱石取卸駅 貨物PF側の受入中継塔、トリッパ付きのアーチ屋根の貯鉱庫、トラックが下を通る積込ビン
    1079 石油積込駅 ローリーの荷下ろし場の大屋根、防油堤と3基の固定屋根タンク、ポンプ棟と配管ラック、消火用水槽
    1080 石油取卸駅 防油堤と2基の浮き屋根タンク、上から積む3車線のローリー出荷場、貨物PF側の受入ポンプ棟、蒸気回収装置
    • 舗装は底面全体を覆い、傾斜地で縁が浮かないよう下端を-1.5mまで延ばす。draw_floor の地面パネルは floor パーツの材質（404・1079〜1081はアスファルト、1077・1078は鉄粉で赤茶けた土間）で描く。
    • 遠景は top-prebuilt_far。水平範囲と天端を通常と揃え、舗装は薄い板、コンテナ置場は列ごとの塊、車両は省く。
    • 接写は top-prebuilt_close。bbox と配置（コンテナの段数と色、車両・設備の位置）を通常と揃え、建具・手すり・梯子・継手などの細部を足す。窓の縦桟と屋上の空調機、ドックの防舷材と作業灯、開口の防護柱、門型クレーンの点検歩廊と背かご付きの梯子、塔の点検床、アーチ屋根の肋骨、防油堤を越える階段、消火栓、車両の車輪と灯火、国境貨物駅1081の柵の忍び返しなど。
    • 原本は blender/buildings.blend。制作元は非公開制作ツールの build_freight_stations.py（形状は freight_stations.py）、実FBX・正規プレハブ・向き・接写・遠景の検証は import_freight.ps1。

    国境検問所（4）

    都市境界のすぐ外で、都市から延びる道路の突き当たりに置く建物（建物 12.13）は、敷地全体を a4/0 の1つの top-prebuilt で持つ。 底面は固定（resizable=no）の間口110m×奥行き70mで、マスターの default_width×default_height と一致させる。 道路は前面の辺（道路側。Blender -X）の中点に突き当たる。4車線（各3.5m）を3つのブース島で分けた幅18.5mの車路が4車線道路の車道をそのまま受け、中央棟の門をくぐって背面の辺（国外側。Blender +X）へ抜ける。 配置は自由配置で前面の辺を道路の端へ向けるか、道路の端に接する区画を作って建てる。

    • 中央棟: 車路をまたぐ幅20m・高さ9.5mの門（石の額縁）、赤地に金の縁と文字板の国名板、金と赤の国章、二段の大庇、屋上の国旗。国名板の文字は形状で再現せず、金の板で示す。
    • 翼棟と低層棟: 中央棟の左右に石張りの1階と3層の窓を持つ翼棟（玄関と庇・屋上設備）、両端に低層棟。
    • 都市側の前庭: 門の手前の審査ブースと閉じた遮断機、車路沿いの石の欄干と3灯の街灯、植え込み。
    • 国外側: 車路をまたぐ審査上屋とブース・遮断機、トラックの駐車場、芝生、車路だけを開けた国境の柵、車路を横切る黄色の国境線。
    • 舗装は底面全体を覆い、下端を-1.5mまで延ばす。draw_floor の地面パネルは floor パーツの材質（舗装と同じコンクリート）で描く。
    • 遠景は top-prebuilt_far。水平範囲と天端（国旗の竿の頂部）を通常と揃え、舗装と車路の板、棟と大庇の箱、審査上屋の屋根、国名板だけにする。接写専用のモデルは持たず、Closeは通常を使う。
    • 原本は blender/buildings.blend。制作元は非公開制作ツールの build_a4.py、実FBX・正規プレハブ・向き・遠景の検証は import_border_checkpoint.ps1。

    1. パーツの意味とスケール規則

    パーツ 個数 Yスケール XZスケール 用途
    base-prebuilt 0〜1 なし（実寸） なし（実寸） 1階部分（エントランス等）
    mid-prebuilt 0〜N回繰り返し 階高に合わせる なし（実寸） 繰り返しフロア1階分
    top-prebuilt 0〜1 なし（実寸） なし（実寸） 頂部。尖塔や、完成済みモデル丸ごと

    base / top は一切スケールされず、モデリング時の実寸のまま配置される。階高（height_per_floor）に合わせて縮めたり伸ばしたりはしないため、階高が 4m でもパーツが 15m で著作されていれば 15m の高さで描画される。

    mid だけは、積む枚数で建物の高さを調整する「詰めもの」の役割を持つため、高さが階高になるようY方向のみスケールされる（幅・奥行きは実寸のまま）。モジュラー建物の mid レベル（F_建物メッシュの生成 §6.3）と同じ規約である。

    スケールされないのはパーツの形状だけで、段の位置は階高グリッドのままである（§2）。base の実寸が階高より低ければ mid との間に隙間が空き、高ければ mid のパーツに埋もれる。これは仕様であり、プログラムは補正しない。

    2. 積み上げ規則

    • base と top はそれぞれ論理階数（floors）のうち 1階分を消費する。mid は残りの階数分繰り返される: midCount = max(0, floors − (baseあり?1) − (topあり?1))
    • 各パーツのY位置は 階高グリッド（消費した段数 × 階高）で決まる。パーツの著作高さは配置位置に影響しない。段を進めるのはファイルが存在するパーツだけなので、base / mid のファイルが無い建物では top が地面（y=0）に接地する。完成済みの建物モデルを top-prebuilt 1つだけで表現できる（例: 完成済み4階建て庁舎モデル、風力発電所）。
    • base / top が階高へ縮められないため、描画上の建物はシミュレーション上の高さ（floors × 階高）と一致しないことがあるが、これは仕様として許容する。コライダーは描画された実高さに合わせる（§4）。
    • 積み上げの天面を塞ぐパネルは生成しない。prebuilt パーツはモジュラーの壁パーツと違い完成された3Dモデルなので、上から見える面はモデル側で閉じておくこと。
    • 各パーツはモデルの原点（y=0）を各段の接続点（下端）に合わせて積まれる。XZはモデルの原点を建物原点（center_point）に重ねる。
    • 向きは底面ポリゴンの前面の辺（頂点0→頂点1。接道辺の規約）の角度から決まり、Unityメッシュのローカル +Z が前面の辺の方向（頂点0→1）、ローカル +X が辺の外側（道路側）を向くよう全パーツがY軸回転される（PreBuiltBuildingMeshBuilder.Generate の rotation。塔屋と同じ回転）。標準FBX（I_建物パーツ作成マニュアル §5.1設定A）で著作する場合、Blenderの −Y が前面の辺の方向、−X が道路側になる。壁・エントランスの「−Yが屋外」とは90°異なる。フットプリントの形状そのものはコライダーと敷地装飾のフォールバックにしか使われない＝パーツは区画に合わせて伸縮せず、向きだけ合わせて実寸で置かれる。
    • FBXが複数オブジェクトで構成されていても、全メッシュがノードのTransform込みで結合されて描画される。

    3. 敷地装飾（フェンス・タイル・地面パネル）

    土地区画の外周フェンス（fence-w / fence-c）・敷地内のタイル（tile）・地面パネル（floor）は、モジュラー建物と共通のロジックで配置される（F_建物メッシュの生成 §8.1・§9）。

    • フェンス・タイルは該当パーツを置いた場合のみ描画されるオプション要素
    • 地面パネルはモジュラーと同じくマスターの draw_floor=yes の建物だけ描画し、マテリアルは floor パーツを a{variant} → b{bd_type} → common の順で解決する（無ければ描画しない）
    • 既成建物は建物中心位置の地形標高に接地するため、超近景セルではフェンス・タイル・地面パネルが地形に追従する（MODEL_MODULAR_GROUND と同じ扱い。F_建物メッシュの生成 §9.4）

    4. コライダー

    描画された実高さ（実際に描画されたメッシュの天端のうち最も高いもの。最低でも1階分）を使用する。 base / top の実寸が論理高さ（floors × floorHeight）をはみ出す建物でも全体をクリックできるようにするためである。 構成は F_建物メッシュの生成 §13 に準じる。

    5. フォールバック

    3種類のパーツがいずれも存在しない場合は白い箱（BuildingMeshBuilder.GenerateSimpleBuilding）にフォールバックする。

    6. モデルに記録する道路間口

    道路への出入口は、FBX内に road_access_{entry|exit|both}_{識別子} というEmptyと、その直下の3つのEmpty a・b・inside を持たせて表す。a と b が舗装端の両端で、距離が間口幅、中点が接続点になる。inside は中点から敷地内側へ置き、中点との差が道路へ向かう向きになる。著作規約は 道路間口マーカー。

    BuildingRoadAccess は無印モデルを読み、建物本体と共通の PrebuiltRotation で回す。地上に実際に配置する最初の段だけを採用し、baseが無くmidを配置しない建物ではtopが対象になる。地上段がmidの場合は、本体と同じ原点基準のYスケールをマーカーにも適用する。舗装高は建物中心の地形標高に相対で、モデルの描画LODを切り替えても間口は変えない。

    国境貨物駅1081は top-prebuilt に検査場の入口45mと出口10mを持つ。通常・接写・遠景の原本とFBXに同じマーカーを記録する。別の既成建物もこの規約でモデルを著作すれば、Unityにバリアント別の固定座標を追加せず接続できる。マーカーは描画・メッシュ結合・コライダーの対象にならない。
