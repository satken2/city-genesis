    19. 環境

    19.1. 住環境倍率

    すべての土地区画は、世帯（TYPE_HOUSEHOLD）の立地倍率として住環境倍率を持つ。 この値は「その場所が世帯にとってどれほど住みやすいか」を表す指標であり、エポックごとに「騒音」「大気汚染」「治安」「日照」の4つの環境要素から算出される。

    マルチプライヤーの値域

    住環境マルチプライヤーは上限（理想環境）から下限（最悪環境）までの範囲に収まり、4要素の悪さに応じて決まる。

    経済への影響

    住環境マルチプライヤーは、世帯の住環境スコア（env_score）に直結する。 住環境スコアは世帯の転居先選択において核心的な評価指標であり、住環境が良い場所ほど実質的な住居コストが下がる形でスコアに反映される。 そのため、騒音や犯罪が多い地域では世帯が都市内で転居を希望しやすくなり、逆に静かで安全な地域には世帯が集まりやすくなる。

    19.2. 騒音

    発生源

    騒音は以下の2種類の発生源から生じる。

    • 道路・線路などのパス — パスごとに設定された騒音強度（noise）が発生源となる。パスの騒音強度は、そのパスの交通量に基づいてエポックごとに算出される。道路交通量と歩行者交通量の両方が寄与するが、歩行者の量は一定の閾値を超えないと騒音を発生させない。なお、完全に地下に埋設されたパス（すべてのアンカー点および中間点のY座標が道路の厚み height を超えて地面の下にある場合。すなわち Y < -height）は騒音を発生させない。
    • 建物エージェント — 建物を持つ経済主体（工場、商業施設など）は、サブカテゴリ（variant）ごとに定義された騒音レベル（noise_level）に応じて周辺に騒音を発生させる。

    空間的な拡散

    騒音は発生源から周囲へ、距離とともに減衰しながら広がる。

    影響の評価

    各土地区画では、区画の中心点における騒音強度を評価して悪さスコアを得る。

    19.3. 大気汚染

    発生源

    大気汚染も騒音と同様に2種類の発生源を持つ。

    • パス — パスの大気汚染強度（air_pollution）が発生源となる。大気汚染は自動車交通量のみに依存し、歩行者交通量は寄与しない。完全に地下に埋設されたパスは大気汚染を発生させない。
    • 建物エージェント — 工場などが持つ大気汚染レベル（air_pollution_level）に応じて周辺に汚染を発生させる。

    空間的な拡散と影響の評価

    基本的な仕組みは騒音と同じだが、大気汚染は騒音よりも広範囲に拡散する。

    19.4. 治安

    犯罪寄与度

    治安の悪化は、市民個人の犯罪性向に由来する。各市民は固有の犯罪性向（potential_criminality）を持つ。この値は子供の頃に決定され、成人してからはほぼ変化しない。 犯罪寄与度は、市民の犯罪性向に加えて、成人でかつ失業中の場合に追加的なペナルティが加算される。つまり、失業成人は雇用されている成人に比べて治安悪化への寄与が大きい。

    世帯単位の集約

    市民個人の犯罪寄与度は、同じ世帯に属するメンバーの平均値として世帯単位に集約される。 この世帯の犯罪寄与度が、世帯の居住地（土地区画の中心点）における治安悪化の発生源となる。

    訪問先地区への影響

    犯罪性向の高い世帯が日常的に訪問する地区も、治安悪化の影響を受ける。 エポックごとに各世帯がどの地区を訪問したかが記録され（household_visit_map）、それを基に、訪問世帯の犯罪寄与度が訪問先地区に加算される。 加算の強度は地区面積で除算されるため、面積の小さい地区が不当に高い犯罪スコアを持つことはない。 このメカニズムは「犯罪指向の高い人物が多く訪れる地区は治安が悪化する」という現実現象をモデル化したものである。

    空間的な拡散と影響の評価

    騒音・大気汚染と同様に、発生源から周囲へ減衰しながら拡散する。

    19.5. 日照

    影の発生源

    日照の悪化は、周辺の建物が地面に落とす影によって生じる。各建物はフットプリント（底面ポリゴン）と高さに応じた影を落とし、高い建物ほど長い影を落とす。道路や地形は影の発生源にならない。

    1日の太陽の動き

    1日を代表する複数の太陽位置（朝から夕方まで、方位と高度が変化する）それぞれについて影の範囲を求め、それらを平均することで「1日のうち影になっている時間の割合」（影時間割合）を得る。太陽高度が低い朝夕は影が長く、南中時は短い。季節による変化はない。

    影響の評価

    各土地区画では、区画に建つ建物のフットプリントの重心（建物の無い区画は区画の中心点）における影時間割合を評価して悪さスコアを得る。

    影は地上レベルで評価され、影を受ける側の建物の高さは考慮しない。高層建物が密集した街区の谷間は「街路レベルの日当たりが悪い場所」として素直に悪いスコアになる。また、建物自身のフットプリント直下は影とみなさず、評価点もその内側に置くため、建物が建っていること自体でその区画の日照が悪化することはなく、周辺の建物から受ける影だけが評価される。

    19.6. ヒートマップによる空間計算

    騒音・大気汚染・治安・日照の4要素は、いずれも都市全体を覆うビットマップ（ヒートマップ）上で計算される。騒音・大気汚染・治安は各発生源をビットマップ上に描画して空間的な拡散を表現し、日照は建物の影を投影して描画する。最後に、騒音・大気汚染・治安は各土地区画の中心点で、日照は前節の評価点で値をサンプリングする。

    APIは、土地区画ごとの評価スコアと、地図表示用の格子を提供する。表示用格子は周辺への影響を面として示し、騒音・汚染の発生源強度は各建物・パス自身がどの程度の負荷を生むかを示す。地図の表示方式と取得契約は都市マップを参照。エポックで計算する表示用格子はセーブ対象外で、ロード後は次のエポックまで未計算となる。

    区画単位の4要素は従来の都市環境APIで取得できる。値は0〜65535の整数と実スコアの最小値・最大値の組で、騒音・大気汚染・治安は区画間の相対値、日照は0〜1の固定スケールで返る。Unityの区画色分けはこの区画単位のAPIを使う。

    土地区画1件分の値は GET /api/v1/parcels/{parcel_id}/environment で取得できる。sunshine・air_pollution・noise・crime の4値はいずれも住環境倍率へ合成する前の生スコアで、0〜1の「悪さ度合い」（0=理想、1=最悪。日照は影になっている時間の割合）である。ヒートマップが未計算（エポック未実行）か区画が未収録なら各値は null になる。

    19.8. 衛生

    下水処理・ごみ収集の不足が続くと、居住地に衛生負荷が蓄積する。いずれか一方の不足をもう一方の供給で帳消しにはできない。施設の有無だけでなく、実際に提供されたサービスを評価する。

    人口がまばらな集落には簡易的な処理能力を見込み、施設未整備だけで衛生危機にはならない。人口密度が高くなるほど公共サービスが必要になる。衛生状態は徐々に悪化し、供給を回復させると徐々に改善する。転居や世帯分割で土地の汚れが消えることはない。

    衛生悪化は健康状態を徐々に損ない、健康悪化が全年齢の死亡リスクを上げる。医療は健康の回復を助けるが、下水・ごみ処理の代わりにはならない。衛生悪化は通知され、健康統計には衛生状態の分布と衛生悪化による死因が表示される。

    満足度への作用

    騒音・治安・日照は生活の快適さ、大気汚染と衛生は健康へ作用する。費用比較用の住環境倍率とは別の評価であり、満足度に家賃や通勤を重複加算しない。詳細は23. 満足度と施政スコア。
