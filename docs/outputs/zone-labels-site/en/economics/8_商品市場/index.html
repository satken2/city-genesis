    8. 商品市場

    8.1. 商品とは

    商品（product）は、経済主体間で取引される財やサービスの単位である。 商品には、パンや鉄鋼のような有形の財だけでなく、輸送サービスのような無形のサービスも含まれる。 すべての商品は一意の商品IDを持つ。

    商品の分類

    商品は以下の6種類に分類される。

    種類 内部名称 説明 例
    天然資源 GOODS_RESOURCE 土地区画の物理的位置に応じて直接分配される原材料。21_天然資源を参照。 鉱石資源
    工業原料 GOODS_MATERIAL 工場で生産され、他の生産の原材料として消費される中間財。輸出入が可能である。 コンクリート
    小売財 GOODS_RETAIL 世帯が消費する最終消費財。需要者が供給者の店舗まで出向いて購入する。 食料品
    サービス財 GOODS_SERVICE 遠隔地から提供されるサービス。輸送コストがかからず、距離に関係なく調達できる。 電力
    インフラ財 GOODS_INFRASTRUCTURE 専用のインフラ網でのみ配送される中間財。26_インフラ網を参照。 高圧電力、パイプライン原油
    公共交通車両 GOODS_TRANSIT 車両基地から鉄道路線を経由して配送される財。6_公共交通機関を参照。 鉄道車両

    8.2. 需要と供給

    需要（demand）

    各経済主体は、商品ごとに需要量（demand_amount）を持つ。 需要には以下の種類がある。

    • 消費需要: 世帯の生活消費や施設の原材料消費に基づく需要
    • 投資需要: 施設の生産効率向上のための投資財需要
    • 輸出需要: 輸出入拠点（TYPE_TRADE）が外国向けに立てる需要

    輸出需要は国内供給から国内需要を差し引いた余剰を、各拠点の取扱品目と能力に応じて分ける。複数の拠点があっても、全拠点の輸出注文の合計は同じ余剰を重複して数えない。

    需要量はエポックごとに生産計画フェーズで設定され、商品市場での調達によって減少していく。 調達が完了しなかった需要は次エポックには持ち越されない（毎エポック独立して需要が計算される）。

    調達済み量（remain_amount）

    需要者が調達（購入）した商品の手持ち量が remain_amount である。調達で増え、生産の原材料消費などで減るため、実態は「消費後に手元へ残っている在庫（残量）」であり、そのエポックにどれだけ調達したかを表す値ではない点に注意（調達実績は後述の received_amount が表す）。持ち越しの扱いは商品の種類（type）によって異なる。

    • 小売り財（GOODS_RETAIL）、サービス財（GOODS_SERVICE）、インフラ財（GOODS_INFRASTRUCTURE）: これらの商品は調達されたエポック内で即座に消費される一時的な財です。各エポックの処理の最初に remain_amount が 0.0 にリセットされます。インフラ財の場合、これは「電気を貯めておけない（蓄電不可）」ことの表現でもあります。
    • 天然資源（GOODS_RESOURCE）、工業原料（GOODS_MATERIAL）: これらの商品は生産のための原材料在庫として扱われます。そのため、エポック開始時にリセットされず、一般施設の生産で消費されるまで次エポック以降へ持ち越されます。

    獲得量（received_amount）

    「そのエポックに実際にどれだけ商品を手に入れたか」を表すのが received_amount である。市場での調達（自家供給を含む）に加えて、市場を経由しない獲得（インフラ財の配送、公共交通車両の配送、天然資源からの直接分配）もすべて合算される。

    remain_amount と違って消費で減ることはなく、全商品についてエポック開始時に 0.0 へリセットされてゼロから数え直される（在庫を持ち越す工業原料でも、received_amount はそのエポックの入荷分だけを表す）。各経済主体の詳細画面の「獲得量」表示や、インフラ施設の受電・受水実績の表示に使われる。

    注文量と実消費量（都市全体の集計）

    都市全体では、財ごとに「注文量」と「実消費量」という2つの量が観測できる。

    • 注文量: その財に対して、輸出入拠点を除く需要者が当エポックに計画した需要の総量。市場で実際に 調達できたかどうかは問わない。「どれだけ欲しがられたか」を表す。
    • 実消費量: その財が当エポックに市場で実際に調達された総量。自家供給で満たされた分も含む。 「実際にどれだけ手に入って消費・利用されたか」を表す。

    注文量と実消費量の差は、供給不足などにより満たされなかった需要を意味する。常に 「実消費量 ≤ 注文量」が成り立つ。

    自家供給量（都市全体の集計）

    実消費量には市場取引による調達だけでなく、自家供給で満たされた分も含まれる。自家供給とは、マッチング後に残った需要と、世帯の最低需要（demand_min）のうち市場で調達できなかった不足分を、商品ごとに定められた上限（self_sustain）まで無償で充足する仕組みである。世帯の市場注文は現預金の範囲でしか計画されないため（10_消費活動）、資金のない世帯の生存最低限はこの仕組みが市場を介さずに保障する。このうち自家供給分のみを分離集計したものが「自家供給量」(total_self_supply)である。

    供給（supply）

    各経済主体は、供給する商品ID（supply_product_id）と供給量（supply_amount）を持つ。 供給可能な経済主体は以下の通り。

    • 一般施設（TYPE_STANDARD）: 生産活動により商品を供給する
    • 輸出入拠点（TYPE_TRADE）: 外国からの商品を国内市場に供給する（輸入）。同じ拠点が需要者として輸出需要も立てる

    供給量は前エポックの在庫（supply_left_amount）に生産量を加えたものである。 供給価格（supply_price）は生産コストを下限として設定される。

    8.3. 需給マッチング

    商品市場では、エポックごとに各商品について需要者と供給者のマッチングが行われる。 マッチングは商品ごとに独立して実行され、すべての商品について一斉に調達が行われる。

    マッチングの考え方

    需要者は各供給者をスコアで評価し、条件の良い供給者から優先的に調達する。スコアには供給価格、輸送コスト、供給者の魅力（attraction）が反映される。attraction は立地と長期稼働（知名度）で決まる「顧客から見た魅力」であり、設備投資の充実度は含まれない（設備は生産効率にのみ影響する。9_生産活動を参照）。

    輸送コストの概念

    商品の種類に応じて、輸送コストの考え方が異なる。

    • 工業原料: 地区間の所要時間と輸送サービス価格に基づく。輸送コストは輸送サービスへの需要として別途加算される。トラック輸送のため所要時間は常に自動車経路のものを用いる。なお、この輸送サービス需要のうち商品ごとに定められた自家供給の枠（self_sustain）に収まる分は、需要者が自力で運ぶものとして市場には出ない。
    • 工業原料の構内物流: 需要者と供給者の土地区画どうしの隙間（最短距離）が一定距離（既定50m）以下なら、配管・コンベア・引き込み線で運ぶものとして所要時間を0とする。輸送コストも輸送サービス需要も生じず、道路の交通負荷にもならない。同じ建物に入居するテナントどうしも含む。工場や貨物の積み下ろしの施設（33_貨物輸送）を寄せて配置すると、原料の搬送で道路を混ませずに済む。
    • 小売財: 需要者が店舗まで出向く際の移動時間を機会費用として換算する。
    • サービス財: 輸送コストはかからない。ただし後述の供給範囲の制約を受ける場合がある。

    サービス財の供給範囲

    サービス財（GOODS_SERVICE）を供給する施設のうち、変電所・下水処理場・電波塔のように 供給が地理的に限定される施設は、施設ごとに定まる 効果範囲 の中にある土地区画にしか 財を供給できない。効果範囲外の需要者は、たとえ価格が見合っていてもその施設からは調達できない。

    効果範囲は施設の種類（variant）ごとの算出方法で決まる。

    • 個別のアルゴリズムを持つ施設は、それに従う。たとえば下水処理場は「設置場所より標高が 高いか、低くても標高差が一定量以内に収まる場所」（効果半径内）、電波塔は「地形の遮蔽物が なく見通せる範囲」に効果を及ぼす。電波塔の見通しは設置場所の標高だけでなく建物自体の 高さも加味されるため、下水処理場は低地に、電波塔は高所に高く建てるほど広い範囲を カバーできる。
    • 個別のアルゴリズムを持たない施設は、施設マスターの効果半径（effective_radius）の円内を 効果範囲とする。
    • 効果半径もアルゴリズムも定義されていないサービス施設（ソフトウェア会社など）は、 従来どおり距離に関係なく都市全域へ供給する。

    各施設がどの土地区画へ供給できるかは、施設を設置したとき、および土地区画を作成・変更・ 削除したときに再計算される。効果範囲は施設の位置・地形だけで決まる幾何的な性質であり、 施設の稼働状況とは独立している。

    効果範囲の判定に使う地形は、都市を作ったときの初期地形である。道路工事や造成で加工した 地形は反映しない（効果範囲が変わるほど地形を変えることは無いという前提）。海面より低い 地形は海面の高さとして扱うので、初期地形では海だった埋立地（造成）や海上構造物の 敷地も、海面の高さで範囲に入るかが判定される。電波塔は効果半径が大きいため、初期地形の粗い格子（遠景）で 見通しを求める。

    距離減衰

    商品ごとに「距離減衰（distance_decay）」という性質を持つ。これは、供給者が遠いほど需要者が実際に発注できる量が減る度合いを表す。既定値は 0 で、その場合は距離による発注量の減衰は一切起きない（従来どおり、遠くても価格が見合えば調達できる）。

    距離減衰が大きい商品では、供給者までの所要時間（道路の渋滞も反映される）が長いほど、その供給者への発注量が急激に小さくなる。これは「遠くからでは実効的にわずかしか頼めない」ことを表現し、たとえば消防サービスのように 到達に時間がかかると意味をなさない 財で用いる。

    距離減衰は供給者の在庫を奪う前に発注量そのものを縮小するため、減衰によって頼まれなかった分の在庫は他の近い需要者に残る（物資が輸送途中で消滅するわけではない）。

    在庫不足時の配分

    需要が供給を上回り在庫が不足した場合の配分方法は商品種別によって異なる。

    • 工業原料・サービス財: 需要者間で均等な比率で配分される。
    • 小売財: 店舗の在庫が売り切れるまで需要者に順に割り当てられる。購入できなかった需要者は他店舗から調達できる。

    調達先の決定

    各需要者は、商品マスターで定義された分散数（split_count）に基づいて調達先を決定する。分散数が1なら最良の供給者1つから全量調達し、2以上なら複数供給者から按分する。分散数0なら全供給者から按分する。

    調達が成立すると、需要者の残高から支出（税込）が引き落とされ、供給者の残高に収入（税抜）が加算される。供給者の在庫は減少し、需要者の調達済み量（remain_amount）と獲得量（received_amount）が増加する。

    8.4. 決済と課税

    消費税

    小売財（GOODS_RETAIL）の取引に対してのみ、取引額に対して消費税（consumption_tax）が課税される。工業原料（GOODS_MATERIAL）やサービス財（GOODS_SERVICE）などの取引には課税されない。

    輸入関税

    供給者が輸出入拠点（TYPE_TRADE）の場合（＝輸入取引）、取引額に対して輸入関税（import_tax）が課税される。 輸入関税は消費税の代わりに課税され、両方は重複して課税されない。

    公共予算の制約

    公共施設（public_facility フラグが立っている需要者）の購入は、支出カテゴリ別の市予算の範囲内に制限される。 各カテゴリはそれぞれ自分の予算枠の中でのみ支出でき、あるカテゴリの予算残額が不足すると、そのカテゴリの公共購入は残額に収まるよう等比で縮小される（残額がゼロの場合は公共購入がすべてキャンセルされる）。 カテゴリ予算は、プレイヤーが設定した「前エポック実績支出に対する比率」と前エポックの実績支出から毎エポック導出される。予算に使われなかった余剰現金は市政府の貯蓄として残る（詳細は予算管理を参照）。

    8.5. 輸入と輸出

    輸出入は輸出入拠点（TYPE_TRADE）が担う。1つの拠点が、供給者として輸入を、 需要者として輸出を同時に行う。輸入と輸出の取扱能力（キャパシティ）は方向別に独立しており、 輸入が多い拠点でも輸出の取扱能力は減らない。

    取扱能力は重さ（t）で数える。拠点の1日あたりの取扱能力は、床面積あたりの能力（capacity_per_space。t/m²/日）× 占有面積で、品目の数量は1単位の重さ（transport_amount。kg）でトンに換算してから能力と比べる。 自動車1台（1,000kg）は鉱石1kgの千倍、原油1バレル（159kg）は159倍の能力を使う。重さの定義が0の品目も、 能力を使わずに無限に輸出入されないよう最低限の重さとして数える。需要の合計が能力を超えるときは、 全品目を同じ比率で縮める。

    輸出入拠点は、海を通じた港、陸を通じた国際貨物駅と陸路輸送、ゲーム序盤の最低限の輸出入のために市庁舎に置かれる 支援拠点である。国際貨物駅の取扱能力は、床面積の能力と、国際貨物輸送路線で届いた輸出入の枠の小さい方になる （33_貨物輸送 33.7）。陸路輸送はトラックで道路の国境を越える輸出入を表す建物ではない拠点で、シナリオの作者が 大陸マップの国境検問所（12_建物 12.13）に入居させる。取扱能力は港と同じく床面積だけで決まり、作者が指定した 入居面積（階数 × 国境検問所の1フロア面積）が広いほど大きい。

    輸入の仕組み

    輸出入拠点は、外国から商品を調達して国内市場に供給する役割を持つ。 拠点は国内の一般施設と同様に商品市場に供給者として参加し、国内の需要者が拠点から商品を購入できる。 輸入の供給価格は、域外価格（external_price）と為替レートから計算される。

    輸出の仕組みと為替ボーナス

    輸出入拠点は、国内市場から商品を調達して外国へ輸出する役割も持つ。 拠点は商品市場に需要者として参加し、国内の供給者から商品を購入する。 輸出需要の上限価格は、域外価格を為替レートで換算した値である。

    拠点が買い付けの対象とするのは、国内の供給量のうち国内の需要が吸収しきらない 余剰分 である。国内需要が供給を吸収しきる商品は輸出されず、国内で生産された商品は まず国内の消費に向かう。

    域外自国建て価格が国内供給価格を上回っている場合、その比率に応じたボーナス倍率が決済価格に乗算される。この上乗せ額は拠点の残高から引き落とされ、国内供給者の残高に直接加算される（ゼロサム）。

    再輸出の禁止

    拠点が輸入供給した商品を、同じエポックで拠点の輸出需要が買い付けることは禁止される （自拠点からの買い戻しを含む）。これにより「輸入した物を同エポックで即輸出する」無意味な取引を防ぐ。

    小売取引の付加効果

    小売財の取引が成立した場合、需要者は供給者のいる地区へ物理的に出向いて購入する。 このため、取引が成立した供給者の地区には昼間人口が加算される。 また、世帯がどの地区の店舗を訪問したかを記録し（household_visit_map）、他の分析に利用する。

    交通負荷の記録

    取引に伴う地区間の移動は、道路の交通負荷として記録される。 工業原料の輸送は自動車交通として、小売財の購入は需要者の自動車保有状況に応じて自動車または歩行者交通として計上される。 構内物流（隣り合う土地区画どうしの工業原料の取引）は道路を使わないので計上しない。
