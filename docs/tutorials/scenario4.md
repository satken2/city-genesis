# 鉄道

シナリオID: `scenario4`。9ステップ。

## 初期状態と対象名

東西道路、完成済み発電所rail.solar、空き区画rail.depotSiteを準備。北側に本線案内と、互いに異なる2駅の配置範囲を用意。具体的な曲率・接続条件は通常の事前検証を満たす配置を採用する。

## 共通の戻り方

パネルを閉じた場合は開く段階へ戻り、取消で形状が失われたら配置段階へ戻る。API失敗では進捗を保存せず再試行する。完了・中断・都市切替では案内と制限を解除する。再開時は対象の存在と保存済み条件を再確認する。

## 移植時の判定上の注意

電化軌道が1本あるだけでは複線とはいえない。基地端子に線が付いているだけでは本線接続とはいえない。1駅だけで路線が成立するという前提を置かず、2駅・往復経路を設計する。運行可否の実API項目を機能追加時に確認し、単なる路線存在へ置き換えない。
