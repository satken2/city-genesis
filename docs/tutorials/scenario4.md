# 鉄道

シナリオID: `scenario4`。9ステップ。地形は平坦(`flat`)。開始時の導入は説明ウィンドウ(`README.md` の共通設計)が担う。

## 初期状態と対象名

平坦マップの支援町(東の町。集合住宅 `support.housing.building`・太陽光発電所 `support.solar.building`・変電所・水道)から、通り `lesson.avenue` が西の海岸近くまで延び、その西端に商業ビル `lesson.store.building`(5階)が建っている。商業ビルには食料品店 `lesson.grocery` が入居していて、町の集合住宅の住民がそこへ通勤する。通りの南の線路予定地に沿って、車両基地用の細長い区画 `lesson.depot` がある(車両基地の種別しか建てられない)。

乗客は通勤・通学の往復でだけ生まれる(買い物や住宅どうしの移動では乗らない)。そのため片方の駅は住宅、もう片方は職場(商業ビル)のそばに置く。徒歩(約10分)より鉄道が速くなるように、駅は建物のすぐそばに置き、路線は運賃0円・運行間隔5分で開業させる。既定の運賃200円・10分では徒歩が選ばれて乗客が出ない。

## 共通の戻り方

パネルを閉じた場合は開く段階へ戻り、取消で形状が失われたら配置段階へ戻る。API失敗では進捗を保存せず再試行する。完了・中断・都市切替では案内と制限を解除する。再開時は対象の存在と保存済み条件を再確認する。

## 判定上の注意

電化軌道が1本あるだけでは駅どうしがつながったとはいえない。基地端子に線が付いているだけでは本線接続とはいえない。1駅だけで路線が成立するという前提を置かず、2駅を結ぶ。乗車は路線の存在ではなく、エポックの乗車回数で確かめる。単線2駅の往復は、運行間隔4分以上・1編成4両以内(ホーム長100m)で開業できる。
