# インフラ

シナリオID: `scenario3`。8ステップ。

## 初期状態と対象名

東西道路と地区、solar_site・house_site・substation_siteの3区画。house_siteに集合住宅houseを完成状態で用意。solar_plant、substationはプレイヤーが作成する。

## 共通の戻り方

パネルを閉じた場合は開く段階へ戻り、取消で形状が失われたら配置段階へ戻る。API失敗では進捗を保存せず再試行する。完了・中断・都市切替では案内と制限を解除する。再開時は対象の存在と保存済み条件を再確認する。

## 移植時の判定上の注意

建物存在だけでは指定区画への建設にならない。端子それぞれに線が付いていることと相互に接続していることを区別する。在庫残量は受電量の代わりに使わない。
