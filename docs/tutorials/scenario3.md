# インフラ

シナリオID: `scenario3`。6ステップ。地形は与論島(`yoron`)。開始時の導入は説明ウィンドウ(`README.md` の共通設計)が担う。

## 初期状態と対象名

与論島の北西の港町。町には道路・集合住宅(`support.housing.building`)・水道(地下水ポンプ・導水管・水道ポンプ)があり、電力の施設(発電所・変電所・送電線)は無い。町から約900m離れた西の平地に発電所用の区画 `lesson.solar`、集合住宅の隣に変電所用の区画 `lesson.substation` がある。どちらの区画も、その施設の種別しか建てられない。

## 共通の戻り方

パネルを閉じた場合は開く段階へ戻り、取消で形状が失われたら配置段階へ戻る。API失敗では進捗を保存せず再試行する。完了・中断・都市切替では案内と制限を解除する。再開時は対象の存在と保存済み条件を再確認する。

## 判定上の注意

建物の存在だけでは指定区画への建設にならない。支援の町にある既存の施設で新規建設を達成したことにしない。端子それぞれに線が付いていることと相互に接続していることを区別する。在庫残量は受電量の代わりに使わない。
