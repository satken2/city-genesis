# 地区設定

シナリオID: `scenario2`。7ステップ。開始時の導入は説明ウィンドウ(`README.md` の共通設計)が担う。

## 初期状態と対象名

H型道路網と沿道区画、初期地区 district.original、右上の道路 district.targetRoad、その位置の鉱脈を用意。対象道路の分離先を district.newZone として保持。

## 共通の戻り方

パネルを閉じた場合は開く段階へ戻り、取消で形状が失われたら配置段階へ戻る。API失敗では進捗を保存せず再試行する。完了・中断・都市切替では案内と制限を解除する。再開時は対象の存在と保存済み条件を再確認する。

## 1. 地区作成

ID: `scenario2.split`

| 項目 | 定義 |
| --- | --- |
| 学習目的 | 道路を新しい地区に割り当てる |
| 前提 | 直前ステップの完了と上記の対象名の解決 |
| 基本分類 | 指定操作だけ許可 |
| Tauri・操作順 | 地区編集ボタンを強調 |
| Unity・操作範囲 | 作成ツールとdistrict.targetRoadのクリックを許可。対象を強調 |
| クリア条件 | 対象道路の地区がoriginal以外の有効IDになった。newZoneへ保持 |
| 代行と順序 | なし |
| 進行 | 途中の操作段階は自動、最終条件を確認して完了ボタン |
