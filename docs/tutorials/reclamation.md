# 海岸を埋め立てよう

シナリオID: `reclamation`。4ステップ。平地のない小さな人工岩礁で、土地の確保から都市創設までを学ぶ。

## 初期状態と案内範囲

支援町・市庁舎・住民は置かず、未創設の状態で始める。岩礁の東側、XZの[0,-70]〜[160,70]に埋立工事を描く。完成判定は岸壁より内側の[20,-50]〜[140,50]を対象とする。新しい区画は中心[80,0]、60m四方を案内し、固定50m四方の市庁舎が収まるようにする。Yは地面相対。最初の4つのマーカーは水深4mの海底から4m上に置き、海面に表示する。

全段階が強調だけ・ワールド観察の方針で、通常の造成・区画・建物パネルを使う。「次へ」を押したときに教材の達成を再確認する。アイコンパネルは各段階の入口だけを許可する。取消・再オープン・詳細の確認は既存基盤の共通設計に従う。

## 1. 埋立工事を計画

ID: `reclamation.plan`

造成ボタンを強調する。4つの黄色いマーカーを順に左クリックし、右クリックで閉じてから見積もりを確定する。海岸線を横断して海へ張り出す形にし、通常の検証で埋立と判定されることが必要。指定領域を覆う埋立工事が計画されたことを `checks.planned` で確認する。合格後に基準期を記録する。

## 2. 埋立地を完成

ID: `reclamation.land`

開始ボタンを強調し、計画後に1エポック以上進める。施工の供給者がいない教材なので、「次へ」で対象の埋立工期を省略して再取得する。時間を進める前には代行しない。埋立地の完成と仮の工事区画の解消を `checks.land` で確認する。通常ゲームの工期は変更しない。

## 3. 埋立地内に区画を作成

ID: `reclamation.parcel`

土地区画ボタンを強調する。「単一区画」で奥行き・長さを各60mにして4つのマーカーの中心を選び、確定する。埋立地内に市所有の2500㎡以上の通常区画ができたことを `checks.parcel` で確認する。範囲外や小さすぎる区画では合格しない。

## 4. 市政府庁舎を配置

ID: `reclamation.hall`

建物ボタン・公共サービス分類・市政府庁舎カードを強調する。作った区画の中心へ市政府庁舎を置く。埋立地内の庁舎によって都市が創設されたことを `checks.hall` で確認して終了する。終了後はテンプレートモードを解除し、そのまま通常プレイを続けられる。
