# 基本操作

シナリオID: `basic`。7ステップ。

## 初期状態と対象名

更地。案内用道路の始点A=(-100,0,0)、終点B=(100,0,0)。Yは地面相対。道路を basic.road、沿道区画群を basic.parcels、集合住宅を basic.home として保持する。

## 共通の戻り方

パネルを閉じた場合は開く段階へ戻り、取消で形状が失われたら配置段階へ戻る。API失敗では進捗を保存せず再試行する。完了・中断・都市切替では案内と制限を解除する。再開時は対象の存在と保存済み条件を再確認する。

## 1. ようこそ

ID: `basic.welcome`

| 項目 | 定義 |
| --- | --- |
| 学習目的 | 都市建設が計画とエポックに分かれることを知る |
| 前提 | 初期状態の準備成功 |
| 基本分類 | 強調だけ |
| Tauri・操作順 | 説明と開始ボタン |
| Unity・操作範囲 | 編集操作は開始まで停止、カメラ可 |
| クリア条件 | 開始ボタン |
| 代行と順序 | なし |
| 進行 | 確認ボタン |

## 2. 道路を配置

ID: `basic.road`

| 項目 | 定義 |
| --- | --- |
| 学習目的 | 道路種別の選択、左クリック始点・右クリック終点・パネル確定 |
| 前提 | 直前ステップの完了と上記の対象名の解決 |
| 基本分類 | 指定操作だけ許可 |
| Tauri・操作順 | 道路ボタン→街路タブ→地上2車線道路→確定。取消とパネル再オープン可 |
| Unity・操作範囲 | A/Bを円で表示し予定線を描く。A左クリック、B右クリックのみ受理。直線・相対高さ0、余分な頂点・制御点の編集は不可 |
| クリア条件 | 指定バリアントの直線がA/B間で保存された。建設予定/建設中/稼働中を許可しIDをbasic.roadへ保持 |
| 代行と順序 | なし |
| 進行 | 途中の操作段階は自動、最終条件を確認して完了ボタン |

## 3. 都市の予算

ID: `basic.budget`

| 項目 | 定義 |
| --- | --- |
| 学習目的 | 予算配分の変更 |
| 前提 | 直前ステップの完了と上記の対象名の解決 |

## 移植時の判定上の注意

道路の存在判定だけでは指定種別・形状を保証しない。区画・建物・稼働の判定は各段階で束縛した対象に限定する。
