# 基本操作

シナリオID: `basic`。5ステップ。開始時の導入は説明ウィンドウ(`README.md` の共通設計)が担う。

## 初期状態と対象名

平坦マップの支援町(東側の町と集合住宅・電気・水道)だけがある。案内用道路の始点A=(-100,0,0)、終点B=(100,0,0)。Yは地面相対。道路を basic.road、集合住宅を basic.home として保持する。

## 共通の戻り方

パネルを閉じた場合は開く段階へ戻り、取消で形状が失われたら配置段階へ戻る。API失敗では進捗を保存せず再試行する。完了・中断・都市切替では案内と制限を解除する。再開時は対象の存在と保存済み条件を再確認する。

## 1. 道路を配置

ID: `basic.road`

| 項目 | 定義 |
| --- | --- |
| 学習目的 | 道路種別の選択、始終点の左クリック・右クリックによる形状確定・パネル確定 |
| 前提 | 直前ステップの完了と上記の対象名の解決 |
| 基本分類 | 指定操作だけ許可 |
| Tauri・操作順 | 道路ボタン→街路→地上2車線道路→始点→終点→形状確定→パネル確定を順に案内。取消とパネル再オープン可。設定・保存・リロード・終了は常に利用可 |
| Unity・操作範囲 | A/Bを円で表示し予定線を描く。A左クリック、B左クリック、3D画面内の右クリックで形状確定。直線・相対高さ0、余分な頂点・制御点の編集は不可 |
| クリア条件 | 指定バリアントの直線がA/B間で保存された。建設予定/建設中/稼働中を許可しIDをbasic.roadへ保持 |
| 代行と順序 | なし |
| 進行 | 途中の操作段階は自動、最終条件を確認して次へボタン |

## 2. 道路の完成

ID: `basic.road_active`

| 項目 | 定義 |
| --- | --- |
| 学習目的 | 計画と完成の違い |
| 前提 | 直前ステップの完了と上記の対象名の解決 |
| 基本分類 | 強調だけ(アイコンパネルは全て無効) |
| Tauri・操作順 | コックピットの開始ボタンを強調。エポック確認・結果を必要な回数繰り返す |
| Unity・操作範囲 | カメラを道路へ向ける |
| クリア条件 | basic.roadの稼働をAPIで確認 |
| 代行と順序 | なし。工期を実際に待つ |
| 進行 | 途中の操作段階は自動、最終条件を確認して次へボタン |

## 3. 沿道区画

ID: `basic.parcels`

| 項目 | 定義 |
| --- | --- |
| 学習目的 | 道路に接する区画作成 |
| 前提 | 直前ステップの完了と上記の対象名の解決 |
| 基本分類 | 指定操作だけ許可(アイコンパネルは区画ボタンだけ。開いた区画作成パネルは「道路沿いに作成」・取消・確定だけ) |
| Tauri・操作順 | 区画ボタン(パネルを開くまで)→沿道方式の選択を確認して道路をクリック→プレビュー→確定を強調。開いたパネルでは他の作成方法・寸法の入力・左右や範囲の選択は押せない |
| Unity・操作範囲 | カメラを道路へ向ける |
| クリア条件 | basic.roadを接道(front_path_id)とする区画が1つ以上保存された |
| 代行と順序 | なし |
| 進行 | 途中の操作段階は自動、最終条件を確認して次へボタン |

## 4. 集合住宅

ID: `basic.home`

| 項目 | 定義 |
| --- | --- |
| 学習目的 | 区画選択による建設 |
| 前提 | 直前ステップの完了と上記の対象名の解決 |
| 基本分類 | 指定操作だけ許可(アイコンパネルは建設ボタンだけ。開いた建設パネルは住宅の分類・集合住宅のカード・戻る・取消・確定だけ) |
| Tauri・操作順 | 建物ボタン(パネルを開くまで)→住宅の分類→集合住宅→確定を強調。階数・構造などの入力や既存建物のコピーは押せない |
| Unity・操作範囲 | カメラを道路へ向ける |
| クリア条件 | 支援町の集合住宅以外に集合住宅(VARIANT_APARTMENT)が建設予定/建設中/稼働中。basic.homeへ保持 |
| 代行と順序 | なし |
| 進行 | 途中の操作段階は自動、最終条件を確認して次へボタン |

## 移植時の判定上の注意

道路の存在判定だけでは指定種別・形状を保証しない。区画・建物・稼働の判定は束縛した対象(basic.road・basic.home)に限定し、支援町の集合住宅で達成したことにしない。
