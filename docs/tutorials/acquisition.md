# 用地買収と地下鉄建設

シナリオID: `acquisition`。4ステップ。既存の高架プラットフォーム間を線路で結び、民間用地の買収と公共施設の撤去の違いを学ぶ。列車の路線設定は扱わない。

## 初期状態と対象名

平坦な地形に支援町と2つの高架プラットフォームがある。内側の端点はA=(-200,7,0)、B=(200,7,0)。Yは地面相対。対象名は `lesson.west_platform` / `lesson.east_platform`。その間には住宅・ビルが2列並び、線路が通る列の中央には公共施設の `lesson.fire_station.building` がある。周囲の住宅・ビルは民間所有。どの建物も線路の高さと干渉する。

線路の配置段階は既存の `world.path` 制約で、端点と高さを吸着させ、複線(421)の直線だけを許可する。パネルを閉じたら開く段階、形状を取り消したら配置段階へ戻る。残りは強調だけ・ワールド観察で、詳細パネルと通常のエポック実行を利用できる。アイコンパネルは各段階の入口だけを許可する。

## 1. 線路を計画

ID: `acquisition.track`

道路・線路ボタン→鉄道分類→複線カード→始点A→終点B→右クリックで形状確定→パネル確定の順に案内する。水色は始点、黄色は終点。計画された直線が高さ7mで両端に一致したことを `checks.track` で確認する。建物への干渉は計画時点の拒否条件にはしない。

## 2. 買収と停止を観測

ID: `acquisition.negotiate`

開始ボタンを強調する。1エポック以上進め、民間区画で買収が始まったこと(`checks.negotiating`)と、消防署が稼働したまま線路の着工を妨げていること(`checks.blocked`)の両方を確認する。複数エポックを実行しても観測結果は保持される。消防署に黄色いマーカーを置き、区画・建物の詳細を見ることもできる。

## 3. 消防署の撤去を指示

ID: `acquisition.demolish`

黄色いマーカーの消防署をクリックし、対象の建物詳細が開くまで案内する。次に詳細の「取り壊し」ボタンを強調し、明示的に撤去を指示する。稼働中の施設はブルドーザによる計画の削除では処理しない。公共施設が撤去予定・撤去中または撤去済みになったことを `checks.demolition` で確認する。民間施設の処理は買収に任せる。

## 4. 線路の完成を待つ

ID: `acquisition.complete`

開始ボタンを強調する。買収・撤去・建設が終わるまでエポックを進め、両プラットフォームの内端が稼働中の線路で接続されたことを `checks.connected` で確認して終了する。買収・撤去・線路の完成代行は使わない。
