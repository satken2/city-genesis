# 基本操作

シナリオID: `controls`。8ステップ。市長の役割・街づくりの目的・エポック制を知ってから、画面の情報の意味と操作を学ぶ。説明は強調と「次へ」で進め、建設・予算変更・路線作成の達成は求めない。選択画面では基本編より先に並べる。

## 初期状態と対象名

同梱の平坦な地形に、市庁舎設置済みの支援町がある。市庁舎が未設置だとアイコンパネルのボタンが無効になり強調されないため、設置済みで始める。定義は舞台の物体や対象名を参照しない。

## 進め方

- 全段階 `policy: highlight`。ステップ内の説明は `page` 条件(「次へ」で送るページ)で進め、各ステップの最終段階だけ `ack`(「次へ」でステップ完了)。
- 強調したボタンは押せる。アイコンパネルは方針に関わらず、段階の `highlight` にあるボタンしか押せない(説明していないアイコンで別のパネルが開かないようにする)。
- ルート全体(コックピット・アイコンパネル)の強調とシステムトレイの案内はしない。コックピットの中身は個別の要素を `data-guide` で指す。

## 1. 市長の役割と街づくり

ID: `controls.welcome`

市長として道路・施設・土地利用・税・予算を決める役割、住民が豊かで安心できる都市を目指すこと、計画してからエポックを進めて結果を確かめる流れを、3ページで説明する。操作中は日付が進まないため、急いで判断する必要がないことも伝える。

## 2. コックピット

ID: `controls.cockpit`

表示・マップ、市民の追跡、ブルドーザ、電気・水道の余裕、施政スコア、予算、日付、月の気候、通知を話題ごとに強調する。スコアは住民の暮らしへの満足度を示す指標として説明し、上限や集計単位は案内しない。

予算は手元の資金に対する今期の支出見込みであり、税収との比較や確定した支出と混同しない。資金の余裕・不足、工事や稼働の調整による変化、余裕がある場合の投資、予算画面での配分と収支確認を説明する。

気候は `hud.climate` を強調し、月の平均的な条件が農業・風力・太陽光発電の効率を変えることと、押すと施設ごとの影響を確認できることを説明する。通知の段階では `hud.notifications` だけを強調し、数字・赤い点滅・黄色い注意の意味を伝える。対象の詳細を確認し、原因への対処後に次のエポックで結果を確かめる流れも案内する。

## 3. 表示パネル

ID: `controls.display`

「表示」ボタンを強調して表示パネル(window `display_options`)を開かせ、調べたい対象の選択と、混雑や不足などを色分けで探す使い方を説明する。パネルを閉じたら最初の段階へ戻り、ページ送りもやり直す。

## 4. アイコンパネル

ID: `controls.icons`

通常表示のボタンを `MENU_ICONS` と同じ上からの順序で紹介する。造成、道路・鉄道・インフラ、土地区画、地区、建設、公共交通機関、プロップ配置、建設プロジェクト、規制、政策、金融政策、統計情報の順。テンプレート編集用のアイコンは扱わない。

各道具の具体的な機能を紹介し、その用途や街づくりでの意味を説明する。土地区画は建物の敷地と民間開発のための土地、地区は地域をまとめて建物の種類を制限し、人口や暮らしを比較する単位として、それぞれ2ページで案内する。後半も、公共交通の路線・停留所・運賃・運行間隔、建設プロジェクトの進捗と費用、規制の制限速度・労働時間など、できることを具体的に伝える。クリック・選択・配置・確定などの操作手順は各パネルのヒントバーが担当する。

## 5. エポック

ID: `controls.epoch`

「開始」ボタンを強調し、工事や住民・企業の活動が進むことと、結果・通知を見て次の計画を考える使い方を説明する。計画の効果には複数エポックかかることも伝える。実行は求めない。

## 6. カメラ操作

ID: `controls.camera`

左ドラッグで移動、右ドラッグで回転、WASD・矢印キーで移動、Q/Eで回転、R/Fで高さ、ホイールでズームを説明する。操作の達成は確認せず、「次へ」で進む。

## 7. フライモードと撮影モード

ID: `controls.viewmodes`

フライモード(Shift+Fで出入り)と撮影モード(画面右上のボタンで開始。Shiftで周回と移動を切替、Spaceで一時停止、Backspaceで逆再生、Escで終了)を説明する。実際に使ったかは確認しない。

## 8. 都市の境界

ID: `controls.boundary`

`world.camera` で都市の東端へカメラを向け、詳細な地形がある四角い範囲が都市の境界であり、カメラもその外へ出られないことを説明する。舞台を入れ替えたら、カメラの案内先を新しい境界に合わせる。
