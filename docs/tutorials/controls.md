# 基本操作

シナリオID: `controls`。7ステップ。画面の見方と基本の操作を、強調と「次へ」の説明で順に学ぶ。都市への書き込みはなく、建設・予算・路線は扱わない。選択画面では基本編の次に並べる。

## 初期状態と対象名

コアが同梱する平坦な地形(1000m四方、原点中心)に、市庁舎設置済みの支援町がある(`support_flat`)。市庁舎が未設置だとアイコンパネルのボタンが無効になり強調されないため、設置済みで始める。舞台は仮のもので、あとから別の都市へ入れ替えられる(定義は舞台の物体を参照しない)。対象名は使わない。

## 進め方

- 全段階 `policy: highlight`。ステップ内の説明は `page` 条件(「次へ」で送るページ)で進め、各ステップの最終段階だけ `ack`(「次へ」でステップ完了)。
- 強調したボタンは押せる。アイコンパネルは方針に関わらず、段階の `highlight` にあるボタンしか押せない(説明していないアイコンで別のパネルが開かないようにする)。
- ルート全体(コックピット・アイコンパネル)の強調とシステムトレイの案内はしない。コックピットの中身は個別の要素を `data-guide` で指す。

## 1. コックピット

ID: `controls.cockpit`

4段階。常用ツール(表示・マップ・ブルドーザ)、公共サービスの充足度、スコアと予算、通知と日付・天気を順に強調して説明する。最後の段階の「次へ」で完了する。

## 2. 表示パネル

ID: `controls.display`

「表示」ボタンを強調して表示パネル(window `display_options`)を開かせ、縦タブ(表示レイヤー)と各タブの表示モードのボタンを順に強調して説明する。パネルを閉じたら最初の段階へ戻り、ページ送りもやり直す。

## 3. アイコンパネル

ID: `controls.icons`

通常表示の12個(道路・鉄道・インフラ、土地区画、造成、地区、建設、建設プロジェクト、公共交通機関、規制、政策、金融政策、統計情報、プロップ配置)を1アイコン1段階で順に強調して説明する。テンプレート編集用のアイコンは扱わない。

## 4. エポック

ID: `controls.epoch`

エポック単位で時間が進むこと、計画を作って「開始」を押すまで都市が変わらないことを、「開始」ボタンを強調して説明する。実行は求めない。

## 5. カメラ操作

ID: `controls.camera`

左ドラッグで移動、右ドラッグで回転、WASD・矢印キーで移動、Q/Eで回転、R/Fで高さ、ホイールでズームを説明する。操作の達成は確認せず、「次へ」で進む。

## 6. フライモードと撮影モード

ID: `controls.viewmodes`

フライモード(Shift+Fで出入り)と撮影モード(画面右上のボタンで開始。Shiftで周回と移動を切替、Spaceで一時停止、Backspaceで逆再生、Escで終了)を説明する。実際に使ったかは確認しない。

## 7. 都市の境界

ID: `controls.boundary`

`world.camera` で都市の東端へカメラを向け、詳細な地形がある四角い範囲が都市の境界であり、カメラもその外へ出られないことを説明する。舞台を入れ替えたら、カメラの案内先を新しい境界に合わせる。
