# docs

Unity・Tauri の OSS 開発者向け公開ドキュメント。MkDocs のソースは `docs/docs/`、教材の設計書はサイト外の `docs/tutorials/` に置く。

## 文書の配置

| 配置 | 内容 |
| --- | --- |
| `docs/docs/economics/` | ゲームの概念・データモデル・観測できるルール |
| `docs/docs/geometries/` | 形状データと Unity の描画・制作仕様 |
| `docs/docs/programs/` | UIの実装仕様とコンポーネント間の契約 |
| `docs/docs/api/` | 自動生成の API 資料 |
| `genesis-core/docs/`（非公開） | コア内部の計算式・アルゴリズム・開発手法 |

## 共通ルール

- コアの内部計算・非公開の関数名や実装ファイル名を載せない。公開できる名前は外部契約・マスター・同期される共有定数を基準にする。
- economics には操作説明や UI の表示仕様を書かない。フロントの実装は geometries・programs、コアの計算手順は非公開側へ書く。
- 現在の仕様を書き、変更経緯や旧仕様との比較を混ぜない。関連する概念・データモデル・通信契約の整合性を保つ。
- サイトのページを追加したら `docs/mkdocs.yml` の nav も更新する。生成 API 資料は手編集せず生成手順で更新する。
- 見出しリンクは MkDocs の slugify 設定に合わせる。リンク先の見出しを一意にし、推測した連番アンカーを使わない。
- 文書・リンク・ナビゲーションの変更はローカルの MkDocs 表示で確認する。
