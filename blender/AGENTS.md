# blender

カテゴリ別の Blender ライブラリ `.blend` をモデル原本として保持する。Unity の FBX はこの原本から書き出し、直接編集しない。

## 共通ルール

- 編集・書き出し・検証は対応する制作 Skill に従う。道具と生成ジョブは並置された `genesis-gallery`（非公開）にあり、このディレクトリへ置かない。
- 編集前にコード生成ジョブの有無を確認する。ジョブが原本を生成するモデルでは、手編集が再生成で消えることがある。
- 通常・接写・遠景の原点・寸法・材質・配置マーカーを揃える。通常モデルの変更後は依存する生成ジョブと出力先も更新する。
- 同じ原本を複数用途へ書き出す場合は、すべての出力先を整合させる。
- テクスチャの相対参照を維持する。原本の場所と Unity のインポート領域を混同しない。
