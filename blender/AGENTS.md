# blender

カテゴリ別の Blender ライブラリ `.blend` をモデル原本として保持する。Unity の FBX はこの原本から書き出し、直接編集しない。

## 共通ルール

- 編集・書き出し・検証は対応する制作 Skill に従う。非公開の制作ツール `genesis-gallery` が利用できる場合は、その道具と生成ジョブを使い、このディレクトリへ置かない。
- 生成ジョブが利用できる場合は、編集前に対象モデルのジョブを確認する。ジョブが原本を生成するモデルでは、手編集が再生成で消えることがある。利用できない場合は、制作 Skill の公開側で確認できる範囲を扱う。
- 通常・接写・遠景の原点・寸法・材質・配置マーカーを揃える。通常モデルの変更後は出力先も更新し、利用できる生成ジョブに依存関係があれば整合させる。
- 同じ原本を複数用途へ書き出す場合は、すべての出力先を整合させる。
- テクスチャの相対参照を維持する。原本の場所と Unity のインポート領域を混同しない。

## 参照先

- ライブラリ構成: `blender/README.md`。
- 制作手順: Skill `genesis-building-parts`・`genesis-path-parts`・`genesis-prop-parts`。
- モデルごとのジョブと制作記録: 非公開の制作ツール `genesis-gallery` が利用できる場合は、そのリポジトリ内の `pipeline/jobs/`。
