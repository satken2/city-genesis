# tauri/src-tauri

Tauri の Rust 側。ウィンドウの生成・配置・再利用、共有状態とセッション監視、Unity との MMF 通信、ユーザーデータと作業コピー、子プロセス(コア・Unity)の起動と監視、ストア連携を管理する。画面の内容は React 側が担当する。

## 共通ルール

- ウィンドウ生成を行うコマンドは非同期にし、イベントループを待ち処理で塞がない。
- 配置・表示先・排他・終了時の後始末は共通のウィンドウ管理を通す。位置は物理座標、記憶するサイズはクライアント領域を基準にする。
- クローズは非表示と再利用を含む。React のアンマウントに後始末を任せず、再表示・転用時の状態も揃える。
- 共有状態・接続状態・版情報は共通窓口で管理し、独立した監視や状態の正を増やさない。
- IPC の Envelope・容量・イベントは Unity 側と一致させる。送信失敗を握り潰さず、受信イベントの届け先と購読開始のタイミングを確認する。
- 新しいウィンドウはレジストリ・排他設定・capabilities と整合させる。初期データはウィンドウコンテキストで渡す。
- 保存先は共通のユーザーデータディレクトリから解決する。受信した ID やパスが作業領域の外を指さないよう検証する。
- 子プロセスの起動・終了は共通のプロセス管理を通す。アプリの終了は発生源によらず共通の終了手順へ合流させ、自分で起動していないコアは止めない。
- ストアの SDK を使う処理は Cargo の feature を付けたストア連携に閉じ、feature なしのビルドでも動くようにする。コアへはストア名ではなく、検証用のチケットとストアが管理するフォルダだけを渡す。
- CSP や権限の変更は開発サーバーだけで判断せず、配布ビルドの挙動も確認する。
