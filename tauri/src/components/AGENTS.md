# tauri/src/components

ドメイン別のUIコンポーネントを置く。コンポーネントと対応する CSS を並べ、共通部品は `common/`、常駐パネルは `hud/` に置く。チュートリアルの定義と進行基盤は `tauri/src/tutorial/` が担当する。

## 共通ルール

- 共通部品・フック・API・整形処理を再利用する。種別やバリアントの判定は共有定数とマスター属性を使い、番号を直書きしない。
- パネルは遅延ロードされる。他の部品の CSS クラスを使う場合は CSS を明示的に import し、読み込み順だけに依存した上書きをしない。
- ポップアップは閉じてもアンマウントされないことがある。表示中かを確認してイベントの副作用を行い、対象や再利用の世代が変わったときは状態を初期化する。
- ウィンドウの位置・排他・クローズ時の後始末は Rust 側へ任せる。新しいパネルはアプリの分岐とウィンドウ登録も揃える。
- 編集状態は IPC 契約で定めた側を正とし、受信値をエコーしない。編集終了は既存の終了・取消しイベントを使い、他のウィンドウのモードを巻き込まない。
- 通常の表示設定と編集中の一時表示を区別し、一時表示でユーザーの選択を上書きしない。
- 通常パネルは安定した `data-guide` の操作名と観測の接点を提供する。シナリオ固有の条件・進行・強調処理を持ち込まない。
