# tauri/src/tutorial

チュートリアルの JSON 定義、検証、進行、各 WebView の操作案内と制限を担当する。通常コンポーネントは操作の接点だけを提供し、シナリオ固有の進行はこの基盤へ集約する。

## 共通ルール

- 定義・型・JSON Schema・意味検証を揃える。任意の関数・式・URL を実行する仕組みにしない。
- Schema の検証は事前生成コードを使う。生成物を手編集せず、Schema の変更時は `npm run gen:tutorial-validator` で再生成する。
- 条件判定は都市へ書き込まない。明示的な書き込みは共通アダプタを通し、セーブ ID を確認する。作成結果が不明な要求を再送しない。
- 実行 ID・revision・シナリオ・セーブ ID を区別し、古い案内や別の都市の状態を引き継がない。
- 操作の許可と強調は共通の操作名を使う。既存の disabled や他の処理が設定した inert を上書きしない。
- 定義の変更は `npm run test:tutorial` と全言語の翻訳整合性で確認する。
