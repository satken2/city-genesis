# 占有ボックスの検証

`run-unity.ps1` は実アセンブリのOccupancyVolumeUtilを独立したUnityへ読み込み、道路幅・占有高さと、道路の占有筒(進行方向を横切る面なし)・建物の占有箱の面数を検証する。赤い占有筒・箱と道路・建物の確認画像をTemp/OccupancyQA/preview.pngへ出力する。本編の都市・シーンを変更しない。

検証画像の透明マテリアルは独立プロジェクトで使える組み込みシェーダーで、頂点生成は本編の実装を呼ぶ。本編では既存のCustom/OverlayLineを使う。実ゲームでは道路を交差させて形状確定するとボタンが無効、衝突を解消して検証が完了すると有効になること、複線の片側だけが衝突する場合と建物の上空を通過する場合も確認する。パス同士の衝突では相手側のパスだけに筒が被り、敷設中のプレビューは覆われないことも見る。
