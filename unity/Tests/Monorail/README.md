# モノレールモデルのUnity取り込み検証

`run.ps1`を実行すると、`Temp/MonorailUnityQA`に独立したUnityプロジェクトを作り、501/502の11個のパスFBXと308/309の車両FBXを取り込む。Unity実行ファイルは本編のcsprojから解決する。

検査対象は軌道とコネクタの断面一致、橋脚の天端原点、キャップと桁の接合、Unity +X側のホームと外縁、8m周期、車両の実寸と接地原点、ホーム縁への離隔、14m連結ピッチ、自動生成されるResourcesプレハブである。結果は独立プロジェクトの`result.txt`、ログは`qa.log`に出力する。本編シーンや本編のプレハブは変更しない。

この検証は実FBXのインポートを対象とする。経路に沿う走行、曲線や分岐の運行シミュレーション、ゲーム内の目視確認は対象外。
