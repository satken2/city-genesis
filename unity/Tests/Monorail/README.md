# モノレールモデルのUnity取り込み検証

`run.ps1`を実行すると、`Temp/MonorailUnityQA`に独立したUnityプロジェクトを作り、501/502の13個のパスFBXと308/309の車両FBXを取り込む。Unity実行ファイルは本編のcsprojから解決する。

検査対象は軌道とコネクタの断面一致、橋脚の天端原点、キャップと桁の接合(支承の上面が桁の下面)、複線(軌道中心±1.5m)の2本の桁それぞれの下にある支承とキャップの幅、柱がキャップの下面に収まること、Unity +X側のホームと外縁、8m周期、車両の実寸と接地原点、ホーム縁への離隔、14m連結ピッチ、上屋の最高高さと乗降縁の被覆、柱の離隔、外壁の天端、自動生成されるResourcesプレハブである。ホームの部品は原点=ホームが面する軌道の中心なので、複線でも単線と同じ寸法で検査する。結果は独立プロジェクトの`result.txt`、ログは`qa.log`に出力する。本編シーンや本編のプレハブは変更しない。

この検証は実FBXのインポートを対象とする。経路に沿う走行、曲線や分岐の運行シミュレーション、ゲーム内の目視確認は対象外。

検証用プロジェクトへはFBXだけをコピーし、metaは独立プロジェクトが生成したものを維持する。本編のGUIDで上書きすると、検証側で生成済みのラッパー参照が切れるため。
