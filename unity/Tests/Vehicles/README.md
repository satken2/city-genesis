# 車両描画の回帰検証

`./run.ps1` で本編のC#をビルドし、独立した `Temp/VehicleUnityQA` のUnityから実アセンブリを検証する。本編のEditorを閉じる必要はない。Unityライセンスが必要。実行先は生成済みcsprojから取得し、必要なら `-UnityExe` で上書きする。

円と線分の交差・複数回進入、車線配置、通行方向、交差点の端点と接線、端点通過後の残り時間を検査する。環状路は1辺1/5/20分割を各20分相当走らせ、総台数とパス遷移数を測る。期待0.2台の端数枠、交通量を0へ変更した後の残留車の解消も確認する。

道路スナップショットはテストで注入する。API・地形ロード・全交差点の路面内への収まりは検証範囲外。結果は `result.txt`、Unityログは `qa.log` に出力する。

道路脇への退出は左右通行×前進/後退で90度旋回と道路外への移動を検査し、長時間走行でも退出途中に車が縮小せず、退出後だけフェードすることを確認する。
