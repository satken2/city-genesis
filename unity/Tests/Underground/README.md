# 地下表示の検証

`./run.ps1` は本編アセンブリをビルドし、`Temp/UndergroundQA` の独立したUnityプロジェクトで描画と物理判定を検証する。本編シーン・都市データ・マスター・現在開いているUnityプロジェクトは変更しない。Unityの実行ファイルは生成済み `Assembly-CSharp.csproj` の参照から取得し、必要なら `-UnityExe` で指定する。

- 既存FBXを通常の道路・線路生成器へ渡し、地下でも同じモデル・元材質を使うことと、ホバー時だけ既存の青い材質へ切り替わることを確認する。通常モデルを持たないインフラのフォールバックと、絶対標高が負でも表示と当たり判定を持つことも確認する。
- 生成・取得・近接線路・交差点端部の再生成を通常の `PathManager` 経由で行い、移動・回転したマネージャーからもワールド座標を保つこと、接写／遠景LOD・通常の退避・表示解除が共通経路で動くことを確認する。地上／地下の混在パス、地下交差点の不透明材質、同一versionで進む地下工事の完成区間と土の標高も検証する。`Temp/path576-underground.json` がある場合は保存した実データのホームとコライダーの座標も確認する。
- 実Terrainと地上の建物・道路を手前に置いて物理レイを飛ばし、地下パスを優先して選べること、地下パスが無い場所でも地上モデルをホバーしないこと、混在パスの地上区間を除外すること、表示切替前の保留クリックを発火させないことを確認する。敷設では地形入力を保持し、通常表示では地上モデルの選択へ戻る。
- 敷設時の地上の辺・ノード・計画中端点を候補から除き、地下への吸着を保持すること、混在区間の切り分け、複線・並行・接線の基準、カメラ静止中の表示切替と通常表示への復帰を検証する。アンカーの相対高さが0の非追従線路も、丘に潜る区間を候補として保持する。
- レイヤー非表示・個別フィルタ・計画中の削除条件、地形コライダーの維持、海面の非表示を確認する。
- 通常表示への復帰時に元材質・カメラ背景・海面・地形を復元することと、後から追加するパーツの材質が半透明のまま固定されないことを確認する。建物の外構生成を実行して建物全体の透明化を保つこと、計画中・色分けの更新で元材質を汚さないこと、交差点の材質差し替え後も新しい元材質と透明化を保つことを検証する。
- 遠景建物の非表示・個別フィルタ・計画中表示、インスタンス描画のプロップとGPU森林の透明度、および森林の深度・影の復元を確認する。
- URP上で地下表示のシェーダーを読み込み・描画し、`underground.png` に見た目を保存する。結果は `result.txt`、ログは `qa.log`。

生成済みcsprojがないワークツリーでは、インストール済みUnityの参照とそのワークツリーのソースを指すcsprojを用意してから実行する。検証は小規模な合成地形を使い、大規模都市の切り替え時間や全モデルの見た目は実ゲームで確認する。

FBXは独立プロジェクトへコピーして読み込む。検証用FBXのBuilt-in既定材質だけ、色と画像を保持してURPへ変換する。本編のモデル・材質アセットは変更しない。
