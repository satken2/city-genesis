# 交差点の信号機の検証

`./run.ps1` で本編のC#アセンブリをビルドし、`Temp/TrafficSignalsQA` の独立したUnityで実FBXと本編の交差点生成器・信号機の配置と結合を実行する。本編のシーン・マスター・モデルは変更しない(マスターは実マスターと同じ断面の値をQA内で登録する)。

- 取り込み後の実FBX: 自動生成されたResourcesラッパー、柱の軸と地中1m、アームの単位長(ローカルZ±0.5)、灯器の下端4.5m以上、レンズの向き(+Z)と並び(表示面に向かって左から青・黄・赤)
- 設置条件: 置く配置(221の十字路・T字路、221×212・221×211、231×241、斜交、ランプの流入、流出専用の一方通行、工事中の腕を含む十字路、右側通行の十字路・T字路)と、置かない配置(1車線道路どうし、センターラインのある道路が1本だけ、直線のつなぎ目、工事中で完成済みの道路が2本、一方通行ばかり)
- 各信号機: 灯器が流入してくる車の側を向くこと、直進先の腕の流出する向きの車線群の中央の上にあること(直進先が無ければ流入車線群の正面)、柱が歩道(歩道の無い腕では地面)に接地し車道に立たないこと、灯器の下端が路面から4.5m以上あること
- 結合メッシュ: `NodeMesh_*/Signals` の頂点数(柱・アーム・灯器の実FBXの頂点数の和)、材質、LODGroup、生成メッシュの所有者

結果は `result.txt`、配置の一覧は `qa.log`(`[TrafficSignalsQA]`)、画像は `cross`・`tee`・`alley-cross`・`wide`・`skew`・`cross-right` の俯瞰(`-overview.png`)と、最初の腕から交差点へ向かう運転席視点(`-driver.png`)。描画は組み込みパイプラインの簡易表示で、本編の都市画面・材質の見た目そのものではない。
