# 道路施工の描画検証

`run-unity.ps1`は本編をビルドし、独立したTemp/ConstructionPathQAで実FBXと本番のURP設定を読み込む。本編の起動中エディタや都市データには操作を送らない。

地上道路・高架道路・高架線路の0、12.5、25、57.5、90、99、100%を生成し、舗装端、橋脚の順番と接地、橋桁の支持点、地上100%での車両撤去、高架90%以降の桁・車両配置の固定、高架の土なし・車両の経路幅内配置、クリック用メッシュを検査する。曲線、全区間トンネル、single_spanの桁単位、JSONからの進捗取得、同一versionでのキャッシュキー変更も対象とする。土のシェーダーのコンパイルエラーも検査する。

同ディレクトリのPNGは実際に生成したメッシュを撮影した比較画像。テスト用の単純な平面と照明を使い、本編の天候や周辺建物を含むスクリーンショットではない。モデルと規約の検査はgenesis-galleryのPropsバリデータ、周辺道路との干渉と更新通知はTests/Pillars、ロード中断と再利用はTests/Lodが担当する。

成功時は正規のModelPrefabGeneratorが生成した4車種のミラーとFBXインポート設定のうち、本編に存在しないファイルだけを同期する。既存モデル・既存ミラーを上書きしない。

地上・高架の道路と線路について、施工済み区間のwall、線路のbody/trackの高架パーツ選択、架線・中央分離帯の非表示も検査する。structural-*.pngが比較画像。

高架の重機は橋脚期間の地表配置と架設期間の路面配置を検査する。水平・上り・下りと短い桁で、未架設部分へのはみ出し、車両同士の重なり、勾配への追従、90%以降の配置固定を実FBXで確認する。elevated-ramp.pngが勾配付き高架の比較画像。
