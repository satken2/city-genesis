# 建物と道路の接続

`./run.ps1` で本編DLLをコンパイルし、独立したUnityプロジェクトで実FBXを読み込む。本編の起動中にも実行できる。

- 1081の通常・接写のマーカー、入口45m・出口10m、舗装高・向きの一致。
- ロータリーの入口/出口分離・共用・車寄せへのフォールバック・微小区画、同じ入力の再現性、回転・平行移動。
- 直線・曲線・道路の方向反転、距離と高低差による除外、施設側の歩道と街路樹の実メッシュ、反対側の保存、すり付け舗装。
- 建物のLOD・再登録・状態変更・削除・全消去、建物の到着と削除による画面外道路のキャッシュキー更新、同じセルの遠い道路を更新しないこと。

結果は `unity/Temp/BuildingAccessQA/result.txt`、ログは `qa.log`、実生成した施設と道路の俯瞰画像は `a3002.png` / `a1081.png`。表示確認用の画像は独立プロジェクトのStandardシェーダーで描き、ゲーム本編のURP材質とは異なる。

敷地側の形状全体の回帰検証は `Tests/Buildings/run-open-space.ps1`。モデルのマーカーを変更した場合は、Blender原本からFBXを再出力してから本検証を実行する。
