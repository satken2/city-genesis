# 道路の並行・終端揃えスナップ検証

`RailJunctionGeometry` は元のベジエ上の任意位置への射影と解析接線を検証する。ワールド座標10km・100kmへ平行移動しても接続位置の許容誤差内に収まることを確認する。線路の敷設可否はバックエンドの `/paths/validate` が判定する。

`powershell -NoProfile -File Tests/RoadSnapping/run.ps1` をUnityディレクトリで実行する。
本編のランタイムアセンブリをビルドし、実際の `RoadParallelSnapGeometry` を呼ぶ。
回転・方向反転・左右の配置、標高の保持、両端揃え、始点配置、閾値外、縮退区間を検証する。
`PolylineUtils`も実アセンブリで検証する。2D距離、端点へのクランプ、XZと3Dの射影の違い、カーソルYへの非依存、ゼロ長・垂直・微小線分の縮退判定を確認する。

Unity上では以下の操作も確認する。

- Ctrlの8方向メニュー。曲線時はParallel、並行OFF時はAlign Endsが無効になる。
- 直線道路の隣へ始点を置き、並行線へ近づけて終端を揃える。始点も両端からの垂線へ吸着する。
- 複数の道路の間で基準が小さな移動ごとに切り替わらないこと。
- 右クリック確定と端点・中間点のドラッグでプレビューと保存位置が一致すること。
- ノード・道路接続と複線オフセット吸着の高さ、グリッド併用、起伏地形上の補助線。
- モード切替・セッション再開時の設定保持と、古い補助線が残らないこと。
