# 送電線の検証

`./run.ps1` は本編のC#をビルドし、独立した `Temp/PowerLinesQA` で実FBXと本編アセンブリを検証する。本編シーンは変更しない。

通常／接写の原点・外接寸法、実寸の高さ、メッシュ読出し、Normal→Closeの詳細度、地上を這わない電線とたるみ、120m間隔、パスの向きの反転、共有ノードの重複防止、所有パスの非表示・再表示・破棄を検査する。合格後、新規Closeモデルのmetaと正規生成器のミラープレハブだけを本編へ同期する。既存GUIDと既存プレハブは上書きしない。

線路接続では、通常鉄塔からかご型受電架構への切り替え、線路方向と標高、導体の取付点、走行空間の確保、並走する単線・まとめた複線・高架・モノレール、非電化線路と未接続交差の除外、混在する送電線の共有・所有権移譲、LODと頂点予算を検査する。接続線路・並走線路の変更通知で送電線の再生成が予約され、橋脚の通知を受けても再生成が維持されることも検査する。実FBXの複線421と接写の架構を組み合わせた確認画像は `Temp/PowerLinesQA/gantry-close.png` に出力する。

施設端子では、BuildingManagerの登録による端子の逆引きとPathManagerの位置供給を通し、大型・小型の両方、始端・終端、全LODのかご型と電線・架空地線の取付位置を検査する。高さは施設で大型9.54m・小型7.74m、線路では小型の架線空間を確保して9.14mとなる。混在する送電線の共有・所有権移譲、地盤への接地、施設でないインフラノード・車両基地端子・未接続プレビューの除外、位置供給の解放も対象とする。
