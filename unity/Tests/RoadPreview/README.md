# 道路プレビューの保持検証

Unityディレクトリで `powershell -NoProfile -File Tests/RoadPreview/run-unity.ps1` を実行する。
実ランタイムアセンブリをビルドし、独立したUnityプロジェクトで検証する。本編シーンは変更しない。

- 100回の追従更新でも詳細な前区間と動的Meshを再生成しない。
- 詳細な後区間の保持、複線の頂点数、傾斜時の面の向き、添字の有効性。
- 軽量表示の解除・再開・リセットと、入力点列を変更しないこと。
- RoadPlanManagerの配置・ドラッグ・復帰、曲線のアンカーと制御点の影響範囲。

操作確認は直線・曲線道路、複線、片側ホーム、高架、起伏上の盛土で行う。
マウス追従中は末尾だけが帯になり、打点すると詳細化すること、点・制御点ドラッグの終了後に全体が詳細へ戻ることを確認する。
右クリック確定・頂点追加削除・キャンセル・再開でも古い帯が残らないことを確認する。
帯は約2m間隔（曲線は制御多角形長を基準に最低16・最大4096分割）であり、付属設備は詳細化時に表示する。
本テストは状態とメッシュの回帰検証であり、実モデルを使ったFPS計測や画面比較ではない。

ノード間距離の警告は、500mちょうど・上限超過・高さを無視したXZ距離・中間ノード追加による解消・制限なし・点不足・複数違反のIPC用詳細を検証する。

曲線ホバーが直線の弦から曲がること、手前区間の接線変化、終点一致、保存制御点の不変、詳細区間の保持、配置中末尾の制御点再計算も検証する。

線形制約の回帰も実RoadPlanManagerで検証する。1kmの緩いベジエの半径、水平高架、急カーブと勾配の独立警告、マスターの80m/10m平滑化、持続する7%勾配、区間境界を跨ぐ等間隔標本、仮終点と手前接線、単一点・重複点・空点列を含む。バックエンドの登録時拒否は `genesis-core/tests/test_path_alignment.py` で検証する。

傾斜した実Terrainを作り、制御点直下とアンカー直下の標高が異なる条件で、保存・復元の往復、手動制御点の頂点追従、反対ハンドルの平面整列が縦断形状を維持することも検証する。

同じ緩曲線をワールド座標10km・50km・100kmへ平行移動しても最小半径が維持されることを検証する。

区間警告ラベルは離れた曲率違反と重なる勾配違反を別々に集計し、各区間固有の最悪値・位置・制限値・単位を表示することを検証する。


高架の下だけを平地から25mの丘へ変えても描画点・評価点・勾配が変わらないことを、直線/曲線、追従既定true/false、0%/2%/7%で検証する。水平200mの先に10%の坂を続けても、水平部分には勾配警告を出さない。

全線検証の共有は、先頭以外の線の違反・3Dと2Dの値と警告数の一致・検証サンプルの二重間引き防止・造成プレビュー受信後の保持・正常応答での警告解除・古い世代の応答拒否を実RoadPlanManagerで検証する。
