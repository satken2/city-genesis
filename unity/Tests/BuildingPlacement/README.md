# 建物配置の回帰検証

- `./run.ps1`: 本編アセンブリをビルドし、回転・道路両側・1〜500mの奥行き、道路への接触と食い込み、交差道路・曲線・短い区間を検査する。
- `./run-unity.ps1`: 独立したUnityを`Temp/BuildingPlacementQA`に作成し、本編のコンポーネントで配置方法の切替、区画入力の貫通/復帰、パネル差分、道路側アンカー、寸法固定、古い形状応答、選び直しを検査する。本編シーン・セーブは変更しない。

手動確認: 建物を選択→Ctrlで道路沿い→道路の脇で1/2・3/4とShift→左クリック→パネルで寸法変更→Escで選び直し。道路両側・交差点・曲線・区画上・固定サイズ施設・既存建物編集・忠実コピーも確認する。Ctrl中に建物とカメラが動かないこと、パネルの数値入力中に3Dキー操作が走らないこと、確定後の形が固定時点のプレビューと一致することを確認する。
