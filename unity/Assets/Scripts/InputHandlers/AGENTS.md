# InputHandlers

クリック・ホバー・ドラッグなどを3D上の対象と入力モードに応じて配送する。編集状態の管理は Editors に委譲する。

## 共通ルール

- 入力の可否は共通ゲートに従う。UI・カメラ操作・通信待ち・チュートリアル制限を各ハンドラで別々に判定しない。
- クリックとドラッグは共通の判定を使う。入力が中断されたときは保留クリック・ドラッグ・ホバーを片付け、復旧時に自動で確定しない。
- レイキャスト対象と実体の識別は共通の分類を使う。地形・海面・背景・岸壁などを各配送先で別々に判定しない。
- ワールド座標・画面座標・相対高さを混同しない。座標取得と吸着は既存の共通経路を使い、二重に補正しない。
- 入力モードと表示モードを混同しない。編集状態の管理は Editors に委譲し、確定送信の責務は既存の編集契約に従う。
