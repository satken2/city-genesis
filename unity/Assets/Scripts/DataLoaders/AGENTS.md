# DataLoaders

コアから取得した都市データを描画物へ変換し、差分更新・セルの常駐・LOD・キャッシュ・寿命を管理する。形状生成は MeshGenerators、表示切り替えは VisualHandlers が担当する。

## 共通ルール

- 物体の取得は全景地形が揃い、カメラが止まってから始め、詳細地形のタイルとは並行に進める。建物・道路の詳細は接地・通過する常駐セルのタイルを待ち、タイルが公開されたら各マネージャーがそのセルの物体を地形に合わせる。建物は区画の適用後に取得する。初期ロード完了は共通の判定へ集約する。
- 生成コルーチンは `RenderWorkScheduler` の開始・停止を対で使う。取消しを確認し、取得中フラグと一時資源を終了経路で確実に解放する。
- 常駐ワーカーは実際に処理待ちの仕事があるかを正しく通知する。初期ロード完了を無期限に待たせない。
- データの登録と描画物の表示・退避・削除を区別する。登録・削除は既存の共通窓口を使い、逆引き索引と関連キャッシュも整合させる。
- 表示モードによる描画範囲の変更も、対象の既存の生成・更新・LOD・退避経路へ渡す。表示モード専用の描画物管理を並立させない。
- 再利用や再生成の判定には、形状・地形・隣接データなど描画に効く入力を含める。未知の版を一致とみなさず、古い取得結果を新しいバッチへ適用しない。
- 全件の同期再生成を避け、共通キューと予算を使う。セッションのリセットでは取消し・データ・索引・描画物を揃えて消去する。
