# Utils

幾何・モデル・描画補助など、複数領域が使う共通処理を置く。Scripts 直下の `Utils.cs` も共通処理の入口となる。

## 共通ルール

- 追加前に既存関数を確認し、各 Manager や生成器へ同じ処理を複製しない。
- 座標系・引数の順序・単位・境界条件を明確にし、既存の呼び出し側と揃える。共有する形状や分類の規則を別の式で実装しない。
- 大量データは既存の空間索引とキャッシュを使う。キャッシュの入力が変わる場合は無効化し、共有資源の所有と寿命を守る。
- 汎用計算と、状態を更新するサービスの副作用を区別する。呼び出し側に見えない全体状態の変更を増やさない。
