# MeshGenerators

建物・区画・道路・線路・交差点・地形の描画メッシュを生成する。ロード・キャッシュ・再生成のタイミングと描画物の寿命は DataLoaders が担当する。

## 共通ルール

- 生成器に取得処理やロードの状態管理を持ち込まない。必要な入力・隣接情報・描画LODは呼び出し側の共通経路から受け取る。
- 共通の形状計算・パーツ解決・材質解決を再利用する。車線・軌道・接地・占有範囲などを生成器や交通描画ごとに別の式で求めない。
- コアと共有する形状・高さ・接続の規則を変える場合は双方と公開の形状契約を揃える。描画用の補正で保存データを変更しない。
- 生成した資源と共有プレハブ・材質を区別する。共通の所有・解放処理を使い、共有アセットを個体の破棄に巻き込まない。
- 頂点数と詳細生成は共通の予算内に収める。生成中の一時コンテキストは終了・例外時にも戻す。
- メッシュのキャッシュは入力の不変性と寿命を守る。可変メッシュを不変アセット向けのキャッシュへ渡さない。
