# Tutorial

Tauri から届く現在のチュートリアル指示に従い、一時マーカーとワールド操作の制限を適用する。教材の進行と API 書き込みは Tauri が担当する。

## 共通ルール

- マーカーは描画物として扱い、実ノード・コライダー・都市データへ登録しない。
- 制限は共通の入力・編集入口に適用する。案内が無効なときは通常処理へ通し、通常の建設条件を迂回しない。
- 古い実行 ID・revision を適用せず、終了済みの実行を再開しない。都市終了・リセットでは案内と制限を解除する。
