# Vehicles

コアの交通量・所要時間・路線を使う描画専用の交通演出。一般車・公共交通・歩行者・路駐・索道・空や海の演出を扱い、経済シミュレーションや永続データへ書き戻さない。

## 共通ルール

- コアが返す流量・時間の単位を守る。所要時間に含まれる減速や停車を描画側で二重に加えない。
- 車線・軌道・接続・沿道入口はメッシュ側と共通の幾何を使う。描画物ごとに独立した横位置や接続の規則を作らない。
- 交通演出の時計は `TrafficClock` を使い、`Time.timeScale` でアプリ全体を止めない。
- 経路・入口のスナップショットは完成後に交換し、利用中の点列をインプレース変更しない。大量の構築は共通予算と共有索引を使う。
- データ更新・都市切り替え・終了時は、時計・キャッシュ・一時個体の世代と寿命を揃える。
- 走行音は Weather の共通音声管理へ通知し、車両ごとに独立した音声管理を持たせない。
