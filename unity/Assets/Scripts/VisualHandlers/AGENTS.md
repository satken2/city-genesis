# VisualHandlers

建物・パス・区画・地形などの表示、ハイライト、データ可視化を管理する。入力時の操作は InputHandlers が担当する。

## 共通ルール

- 色モード・表示フラグ・個別フィルタを区別し、共通の表示状態を参照する。編集プリセットと通常表示の記憶は IPC の表示管理を通す。
- 表示可否はステータス・レイヤー・個別フィルタを合わせた共通判定を使う。通常の個体と遠景・結合・インスタンス描画で結果を揃える。
- 材質の上塗りと元材質の記憶を区別し、差し替え・復元・終了時に整合させる。共有材質を個体の色変更で書き換えない。
- 非表示にした描画物はクリック対象としても残さない。表示専用の地形を接地や入力の基準へ流用しない。
- 大量の表示更新は共通のバッチ処理を使う。後から生成・復元された描画物にも現在の表示設定を適用する。
- 一時的な色・フィルタは明示的に解除し、セッションのリセット後へ持ち越さない。
