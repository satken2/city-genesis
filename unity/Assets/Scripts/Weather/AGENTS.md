# Weather

天気・時刻・気候に応じた空・光・霧・降水と、環境音・工事音・走行音を扱う。Unity の環境表現だけを担当し、経済・マスター・セーブへ書き込まない。

## 共通ルール

- 実際のエポック更新と編集による再ロードを区別し、再取得だけで時間や天気を進めない。
- 抽選は専用の乱数源を使い、他の描画処理の乱数状態へ影響させない。
- 所有する光・環境設定・音源だけを変更する。無効化時は元の設定を戻し、破棄時は所有資源を解放する。
- 音量は共通の設定通知に従い、`AudioListener.volume` を変更しない。都市の描画物の寿命と音源の寿命を混同しない。
- 表現の値と状態は Unity、翻訳・表示は Tauri が担当する。双方の通知契約を揃える。
