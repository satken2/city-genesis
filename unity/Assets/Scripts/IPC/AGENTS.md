# IPC

Tauri と Unity の MMF 通信、イベントの配送、編集ステートと表示状態の同期を担当する。コアとの HTTP は別系統の API が担当する。

## 共通ルール

- Envelope・MMF 容量・イベント名・ペイロードは Tauri 側と同一に保ち、変更時は双方と公開契約を揃える。
- UIからのコマンドと Unity からの状態通知を区別する。受信値をそのまま送り返すループや、相手が不在でも溜まり続ける周期送信を作らない。
- Unity API に触る受信処理はメインスレッドへ配送する。購読開始前に届く初期通知の扱いも揃える。
- 入力ステートと表示の記憶は共通の coordinator を通す。プリセット適用と通常表示への復帰で別の状態の正を持たない。
- 確定後の再取得・状態復帰は共通の終了イベントへまとめる。取消しは対象のモードだけを終了し、併存する別の操作を巻き込まない。
- 要求への完了通知は失敗時も返す。互換性・接続の共通ゲートを迂回してゲーム用操作を受け付けない。
