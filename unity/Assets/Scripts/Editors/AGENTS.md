# Editors

3D上の建設・編集における形状、選択、プレビュー、UIへの通知、終了時の状態を管理する。マウス入力は InputHandlers から受け取る。

## 共通ルール

- パネルで確定する操作は Tauri がコアへ送信し、3Dジェスチャだけで完結する操作は既存契約に従って Unity が送信する。同じ操作を両側から確定しない。
- ローカルの幾何・干渉判定は表示用の推定と確定的な制約を区別する。確定可否の正はコアで、独自の拒否条件を増やさない。
- ポリゴン編集・Ctrlメニュー・配置入力・座標計算は共通部品を使う。プレビューと確定済み描画で別の形状規則を持たない。
- 状態の正を持つ側は IPC 契約に従う。受信値をエコーせず、非同期応答は現在の要求に対応するものだけ適用する。
- 終了・取消し・別モードへの遷移では、一時描画・選択・登録を片付ける。別のウィンドウのモードまで無条件に終了しない。
- チュートリアル制約は共通の案内基盤を通し、各編集入口で一貫させる。教材 ID による個別分岐を持たない。
